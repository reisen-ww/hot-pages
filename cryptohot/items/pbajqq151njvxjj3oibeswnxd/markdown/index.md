# Bitcoin Core披露中危漏洞，修复版本包含29.2和30.0

> 原标题：Bitcoin Core披露可停滞区块处理的中危漏洞，修复已包含在29.2和30.0版本中

- 来源：PANews
- 发布时间：2026-11-11T01:41:40.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/pbajqq151njvxjj3oibeswnxd
- 原文：https://www.panewslab.com/zh/articles/01a1c844-94b0-76a9-ba01-97ec27a14d12

## 摘要

Eugene Siegel发现Bitcoin Core中危漏洞，可能导致节点区块处理停滞，修复已包含在29.2和30.0版本中。漏洞机制为恶意节点篡改紧凑区块见证数据，若攻击者控制受害者3个高带宽对等节点或运行-blockonly模式，可无限重复攻击。受影响版本为29.2及之前，30.0版本已修复。

## 推荐理由

原文提供了漏洞触发条件（需控制3个高带宽节点或运行-blockonly模式）和修复版本号，读者可据此判断是否需要升级节点软件。
