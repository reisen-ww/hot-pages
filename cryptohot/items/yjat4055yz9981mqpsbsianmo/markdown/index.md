# 九芝堂并购吉象隆致单季净利激增588%仍陷FDA监管风险

> 原标题：单季净利增速达588%，百年九芝堂靠“多肽”换挡

- 发布时间：2026-11-19T02:03:13.000Z

## 摘要

九芝堂2026年前三季度归母净利润同比增100.33%，单季增速达588.01%。并购吉象隆51.67%股权推动利润增长，但FDA认定其原料药‘掺假’并列入扣留名单，致多肽业务出口受阻。OTC板块收入同比增11.49%，处方药收入降12.29%，创新药管线YB209/YB211处于临床阶段。
