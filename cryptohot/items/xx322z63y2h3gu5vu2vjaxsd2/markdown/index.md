# 俄罗斯总理：与友好国家贸易占比达85%

## 摘要

俄罗斯总理米舒斯京在‘俄罗斯制造’国际出口论坛上表示，与友好国家的贸易占俄对外贸易总额的85%，今年前八个月贸易额增长17%，达35万亿卢布（约合4218亿美元）。
