# Viatris完成对Pacira的并购

> 原标题：Viatris completes Pacira acquisition

- 来源：Crypto Briefing
- 发布时间：2026-11-17T14:12:48.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/y0sy7sdvkgyg9b9dlixs4dcx8

## 摘要

Viatris完成对Pacira的现金收购，支付每股36.50美元，获得约66.46%股份，预计2026年底贡献9000万至1亿美元收入，Pacira将从纳斯达克退市。

## 推荐理由

并购完成使Viatris获得Pacira的非阿片类疼痛管理业务，并预计在2026年底贡献9000万至1亿美元收入。
