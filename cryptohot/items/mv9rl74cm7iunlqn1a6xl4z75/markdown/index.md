# 卫星化学连云港扩建C3产业链：两期投资207亿元

> 原标题：卫星化学再投207亿元，连云港补上C3产业链

## 摘要

卫星化学宣布在连云港投资207亿元扩建C3产业链，分两期实施。一期投资120亿元，建设100万吨/年丙烷脱氢、30万吨/年丙烯酸、30万吨/年丙烯酸丁酯和80万吨/年多碳醇装置，预计建设周期不超过三年。

## 推荐理由

原文提供了项目分两期实施、一期投资120亿元、丙烷脱氢产能100万吨/年、多碳醇产能80万吨/年等具体数据，读者可据此评估卫星化学产能扩张对C3产业链供需的影响。
