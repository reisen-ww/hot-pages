# 美国10月零售数据降温：汽车及家具销售环比下滑

## 摘要

美国商务部人口普查局公布10月零售数据：整体环比增长0.2%，汽车及家具销售下滑拖累增长，非店铺零售环比增1.2%。剔除汽车后零售环比增0.5%，建材销售回升至增0.5%。亚马逊、塔吉特、沃尔玛促销活动或推动杂项零售环比大增4.7%。
