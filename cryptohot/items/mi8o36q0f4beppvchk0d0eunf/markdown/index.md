# Hormel Foods 签署 1 亿美元定期贷款完成 Brakebush 收购

## 摘要

Hormel Foods于2026年11月13日签署1亿美元定期贷款，其中7000万美元用于支付Brakebush收购价及相关费用，剩余3000万美元用于再融资包括2027年3月30日到期的4.800%高级票据。收购已于11月16日完成。
