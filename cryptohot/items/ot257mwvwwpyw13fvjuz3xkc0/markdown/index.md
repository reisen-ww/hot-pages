# 西西弗书店与咖啡区分设消费规则

> 原标题：西西弗仅购书不能入座咖啡区，主管：所有门店都如此，书店与咖啡店打通但营收分开

## 摘要

西西弗书店与咖啡区分设消费规则，购书后需额外付费才能进入咖啡区。门店主管表示所有门店均执行此政策，书店与咖啡店空间打通但营收独立核算，引发消费者对‘一体空间两套规则’的争议。
