# 美国联合航空禁止第三方AI代理完成机票预订

> 原标题：United Airlines lets AI agents browse flights but blocks them from booking

## 摘要

美国联合航空允许第三方AI代理展示航班信息但禁止其完成预订。该政策与航空公司现有自动化设备使用条款一致，旨在防止库存被恶意操控和欺诈风险。目前Delta航空、摩根大通等企业也采取类似限制。对用户而言，AI仍可作为比价工具，但最终预订需人工操作；航空公司则通过直接控制预订流程保留客户数据与销售机会。
