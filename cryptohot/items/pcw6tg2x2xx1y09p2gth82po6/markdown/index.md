# 多家百亿量化私募指增产品近半年回撤超50%

> 原标题：多家百亿量化私募的指增不行了，有产品近六月最大回撤超50%

## 摘要

多家百亿量化私募旗下指增产品近六个月最大回撤超50%，包括稳博投资（回撤50.05%）、超量子私募（回撤47.31%后修复至45%收益）及进化论资产（回撤32.83%）。业内人士指出因子拥挤、流动性压力及杠杆使用加剧回撤，需精准拆解诱因制定应对策略。

## 推荐理由

原文列出了13只近六个月最大回撤超50%的量化产品，并分析因子拥挤、流动性压力等导致回撤的核心诱因。
