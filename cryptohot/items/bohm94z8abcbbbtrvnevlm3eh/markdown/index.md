# 截至10月底江苏月度词元调用量超450万亿

- 发布时间：2026-11-19T12:17:25.000Z

## 摘要

截至10月底，江苏全省月度词元调用量突破450万亿，环比增长30.39%。当前全省算力总规模达279.27EFlops，智能算力占比74.75%。全省已有61个词元相关项目覆盖13个设区市。
