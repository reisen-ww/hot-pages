# 爱回收经营利润增五成，自营业务成增长主力

## 摘要

爱回收三季度营收64.53亿元，同比增长25.3%，经调整经营利润同比增长50.7%至2.11亿元。自营业务收入增长27%，成为主要增长来源，履约费用率下降至7.9%。
