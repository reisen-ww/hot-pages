# 香港立法会通过加密资产申报框架条例草案，2028年起自动交换税务资料

## 摘要

香港立法会通过《2026年税务（修订）条例草案》，落实OECD加密资产申报框架（CARF）及修订共同申报准则（CRS）。CARF将于2027年实施，要求服务提供者收集加密资产信息；CRS将于2028年生效，税务局自2029年起自动交换金融账户信息。税务局表示将发布指引并设立专责团队提供技术支持。
