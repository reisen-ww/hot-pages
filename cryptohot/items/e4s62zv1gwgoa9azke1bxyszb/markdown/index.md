# 信用债两周跌去半年收益，投资者应如何应对？

## 摘要

近期信用债市场出现大幅回撤，两周内跌去过去半年的收益。主要原因包括离岸人民币点心债违约风险、固收+基金和理财资金赎回压力，以及政府债利息免税政策调整。投资者应关注债券是否违约、利差及久期，选择优质高票息资产，并注意净值波动源于价格折价而非违约风险。
