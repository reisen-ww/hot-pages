# 英伟达股价跌至52周低位

- 发布时间：2026-11-12T04:38:00.000Z

## 摘要

英伟达股价在一个月前达到峰值后，本周进一步下跌，逼近52周低位。目前，英伟达成为标普500第二大市值股票，仅次于苹果，微软市值比英伟达仅低约1100亿美元。苹果再次成为标普500中市值最大的股票，并接近52周高位。
