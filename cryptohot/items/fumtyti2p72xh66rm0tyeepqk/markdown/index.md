# 中国证监会优化上市公司回购规则并推进主动ETF产品

## 摘要

中国证监会宣布优化上市公司护盘式回购规则（新增股价破发情形、取消六个月上市限制等），推进主动ETF产品（首批18只募集超350亿元），并调整融资融券保证金比例以稳定资本市场。截至2026年10月，上市公司回购金额创历史新高，达1345亿元；主动ETF募集规模突破单只上限，显示市场对政策工具的积极运用。
