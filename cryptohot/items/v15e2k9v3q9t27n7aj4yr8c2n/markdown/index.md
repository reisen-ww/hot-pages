# Bitwise申请在德州证券交易所上市Zcash现货ETF

- 来源：PANews
- 发布时间：2026-11-18T11:03:53.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/v15e2k9v3q9t27n7aj4yr8c2n

## 摘要

Bitwise向美国SEC提交S-1注册声明，拟在德州证券交易所（TXSE）上市Zcash现货ETF（代码ZEC），由Coinbase Custody托管，Bitwise Investment Advisers管理。此前草案曾计划在NYSE Arca上市，目前该ETF尚未开始交易，注册声明及管理费尚未生效。

## 推荐理由
