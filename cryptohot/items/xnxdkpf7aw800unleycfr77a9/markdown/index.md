# 蚂蚁国际区块链平台Whale处理超1.1万亿美元跨境资金

> 原标题：从跨境结算到智能体支付，蚂蚁国际加码支付基础设施

## 摘要

蚂蚁国际CEO杨鹏在新加坡金融科技节表示，其自研区块链平台Whale已处理超过1.1万亿美元跨境资金，并与23家银行合作。平台支持通证化存款结算，从支付指令到收款最快5分钟完成。此外，蚂蚁国际通过AMP协议连接10家电子钱包和7家收单机构，并与Visa、万事达卡推动智能体身份互认（KYA框架），目前账户到钱包转账最快1.5秒。

## 推荐理由

原文提供了Whale平台过去12个月处理1.1万亿美元资金、覆盖23家银行的数据，以及未来全年预测达2万亿美元，读者可据此评估其跨境支付基础设施的规模与增长潜力。
