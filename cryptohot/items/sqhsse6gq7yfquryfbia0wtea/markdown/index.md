# 中国大额采购法国及阿根廷小麦应对全球价格暴跌

## 摘要

中国通过Cofco进口至少12万吨法国小麦，创2024年以来最大单周进口量。全球小麦价格因供应过剩和需求疲软持续下跌，中国通过扩大进口量平抑国内市场波动。海关数据显示进口量同比激增300%，阿根廷同期出口量也显著上升。

## 推荐理由

读者可据此了解中国在大宗商品价格波动下的采购策略调整
