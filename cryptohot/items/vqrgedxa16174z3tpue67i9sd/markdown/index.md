# 国元证券联合设立10亿私募股权基金布局硬科技领域

## 摘要

国元证券宣布与多家机构共同设立10亿元私募股权基金，聚焦硬科技领域，包括量子科技、具身智能等。此前，国元证券通过间接投资长鑫科技获得丰厚回报，正加快私募股权布局。短短半个月内，多家券商已设立规模达260亿元的私募股权基金，显示出券商对硬科技领域的投资热情。
