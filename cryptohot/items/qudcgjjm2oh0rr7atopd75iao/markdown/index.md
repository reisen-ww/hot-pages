# 长鑫科技四季度DRAM供给紧缺格局延续

## 摘要

长鑫科技在业绩会上宣布2026年四季度DRAM产品供给将持续紧缺，毛利率有望保持稳定。主要支撑因素包括：1）供需格局延续紧缺，通过精益生产与成本管控维持利润；2）产品结构升级，高附加值新产品占比提升。
