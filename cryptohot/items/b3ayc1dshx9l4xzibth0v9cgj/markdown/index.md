# 多家券商完成第三批互换便利首批买入

## 摘要

截至11月16日已有中信证券、国泰海通等10家券商完成第三批互换便利业务首批买入（操作规模达千亿元级）。互换便利直击非银机构流动性痛点，提升融资能力，推动增量资金入市稳定市场预期。

## 推荐理由

互换便利直达投资端，推动增量资金入市，稳定市场预期，提振投资者信心。
