# Anthropic拟以1.4万亿美元估值启动IPO，基石投资者包括谷歌和英伟达

## 摘要

Anthropic宣布以最高1.4万亿美元估值启动IPO，计划发行8.25亿股A类股，价格区间70-78美元。基石投资者包括谷歌（10亿美元）、英伟达（10亿美元）、AMD、博通、美光、微软和台积电，同步进行26亿美元的非投票N类股私募。

## 推荐理由

原文提供了Anthropic IPO估值从1.5万亿降至1.4万亿的对比，以及Google、Nvidia等基石投资者参与的具体金额。
