# 二手房价格连续8个月上涨，一线城市率先企稳

## 摘要

国家统计局数据显示，2026年10月一线城市二手房价格环比上涨0.2%，连续8个月上涨。二线城市同比降幅收窄但环比仍降0.3%，政策贴息首周咨询热度提升12.3%。专家分析称交易量增长、挂牌量减少及需求转移支撑价格修复，但全国市场仍处结构性分化阶段。
