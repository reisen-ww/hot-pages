# 以太坊Glamsterdam升级可能影响15,000个智能合约

> 原标题：Ethereum’s Glamsterdam upgrade could disrupt 15,000 smart contracts

- 来源：Crypto Briefing
- 发布时间：2026-11-17T19:30:38.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/xjtwn0zcvjy5zz7svk8rnmn6n

## 摘要

以太坊Glamsterdam升级因Gas费调整可能导致15,000个智能合约失效（占链上合约总量约1.7%），涉及EIP-8037和EIP-8038提案。开发者计划在11月19日核心会议前收集项目反馈，并探索缓解方案。该升级原定包含提案者-构建者分离和块级访问列表功能，但兼容性问题可能推迟后续测试网激活。
