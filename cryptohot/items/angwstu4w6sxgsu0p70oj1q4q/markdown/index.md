# 荷兰芯片设备出口限制引发中欧贸易摩擦，中国外交官屈迅呼吁自主决策

## 摘要

荷兰自2019年起限制向中国出口ASML先进芯片制造设备，导致中欧产业政策谈判出现摩擦。中国驻马德里外交官屈迅表示，中国希望进口ASML设备但现有技术已落后数代，若欧洲继续限制出口，中国可能采取对等限制措施。屈迅呼吁欧盟在中欧贸易谈判中自主决策，不要跟随其他方面指示。中欧贸易谈判预计2024年恢复，双方此前在10月达成中国混合动力汽车出口配额协议，称该协议具有积极意义。
