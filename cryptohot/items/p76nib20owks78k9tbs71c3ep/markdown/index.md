# 美银：DRAM环比涨8%而NAND现货周跌12% 开启存储芯片分化周期

> 原标题：存储正在分化，美银：DRAM依然坚挺，NAND已悄然走弱

- 发布时间：2026-11-15T08:33:47.000Z

## 摘要

美银报告显示DRAM环比上涨8%而NAND现货价格周跌12%（512Gb晶圆周环比跌12%至14.3美元），存储芯片市场进入分化周期。NAND现货累计回调20%，主要受PC/手机订单疲软及2027Q1合约价谈判可能推迟影响，但厂商通过促销维持eSSD价格微涨。

## 推荐理由

原文对比了DRAM和NAND的供需变化及价格趋势，指出美银对2027年NAND合约价下滑的预测与市场主流预期存在分歧，为投资者判断存储板块估值提供参考依据。
