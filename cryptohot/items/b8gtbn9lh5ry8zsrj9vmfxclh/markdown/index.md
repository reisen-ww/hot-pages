# Diraq 在商业数据中心启用硅基量子计算机

> 原标题：Diraq switches on a silicon quantum computer inside a commercial data center

## 摘要

澳大利亚初创公司Diraq在Equinix悉尼数据中心部署了首台硅自旋量子计算机，计划一年内升级至256量子位。该系统占用约170平方英尺空间，功耗低于20千瓦，采用与经典服务器和GPU共存的混合架构，旨在测试实际环境中的量子-经典混合工作流。公司还获得DARPA第三阶段资格及38亿美元CHIPS法案意向金支持。
