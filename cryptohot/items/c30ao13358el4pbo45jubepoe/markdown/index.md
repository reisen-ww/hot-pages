# 先声药业创新药首次纳入国家医保目录

## 摘要

2026版国家医保目录11月14日公布，先声药业脑卒中创新药依达拉奉右莰醇舌下片首次被纳入。该药物此前已完成第三次医保续约，价格降幅达12%。
