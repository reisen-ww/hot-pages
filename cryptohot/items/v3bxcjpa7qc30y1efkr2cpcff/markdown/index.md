# 通用汽车将普通股上市地从纽交所迁至纳斯达克

- 来源：界面新闻
- 发布时间：2026-10-27T10:36:00.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/v3bxcjpa7qc30y1efkr2cpcff
- 原文：https://www.jiemian.com/article/15248747.html

## 摘要

通用汽车宣布将其普通股上市地从纽交所迁至纳斯达克全球精选市场，继续沿用‘GM’股票代码，纳斯达克交易预计将于11月17日开始。

## 推荐理由

通用汽车变更上市地，可能影响其股票流动性与投资者分布。
