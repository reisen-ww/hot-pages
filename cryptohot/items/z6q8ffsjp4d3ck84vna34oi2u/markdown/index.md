# 因未获欧盟MiCA监管许可，币安将于12月31日关闭法国用户账户

- 来源：PANews
- 发布时间：2026-11-07T00:39:47.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/z6q8ffsjp4d3ck84vna34oi2u
- 原文：https://www.panewslab.com/zh/articles/01a1b372-7e05-73d9-9bd9-ff01bb7288bc

## 摘要

币安因未获欧盟MiCA监管许可宣布关闭法国用户账户，截止日期为2026年12月31日。存款功能已停，11月29日后持有资产需每月支付0.025%管理费（最低10 USDC），提现前可免费用。未提现资产可能被转换、转移或以其他方式处理。

读者可关注欧盟MiCA监管框架对跨境业务的影响及资产处理细则
