# 2026上半年加密钱包收入暴跌60%，1kx报告揭示行业趋势

> 原标题：Crypto wallet revenues drop 60% in H1 2026, 1kx report finds

- 来源：Crypto Briefing
- 发布时间：2026-11-02T22:45:34.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/stkeu4l4nozksr8ys0jrg1sp4
- 原文：https://cryptobriefing.com/crypto-wallet-revenues-drop-60-h1-2026/

## 摘要

2026上半年加密钱包收入暴跌60%，主因市场行情疲软与交易量减少。报告显示赌博游戏类应用收入反增8%，成为消费端主要增长点；同时指出整体区块链行业收入同比减少28%，与比特币价格下跌趋势一致。

## 推荐理由

原文对比了加密钱包收入下降60%与赌博游戏收入上升8%的现象，揭示市场行情对应用层收入的影响差异。
