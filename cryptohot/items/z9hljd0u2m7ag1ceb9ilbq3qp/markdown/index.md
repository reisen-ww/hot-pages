# 舟山船供油企业收缩远期采购应对价格波动与船期不确定性

> 原标题：绕远的好望角航线 改变了舟山的加油生意

## 摘要

舟山船供油企业为应对燃料油价格波动和船期不确定性，调整采购策略，将远期锁货比例从去年同期的近四成降至一成出头，库存周转天数缩短至14-18天。企业案例显示，绕行好望角航线导致单次加油量增加但频次不稳定，迫使供油商采用现货敞口与期货头寸同步管理的新模式。
