# H100集团股东大会将投票决定动用比特币回购最多10%股份

## 摘要

H100集团将于12月7日召开股东大会投票决定是否动用比特币回购最多10%股份。公司第三季度净利润达1.479亿克朗（约1450万美元），持有233.4 BTC交易池及3243.4 BTC长期储备，交易池在三季度亏损30 BTC。
