# MSCI将策略公司（Strategy）移出全球标准指数

> 原标题：MSCI将把Strategy移出旗下全球标准指数，11月30日收盘后生效

## 摘要

MSCI宣布将策略公司（Strategy）移出全球标准指数系列，调整生效时间为11月30日收盘后。此前MSCI已发布新规则：资产以非经营性资产为主且五项财务指标中至少四项触发标准的公司将被移出。被移出后跟踪相关指数的基金需卖出Strategy股票，但Strategy本身无需出售其持有的比特币。
