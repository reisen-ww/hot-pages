# Lido关闭Golden Goose Vault，指引持有者迁移至EarnETH元 Vault

> 原标题：Lido sunsets GGV vault, directs holders to EarnETH migration

- 来源：Crypto Briefing
- 发布时间：2026-11-13T16:19:44.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/q68z1yyi5vakin1j2uzx5tj3g
- 原文：https://cryptobriefing.com/lido-sunsets-ggv-vault-earneth-migration/

## 摘要

Lido宣布关闭Golden Goose Vault（GGV），要求持有者于2026年11月17日前完成迁移至EarnETH元 Vault或提取。GGV自2025年9月上线，采用免手动策略的质押产品。

## 推荐理由

需在11月17日前完成迁移或提取，否则将失去质押收益
