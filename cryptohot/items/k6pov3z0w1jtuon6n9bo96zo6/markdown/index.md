# OpenAI收购AI旅行代理公司Odessia并聘请前Sonder联合创始人

## 摘要

OpenAI于2026年11月10日收购AI旅行代理公司Odessia，并聘请其联合创始人Francis Davidson。交易发生在Odessia夏季预览期间处理超600万美元预订后不到一个月，该平台具备IATA认证的完整旅行服务能力。需注意的是，Francis Davidson曾创立短期租赁平台Sonder，后者因收入未能持续在2025年11月进入破产清算程序。

## 推荐理由

收购带来旅行代理产品、交易许可架构及创始人经验，同时需注意Sonder因收入未能持续而进入破产清算的教训。
