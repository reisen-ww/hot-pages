# 韩国计划允许3,500家上市公司投资比特币，报告称政策或下周发布

## 摘要

韩国计划允许3,500家上市公司投资比特币，政策或下周发布。此前因市场基础设施问题（如大额交易需通过场外 desks，而韩国尚未规范OTC操作）导致2025年第二阶段企业入场计划停滞。报道提及FSC（韩国金融监管机构）拟与《数字资产基础法》草案同步发布细则，Jeonbuk Bank等机构已开始布局比特币相关金融产品。
