# Lighter交易所因API密钥漏洞导致约500万美元USDC被盗，已恢复提现并追回部分资金

> 原标题：Lighter resumes withdrawals after recovering $5 million following API key exploit

## 摘要

Lighter交易所因API密钥漏洞导致约500万美元USDC被盗，已恢复提现并追回部分资金。事件源于用户使用非官方SDK时重复使用加密非ces，攻击者通过公开签名重构私钥，利用公共池转移资产。交易所已实施钱包签名、API密钥非公开等新措施，并建议用户切换至官方SDK。

## 推荐理由

交易所通过技术措施减少API漏洞风险，并建议用户更换第三方SDK
