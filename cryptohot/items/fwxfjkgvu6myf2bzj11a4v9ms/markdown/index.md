# 华住集团CEO金辉称行业趋于理性，上调全年业绩指引

> 原标题：加盟商投资更谨慎，华住CEO金辉称“行业趋于理性”

## 摘要

华住集团三季度营收78亿元，同比增长11.3%，上调全年业绩指引至9%-10%。加盟业务收入42亿元，同比增长25.7%，但RevPAR同比下降4.4%。集团计划闭店数量略高于预期以提升存量酒店品质，同时供应链业务收入3.62亿元，同比增长119.4%。国际业务方面，欧洲市场关闭部分酒店后经调整EBITDA改善，东南亚市场持续扩张。

## 推荐理由

原文提供了华住三季度RevPAR下降4.4%但加盟业务收入同比增长25.7%的对比数据，以及闭店计划与供应链业务119.4%增长率的关联性，读者可据此分析酒店行业扩张与精细化运营的平衡策略。
