# NYSE选择Avalanche区块链作为数字证券交易平台底层技术

## 摘要

NYSE选择Avalanche区块链作为数字证券交易平台底层技术，合作项目预计2026年第四季度上线。技术优势包括定制化Layer-1架构（支持子网 subnet）和可预测成本结构，同时NYSE计划兼容多链资产。Avalanche原生代币AVAX在宣布后上涨约5%至8%。

## 推荐理由

原文指出NYSE选择Avalanche作为核心区块链，并强调其速度、可靠性和成本结构优势，这对区块链行业竞争格局有参考价值。
