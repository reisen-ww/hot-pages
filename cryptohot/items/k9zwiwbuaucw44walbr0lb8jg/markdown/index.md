# 微软CEO Satya Nadella公开支持Nvidia临时CEO Colette Kress

> 原标题：Satya Nadella backs Nvidia’s interim CEO Colette Kress after Jensen Huang’s exit

## 摘要

微软CEO Satya Nadella在纽约时报峰会上公开支持Nvidia临时CEO Colette Kress，肯定其财务背景对AI芯片供应链稳定性的关键作用。Kress自2013年起担任Nvidia首席财务官，市场在CEO更替后股价先跌后反弹，董事会计划寻找永久CEO，同时维持与微软的战略合作。
