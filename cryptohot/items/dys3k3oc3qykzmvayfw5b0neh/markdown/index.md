# 杜克能源获北卡罗来纳州批准电价上调及数据中心附加费

## 摘要

杜克能源获北卡罗来纳州监管机构批准电价上调及数据中心附加费，新规将于2027年1月1日生效。具体包括：Progress公司客户年增3.4%，Carolinas客户年增3.7%；数据中心客户需支付 upfront费用及满足安全要求；股东注资2000万美元用于客户补贴；合并后两家公司电价逐步统一，退款与升级进度挂钩。
