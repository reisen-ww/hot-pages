# OpenAI智能体自主完成研究任务比例升至46%

> 原标题：报告：OpenAI智能体已可独立完成近半数中等时长研究任务

## 摘要

OpenAI智能体对预计耗时两至四小时的研究任务自主成功率从3月的23%升至10月的46%，四至八小时任务成功率从13%升至35%。研究人员日均用量中位数10月达2400美元，较9月增62%。
