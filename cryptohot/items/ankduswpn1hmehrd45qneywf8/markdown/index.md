# Bitwise与Coinbase高管支持Chainlink CCIP分模型设计

> 原标题：Bitwise and Coinbase executives back CCIP’s split model for real-world blockchain use

- 来源：Crypto Briefing
- 发布时间：2026-11-03T19:49:48.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/ankduswpn1hmehrd45qneywf8
- 原文：https://cryptobriefing.com/bitwise-coinbase-back-ccip-split-model/

## 摘要

Bitwise与Coinbase高管支持Chainlink CCIP分模型设计，该设计通过分离消息确认与执行步骤提升机构级跨链金融安全性。Coinbase于2025年12月将价值约700亿美元的代币资产迁移至CCIP，BitGo随后在2026年初将超777亿美元WBTC迁移至CCIP。

## 推荐理由

原文指出CCIP 2.0已吸引Coinbase和BitGo等机构迁移超1500亿美元资产，并成为跨链金融的核心基础设施。
