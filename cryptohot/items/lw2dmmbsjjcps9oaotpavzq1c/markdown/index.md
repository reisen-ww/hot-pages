# 币安更新大宗商品期权结算价规则，11月23日起生效

- 来源：PANews
- 发布时间：2026-11-12T06:01:26.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/lw2dmmbsjjcps9oaotpavzq1c
- 原文：https://www.panewslab.com/zh/articles/01a1ce58-c46f-72eb-aebd-9e194cbf7137

## 摘要

币安宣布更新大宗商品期权结算价规则，11月23日起生效。新规则将结算价改为到期前0.5小时币安期货指数的算术平均值，原规则为到期日标的市场收盘价。仅合约到期时间决定适用规则，2026年11月23日及之后到期的期权均适用新规。
