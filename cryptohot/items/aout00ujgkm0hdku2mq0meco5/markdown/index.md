# 美SEC 2026财年执法行动下降23.7%，加密欺诈案件成焦点

## 摘要

美国证券交易委员会（SEC）2026财年发起348起执法行动，同比下降23.7%至1991年以来最低水平。该年度涉及加密欺诈案件，包括指控3家加密平台和4个投资俱乐部诈骗至少1400万美元，以及某比特币矿业公司创始人挪用4850万美元（此前募资超9560万美元）。
