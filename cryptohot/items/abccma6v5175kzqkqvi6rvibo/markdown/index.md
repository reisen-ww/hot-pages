# Epoch AI发布大模型自动化测试报告：六款主流模型均未达内部标准

> 原标题：Epoch AI tests six leading LLMs, and none match its own employees

## 摘要

Epoch AI于2026年10月8日发布自动化测试报告，结果显示六款主流大模型在开放任务中的表现均未达标。最高分的Claude Fable 5.1和GPT-6 Astra平均得分65%，Gemini 3.8 Flash得分42%。测试涵盖图形设计和研究设计等开放任务，未发现模型排名变化。报告指出当前模型在需要主观判断的任务上仍需人类介入。
