# AMD CEO苏姿丰称数据中心业务明年占比料达80%，强调‘世代级’增长机会

## 摘要

AMD CEO苏姿丰在TomorrowX峰会上表示，数据中心业务将成公司核心增长引擎，预计2027年收入占比超80%。2026年Q3数据中心业务收入同比增长97%达85.5亿美元。

## 推荐理由

AMD通过强调AI基础设施的长期增长机会，展示了其业务转型的关键路径和行业影响。
