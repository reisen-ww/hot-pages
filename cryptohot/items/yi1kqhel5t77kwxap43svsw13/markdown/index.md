# Polymarket 将每小时及每日加密赌注迁移至 Chainlink

## 摘要

Polymarket 新增基于 Chainlink 的每小时加密赌注合约，每日市场仍沿用 Binance 规则。新合约采用 60 秒平均价格定价，而每日市场维持原有 Binance 机制不变。

## 推荐理由

读者可对比新旧机制，评估其对加密赌注策略的影响。
