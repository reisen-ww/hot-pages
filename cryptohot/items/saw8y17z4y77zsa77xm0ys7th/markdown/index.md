# SoFi将银行发行的稳定币SoFiUSD扩展至Polygon支付堆栈

## 摘要

SoFi宣布将银行发行的稳定币SoFiUSD扩展至Polygon支付堆栈，用户可直接在SoFi应用内进行交易。该扩展使SoFiUSD接入Polygon、以太坊和Solana三大公链的支付基础设施，与Visa、Mastercard、Stripe等现有合作方形成互补。根据Polygon数据，其稳定币支付业务已处理超3万亿美元跨境交易。
