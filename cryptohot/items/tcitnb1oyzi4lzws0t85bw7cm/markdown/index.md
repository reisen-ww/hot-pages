# 青岛啤酒管理层预计明年成本总体平稳

> 原标题：包材成本上行挤压毛利，青岛啤酒管理层预计明年成本总体平稳

## 摘要

青岛啤酒第三季度业绩下滑，毛利率受包材成本上涨影响下降约1.5个百分点。管理层预计明年成本总体平稳，并将持续优化产品结构提升盈利能力。公司还通过即时零售等渠道创新，销量创历史新高。
