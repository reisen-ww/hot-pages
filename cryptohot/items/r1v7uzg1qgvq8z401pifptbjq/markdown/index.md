# 回天新材获中信银行襄阳分行1.8亿元股票回购专项贷款

## 摘要

回天新材获得中信银行襄阳分行1.8亿元股票回购专项贷款承诺函，贷款期限不超过3年，资金将用于回购股价不超过15元/股的股份（回购总额1-2亿元）。此前公司已通过董事会决议实施第四期股份回购计划，期限12个月。
