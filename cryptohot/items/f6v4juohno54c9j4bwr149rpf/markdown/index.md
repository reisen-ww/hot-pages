# Coinbase与Broadridge合作推出链上股东通信开放标准

## 摘要

Coinbase与Broadridge联合提出链上股东通信开放标准，支持在Base、以太坊等链上实现代币化股票股东投票及信息披露，下一步将推动链上代理投票功能落地。

## 推荐理由

该合作通过开放标准实现股东投票链上化，为代币化股票提供合规基础设施，可迁移至其他资产通证化场景。
