# Solana发布2027技术升级路线图：双倍计算能力与80%成本削减

> 原标题：Solana targets doubling compute capacity, cutting costs by 80% by 2027

- 来源：Crypto Briefing
- 发布时间：2026-11-19T12:54:50.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/yz5y8qspszc22l1xwzvg0orrw

## 摘要

Solana在伦敦Solana Breakpoint 2026大会上发布2027技术路线图，目标将计算能力提升至500万亿次/秒并降低80%交易成本。Alpenglow升级已实施，将最终确认时间缩短至150毫秒。SIMD-0437提案计划将存储租金降低约90%，并提升单笔交易可操作账户数至96个。

## 推荐理由

Solana通过降低交易计算成本和提升吞吐量，为开发者提供更高效的公链环境，具体措施包括SIMD-0437提案和账户数上限提升。
