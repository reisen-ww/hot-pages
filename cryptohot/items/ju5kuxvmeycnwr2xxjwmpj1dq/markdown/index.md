# 2026年1—10月份全国房地产市场基本情况

- 来源：国家统计局
- 发布时间：2026-11-16T10:00:02.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/ju5kuxvmeycnwr2xxjwmpj1dq

## 摘要

2026年1—10月份，全国房地产开发投资同比下降21.6%，其中住宅投资下降21.4%。商品房销售面积和销售额分别下降13.7%和14.3%，而二手房交易网签面积同比增长11.4%。
