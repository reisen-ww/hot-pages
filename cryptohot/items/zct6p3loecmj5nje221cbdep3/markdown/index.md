# 山姆推出20元泡面验证高端速食面市场

## 摘要

山姆推出每包20元的康师傅潮卤牛三宝牛肉面，验证高端速食面市场潜力。该产品在山姆App已下架，首月销售额破千万元。康师傅希望通过此实验提升泡面价格天花板，统一也推出类似产品。
