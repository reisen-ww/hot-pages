# 波音10月飞机交付量下降14%，但新订单创1997年以来最高纪录

> 原标题：Boeing jet deliveries drop 14% in October

## 摘要

波音10月交付49架飞机，同比下降14%，但新订单达165架（无取消），创1997年以来单月最高。其中Avolon订购140架737 MAX，占订单总量90%。波音计划2027年初将737月产量提至47架，但受供应商纠纷影响，777和767交付受阻。截至10月，波音今年交付量524架，落后欧洲对手空客（前10月交付621架）。

原文提供了波音10月交付量、订单量及具体客户数据，读者可据此对比空客交付量并分析波音产能调整计划。
