# 美国二手房销售量跌至16年最低 持续受房贷利率和通胀压制

## 摘要

美国房地产协会(NAR)周四数据显示，10月二手房合同关闭量同比减少5.5%至年化375万笔，创2009年以来最低。报告指出房贷利率上升和通胀压力是主要抑制因素，当前销售量较疫情前峰值下降约20%。
