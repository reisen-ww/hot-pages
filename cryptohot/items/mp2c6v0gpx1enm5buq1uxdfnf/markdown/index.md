# 花旗、富国银行等多家投行密集下调英伟达目标价

## 摘要

多家国际投行密集下调英伟达目标价。花旗将目标价从285美元下调至225美元，富国银行从315美元下调至300美元，贝尔德从500美元下调至200美元，部分评级降至‘与大盘持平’或‘中性’。
