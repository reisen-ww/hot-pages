# Trump与Putin达成俄罗斯柴油供应安排，引发对制裁政策冲突的质疑

## 摘要

Trump宣布俄罗斯将向全球市场供应柴油，美国财政部随后指示OFAC发布临时通用许可证，授权相关受制裁交易约六个月至4月7日。协议计划立即供应超过300,000吨柴油，11月再供应500,000吨，之后供应1 million吨及最多3 million吨，但美国政界人士和乌克兰总统Zelenskyy认为此举可能放松对俄能源制裁并削弱对莫斯科的经济压力。

## 推荐理由

报道梳理了柴油供应安排与既有对俄制裁法案的冲突，并呈现美国政界、乌克兰和市场人士的不同担忧。
