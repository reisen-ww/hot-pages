# Gemini连续第三个季度削减开支 收入同比下滑19%

## 摘要

Gemini第三季度净亏损收窄至5860万美元，但收入同比下滑19%。交易量同比降73%（环比增18%），运营成本同比降30%至1.2亿美元，但仍超收入三倍（1.2亿/4090万）。员工数从682减至397，未来成本空间有限。投资者需关注交易量环比增长持续性、收入稳定性及成本优化极限。
