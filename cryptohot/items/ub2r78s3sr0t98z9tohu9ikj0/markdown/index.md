## 摘要

Invesco 多元化股息基金在第三季度表现不佳，主要由于严格遵守分红、估值和质量要求，以及在科技股选择上的失误。尽管基金整体回报为正，但仍落后于 Russell 1000 Value Index，后者回报率为 2.61%。基金在 IT 股上仓位不足，该板块是季度表现最佳的指数板块。
