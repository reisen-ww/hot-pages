# 碧桂园：新增逾期有息债务约人民币3.74亿元

- 来源：界面新闻
- 发布时间：2026-11-17T15:40:55.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/g703n5tvxcojfvdbn57rh5u98

## 摘要

2026年11月12日，碧桂园控股有限公司公告显示新增逾期的有息债务约3.74亿元人民币，涉及8宗标的金额5000万元以上的未决诉讼及仲裁案件。公司表示将积极沟通解决债务问题。
