# 英伟达创始人黄仁勋离职致股价单周暴跌14%市值蒸发超6200亿美元

> 原标题：英伟达创18个月最差单周表现，黄仁勋离职引发市场重估

## 摘要

英伟达创始人黄仁勋因婚外情丑闻被董事会解职，导致股价单周暴跌14%市值蒸发超6200亿美元。至少13名分析师下调评级至'持有'，市场聚焦11月17日财报中营收指引与管理层过渡稳定性。

## 推荐理由
