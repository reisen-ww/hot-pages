# 腾讯音乐娱乐集团2026Q3财报：总收入89.4亿元，调整后净利润25.3亿元

## 摘要

腾讯音乐娱乐集团第三季度总收入为89.4亿元，同比增长5.6%；调整后净利润为25.3亿元，同比增长2.1%。音乐相关服务收入增长显著，会员服务收入达49.9亿元，同比增长9.2%。
