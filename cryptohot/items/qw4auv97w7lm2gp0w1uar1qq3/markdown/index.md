# 古驰法国官网Padlock系列手袋降价约7700元人民币

> 原标题：古驰在法国降价了，Padlock经典手袋下调约7700元

- 发布时间：2026-11-17T13:41:05.000Z

## 摘要

古驰法国官网Padlock水晶手袋降价至2450欧元（约1.8万元人民币），降幅30%，国内售价仍为1.9万元。开云集团回应称降价属清理策略，但财报显示其第三季度营收12.91亿欧元同比下降4%，连续13个季度下滑，亚太区跌幅达14%。行业报告指出2026年全球奢侈品增速仅2%-4%，呈现K型分化。
