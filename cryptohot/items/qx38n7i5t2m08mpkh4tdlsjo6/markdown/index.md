# 辽宁发布储能容量补偿标准：370元/千瓦·年覆盖电网侧电站

> 原标题：辽宁370元容量补偿落地，搁置储能项目"苏醒"

## 摘要

辽宁省发展和改革委员会、工业和信息化厅发布《关于建立发电侧可靠容量补偿机制的通知》，明确2027年1月起试行370元/千瓦·年补偿标准，覆盖电网侧独立新型储能电站。政策将容量补偿纳入项目收益测算，但需分摊充电时承担的费用。原文测算显示补偿收入占项目毛收益四成，可提升IRR至6%-7%，但实际收益受年度清算扣减和分摊成本影响。

## 推荐理由

辽宁储能政策补偿标准提升，但需考虑分摊成本对收益的影响
