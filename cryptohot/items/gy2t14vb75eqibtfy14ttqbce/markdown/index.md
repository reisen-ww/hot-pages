# 海光信息完成2.35亿元股份回购，剩余4.65亿至6.65亿元待购

## 摘要

海光信息于2026年11月19日通过回购股份，使用2.35亿元购买137.67万股（占总股本0.06%），回购价格区间162.69元至174.99元/股。根据此前方案，公司拟在2027年11月3日前完成总额不低于5亿元且不超过8亿元的回购，剩余可回购金额4.65亿至6.65亿元。
