# Securitize完成对River One的收购，业务拓展至6万亿美元资产支持融资市场

- 发布时间：2026-11-17T14:45:53.000Z

## 摘要

代币化资产平台Securitize完成对River One的收购，业务覆盖扩展至6万亿美元资产支持融资市场（KKR预测2029年达9.2万亿美元）。River One成立于2025年，专注小企业贷款及应收账款仓储融资，技术整合AI信贷评估、链上基础设施和代币化分销方案。

## 推荐理由

收购后市场覆盖扩大至6万亿美元，并探索稳定币与实体信贷的连接路径
