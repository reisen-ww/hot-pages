# Avalanche上线由Tether支持的稳定币USA₮

> 原标题：由Tether支持的稳定币USA₮已上线Avalanche

## 摘要

Avalanche宣布上线由Tether支持的稳定币USA₮，该币种将为Aave在Avalanche上构建的新RWA Hub提供美元流动性。该Hub允许机构在不出售持仓的情况下，以代币化资产为抵押借入USA₮，实现资产的高效运用。

## 推荐理由
