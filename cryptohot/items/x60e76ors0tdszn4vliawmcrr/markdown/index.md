# 比特币矿工2026年交易手续费创2011年以来最低

> 原标题：Bitcoin miners collect lowest yearly transaction fees since 2011

- 来源：Crypto Briefing
- 发布时间：2026-11-18T14:44:07.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/x60e76ors0tdszn4vliawmcrr
- 原文：https://cryptobriefing.com/bitcoin-miners-lowest-transaction-fees-since-2011/

## 摘要

2026年比特币矿工交易手续费收入创2011年以来最低，仅912 BTC，较2025年的1,720 BTC下降46.3%。手续费占矿工总收入比例降至0.63%，创2015年以来新低；同期网络日交易量达578,012笔，创历史新高。
