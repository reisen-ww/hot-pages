# Fractile完成7.2亿美元C轮融资，投后估值70亿美元

- 发布时间：2026-11-11T20:05:29.000Z

## 摘要

英国AI芯片初创公司Fractile完成7.2亿美元C轮融资，投后估值达70亿美元。本轮由Thrive Capital、Founders Fund、Lightspeed和Redpoint领投，谷歌旗下CapitalG、贝莱德等参投。该公司今年5月完成2.2亿美元B轮融资，计划明年推出首款商用AI推理芯片。
