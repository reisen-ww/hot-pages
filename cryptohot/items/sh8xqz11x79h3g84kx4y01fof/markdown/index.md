# Wormhole将于2026年12月2日终止对Linea、Moca和Plume的支持

> 原标题：Wormhole to end support for Linea, Moca, and Plume on December 2, 2026

- 来源：Crypto Briefing
- 发布时间：2026-11-18T08:21:26.000Z

## 摘要

Wormhole将于2026年12月2日终止对Linea、Moca和Plume的支持，用户需在四周内将桥资产返回原链，否则可能无法转移。分两阶段执行：先从Portal桥接界面移除相关链，再切断Guardians维护的全节点。Plume仅上线8个月，Moca整合时间不足一年。协议通过移除低活跃度链维持可持续性。

## 推荐理由

用户需在12月2日前将桥资产返回原链，否则可能无法转移，影响资产流动性
