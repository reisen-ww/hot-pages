# Payward更换核心财务指标并报告第三季度平台利润达4.87亿美元

## 摘要

Payward宣布将核心财务指标从调整后收入改为平台利润（TPM），并披露第三季度TPM为4.87亿美元，同比增长12%，但较2025年同期下降15%。调整后收入为4.98亿美元，较最初报告的5.08亿美元有所修正。
