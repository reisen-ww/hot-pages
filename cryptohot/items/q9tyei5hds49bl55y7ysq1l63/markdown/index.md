# 海正药业与圣兆、炫景生物达成合作，布局小核酸及复杂制剂研发

## 摘要

海正药业与圣兆药物达成2亿元参股协议，并首付款1亿元引进炫景生物小核酸技术平台使用权，聚焦心血管、代谢及呼吸疾病领域研发。合作包含3.48亿元研发里程碑付款及海外分许可益分成，海正保留现有制造设施用于新业务，同时计划配置专用设备支持小核酸药物生产。
