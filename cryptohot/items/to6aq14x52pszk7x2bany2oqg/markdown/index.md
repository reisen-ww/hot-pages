# 欧盟月活用户达1.86亿的ChatGPT搜索功能触发AI监管新规

> 原标题：ChatGPT search reaches 185.6 million average monthly users in the EU

## 摘要

欧盟月活用户达1.86亿的ChatGPT搜索功能触发AI监管新规，需在2027年1月前完成系统性风险评估和透明度措施。用户数从2024年底的1120万激增至2026年9月的4510万，连续6个月超过45万监管阈值。

## 推荐理由

ChatGPT搜索用户数连续6个月超过欧盟45万监管阈值，触发首次AI聊天机器人VLOSE分类，合规义务将于2027年1月生效。
