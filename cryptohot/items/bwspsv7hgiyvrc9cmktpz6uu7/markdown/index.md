# 国家医保局调整2026年商业健康保险创新药品目录

> 原标题：新增12种药品，2026年商业健康保险创新药品目录共有28种

## 摘要

国家医保局新增12种药品至2026年商业健康保险创新药品目录，目录总数达28种，包括全球首个实体瘤CAR-T和中国首个血友病基因治疗药物。同时，建立了商保创新药目录与基本医保目录的衔接机制。
