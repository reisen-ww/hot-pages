# 腾讯第三季度营收同比增长8%至2073亿元

- 来源：PANews
- 发布时间：2026-11-18T08:48:12.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/xs4w261ayvu9qttj3zvc32zhr
- 原文：https://www.panewslab.com/zh/articles/01a1edd7-8d0e-730a-842d-4dba03a75c5d

## 摘要

腾讯控股第三季度实现收入2073.36亿元，同比增长8%；经营盈利591.47亿元，同比下降7%；非国际财务报告准则下权益持有人应占盈利665.19亿元，同比下降6%。
