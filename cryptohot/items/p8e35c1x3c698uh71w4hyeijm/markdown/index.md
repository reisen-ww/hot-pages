# 长安汽车挂牌转让阿维塔10%股权

## 摘要

长安汽车在上海联合产权交易所挂牌转让所持阿维塔科技10%股权，底价31.828亿元，信息披露期至12月10日。若交易完成，长安持股比例降至30.99%仍为第一大股东。阿维塔计划将港股募资用于技术研发、国内渠道运营和海外销售网络建设，2025年境外收入占比5.5%。当前交易可能影响其上市进程及股东结构变化。

## 推荐理由

阿维塔赴港上市进程中的股权变动，影响其未来资金用途和股东结构，需关注交易进展对融资计划的影响。
