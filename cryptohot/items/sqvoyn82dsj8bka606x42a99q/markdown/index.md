# 长江存储持续推进科创板上市最早或定于2027年一季度

## 摘要

长江存储持续推进科创板上市，最早或定于2027年一季度。彭博社11月11日报导知情人士称目标为2027年Q1，而路透社11月4日引述备忘录及知情人士称可能推迟至上半年，具体取决于市场状况。公司已进入上市审核下一阶段，拟募资330亿元人民币。
