# 对冲基金CEO分享7条卖出股票的理由及“黄金法则”

## 摘要

对冲基金CEO Karen Finerman 提出，当股票的原始投资逻辑不再成立、存在监管风险、管理层失去可信度、股票占比过大、估值过高或急需资金时，应考虑卖出。她强调，卖出决策应基于逻辑而非情绪，避免因短期波动而频繁交易。
