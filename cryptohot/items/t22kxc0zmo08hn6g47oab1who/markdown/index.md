# 黄仁勋被解职传闻导致 NVIDIA 股价下跌 8%

## 摘要

NVIDIA 股价周四下跌 7.2%，因董事会讨论是否解雇黄仁勋 CEO 职位。黄仁勋承认与两名下属有婚外情，多位分析师认为这可能导致股价进一步下跌 20%。U.S. 政府官员怀疑黄仁勋是为中国情报机构工作的间谍，加剧了股价压力。
