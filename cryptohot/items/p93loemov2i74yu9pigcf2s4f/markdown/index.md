# 高盛、花旗等21家银行联合投资2700万美元启动稳定币项目

## 摘要

高盛、花旗等21家银行宣布联合投资2700万美元启动稳定币项目，首期资金将用于支付发行方前五年运营成本。项目计划2027年上半年推出，合规遵循美国GENIUS法案和欧盟MiCA监管框架。其他参与者包括美国银行、富国银行、富达投资等。目前尚未公布具体区块链技术方案及股权结构细节。
