# 2026年10月份能源生产情况

- 发布时间：2026-11-16T10:00:00.000Z

## 摘要

10月份，规上工业原煤产量同比下降5.8%，降幅比上月收窄；原油产量同比增长2.3%，增速加快；天然气产量由降转增，同比增长0.8%；电力生产有所下降，发电量同比下降2.1%。
