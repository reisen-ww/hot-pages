# 币安建议iPhone用户删除非官方应用防范iOS漏洞

> 原标题：Binance Tells iPhone Users to Delete Sideloaded Apps Over iOS Exploit

- 发布时间：2026-11-10T15:17:57.000Z

## 摘要

币安建议iPhone用户删除非官方应用并升级至iOS 27.2.1最新版本。漏洞源于GitHub公开的forcequitOS开发者代码，可能导致私钥和登录凭证泄露；苹果已发布iOS 27.2.1修复该问题，但币安仍建议用户转移资金至新钱包设备。

## 推荐理由

原文给出了删除侧载应用、升级iOS到最新版本、转移钱包到清洁设备等安全操作建议，读者可据此防范类似风险。
