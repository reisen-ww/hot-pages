# 贵州茅台i茅台APP取消飞天茅台抢购机制 改为16款产品全天动态补货

> 原标题：i茅台不再抢购，贵州茅台改变渠道压货模式

- 发布时间：2026-11-11T14:42:14.000Z

## 摘要

贵州茅台i茅台APP自2026年11月11日起取消53度500ml飞天茅台定时抢购模式，改为16款产品全天动态补货，合同价累计上涨200元，零售价上涨140元。渠道调整后，直销收入占比提升至56.36%，非标酒代售模式探索中，终端市场价格较i茅台高81元/瓶。
