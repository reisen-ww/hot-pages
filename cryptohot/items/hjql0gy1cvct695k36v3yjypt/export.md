# OpenAI Codex Security工具被苹果用于修复WebKit漏洞，网络传言35个漏洞不实

> 原标题：Claim that OpenAI model found 948 Linux flaws runs ahead of the record

## 摘要

苹果官方确认OpenAI的Codex Security工具发现并修复了三个WebKit安全漏洞，网络传言的35个漏洞不实。OpenAI在Linux内核中发现948个本地提权漏洞并生成修复方案，该工具链被用于加速苹果安全更新周期以应对AI加速的攻击技术发展。
