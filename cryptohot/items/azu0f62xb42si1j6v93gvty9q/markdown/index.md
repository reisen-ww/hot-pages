# 中远海运天津临港大型船舶建造基地落子

> 原标题：总投资约82亿元，中远海运大型船舶建造基地落子天津临港

- 发布时间：2026-11-19T02:00:44.000Z

## 摘要

天津中远海运重工以5.7亿元竞得天津港保税区地块，总投资约82亿元建设大型船舶建造基地，规划两座30万吨级船坞，主营大型散货船、集装箱船等，首批新船预计2029年底交付。
