# NVIDIA临时CEO科莱特·克雷斯定于11月18日召开公司会议

## 摘要

NVIDIA将于11月18日上午9点召开公司会议，由临时CEO科莱特·克雷斯主持，会议将在财报公布前一天举行，旨在安抚员工和股东。NVIDIA股价在黄仁勋辞职后下跌超过8%，市场关注临时CEO的领导能力及后续CEO人选。
