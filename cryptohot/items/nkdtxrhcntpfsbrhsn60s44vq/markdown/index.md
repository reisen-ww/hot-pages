# TONX第三季度财报：质押收益13.1万美元，净亏损24万美元

## 摘要

TONX第三季度财报显示质押收益13.1万美元，净亏损24万美元（主要因27.2万美元未实现亏损）。公司持有约2.35亿GRAM代币（市值3485万美元），其中232.9百万GRAM处于质押状态（年化收益率16%）。
