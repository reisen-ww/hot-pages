# 三星称云服务商债务占比有限 不会显著威胁AI行业增长

> 原标题：三星称云服务商仅占整体市场约8%，认为不会显著威胁AI行业增长

## 摘要

三星表示高负债云服务商在整体市场中占比约8%，不会显著威胁AI行业增长。三星认为市场对这类企业债务驱动数据中心扩张的担忧被过度放大，当前AI投资热潮由实际需求驱动。
