# Solana移动端任命Helius和Jito为dApp商店首批独立Guardians

> 原标题：Solana Mobile names Helius and Jito as first independent dApp Store Guardians

- 来源：Crypto Briefing
- 发布时间：2026-11-11T18:36:44.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/f9w7ujilhl19t2qgg4k74qx17
- 原文：https://cryptobriefing.com/solana-mobile-helius-jito-dapp-store-guardians/

## 摘要

Solana移动端宣布任命Helius和Jito为dApp商店首批独立Guardians，将审核职责从单一公司转移至第三方。每个Guardians需质押250,000 SKR，质押机制通过SKR销毁（自2026年10月15日起已销毁超110万枚）激励持有者参与审核。该设计使商店突破Seeker手机端限制，未来计划引入DoubleZero、Triton One等更多Guardians。
