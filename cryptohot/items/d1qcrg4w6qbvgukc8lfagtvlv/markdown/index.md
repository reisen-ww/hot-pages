# 松下机电追加12.7亿元投资扩建苏州AI服务器基板材料工厂

## 摘要

松下机电宣布追加投资12.7亿元用于扩建苏州AI服务器基板材料工厂，苏州工厂一期将于2023年12月量产，二期预计2028年8月投产。中国业务占其全球营收四分之一及利润30%。
