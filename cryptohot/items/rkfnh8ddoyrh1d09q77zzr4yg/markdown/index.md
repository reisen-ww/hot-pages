# Netflix发布FTX相关剧集《The Altruists》遭批评

## 摘要

Netflix于2026年11月19日推出聚焦FTX破产的剧集《The Altruists》，因淡化Sam Bankman-Fried的欺诈责任、将Binance创始人Changpeng Zhao塑造成反派，以及将事件简化为爱情叙事而遭批评。前FTX高管Constance Wang指出该剧歪曲事实，忽略Alameda Research在资金挪用中的核心角色，并称其将投资者和员工损失轻描淡写。
