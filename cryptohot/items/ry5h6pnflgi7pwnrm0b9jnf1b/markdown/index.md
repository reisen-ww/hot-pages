# 亿华通暂停海外研发计划并调整资金用途，前三季度净亏损1.87亿元

> 原标题：氢能汽车遇冷，亿华通收缩研发

- 来源：华尔街见闻
- 发布时间：2026-11-19T09:23:55.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/ry5h6pnflgi7pwnrm0b9jnf1b
- 原文：https://wallstreetcn.com/articles/3786280

## 摘要

亿华通披露四项海外研发计划暂停，原计划2025年底完成资金投入，但截至6月底设备未采购、人员未招聘。公司将资源转向核心零部件国产化与降本，前三季度营收1.14亿元，归母净亏损1.87亿元。行业层面，2023年1-10月燃料电池汽车销量同比下降65%，纯电重卡向长途运输延伸，氢能汽车需拓展非车用场景如船舶、发电等。

## 推荐理由

原文指出行业商业化进度低于预期，导致亿华通暂停海外研发并调整资金用途，前三季度归母净亏损1.87亿元。
