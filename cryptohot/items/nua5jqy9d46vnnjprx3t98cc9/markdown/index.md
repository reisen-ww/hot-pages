# 金价持续低位震荡，饰品消费观望心态依旧

- 来源：界面新闻
- 发布时间：2026-11-18T23:06:29.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/nua5jqy9d46vnnjprx3t98cc9

## 摘要

上海黄金交易所现货黄金每克最低跌至810元/克，当日跌幅为10月以来最大。多家黄金珠宝品牌足金饰品挂牌价下调至1150元/克左右，较今年高点下调超过550元。业内人士预计短期内金价仍将维持低位震荡，投资者需警惕金价波动风险。
