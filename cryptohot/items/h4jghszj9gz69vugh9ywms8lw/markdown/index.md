# 币安推出抵押加密资产消费功能Pay Later

> 原标题：币安推出Pay Later功能，用户可抵押BTC、ETH或BNB消费，额度最高1000 USDC

## 摘要

币安推出抵押加密资产消费功能Pay Later，用户可抵押 BTC/ETH/BNB 获得最高 1000 USDC 消费额度。还款需在次月1日前完成以享0%利息，逾期部分计息；符合条件的币安卡消费最高可获得3%返现。功能初期仅限阿根廷和墨西哥用户，后续将拓展至更多市场。
