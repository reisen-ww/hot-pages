# 以太坊链上交易所Lighter发生安全漏洞致超百万美元USDC被盗

> 原标题：Lighter returns about $5M USDC to affected trader after security incident

## 摘要

2026年11月16日，以太坊链上交易所Lighter发生安全漏洞，导致约103.9万美元USDC被盗。交易所通过触发智能合约机制追回约50万美元USDC并恢复运营，但仍有约155万美元未追回。事件调查显示漏洞源于API密钥泄露及签名代码中nonce重复使用问题，导致攻击者可推导私钥。该事件导致其原生代币LIT日内跌幅超10%。

## 推荐理由

该事件揭示了零知识证明系统在API密钥和签名代码层面的安全漏洞，交易所通过触发智能合约机制追回部分资金并修复漏洞，为同类平台提供风险控制参考。
