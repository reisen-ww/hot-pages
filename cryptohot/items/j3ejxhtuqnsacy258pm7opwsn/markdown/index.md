# 微软宣布2027年资本支出将达1700亿美元

## 摘要

微软首席财务官艾米·胡德在2027财年第一财季业绩电话会上宣布，2027日历年资本支出将达1700亿美元，主要因CPU和GPU成本上升及第三方产能延迟交付。
