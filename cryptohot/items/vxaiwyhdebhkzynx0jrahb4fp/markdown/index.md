# Komainu's Darren Jordan呼吁机构分离加密交易与托管

> 原标题：Komainu’s Darren Jordan urges institutions to separate crypto trading from custody

## 摘要

Komainu推出Connect平台，帮助机构分离加密交易与托管服务。该平台通过链上隔离钱包实现资产安全，并与Binance、Bybit等交易所合作。此前Binance因安全漏洞损失约63亿美元，凸显托管与交易分离的必要性。

## 推荐理由

原文通过Binance安全事件案例，说明托管与交易分离的必要性，并详细解释了Komainu Connect平台如何实现这一目标，读者可据此评估机构在加密资产托管中的风险控制策略。
