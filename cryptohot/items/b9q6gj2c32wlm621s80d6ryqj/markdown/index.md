# 台积电（TSMC）Q3财报超预期但股价暴跌18%，产能扩张能否扭转颓势？

> 原标题：TSMC Is Down 18%: The 2nm Ramp Should Change That

- 发布时间：2026-11-03T13:16:25.000Z

## 摘要

台积电Q3营收超预期9.2亿美元，AI驱动高性能计算贡献68%收入，但股价仍暴跌18%。公司计划2027年前将2nm产能翻倍，A14节点获早期合作。尽管盈利增长强劲，宏观与AI行业担忧导致市盈率从31.7x压缩至25.7x。作者维持'买入'评级，认为当前股价低估了2nm增长潜力，但高资本支出构成中期风险。

## 推荐理由

当前股价与台积电2nm产能扩张带来的长期收益不匹配，需关注资本支出对盈利的影响。
