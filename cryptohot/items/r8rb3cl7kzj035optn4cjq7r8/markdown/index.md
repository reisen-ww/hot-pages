# MSCI剔除Strategy等四家非运营公司，SharpLink被列入观察名单

> 原标题：MSCI全球指数将剔除Strategy、Metaplanet等公司，并将SharpLink列入观察名单

## 摘要

MSCI宣布从12月1日起剔除Strategy、Metaplanet等四家非运营公司，并将SharpLink列入观察名单。Strategy称剔除将导致28亿美元股票抛售，摩根大通估计若其他指数跟进，抛售规模或达88亿美元，或抑制被动投资。
