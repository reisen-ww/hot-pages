# 腾景科技拟注销10.17万股并减少注册资本

## 摘要

腾景科技拟将101,700股回购股份用途变更为注销，占总股本0.06%，注销后总股本将减少至180,988,300股，注册资本相应调整。该事项已获董事会审议通过，需提交股东会审议。
