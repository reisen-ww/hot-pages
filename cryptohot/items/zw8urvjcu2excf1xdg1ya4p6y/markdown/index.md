# 存储芯片涨价致手机PC市场销量下滑，AI未能推动换机潮

> 原标题：最贵双十一，疲软的手机PC还在为AI买单

- 发布时间：2026-11-12T02:01:19.000Z

## 摘要

2026年双十一手机PC销量同比下滑，主因存储芯片涨价推高终端成本，消费者观望情绪浓厚。IDC数据显示第三季度中国智能手机出货量同比下降15.4%，联想小新Pro16起售价上涨36%，华为推出OSTA星芒子品牌。AI相关产品销量增长但未形成刚性需求，终端厂商受限于生态壁垒难以突破。
