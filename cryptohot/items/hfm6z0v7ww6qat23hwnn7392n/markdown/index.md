# 中国人民银行上调金融机构外汇存款准备金率至6%

## 摘要

中国人民银行自2026年11月15日起上调金融机构外汇存款准备金率至6%，旨在平衡外汇市场供求并缓解人民币升值压力。该调整是近五年首次，反映了当前人民币对美元汇率持续升值的趋势。
