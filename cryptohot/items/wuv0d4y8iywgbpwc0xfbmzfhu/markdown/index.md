# 香港IBSH公司出售300枚比特币资助量子计算公司收购

## 摘要

香港IBSH公司于11月16日通过Matrixport平台出售300枚比特币，获约1920万美元用于收购QuantumCompute Solutions。此次交易预计产生160万美元净亏损（按比特币入账价值计算），最终金额需经审计确认。这是该公司继8月出售比特币后第二次通过加密资产变现支持战略收购。
