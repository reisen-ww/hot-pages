# 美第四巡回上诉法院支持马里兰州监管预测市场平台Kalshi

## 摘要

美国第四巡回上诉法院周三裁定马里兰州有权监管预测市场平台Kalshi，导致行业面临联邦与州双重合规压力。CFTC此前要求Kalshi等平台恢复全美50州服务，期限30天将满。若遵守州法院命令则违反CFTC规定，Kalshi发言人表示法官意见分歧且近期裁决相互矛盾。

## 推荐理由

法院裁决与CFTC监管要求形成冲突，揭示预测市场平台在合规路径上的困境。
