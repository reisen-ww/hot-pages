# 花旗证券（中国）公司设立在即 2027年下半年有望开业

## 摘要

花旗证券（中国）有限公司获证监会核准设立，预计2027年下半年开业。公司注册资本12亿元人民币，业务涵盖证券经纪、承销保荐等。花旗称其全球服务网络覆盖180个国家，已服务全球500强约70%在华企业，将重点支持中企海外融资需求。

## 推荐理由

读者可据此了解花旗在华业务拓展节奏及服务范围，判断其对中企全球化融资的影响。
