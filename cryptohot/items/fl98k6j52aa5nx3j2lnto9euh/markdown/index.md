# Robinhood前工程师认罪，借上币内幕在Hyperliquid获利12.55万美元

- 来源：PANews
- 发布时间：2026-11-16T22:57:48.000Z

## 摘要

Robinhood前工程师Huaisong Xiang因利用公司内部上币计划信息在Hyperliquid交易永续合约被指控，获利12.55万美元并同意没收所得。今年9月，Xiang与另一名前工程师Hefu Chai被指控抢跑公司上币公告。
