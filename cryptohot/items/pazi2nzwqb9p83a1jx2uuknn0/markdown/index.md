# 比利时微电子研究中心（Imec）在日本设立研究基地推进半导体研发

> 原标题：比利时微电子研究中心将在日本设基地，推进下一代半导体研发

- 发布时间：2026-11-17T08:31:35.000Z

## 摘要

比利时微电子研究中心（Imec）宣布在日本北海道大学设立首个研究基地，计划与Rapidus等机构合作推进下一代半导体技术研发，并将成果应用于日本半导体公司Rapidus的业务。
