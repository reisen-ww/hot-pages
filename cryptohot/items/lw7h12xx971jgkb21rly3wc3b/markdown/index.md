# 大冢制药IgA肾病靶向药斯贝利单抗纳入2026年国家医保目录

## 摘要

大冢制药的IgA肾病靶向生物制剂斯贝利单抗注射液（商品名：伊再可®）被纳入2026年国家医保药品目录，用于降低存在疾病进展风险的原发性免疫球蛋白A肾病（IgAN）成人患者的蛋白尿。
