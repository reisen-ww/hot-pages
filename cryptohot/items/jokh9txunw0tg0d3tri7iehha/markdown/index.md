# Ledger：官网曾受Optimizely安全事件波及，已移除恶意代码

- 来源：PANews
- 发布时间：2026-11-17T08:42:11.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/jokh9txunw0tg0d3tri7iehha

## 摘要

Ledger 安全团队Donjon确认，其官网曾受Optimizely供应链攻击影响，现已修复并移除恶意代码。该事件不影响Ledger设备安全。此前，Optimizely供应链攻击波及至少186个网站，旨在窃取加密资产与支付信息。
