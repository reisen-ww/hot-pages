# SpaceX 计划斥资超740亿美元建设两个AI超级计算校园

## 摘要

SpaceX宣布将投资超过74亿美元用于建设位于得克萨斯州Starbase和亚利桑那州Cochise县的两个AI超级计算校园，其中Starbase项目配备自建燃气电厂，亚利桑那校区计划接入当地电力合作社。
