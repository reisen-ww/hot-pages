# Ondo Finance加入新加坡金管局Project Guardian推动资产代币化

## 摘要

Ondo Finance宣布加入新加坡金管局Project Guardian项目，旨在推动资产代币化标准化。该计划已吸引40多家跨国机构参与，涵盖六个司法管辖区。Ondo将聚焦投资者接入、保护机制和跨境市场连通三大领域，其核心业务为将传统金融产品（如基金、固收工具）代币化。需注意，此次合作未涉及新加坡零售投资者资质变更。
