# Jupiter上线许可借贷市场支持Bullish股票抵押

> 原标题：Jupiter launches permissioned lending market for Bullish shares

- 来源：Crypto Briefing
- 发布时间：2026-11-16T17:13:44.000Z

## 摘要

Jupiter在Solana上推出首个允许代币化NYSE上市公司股票作为抵押品的许可借贷市场。该市场支持BLSH代币作为抵押品获取流动性，无需出售股票。同时发布Global Passport身份验证服务和流动性支持工具，帮助发行方将代币引入链上交易。
