# MEXC关闭全球虚拟Visa卡服务

> 原标题：MEXC shuts down Global Card service after third-party issuer changes

- 来源：Crypto Briefing
- 发布时间：2026-11-18T09:05:56.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/xqalq9myp0w74u4ox8r5eu3mb
- 原文：https://cryptobriefing.com/mexc-shuts-down-global-card-service/

## 摘要

MEXC宣布将于2026年11月18日15:30 UTC永久停用全球虚拟Visa卡服务，因第三方发卡机构变更导致。用户需在截止前将余额转移至法币或现货账户，逾期未操作者资金将于11月21日自动结算并转入现货账户（3个工作日内完成）。该服务自2026年8月31日上线仅运行2个月，此前其亚太区卡服务已于11月11日停用。
