# 特斯拉拟投30亿欧元扩建德国工厂生产Cybercab，高管称2029年投产

- 发布时间：2026-11-16T23:24:46.000Z

## 摘要

特斯拉宣布斥资30亿欧元扩建德国格伦海德超级工厂，计划2029年投产无人驾驶出租车Cybercab。扩建后年产能目标最高达100万辆，但需克服欧盟无人驾驶商业运营许可的监管障碍。当前Model Y周产量已达7000辆，2025年总产量同比减少9000辆。工厂计划2027年年中启动电池电芯生产，并将在2027年夏末结束美国得州Cybertruck生产以腾出产能。
