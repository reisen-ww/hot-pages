# 欧洲央行拟将商业银行最低准备金率上调至2%

## 摘要

欧洲央行计划于11月25日会议讨论将商业银行最低准备金率从1%上调至2%，预计每年节省至少44亿欧元。此举旨在应对2015-2022年购债遗留的过剩流动性问题，同时为央行应对利率上升提供财务缓冲。
