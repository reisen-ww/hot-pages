# 金融监管总局上海局发布绿色金融促进通知

> 原标题：金融监管总局上海监管局：丰富各类碳金融产品，扩大碳资产质押融资等业务规模

## 摘要

金融监管总局上海局发布通知，鼓励银行保险机构参与碳市场建设并扩大质押融资规模。支持利用碳账户拓展绿色金融服务场景，包括企业碳排放数据互通平台建设，提升碳市场数字化管理水平。
