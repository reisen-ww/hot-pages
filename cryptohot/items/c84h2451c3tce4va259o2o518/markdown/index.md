# 南京新百出售AS Nursing和AS One股权

## 摘要

南京新百全资子公司拟将持有的AS Nursing和AS One 100%股权出售给Danel，交易基础股权价值约9亿元人民币。交易完成后，公司将不再持有上述两家公司的股权。
