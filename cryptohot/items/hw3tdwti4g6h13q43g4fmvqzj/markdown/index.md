# 智利养老金基金外币利率互换亏损收窄

## 摘要

智利养老金基金（AFPs）在10月将外币利率互换的市场价值亏损从9月底的77亿美元降至29亿美元，得益于美国国债的上涨。政府正施压要求减少风险并提高支付。
