# 恩捷股份：子公司拟与云南产投等设立基金并增资玉溪恩捷

## 摘要

恩捷股份控股子公司上海恩捷与云南产业投资、云南先进制造母基金、玉溪产业投资基金签署协议，共同设立总规模未披露的股权投资基金。该基金将增资玉溪恩捷8.01亿元，上海恩捷同步以自有资金增资玉溪恩捷18.11亿元，最终持股75%。
