# 高鑫零售上半财年营收降9.9%，大润发持续扩大生鲜联采

## 摘要

高鑫零售（06808.HK）2027财年中期业绩显示，营收同比下降9.9%，净亏损扩大至5.17亿元。公司正通过扩大生鲜联采和自有品牌销售，改善经营状况。大润发Super线上销售占比达31%，但整体业绩增长仍需时日。
