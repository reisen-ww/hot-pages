# 广生堂：乙肝三联全口服方案完成II期临床试验入组

- 发布时间：2026-11-12T08:16:00.000Z

## 摘要

广生堂子公司广生中霖的GST-Peak-Triple三联全口服有限疗程方案已完成II期临床试验入组，合计入组176例患者。该方案旨在评估联合治疗对慢性乙肝的功能性治愈情况。相关药物已被纳入突破性治疗品种名单。
