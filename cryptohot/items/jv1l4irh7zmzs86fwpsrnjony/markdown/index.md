# Roundhill终止Solana和XRP期权ETF的发行计划

> 原标题：Roundhill scraps plans for XRP and Solana covered-call ETFs

- 来源：Crypto Briefing
- 发布时间：2026-11-19T10:30:33.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/jv1l4irh7zmzs86fwpsrnjony

## 摘要

Roundhill宣布终止Solana和XRP期权ETF的发行计划，主要因资产基数小和期权市场流动性不足。Solana相关ETF单周净流出超2600万美元，累计流入不足14.5亿美元；XRP相关ETF多次出现零交易记录，反映市场基础设施待完善。
