# 币安将于11月20日移除GAS/TRY、HBAR/BNB等5个现货交易对

- 来源：PANews
- 发布时间：2026-11-18T05:01:24.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/mlfsc0x6l5mkjgar2eu6wgh4j
- 原文：https://www.panewslab.com/zh/articles/01a1ed07-e83c-7359-bb4d-f454d0e4e3e3

## 摘要

币安宣布将于11月20日11:00（东八区时间）下架GAS/TRY、HBAR/BNB、HIVE/TRY、KSM/TRY和ZAMA/TRY现货交易对并停止交易。币安表示会定期审核所有上线现货交易对，可能因流动性、交易量不佳等多种因素下架部分交易对，以保护用户并维护高质量交易市场。
