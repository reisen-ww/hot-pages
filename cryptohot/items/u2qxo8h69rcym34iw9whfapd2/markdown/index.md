# ARK Invest减持NVIDIA股票并增持加密货币相关企业及SpaceX

> 原标题：ARK Invest sells $85M in Nvidia, buys $40M in crypto stocks

## 摘要

ARK Invest宣布在科技股下跌期间减持NVIDIA股票约8480万美元（售出543092股），同时增持Block（XYZ）、Circle（CRCL）、Coinbase（COIN）等加密货币相关企业股票约4000万美元，并投资SpaceX约5200万美元。该操作显示机构投资者在市场波动中调整风险偏好，减少对芯片股的暴露，增加对加密货币和航天领域的配置。
