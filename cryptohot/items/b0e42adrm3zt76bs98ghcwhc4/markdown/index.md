# 美国财政部因涉嫌16亿美元非法资金流动切断MEXC与美国金融系统联系

> 原标题：U.S. Treasury Cuts Off MEXC From U.S. Financial System Over Alleged $16 Billion in Illicit Flows

- 发布时间：2026-11-06T21:28:56.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/b0e42adrm3zt76bs98ghcwhc4

## 摘要

美国财政部以涉嫌16亿美元非法资金流动为由，通过FinCEN 9714条款切断MEXC与美国金融系统的联系。具体涉及俄罗斯、伊朗、朝鲜的制裁规避行为，包括与伊朗加密交易所的$1亿直接交易和A7制裁网络关联的$26M资金流动。该处罚同步于近期对朝鲜加密项目的制裁，并成为继Bitzlato后又一典型案例。

## 推荐理由

原文提供了被制裁交易所的具体非法资金流动规模（$16亿）和时间跨度（2021-2026），并指出该处罚属于FinCEN 9714条款的首次应用案例，读者可据此对比其他受制裁交易所（如Bitzlato）的合规教训。
