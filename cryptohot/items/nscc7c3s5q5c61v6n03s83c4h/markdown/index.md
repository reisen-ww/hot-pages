# 美国商务部终裁中国卡车后斗盖反补贴税

> 原标题：美国对进口自中国的卡车后斗盖作出反补贴产业损害终裁

- 来源：界面新闻
- 发布时间：2026-11-17T08:09:42.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/nscc7c3s5q5c61v6n03s83c4h

## 摘要

美国商务部于2026年10月14日终裁中国卡车后斗盖存在补贴行为，认定其损害美国相关产业。该终裁将导致美国商务部颁布反补贴征税令。此前2026年3月18日美国商务部已对进口自中国的卡车后斗盖发起反倾销和反补贴调查。
