# 英特尔Q3财报受内存短缺拖累，Q4营收指引低于市场预期

> 原标题：Intel CEO Lip-Bu Tan blames memory costs for Q3 stumble as Q4 guidance disappoints

- 发布时间：2026-11-18T21:23:03.000Z

## 摘要

英特尔Q3数据中心收入增长78%至73亿美元，但客户业务因内存短缺下降5%至81亿美元。Q4营收指引为150-160亿美元，低于分析师预期的约170亿美元。CEO称内存成本上升拖累业绩，并计划通过优化芯片分配和扩大Xeon服务器芯片供应缓解问题。
