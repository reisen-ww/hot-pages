# Anthropic IPO定价上调至83美元，散户认购需求近千亿美元

> 原标题：报道：Anthropic IPO定价上调至83美元，认购逼近5000亿美元

- 来源：华尔街见闻
- 发布时间：2026-11-18T15:48:17.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/pt02ajos97isaxdfgi1mmfv6d
- 原文：https://wallstreetcn.com/articles/3786222

## 摘要

Anthropic宣布将IPO定价上调至83美元，散户认购需求达近千亿美元。机构投资者需求约4000亿美元，总需求或超5000亿美元。公司计划周四在纳斯达克以'ANT'代码上市，若扩大发行规模或突破SpaceX保持的857亿美元IPO纪录。

## 推荐理由

原文对比了Anthropic与SpaceX的IPO规模，指出后者目前仍是史上最大规模IPO，但前者市场需求更为强烈。
