# 德意志银行面向付费客户上线比特币托管服务

## 摘要

德意志银行宣布面向机构及企业客户提供比特币托管服务，支持BTC/ETH及USDC/EURC/EURAU等稳定币。服务通过Autobahn平台接入，符合欧盟MiCA监管要求，并与德意志资产管理公司合作探索代币化金融产品。未披露客户数量及托管费率。
