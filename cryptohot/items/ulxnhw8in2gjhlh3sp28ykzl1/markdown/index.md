# 四季度业绩展望不及预期，英特尔开盘暴跌超29%

- 来源：界面新闻
- 发布时间：2026-10-30T13:37:33.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/ulxnhw8in2gjhlh3sp28ykzl1
- 原文：https://www.jiemian.com/article/15274970.html

## 摘要

英特尔四季度营收指引为150-160亿美元（低于市场预期的170亿），非GAAP每股收益0.25美元（低于预期的0.43美元），导致美股开盘暴跌超29%。财报显示：数据中心与AI业务营收73亿美元（同比+78%），但客户端计算业务营收81亿美元（同比-5%）；代工业务营收67亿美元（同比+58%）仍亏损。

## 推荐理由

英特尔四季度营收指引全面低于市场预期，且代工业务持续亏损叠加PC需求疲软，需关注产能爬坡进展与PC行业库存出清节奏。
