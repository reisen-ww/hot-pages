# 微软CEO纳德拉称若可租将向SpaceX采购计算能力

> 原标题：Nadella says Microsoft would lease SpaceX compute capacity if it were available

## 摘要

微软CEO纳德拉表示，若SpaceX提供计算能力，将考虑租赁。SpaceX AI业务年化营收已达411亿美元，但当前1.7GW算力容量难以满足客户需求（包括Anthropic和Google）。微软Q3已新增5大洲24个数据中心，同时谨慎对待市场租赁模式。SpaceX计划2027年前斥资740亿美元建设10GW算力基地，若合作达成将改变AI基础设施格局。

## 推荐理由

微软可能通过租赁外部算力缓解AI需求激增，SpaceX的算力扩容计划（2027年底达10GW）与微软现有全球数据中心布局形成互补性市场观察窗口。
