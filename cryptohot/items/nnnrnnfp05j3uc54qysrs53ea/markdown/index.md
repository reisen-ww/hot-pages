# 某巨鲸ENA持仓亏损57.44%后向币安转入2000万枚

## 摘要

某巨鲸地址0x9a80在ENA上亏损57.44%后向币安转入2000万枚ENA（约233万美元）。一个月前，该地址以0.27美元高价买入3796万枚ENA（约1029万美元），当前仍持有1796万枚（约205万美元），总亏损591万美元。
