# 华新建材拟为巴西恩布公司提供112.92亿元担保

## 摘要

华新建材拟为全资子公司巴西恩布公司提供约合人民币112.92亿元的连带责任履约担保，以确保其与巴西国家钢铁公司签署的股权收购协议顺利执行。
