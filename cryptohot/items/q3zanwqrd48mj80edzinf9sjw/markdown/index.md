# 央行下调股票回购增持再贷款利率至1% 多家银行加速对接上市公司

> 原标题：股票回购增持再贷款今起加力 多家银行加大上市公司对接力度 贷款利率预计跟随下调

## 摘要

央行宣布将股票回购增持再贷款利率下调0.25个百分点至1%，支持对象包括21家全国性银行和5家系统重要性城商行，期限1年。工行、建行等已为十余家上市公司落地相关业务，但银行人士坦言企业端需求不足仍是主要障碍。

## 推荐理由

原文揭示了央行通过降低再贷款利率至1%推动上市公司融资，并反映了银行在政策激励下加速对接企业的动态，同时指出实际需求仍存挑战。
