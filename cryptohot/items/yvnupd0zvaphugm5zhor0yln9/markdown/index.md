# 比特币活跃供应量中亏损持仓占比超盈利

## 摘要

分析师指出，比特币活跃供应量中处于亏损状态的占比已超过盈利占比，调整后不到 45% 的供应处于盈利状态。历史数据显示，该比例低于 40% 时通常对应市场回调阶段的低点。
