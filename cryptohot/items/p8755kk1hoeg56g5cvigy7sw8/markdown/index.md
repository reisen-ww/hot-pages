# Polymarket US上线原油与天然气15分钟快速交易产品

## 摘要

Polymarket US宣布推出原油与天然气15分钟快速交易产品，基于加密市场成功经验，六周内吸引30万交易者并达成10亿美元交易额。新产品采用Pyth Network和Chainlink的Oracle价格数据，结算周期为15分钟或1小时，与贵金属交易产品结构相同但标的不同。
