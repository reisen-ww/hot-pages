# 美国放松俄罗斯柴油贸易制裁，特朗普称俄将向美供油

> 原标题：【环球财经】美国放松针对俄罗斯柴油贸易相关制裁 特朗普称俄将对美供油

## 摘要

美国财政部下属外国资产控制办公室宣布放松俄罗斯柴油贸易相关制裁，授权销售、交付、卸货或进口柴油的许可持续至美东时间2027年4月7日零时。特朗普称俄罗斯将立即向美国及世界市场提供超过30万吨柴油，11月提供50万吨，此后再提供100万吨。美国9日柴油平均零售价格为每加仑6.2785美元，同比上涨70.8%。

原文串联了制裁放松、俄罗斯供油安排与美国柴油价格数据，呈现政策变化对能源供应和价格的直接影响。
