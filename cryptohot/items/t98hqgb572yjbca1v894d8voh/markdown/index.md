# 巴菲特再捐55亿美元 1620亿剩余财富8年内捐完

- 发布时间：2026-11-17T10:19:31.000Z

## 摘要

巴菲特宣布捐赠价值55亿美元的伯克希尔股票给四家家族基金会，剩余1620亿美元计划8年内捐完。捐赠后，各基金会资产规模均超过此前总资产，显示其慈善承诺的持续深化。
