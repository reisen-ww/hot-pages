# 商务部回应美半导体限制措施 英伟达财报增长103.1% 6G试点启动

## 摘要

商务部回应美国对华半导体限制措施，英伟达第三季度营收同比增长103.1%，并预计第四季度营收1274亿至1326亿美元。此外，工信部批准8省市开展6G创新发展试点，并发布半导体设备与零部件质量管理体系标准。三星与苹果达成DRAM长期供货协议，首期供货量及价格待定。
