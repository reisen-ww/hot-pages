# 意大利工业生产在九月反弹，但仍面临复苏挑战

## 摘要

意大利工业生产在九月环比增长1.2%，得益于资本货物和中间货物的增长，但消费者货物和能源生产下降。季度环比下降0.4%，经季节调整后，产量也低于去年同期水平。
