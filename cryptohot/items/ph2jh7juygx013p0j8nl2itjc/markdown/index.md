# 亚玛芬三季度营收增长24%，美股上市后首推10亿美元级回购

- 来源：华尔街见闻
- 发布时间：2026-11-18T02:05:44.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/ph2jh7juygx013p0j8nl2itjc

## 摘要

亚玛芬2026年第三季度营收21.69亿美元，同比增长24%，调整后净利润2.50亿美元，同比增长35%，并宣布最高10亿美元股票回购计划。公司将全年营收增长预期上调至25%-26%，调整后营业利润率预期提升至14.5%-14.7%，但2027年初步增长目标降至长期目标区间中值。
