# 华尔街AI热捧遭遇抛售潮，野村警示投资者需重新评估风险敞口

## 摘要

野村警告称，因AI相关股票抛售潮，投资者正重新评估其风险敞口。MSCI AI基础设施指数在9月30日至11月6日期间下跌22%，野村分析师Andy Goldberg指出，仅需1-2%的配置调整就可能引发市场剧烈波动。数据显示，全球前十大企业中涉及AI业务的公司总市值达25.3万亿美元，机构正在加速对冲风险。

## 推荐理由

原文提供了MSCI AI基础设施指数22%的跌幅和野村对市场抛售的警示，读者可据此评估AI相关资产配置风险。
