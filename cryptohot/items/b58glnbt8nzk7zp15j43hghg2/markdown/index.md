# 特斯拉向受邀个人开放Cybercab购买，起售价29990美元，首批12月交付

## 摘要

特斯拉宣布向精选客户开放无方向盘自动驾驶车型Cybercab个人购买，起售价29990美元，首批交付定于2026年12月。该车型需支付每月299美元自动驾驶订阅费，定位为现售车型中价格最低产品。公司计划明年停止Cybertruck生产以扩大Cybercab产能，但需关注美国国家公路交通安全管理局（NHTSA）此前启动的合规性调查可能对交付进度造成影响。
