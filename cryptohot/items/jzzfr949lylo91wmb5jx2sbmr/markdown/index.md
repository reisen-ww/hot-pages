# Trade.xyz上线NVIDIA股票衍生品合约，周交易额达55亿美元

> 原标题：Trade.xyz NVDA perp hits $5.5B weekly volume, dwarfing Hyperliquid rivals

- 发布时间：2026-11-18T13:50:32.000Z

## 摘要

Trade.xyz宣布其基于NVIDIA股票价格的衍生品合约单周交易额达55亿美元，远超同类平台Hyperliquid的25亿美元周均量。该合约通过稳定币USDC结算，杠杆率上限为2.5倍。研究显示，11月中旬某24小时窗口内单日交易量达52亿美元，日均交易量介于5亿至10亿美元区间。
