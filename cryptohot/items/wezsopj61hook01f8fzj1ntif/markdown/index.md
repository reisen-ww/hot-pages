# 贝莱德将价值约4.44亿美元的BTC和ETH转移至Coinbase Prime

- 来源：PANews
- 发布时间：2026-11-12T12:08:15.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/wezsopj61hook01f8fzj1ntif
- 原文：https://www.panewslab.com/zh/articles/01a1cfa8-979c-745b-b44e-53d562136aa5

## 摘要

贝莱德将价值约4.44亿美元的BTC和ETH转移至Coinbase Prime托管服务。根据Onchain Lens监测，转移包括4,189枚BTC（约3.05亿美元）和68,230枚ETH（约1.39亿美元），涉及金额总计约4.44亿美元。
