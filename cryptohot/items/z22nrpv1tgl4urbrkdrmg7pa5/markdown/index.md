# 美国商务部发布AI算力远程使用新规，海外数据中心出租需获许可

> 原标题：美国纳管AI算力远程获取，海外数据中心出租算力将须许可

- 发布时间：2026-11-17T03:32:00.000Z

## 摘要

美国商务部11月15日发布新规，将远程使用先进AI芯片纳入出口管制，要求海外数据中心出租算力需获许可。分析指出，新规通过限制服务关系而非硬件出口，可能改变全球AI算力供需格局，短期影响英伟达（下跌4.12%）、阿里巴巴（美股下跌3.98%）等企业股价，长期或导致基础设施重复投资和区域分化。

## 推荐理由

原文通过分析新规的执行细节、市场反应和不同时间维度的影响，揭示了远程算力访问监管转变对AI基础设施供需格局的结构性重塑，为评估类似政策的经济后果提供框架。
