# 名创优品2026年三季度收入同比增长14.3%

- 来源：东方财富
- 发布时间：2026-11-17T16:28:37.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/cpi4wsbajamxzfmmtv25hr3d9
- 原文：http://finance.eastmoney.com/news/1354,202611173933219914.html

## 摘要

名创优品2026年三季度收入66.25亿元同比增长14.3%，经调整净利润7.15亿元同比下降3.5%。毛利率提升至45.3%主要因定价策略优化及自有IP产品贡献，海外市场收入占比从42.1%降至38.5%。前三季度累计收入181.24亿元，同比增长19.3%。财报披露其在中国内地开设超120家'乐园'门店，并首次进入黎巴嫩及奥地利。
