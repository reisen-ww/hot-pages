# Meta Muse AI 现支持为美国用户拨打电话

> 原标题：Meta’s Muse AI agent can now make phone calls for US users

- 来源：Crypto Briefing
- 发布时间：2026-11-12T17:58:15.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/n25avrbsrdj3sgxgfl70m711a

## 摘要

Meta宣布其Muse AI助手已开放美国用户拨打电话功能，此前因隐私问题暂停的人工代工模式已改为纯AI处理。硬件测试显示单Nvidia GB200芯片可支持12个实时语音会话（延迟约870毫秒）。该功能限制18岁以上用户，并计划扩展至AI眼镜和Muse手环（预计2026年底）。
