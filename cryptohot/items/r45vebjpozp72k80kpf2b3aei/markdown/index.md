# 比特币休眠钱包2026年链上转移规模达22.7万枚

## 摘要

2026年比特币休眠钱包链上转移规模达22.7万枚，其中2015-2018年间获得的占比81.9%。Checkonchain数据显示，2010-2017年休眠地址在2026年1-10月间完成873笔转账，涉及金额约1835.8亿美元。部分2010年矿工地址在2026年1月10日转移2000枚BTC，9月5日完成早期矿工奖励转移。
