# 比特币周跌14%致加密财库公司市值低于持仓资产

> 原标题：分析：比特币周跌约14%，多数加密财库公司市值已低于所持币价

## 摘要

比特币过去一周下跌约14%，Strategy、Strive等加密财库公司股价跌幅达15%，其'溢价增发再买入'模式承压。Blockworks数据显示25家追踪公司中24家市值低于所持加密资产价值。此前MSCI已剔除Strategy等公司（来源：彭博社/PANews）
