# 比特币因Anthropic上市及纳斯达克期货上涨反弹

## 摘要

比特币在Anthropic上市前后的价格波动与纳斯达克期货形成联动。Anthropic通过IPO和私人配售共筹集1073亿美元，其中NVIDIA、Microsoft等科技巨头参与私人配售。比特币价格在IPO定价期间（11月18-19日）从62,000美元附近反弹至63,000-64,000美元区间，与科技股市场情绪传导一致。

## 推荐理由

原文揭示了比特币与科技股IPO的联动效应，并量化了市场情绪对风险资产价格的影响程度。
