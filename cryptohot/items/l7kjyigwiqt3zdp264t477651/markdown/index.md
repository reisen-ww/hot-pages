# Bitget交易所推出AI驱动的威胁检测功能升级

> 原标题：Bitget Wallet rolls out expanded AI protections to all users amid phishing surge

## 摘要

Bitget钱包宣布升级AI威胁检测系统，Q4首四周检测准确率达90.2%（Q3为70.2%，Q2为36.3%），Q3周均拦截钓鱼风险3.7万次（Q2为0.5万次）。系统整合AI分析、规则筛查和人工审核，可模拟交易检测隐藏授权风险，用户无需额外付费即可使用网站访问、DApp连接和交易签署环节的防护。

## 推荐理由

原文提供了Bitget钱包在Q4季度AI威胁检测准确率（90.2%）和风险拦截量（Q3周均3.7万次）等核心数据，读者可据此评估其安全防护的实际效果。
