# Bitcoin Core披露高危漏洞并完成修复

> 原标题：Bitcoin Core披露高危漏洞：重组期间TRUC规则可致节点无法出块，已完成修复

## 摘要

Bitcoin Core于2026年11月10日披露CVE-2025-62861漏洞，影响版本28.0至28.2及29.0至29.1，修复已发布于v30.0并回溯至旧分支。漏洞由Niklas Goegge发现，可能导致节点在重启前无法出块。
