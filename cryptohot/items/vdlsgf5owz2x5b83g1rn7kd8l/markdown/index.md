# Backpack Clearing获美国CFTC批准注册为衍生品清算机构

## 摘要

美国商品交易委员会（CFTC）于11月13日批准Backpack Clearing注册为衍生品清算机构，获准清算保证金期货及全额抵押的期货期权和互换合约。Backpack在Solana Breakpoint大会期间公布此进展，其关联交易所的申请仍在审批中。
