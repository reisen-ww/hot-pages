# 中证指数升级ESG评价方法推动上市公司治理架构调整

> 原标题：从“年报附录”到“战略决策”，上市公司治理架构迎来升级潮

## 摘要

中证指数发布新版ESG评价方法（V4.0），将可持续发展相关治理架构纳入核心评价维度。A股上市公司近期普遍设立战略与ESG委员会，将ESG正式纳入公司最高决策层议事范围，反映评价体系变化对治理实践的影响。

## 推荐理由

该评价方法升级推动上市公司将ESG纳入最高决策层，影响企业治理架构调整方向。
