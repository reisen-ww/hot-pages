# CFTC要求Kalshi下架涉及特朗普的预测市场

> 原标题：Kalshi takes down controversial Trump 'mention' markets at CFTC's request

## 摘要

CFTC要求Kalshi下架涉及特朗普的预测市场，因存在操纵风险。具体下架市场包括询问特朗普在2027年前使用的昵称、2026年11月言论内容以及本月提及的国家和公司。此前CFTC曾发布指导方针警示此类市场风险，并在2026年8月启动内部审查。2026年7月，一名白宫提词员利用内幕信息在相关预测市场交易已被CFTC处罚。目前Kalshi仍活跃运营其他非体育类预测市场。

## 推荐理由

CFTC要求Kalshi下架涉及特朗普的预测市场，因存在操纵风险，并提及此前类似案例及监管趋势。
