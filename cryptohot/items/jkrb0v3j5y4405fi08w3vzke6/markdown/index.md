# 迪士尼Q4财报超预期，计划2029年前节省30亿美元

## 摘要

迪士尼Q4财报营收259.5亿美元（+16% YoY）、EPS 1.51美元（+15% YoY）均超预期，并宣布通过裁员和削减开支在2029年前节省30亿美元。流媒体收入增长19%至61亿美元，主题公园收入增长15%至101亿美元，体育业务利润翻倍至13.9亿美元。公司计划将年度股息提高33%至每股2美元（分两次发放）。
