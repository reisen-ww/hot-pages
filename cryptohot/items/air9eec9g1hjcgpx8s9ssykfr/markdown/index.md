# Maple Finance CEO 表示贷款业务正常运营

> 原标题：Maple Finance CEO Sid Powell says loan book is performing after executive exits

- 发布时间：2026-11-17T20:10:31.000Z

## 摘要

Maple Finance CEO Sid Powell 表示，公司两位高管的离职与其贷款业务质量无关，贷款业务正在正常运营。尽管 SYRUP 代币在高管离职后下跌超过 7%，但 Maple 的贷款平台自 2019 年以来已发放超过 200 亿美元贷款，且无不良记录。
