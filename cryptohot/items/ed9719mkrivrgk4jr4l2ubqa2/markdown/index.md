# 英伟达董事会设立国家安全与出口管制监督委员会

- 发布时间：2026-11-17T14:23:43.000Z

## 摘要

英伟达董事会设立国家安全与出口管制监督委员会，由苏珊娜·诺拉·约翰逊担任主席，成员包括斯蒂芬·C·尼尔和约翰·O·达比里。委员会负责监督国家安全政策、出口管制合规及全球贸易风险管理，英伟达现有相关团队将直接向该委员会汇报。委员会每季度至少召开一次会议，包括与管理层联席会议和董事闭门会议。

## 推荐理由

该委员会的设立表明英伟达在应对全球贸易管制和合规风险方面采取主动措施，影响其供应链和产品出口策略。
