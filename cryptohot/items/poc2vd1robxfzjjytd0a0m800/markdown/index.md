# SK Hynix 在印第安纳州动工建设$4B HBM封装厂，支持AI需求

> 原标题：SK Hynix breaks ground on $4B HBM memory facility in Indiana for AI

## 摘要

SK Hynix宣布在美国印第安纳州动工建设投资超$4B的HBM封装厂，用于支持AI需求。该工厂计划2028年完成洁净室建设，2029年第二季度量产HBM4E芯片，预计创造1000个就业岗位。项目已获CHIPS法案$458 million补贴，但NAND闪存工厂选址和投资决策尚未最终确定。
