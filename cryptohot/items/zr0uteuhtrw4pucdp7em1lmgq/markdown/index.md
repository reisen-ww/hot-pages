# CFTC 调查 Kalshi 是否违规自认证事件合约

## 摘要

CFTC 正调查预测市场平台 Kalshi 是否未按规定通知该机构关于拟议事件合约的提交情况，Kalshi 称为程序性错误并已着手解决。这是 CFTC 加强监管预测市场的最新举措，此前已要求 Kalshi 下架相关“提及市场”。
