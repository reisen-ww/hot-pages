# 乌克兰吸引12亿美元稳定币，东欧加密货币活动同比下滑7.9%

## 摘要

乌克兰在2025年7月至2026年6月期间吸引12亿美元稳定币跨境转账（其中零售转账2.41亿美元），而东欧整体加密经济规模同比缩水7.9%至6421亿美元，低于全球1.6%的降幅。报告显示东欧零售级稳定币转账占比13.1%，为全球最高。波兰ATM交易额同比增120%，稳定币占比约90%。数据基于Chainalysis对钱包间跨境流动的追踪方法，受加密资产价格波动影响。
