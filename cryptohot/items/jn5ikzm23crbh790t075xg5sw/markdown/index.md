# 中国香港通过加密资产税务申报法案，2027 年起实施

## 摘要

中国香港立法会通过《2026 年税务条例修订草案》，落实 OECD 加密资产申报框架 CARF（2027 年生效）及修订版共同申报准则 CRS（2028 年自动交换税务信息，2029 年自动交换金融账户信息）。香港财政司司长许正宇称此举旨在巩固国际金融中心地位。

## 推荐理由

法案明确实施时间与信息交换范围，读者可据此预判跨境税务合规成本变化。
