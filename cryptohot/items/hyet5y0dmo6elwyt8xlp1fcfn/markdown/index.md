# Nebius股价下跌16% 因预计2026年资本支出增加及展望疲软

## 摘要

Nebius周四公布第三季度财报：收入9.808亿美元（同比+571%），净亏损375万美元（-13美分/股），较去年同期收窄。公司预计2026年资本支出增加，同时关联方NVIDIA正面临董事会高层变动风险。近期美国多州通过限制AI设施建设的投票，以及行业竞争加剧背景下，Nebius股价当日下跌16%。

## 推荐理由

Nebius的财报显示收入同比激增571%但净亏损扩大，需结合NVIDIA高层变动及行业资本支出趋势分析其长期竞争力。
