# 微软CEO回应服务中断：AI既能加速漏洞修复也能被恶意利用

## 摘要

微软CEO Satya Nadella在Ignite大会上回应服务中断事件，称AI既能加速软件漏洞修复也能被恶意利用。事件始于2026年11月12日，因7月更新遗留的软件缺陷叠加服务器负载激增引发全球服务瘫痪，影响4500万付费用户。Nadella强调AI可提升系统健壮性，但实际案例暴露漏洞检测滞后问题。分析指出，AI工具若未主动应用于代码审计，企业仍面临重大基础设施风险。
