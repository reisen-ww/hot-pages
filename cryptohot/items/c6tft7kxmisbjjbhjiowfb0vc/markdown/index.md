# Strive CEO：即使比特币跌至一美分公司也能存活

## 摘要

Strive Inc. CEO Matt Cole表示，即使比特币价格跌至一美分，公司也能存活，因公司没有债务迫使其出售比特币。公司已为比特币下跌80%做好准备，资产负债表上约85%至90%为比特币，足以度过任何熊市。目前公司持有的43,153枚BTC平均购入成本为87,821美元。
