# 美联储官员戈尔斯比要求证明AI生产力增益已超科技行业

## 摘要

美联储官员戈尔斯比指出AI生产力增益尚未突破科技行业，并警示基建投资可能加剧通胀压力。其观点基于对比1990年代IT革命与当前AI应用场景，强调经济数据尚未验证生产力提升的广泛性。
