# 商务部回应中美经贸合作与欧盟禁用中国设备

## 摘要

商务部新闻发言人何亚东表示，中美经贸关系本质是互利共赢，双方将继续加强合作，妥善管控分歧。美国延长178项对华301关税豁免至2027年1月9日，中方则暂停实施部分对美加征关税。针对欧盟禁用中国设备，中方表示反对技术政治化，呼吁提供公平营商环境。
