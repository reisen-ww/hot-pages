# Visa 与 dtcpay 合作试点稳定币跨境支付

> 原标题：Visa pilots stablecoin funding for cross-border payouts with dtcpay

## 摘要

Visa 与新加坡支付公司 dtcpay 合作，试点稳定币用于亚太区跨境支付，收件人仍获当地法币结算。Visa 通过第三方机构 Triple-A 处理稳定币兑换、结算及合规，不直接提供数字资产服务。此前 Visa 已在美国使用 USDC 试点该功能，亚太版同步推出 AI 驱动支付计划，覆盖超 50 家亚太企业。
