# CFTC主席：加密衍生品平台入美须持牌或合作

## 摘要

CFTC主席Michael Selig表示，加密衍生品平台进入美国市场需持牌或与持牌交易所合作。他以Backpack本周获得FCM、DCM和DCO三项牌照为例，并指出股票永续合约虽无到期日、以资金费率结算，但其结构仍属期货而非证券互换。

## 推荐理由

原文指出合规路径和监管技术要求，对加密平台进入美国市场有参考价值。
