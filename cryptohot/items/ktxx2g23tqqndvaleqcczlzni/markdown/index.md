# Revolut推出区块链私募基金，散户可零门槛投资另类资产

> 原标题：Revolut’s Martin Gilbert warns of looming liquidity crunch in private markets, sees blockchain as solution

## 摘要

Revolut宣布推出四只区块链私募基金，通过智能合约分割私募资产，为散户提供零门槛投资渠道。该方案将传统私募市场（平均赎回周期长达数月）的流动性问题转化为可即时交易的区块链资产，同时允许用户以小额定投。Martin Gilbert在伦敦Solana Breakpoint大会上指出，当前机构投资者正寻求从私募股权基金中撤资，但面临流动性短缺问题，区块链技术可解决这一痛点。
