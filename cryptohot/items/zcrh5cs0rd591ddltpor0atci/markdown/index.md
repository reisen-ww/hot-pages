# 希腊津巴布韦欲加入 MSCI 前沿市场指数

- 来源：Bloomberg Markets

- 原文：https://www.bloomberg.com/news/articles/2026-11-11/zimbabwe-seeks-entry-into-msci-frontier-markets-index-for-dollar-stocks

## 摘要

津巴布韦希望将其美元股票交易所的证券纳入 MSCI 前沿市场指数，以吸引国际投资者并提升市场流动性。维多利亚瀑布证券交易所首席执行官 Justin Bgoni 表示已多次致函 MSCI。
