# 联合圣保罗银行减持比特币ETF并增持Solana、XRP等加密资产ETF

## 摘要

联合圣保罗银行减持比特币ETF并增持Solana、XRP等加密资产ETF，比特币敞口减少11.43%，XRP敞口增长88.66%。具体持仓变化：ARK比特币ETF减持42.88%至198.4024万份（价值5494万美元），Bitwise Solana质押ETF增持至87.5407万份（价值1414万美元），Bitwise XRP ETF新建仓位40.275万份（价值670万美元）。

## 推荐理由

读者可对比机构持仓变化，分析比特币ETF与其他加密资产ETF的配置策略差异。
