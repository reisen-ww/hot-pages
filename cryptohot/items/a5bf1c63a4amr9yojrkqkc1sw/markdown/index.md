# 极狐全系车型推出换电版，宁德时代换电站目标6000座

## 摘要

极狐宣布为贝塔、阿尔法和问道三大系列全系车型推出换电版，其中贝塔S3和T1换电版月租399-599元。极狐10月销量环比增长22.3%，前10个月累计销量达16.18万辆。宁德时代计划2027年建成6000座换电站，已扩展至200座城市，并计划沿高速布局1000座。双方通过车企渠道和地方国资合作降低建站成本。
