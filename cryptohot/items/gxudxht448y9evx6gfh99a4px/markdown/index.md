# Anthropic史上最大IPO募资直投计算基础设施

> 原标题：Anthropic’s record IPO haul is headed straight into compute

- 发布时间：2026-11-19T17:20:28.000Z

## 摘要

Anthropic宣布完成史上最大规模IPO，共募资1073亿美元（IPO 81.3亿+私募26亿），其中707亿美元需在12个月内支付。资金将用于扩展计算基础设施，合作伙伴包括Google、Nvidia等。公司现有储备112亿美元，但长期支出901亿美元远超募资金额，需关注未来融资及现金流情况。

## 推荐理由

读者可对比历史IPO规模与资金用途，分析AI企业长期财务风险。
