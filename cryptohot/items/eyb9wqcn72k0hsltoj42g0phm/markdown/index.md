# Zcash完成NU7主网升级，出块时间缩短至25秒

## 摘要

Zcash宣布NU7主网升级于区块3543405激活，将目标出块时间从75秒缩短至25秒，并减少每区块补贴至三分之一。升级还引入网络可持续发展机制，将60%交易费存入储备，矿工保留40%。四年减半计划和2100万枚供应上限保持不变。
