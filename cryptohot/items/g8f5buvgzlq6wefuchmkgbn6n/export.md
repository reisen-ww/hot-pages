## 摘要

Lighter 官方披露 API 密钥泄露事件导致约500万美元 USDC 被盗，已通过智能合约 Guardian 暂停提现并追回资金。安全措施包括 API 密钥 IP 白名单、权限分级配置及 Nonce 重复使用监测，建议用户优先使用官方 SDK 避免风险。
