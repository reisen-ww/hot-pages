## 摘要

BTCPay Server 发布紧急安全更新修复五个Nginx漏洞。漏洞可能允许未登录攻击者远程执行恶意代码，已验证存在利用案例。建议用户通过维护设置或Docker安装更新，暂时无法更新的用户可参考项目提供的临时应对方案。此前8月和11月已发生两次利用不同漏洞的攻击事件导致加密货币被盗。
