# 货船在霍尔木兹海峡沉没，伊朗加大对商船袭击

## 摘要

新加坡注册集装箱船 GFS Pride 在霍尔木兹海峡遭不明投射物击中起火后沉没，21名船员全部获救且无人受伤。伊朗革命卫队称该船触雷，但海事安全机构表示暂无独立证据确认这一说法。本月已有20多艘船只在相关海域遭袭，霍尔木兹海峡原油运输量截至10月12日当周平均为每天850万桶，较伊朗战争前正常水平低近40%。

## 推荐理由

文章结合船只遇袭、航运受阻与原油流量数据，呈现霍尔木兹海峡安全局势对区域能源运输的影响。
