# Index Industries完成5000万美元种子轮融资

## 摘要

Index Industries宣布完成5000万美元种子轮融资，由Lightspeed Venture Partners领投，Polychain Capital等参投。该公司通过代币化技术将美国住房转化为可投资资产类别，首个产品为美国房价基准指数USHP Index。
