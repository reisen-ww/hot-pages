# 南宁太阳纸业注册资本增至40亿元 增幅33%由母公司全资持股

## 摘要

南宁太阳纸业注册资本由30亿元增至40亿元，增幅约33%，由山东太阳纸业全资持股。该公司成立于2022年2月，法定代表人为李洪信，主营纸制造、纸制品制造及纸容器制造。
