# 谷歌因欧盟法院顾问支持 AdSense 罚款面临挫折

## 摘要

欧盟法院顾问Juliane Kokott建议推翻2024年对谷歌AdSense业务的罚款撤销决定，要求重审案件。该案件涉及2019年欧盟委员会对谷歌的1.49亿欧元（约$1.7亿）反垄断罚款，原裁决认为谷歌通过排他性合同维持市场支配地位。此建议可能使谷歌面临重新缴纳罚款或金额调整，并影响欧盟未来针对科技巨头的反垄断执法路径。

## 推荐理由

欧盟法院顾问意见可能影响谷歌未来在欧盟的罚款金额及类似案件处理方式
