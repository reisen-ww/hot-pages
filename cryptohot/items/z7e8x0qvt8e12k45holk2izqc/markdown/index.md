# Anthropic 七位创始人将在 IPO 中各套现约 2.5 亿美元

- 来源：链捕手 ChainCatcher
- 发布时间：2026-11-11T01:14:08.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/z7e8x0qvt8e12k45holk2izqc
- 原文：https://www.chaincatcher.com/article/2303564

## 摘要

Anthropic 在新提交的 S-1 文件中披露，七位联合创始人计划在 IPO 中分别出售约 337.8 万股，按每股 74 美元的中间价计算，每人将获得略低于 2.5 亿美元；公司 IPO 估值可能达到 1.4 万亿美元。
