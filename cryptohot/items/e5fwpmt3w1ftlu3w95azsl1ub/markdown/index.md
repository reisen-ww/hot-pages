# 新加坡10月非石油出口同比增79.8%，创数十年来新高

- 来源：界面新闻
- 发布时间：2026-11-17T09:42:14.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/e5fwpmt3w1ftlu3w95azsl1ub
- 原文：https://www.jiemian.com/article/15342665.html

## 摘要

新加坡10月非石油国内出口同比大增79.8%，远超预期的37.7%，显示强劲的贸易表现。电子产品和非电子类商品出口均显著增长，延续了今年以来的趋势，受益于全球科技周期。
