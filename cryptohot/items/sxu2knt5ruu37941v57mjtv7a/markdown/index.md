# 币安冻结MEXC资金往来 规避即将生效的美国制裁禁令

## 摘要

币安宣布即日起禁止与MEXC及其关联公司进行资金往来，以规避即将生效的美国制裁禁令。美国财政部（FinCEN）11月6日发布禁令，指控MEXC Global 2021-2026年间通过加密资产转移至少16.7亿美元至俄罗斯非法金融活动。

## 推荐理由

币安主动冻结MEXC资金往来，揭示美国制裁对跨境加密交易的影响机制
