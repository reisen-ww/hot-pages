# Anthropic启动拟议首次公开募股路演

- 来源：界面新闻
- 发布时间：2026-11-10T15:05:01.000Z

## 摘要

Anthropic宣布启动拟议IPO路演，计划发行8.25亿股A类普通股（其中8.014亿股由公司自购，2365万股由现有股东出售），定价区间每股70至78美元，承销商为高盛和摩根士丹利，拟于纳斯达克全球精选市场上市（股票代码ANT）。
