# CFTC拟将事件合约纳入掉期定义并排除赌场式赌博

## 摘要

CFTC周五发布两项措施，拟将涵盖体育、政治、文化活动和天气的事件合约明确纳入“swap”定义，同时通过立即生效的临时最终规则，将体育博彩和赌场游戏等赌场式赌博产品排除在外。两项措施均设有30天征求意见期，相关规则可能影响 Kalshi 和 Polymarket 面临的州级赌博监管诉讼。
