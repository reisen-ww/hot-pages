# CFTC报告：比特币期货投机者净多头增至2,375份合约

## 摘要

CFTC最新持仓报告显示，投机者持有的比特币期货净多头增至2,375份合约（较前一周+145份），杠杆基金维持净空头，资产管理人仍为净多头。报告指出截至11月3日总持仓量降至17,527份合约，显示市场谨慎情绪。同时比特币价格维持在8.2万美元以上，机构比特币ETF持仓兴趣持续增长，综合判断市场短期看涨但需关注波动风险。
