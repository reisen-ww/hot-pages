# 海正药业与炫景生物签署小核酸授权合作协议

- 来源：界面新闻
- 发布时间：2026-11-14T09:17:11.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/quov2hgu1vq4cx6ykn9qinawh
- 原文：https://www.jiemian.com/article/15333557.html

## 摘要

浙江海正药业股份有限公司与苏州炫景生物科技有限公司签署合作协议，授权海正药业在心血管、代谢和呼吸病领域利用炫景生物的小核酸技术平台开发药物，并获得一款肝靶向siRNA药物RGN6669的后续开发和商业化权利。
