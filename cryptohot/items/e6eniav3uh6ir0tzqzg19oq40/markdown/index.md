# 英特尔与首家外部客户签约 18A 芯片制造协议

> 原标题：Intel signs first external customer for advanced 18A chips

## 摘要

英特尔宣布与首家外部客户达成18A芯片制造协议，未具名客户可能为英伟达、苹果或云服务巨头。同时，微软成为其最先进封装技术EMIB的首个公开客户。此前英特尔因营收不及预期股价暴跌，此次合作被视为其在半导体制造领域的突破。
