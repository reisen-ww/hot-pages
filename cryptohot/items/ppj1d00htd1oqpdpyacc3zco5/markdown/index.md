# 中信建投建议2027年布局证券行业头部集中与高弹性双主线

## 摘要

中信建投预计2027年证券行业将受益于自营配置化、财富管理化和出海多元化，建议投资者关注头部券商和高弹性标的。2026年前三季度，42家上市券商营收和净利润分别同比增长18.7%和23.76%，ROE升至7.9%。
