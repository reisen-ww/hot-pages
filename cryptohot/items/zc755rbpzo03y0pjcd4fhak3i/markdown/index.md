# 芒果TV《后会友期》带动市值6天暴涨60.54%，AI短剧冲击下盈利承压

## 摘要

芒果TV旗下综艺《后会友期》在11月8日正片有效播放市场份额达47%，带动市值6天累计上涨60.54%（约250亿元），但AI短剧冲击下，2026年上半年互联网视频业务营收同比下降8.61%，净利润同比下滑79.01%。文章分析芒果通过电视台基因与互联网平台结合提升内容竞争力，同时面临用户覆盖不足、广告收益下滑及AI短剧分流市场的挑战。
