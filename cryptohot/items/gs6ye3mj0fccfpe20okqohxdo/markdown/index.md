# 美国ITC终裁：部分终止电池负极材料337调查

> 原标题：美国ITC发布对用于电池电芯和电池的负极材料的337部分终裁

## 摘要

美国国际贸易委员会（ITC）2026年11月10日发布公告，终裁部分终止对特定电池负极材料（337-TA-1513）的调查。该调查原由Sila Nanotechnologies等美国机构于2026年6月18日提出，指控中国浙江Carbon One等企业侵权多项美国专利。ITC基于申请方撤回部分专利主张，维持对其他专利的有限排除令和禁止令要求。
