# 巴西交易所Mercado Bitcoin称将承担4000万美元被盗损失

- 来源：PANews
- 发布时间：2026-11-02T16:57:26.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/th8kst8av83x3j006axh3rfvy
- 原文：https://www.panewslab.com/zh/articles/01a19d31-c356-7649-ab02-30c1e5219aa5

## 摘要

巴西交易所Mercado Bitcoin宣布将自行承担4000万美元黑客攻击造成的损失，称已控制事件并正在追踪资产。彭博社数据显示，攻击者目前持有约4650万美元加密资产（含3677枚ETH、106枚BTC及800万美元稳定币），但客户资金未受影响。交易所表示将与相关部门协调处理。
