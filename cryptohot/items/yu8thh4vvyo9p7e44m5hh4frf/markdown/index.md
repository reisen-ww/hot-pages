# Supermicro发布H15服务器，搭载AMD第六代EPYC 9006芯片

> 原标题：Supermicro ships H15 servers built on AMD’s sixth-gen EPYC 9006 chips

## 摘要

Supermicro宣布开始发货基于AMD EPYC 9006 Venice芯片的H15服务器系列，单插槽最高支持256核/512线程，配备16通道DDR5-8000内存和PCIe 6.0接口。该产品线性能较前代提升1.7倍，并支持AMD Instinct GPU和Pensando网络技术。对数据中心买家而言，其高密度设计可减少服务器数量需求，但需注意600W/插槽的功耗对冷却系统的要求。

原文给出了H15服务器核心配置参数（256核/512线程/DDR5-8000内存/PCIe 6.0支持）和性能提升幅度（1.7倍），读者可据此评估其对AI推理和云计算场景的硬件选型影响。
