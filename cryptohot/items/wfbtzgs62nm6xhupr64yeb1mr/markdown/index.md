# 欧洲央行发布基于AI的Reddit投资者情绪追踪工具

> 原标题：The ECB built an AI tool that reads Reddit to track retail investor mood

- 来源：Crypto Briefing
- 发布时间：2026-11-12T10:17:38.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/wfbtzgs62nm6xhupr64yeb1mr

## 摘要

欧洲央行发布基于AI的Reddit投资者情绪追踪工具，显示市场下跌期间与次日标普500回报的相关性提升3.4倍。该工具基于ChatGPT-5.1模型分析2015年至2026年4月间14个Reddit投资版块约890万条帖子，并与FinBERT等专业模型对比，证明其在非正式文本处理上的优势。研究指出工具适用于多资产类别的早期市场预警。
