# Trezor宣布将默认使用更安全的stateless签名方案应对量子计算威胁

## 摘要

Trezor CTO Tomáš Sušánka表示将考虑将更安全的stateless签名设为默认设置并隐藏高风险stateful选项，同时硬件设备需升级量子抗性认证。原文提到Trezor Safe 7已支持量子抗性钱包认证，但交易量子安全需比特币主网升级。
