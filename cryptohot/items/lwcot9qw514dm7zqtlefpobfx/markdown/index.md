# 微软申请专利：利用闲置计算能力训练AI

> 原标题：Microsoft patent filing describes paying users for idle computing power to train AI

- 发布时间：2026-11-11T19:30:41.000Z

## 摘要

微软申请了一项专利，设想在用户不使用设备时利用其闲置的图形处理能力进行AI训练，并可能对设备主人进行补偿。该专利描述了一种系统，能够将大规模训练任务拆分成小任务分配给闲置的设备，同时确保不会干扰用户的正常使用。然而，专利中并未明确提及具体的补偿机制。
