# 青岛港以19.18亿元全资收购董家口矿石码头公司

> 原标题：鲁股观察 | 三方股东同步退出，青岛港19.18亿收回董家口矿石码头

## 摘要

青岛港宣布以19.18亿元收购董家口矿石码头公司70%股权，使其持股比例升至100%。交易前青岛港持有董矿公司30%股权。董矿公司近年持续亏损（2025年亏损1.10亿元，2026年前8个月亏损3844万元），但青岛港2026年前三季度实现营收154.74亿元、净利润41.49亿元。收购后董矿公司资产、业务及报表将并入青岛港体系，强化其在大宗干散货领域的运营控制权。
