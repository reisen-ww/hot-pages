# 美联储主席哈马克重申加息节奏警告通胀失控或致加速提息

## 摘要

美联储克利夫兰联储主席哈马克在11月16日采访中重申倾向于小步加息，警告若通胀预期失控可能被迫提速。她指出当前通胀由关税余波、能源供给、AI基建需求及非AI经济增长共同驱动，并提到辖区劳动力招募困难或预示市场收紧。哈马克强调企业成本转嫁能力显示需求未受压制，同时肯定长期通胀预期锚定在2%目标，为政策留出决策空间。
