# NVIDIA股价因财报超预期仍下跌36%

## 摘要

NVIDIA在2027财年第三季度财报中收入115.8亿美元，调整后每股收益2.68美元，均超分析师预期，但股价仍下跌36%。公司预计2027财年第四季度收入达130亿美元，但未包含中国数据中心业务，反映地缘政治和监管挑战。

## 推荐理由

原文指出NVIDIA Q4收入预测未包含中国数据中心业务，反映地缘政治和监管挑战可能影响其增长前景。
