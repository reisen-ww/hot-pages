# 英特尔财报电话会：服务器CPU供不应求，2026-2027年出货量年增超30%

> 原标题：英特尔：服务器CPU供不应求，预计出货量将在2026年和2027年均增长超过30%

## 摘要

英特尔在2026年第三季度财报电话会议上表示，数据中心业务成Q3增长核心，服务器CPU供不应求。CFO David Zinsner指出工厂网络和外部供应商支持了产出提升，预计DCAI全年收入较年初预期高出近100亿美元。公司同时预测行业服务器CPU出货量将在2026和2027年均增长超过30%，若供应改善增速将进一步提升。

## 推荐理由

英特尔通过财报电话会议披露了服务器CPU的供需数据，为观察行业供应链动态提供直接信源。
