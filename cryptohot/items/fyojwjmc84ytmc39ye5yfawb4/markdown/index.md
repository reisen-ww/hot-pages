# 德勤收购Flipside AI业务后成立Edisyl公司

## 摘要

德勤收购Flipside AI业务后成立Edisyl公司，推出基于区块链数据分析的AI知识包解决方案。Flipside于2026年5月将区块链数据业务出售给SonarX，其AI团队（含原CEO Dave Balter）于7月被德勤收购，并于11月正式成立Edisyl。该方案通过专家标注的领域知识包与公司私有数据结合，解决AI模型在需要专业判断场景下的准确性问题。
