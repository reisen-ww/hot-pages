# 洲际交易所推出数据中心建设风险评估工具

## 摘要

洲际交易所推出ICE Data Center Site Analytics Tool，评估美国3100多个县的数据中心项目建设可行性及延期风险，预测未来24个月项目中断概率，历史回测准确率达77%。对于投资额中位数为27亿美元的项目，延期12个月可能增加1.62亿至2.7亿美元的成本。
