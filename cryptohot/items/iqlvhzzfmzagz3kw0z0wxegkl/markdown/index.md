# 纽约梅隆银行与城堡证券完成代币化美债三方回购交易

- 来源：PANews
- 发布时间：2026-10-13T20:51:00.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/iqlvhzzfmzagz3kw0z0wxegkl
- 原文：https://www.panewslab.com/zh/articles/01a13709-9cb6-740c-bad9-ffb28b5030fa

## 摘要

纽约梅隆银行与城堡证券完成一项使用代币化美国国债的三方回购交易，相关资产在主要三方回购平台上投入使用。城堡证券通过BNY在Tradeweb平台购买一张2年期美国国债，其代币化表示记录在BNY私有数字账本上，并在数分钟内完成结算；随后该国债被用作隔夜三方回购融资抵押品，由BNY提供现金。BNY计划推出更多数字现金和代币化存款功能，并预计明年将传统结算平台的运营时间延伸至欧洲和亚洲交易时段。

## 推荐理由

交易展示了代币化美国国债在三方回购中的具体用法，并对比了数分钟结算与标准T+1周期的差异。
