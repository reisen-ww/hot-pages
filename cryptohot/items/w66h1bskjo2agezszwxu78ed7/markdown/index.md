# 蚂蚁国际推出Whale编排协议，连接代币化存款与货币市场基金

## 摘要

蚂蚁国际推出Whale编排协议，连接代币化存款与货币市场基金。该协议已与星展银行、富兰克林邓普顿完成试点交易，将星展财资代币（DBS Treasury Tokens）及富兰克林邓普顿的代币化货币市场基金方案接入，缩短结算等待时间并支持企业实时调配闲置资金。三方联合发布白皮书，介绍协议框架及跨账本即时交易结算应用。

## 推荐理由

该协议通过缩短结算时间，可能提升企业资金使用效率，为代币化金融工具提供可复用的原子结算框架。
