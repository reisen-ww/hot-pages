# Luxor因Commander漏洞致客户算力被转移并启动赔偿

## 摘要

Luxor于11月15日通过X披露，其挖矿管理软件Commander遭AI攻击导致客户算力被转移至第三方矿池，承诺全额赔偿。公司称漏洞在2小时内修复，并已暂停新功能开发以强化安全，未泄露用户数据。
