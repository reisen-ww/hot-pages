# Visa将西联汇款稳定币USDPT纳入VisaNet结算资产

- 来源：PANews
- 发布时间：2026-11-12T16:39:09.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/x4wfgx0a5iqoleytf3ts8jft5
- 原文：https://www.panewslab.com/zh/articles/01a1d0a0-9f8b-769f-bbce-9a7cdcaebaac

## 摘要

Visa将西联汇款稳定币USDPT纳入VisaNet结算资产。USDPT由Anchorage Digital Bank发行并托管，于今年5月在Solana链上推出，合作方将建立框架评估更多稳定币接入VisaNet的可能性。

## 推荐理由

USDPT成为VisaNet结算资产的首个稳定币，Anchorage与Visa合作将评估更多稳定币接入可能性。
