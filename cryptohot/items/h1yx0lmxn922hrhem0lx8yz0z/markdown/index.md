# 欧元区9月工业产出环比增长0.2%

- 来源：界面新闻
- 发布时间：2026-11-17T13:46:59.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/h1yx0lmxn922hrhem0lx8yz0z
- 原文：https://www.jiemian.com/article/15343456.html

## 摘要

欧盟统计局11月16日公布数据显示，2026年9月欧元区工业产出环比增长0.2%，结束连续三个月下滑。分行业看，耐用消费品产出环比增1.3%，中间产品增0.7%，能源产出环比降1.7%。
