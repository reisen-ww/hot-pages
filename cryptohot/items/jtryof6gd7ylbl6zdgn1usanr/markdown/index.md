# AARP研究报告：社保税基调整或延长支付期限至2059年

> 原标题：Social Security could pay full benefits until 2059 if taxable payroll kept pace with GDP: AARP report

## 摘要

AARP研究显示，若保持1983年41%的社保税基/GDP比例，美国社保资金可支撑至2059年，较当前2034年预测延长25年。主要挑战包括：1）工资占比从41%（1983）降至34%（2025）；2）自动化与商业收入结构变化导致税基萎缩；3）工人与受益者比例从3.4降至2.4（2000-2030）。

## 推荐理由

对比研究显示，若维持1983年社保税基占GDP比例，美国社保资金可支撑至2059年，较当前2034年预测延长25年，为政策制定提供数据参照。
