# Gamehaus拟控股Anamana：AI原生微短剧平台纳入战略布局

> 原标题：致力打开AI原生娱乐集团的新边界，Gamehaus创始人致信股东公司“新方向”

## 摘要

Gamehaus宣布拟控股AI原生微短剧平台Anamana约56%股权，交割后Anamana将作为主要增长引擎，战略转向AI原生娱乐集团，协同发行与制作能力。收购基于AI将改变微短剧制作方式的判断，Anamana通过AI工具降低97%制作成本，计划连接创作者、内容与用户。
