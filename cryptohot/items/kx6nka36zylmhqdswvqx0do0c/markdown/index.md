# AI PC带飞联想戴尔毛利率，全球PC出货量同比降20.1%

> 原标题：PC出货大跌两成，但头部厂商反而越赚越多

- 发布时间：2026-11-19T09:17:19.000Z

## 摘要

IDC数据显示2026 Q3全球PC出货量同比降20.1%，但联想营收增长18%净利润增36%，戴尔股价涨幅达259%。厂商通过AI PC（如联想YOGA Pro 15 RTX Spark定价42999元）与硬件提价（PC平均售价上涨20%）实现盈利，同时供应链回流我国（惠普、戴尔代工订单转立讯精密、华勤技术）。

## 推荐理由

原文通过IDC、Omdia、高盛等机构数据，结合联想、戴尔等厂商财报与供应链调整案例，揭示AI PC如何重构PC行业盈利逻辑及厂商战略选择。
