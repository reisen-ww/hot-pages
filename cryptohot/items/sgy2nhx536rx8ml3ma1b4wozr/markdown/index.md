# IBM 将于 2027 年推出 520 超导量子比特处理器

> 原标题：IBM Targets 520 Qubits With Next Nighthawk Processor

- 发布时间：2026-11-11T12:11:37.000Z

## 摘要

IBM 计划在 2027 年推出新的 Nighthawk 处理器，目标达到 520 超导量子比特。开发者目前可以使用新的量子-经典工作流，但处理器设计仍在开发中。
