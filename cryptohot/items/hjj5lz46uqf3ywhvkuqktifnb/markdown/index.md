# 马斯克回应 AI 算力需求：SpaceX 假设对 OpenAI 销售额为零

- 发布时间：2026-11-18T10:06:20.000Z

## 摘要

马斯克表示 SpaceX 在预测时假设对 OpenAI 的销售额为零，认为 OpenAI 产品若未见快速增长则存在问题。OpenAI CEO Sam Altman 称多家芯片制造商预计 OpenAI 等机构将购买其大部分产品，但数据中心容量有限，无法全数采购。
