# 上海迪士尼启动官方合作酒店项目，牵手邻家美利亚酒店

## 摘要

上海迪士尼度假区启动官方合作酒店项目，首家合作酒店为邻家美利亚酒店，提供“客房+乐园一日票+早享卡”组合套餐。迪士尼现有自营酒店仅1620间客房，难以覆盖高峰期全部住宿需求，合作酒店可补充更多价格区间和住宿选择。
