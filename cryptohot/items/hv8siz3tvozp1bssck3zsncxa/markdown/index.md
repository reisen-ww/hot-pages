# 美国财政部制裁柬埔寨太子集团关联4名个人及41家实体

- 发布时间：2026-11-06T01:37:57.000Z

## 摘要

美国财政部制裁柬埔寨太子集团关联4名个人及41家实体，涉及跨国网络诈骗与数字资产洗钱。被制裁者包括Qiu Yong、Zhao Mengyao等个人及香港、英属维尔京群岛等地离岸公司。犯罪手法包括数字资产投资骗局和杀猪盘，累计非法收益达数十亿美元。

## 推荐理由

原文揭示了美国财政部针对柬埔寨太子集团跨国犯罪网络的制裁细节，包括被制裁个人及实体数量、主要犯罪手法（数字资产投资骗局、杀猪盘）和涉案金额（数十亿美元）。
