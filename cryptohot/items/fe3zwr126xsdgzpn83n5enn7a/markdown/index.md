# 币安热钱包遭攻击 14895.59枚ETH被兑换为BTC

## 摘要

币安热钱包遭攻击，24小时内14895.59枚ETH被兑换为BTC。攻击者通过94笔交易将12,000枚ETH分散至11个地址，其中约11773.6枚ETH经Thorchain跨链兑换为BTC，剩余226.3枚ETH转入以太坊新地址。事件涉及0x2763b7244b37febefb220864b6a89f7c2e69af81攻击者地址。
