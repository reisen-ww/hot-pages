# 特斯拉发函要求整改破解FSD评测，第一电动网CEO拒绝撤稿

## 摘要

特斯拉要求第一电动网立即停止破解FSD V14评测并下架相关内容，否则将报案。事件源于长沙智驾大赛中，第一电动网使用非官方激活的FSD V14进行评测，引发法律争议。评测显示FSD V14在复杂路况表现优于本土方案，但暴露本土数据训练不足问题。
