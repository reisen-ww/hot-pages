# Ledger 首席技术官 Charles Guillemet 即将离职

- 发布时间：2026-11-19T16:18:03.000Z

## 摘要

Charles Guillemet 计划在 Ledger 工作九年之后离职，专注于新的安全项目。Guillemet 期间领导 Ledger 从初创公司成长为独角兽企业，期间披露了大量行业安全漏洞，并推动了 Ledger 的多项产品和服务发展。
