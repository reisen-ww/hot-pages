# LangChain 完成C轮融资估值达30亿美元 用户数突破7000家

## 摘要

LangChain宣布完成C轮融资估值达30亿美元 用户数突破7000家。本轮融资由CapitalG领投，估值较上次融资增长2.4倍。LangSmith作为其核心平台，已服务NVIDIA、Salesforce等企业客户，帮助Workday将AI代理部署时间从5个月缩短至1天。公司计划将资金用于扩大LangSmith团队至850人，并计划于2026年11月20日发布新功能。
