# 美国证券业协会将 Solana 纳入华尔街代币化计划，目标 2027 年推出

## 摘要

美国证券业协会（DTCC）宣布将 Solana 公链纳入华尔街代币化证券计划，目标 2027 年推出。该计划涵盖代币化股票、ETF 和美国国债，通过 Solana 的 Layer2 扩展提升交易效率。
