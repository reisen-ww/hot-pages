# 美国金融犯罪执法局（FinCEN）拟对商业账户实施更严格身份验证规则

> 原标题：FinCEN Proposes Tighter ID Rules for Business Accounts

## 摘要

美国金融犯罪执法局（FinCEN）提出对商业账户实施更严格身份验证规则，明确禁止使用ITIN作为受益所有人身份证明，并允许基于风险的身份审查，但暂不将金融服务业务纳入监管范围。
