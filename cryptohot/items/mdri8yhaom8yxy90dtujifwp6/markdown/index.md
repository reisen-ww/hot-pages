# 币安数据显示AI及DeFi代币持续流出，低流动性币种逆势流入

> 原标题：Binance data shows AI and DeFi tokens leaving the exchange while low-liquidity coins flow in

- 发布时间：2026-11-17T16:10:45.000Z

## 摘要

币安数据显示AI及DeFi代币持续流出，低流动性币种逆势流入。分析指出，HOT、GRT、LINK、FET、AXS等高质代币出现净流出，而GTC、YFI、CHZ等低流动性币种接近流入阈值，BTC和ETH呈现小幅波动。研究强调需结合交易量与价格趋势判断市场动向，避免单一数据误导决策。
