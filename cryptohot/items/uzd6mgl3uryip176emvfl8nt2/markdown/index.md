# 日本央行行长：通胀取得阶段性胜利，暗示年内仍可能加息

- 来源：华尔街见闻
- 发布时间：2026-10-30T07:09:08.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/uzd6mgl3uryip176emvfl8nt2

## 摘要

日本央行宣布维持政策利率1.25%不变，但行长植田和男表示潜在通胀已接近2%目标，暗示年内可能加息。同时宣布明年ETF年减持规模提升至8600亿日元，市场对12月加息预期升温。鹰派委员Hajime Takata反对维持利率决定，主张直接加息至1.5%。植田和男强调需持续观察工资增长机制对通胀的支撑作用，并指出央行将主动引导通胀稳定在2%附近而非被动应对。
