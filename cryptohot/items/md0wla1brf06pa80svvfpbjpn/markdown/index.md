# AVA基金会与Travala推出AVA 3.0版本强化代币在旅游场景的效用

## 摘要

AVA基金会与Travala宣布推出AVA 3.0版本，旨在强化代币在旅游预订平台的应用。已累计回购5,604,414枚AVA，其中779,691.92枚永久锁定于Travala的‘AVA战略储备库’。

## 推荐理由

原文提供了AVA基金会回购代币的具体数量（5,604,414枚）和锁定比例（1.1%），读者可据此评估其对市场流通量和Travala平台服务的影响。
