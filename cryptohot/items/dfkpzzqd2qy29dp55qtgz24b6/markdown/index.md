# Nvidia 财报发布前夕科技股抛售拖累比特币跌破6.4万美元

## 摘要

Nvidia 财报发布前夕科技股抛售导致比特币价格跌破6.4万美元，24小时内维持窄幅震荡。Nvidia 股价在财报前下跌3%至150美元后反弹至155美元，比特币从7.2万美元高位回落至7.125万美元，触发超16亿美元清算（82%为多头平仓）。同时美国现货比特币ETF单日净流入790万美元，但市场仍缺乏明确资金动向信号。
