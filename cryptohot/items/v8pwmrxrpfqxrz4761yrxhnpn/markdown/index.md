# Team Group CEO 警告内存芯片短缺将持续至2027年中

> 原标题：Team Group CEO warns memory chip shortage will worsen through mid-2027

## 摘要

Team Group CEO 陈国祥在2026年11月2日财报电话会议上警告，全球内存芯片短缺将加剧至2027年第二季度结束，并预测供需平衡最早可能出现在2028年下半年。公司计划通过新建工厂将产能提升约50%，但当前短缺主要因上游厂商转向HBM等高端产品，导致主流DDR4等芯片供应不足，现货价格较合同价溢价30%-50%。
