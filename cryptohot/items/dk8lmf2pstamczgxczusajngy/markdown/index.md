# 美联储官员Barr：AI对收入分配的影响仍是开放性问题

> 原标题：Fed’s Barr says AI’s effect on who gets paid is still an open question

## 摘要

美联储官员迈克尔·巴勒（Michael Barr）提出AI可能改变收入分配格局的两种路径：渐进式采用提升生产力共享收益，或快速替代劳动力加剧资本收益集中。当前数据显示美国非农部门劳动收入占比已降至52.8%历史低位，但AI对就业市场的实际影响仍不明确。巴勒指出美联储货币政策工具难以解决结构性收入分配问题，若AI导致就业市场失衡可能引发政策应对困境。

## 推荐理由

原文给出了两种AI对收入分配的潜在影响路径及对美联储政策工具局限性的分析，读者可据此理解当前经济结构转型中的政策挑战。
