# 以太坊上K3 Capital sBOLD金库遭攻击，约343万美元被窃取

- 发布时间：2026-11-18T12:53:52.000Z

## 摘要

以太坊上K3 Capital的sBOLD金库遭攻击，约343万美元资金被窃取。攻击者利用闪电贷和自清算机制低价铸造sBOLD份额并赎回抵押品，目前攻击仍在持续。
