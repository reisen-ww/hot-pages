# 比亚迪计划在葡萄牙建设欧洲首个电芯工厂

> 原标题：全球储能第一的比亚迪，把欧洲第一家电芯工厂选在了葡萄牙

## 摘要

比亚迪正与葡萄牙政府洽谈在马托西纽什建设电池工厂，占地约240公顷的原炼油厂地块预计2026年底完成拆除和土壤修复。2025年，比亚迪全球储能系统出货量超过60GWh，市占率13%，超越特斯拉登顶全球第一。然而，比亚迪在欧洲尚未建立电芯工厂，新工厂的建设将填补这一空白，助力其储能业务在欧洲市场的发展。
