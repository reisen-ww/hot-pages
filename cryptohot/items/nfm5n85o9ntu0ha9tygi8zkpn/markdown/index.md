# Anthropic IPO草案：上半年营收163亿美元，净亏损807亿美元

- 来源：PANews
- 发布时间：2026-10-20T19:58:04.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/nfm5n85o9ntu0ha9tygi8zkpn
- 原文：https://www.panewslab.com/zh/articles/01a15ae4-7632-7432-8dee-fead3e2b8e2f

## 摘要

Anthropic 提交的 S-1 注册声明草案显示，其 2026 年上半年营收 163 亿美元，去年同期为 11 亿美元；上半年净亏损 807 亿美元，去年同期亏损 130 亿美元，亏损主要来自融资相关的非现金会计费用。

## 推荐理由

该S-1草案给出了Anthropic的收入、亏损与算力承诺结构，读者可据此理解其IPO前的成本压力和资本需求。
