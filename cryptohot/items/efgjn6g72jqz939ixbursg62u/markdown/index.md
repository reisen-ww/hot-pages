# 波兰议会以240-202票通过加密资产冻结法案

> 原标题：Poland’s Parliament Votes 240-202 to Let Officials Freeze Crypto Before Court Review

## 摘要

波兰议会以240-202票通过法案，允许官员在法院审查前冻结加密资产。法案基于欧盟MiCA regulation，冻结对象为列入制裁名单的个人或实体，执行机构包括内政部长、金融情报单位等，冻结措施立即生效且不可通过法院暂缓。该法案需经参议院审议和总统签署后生效。
