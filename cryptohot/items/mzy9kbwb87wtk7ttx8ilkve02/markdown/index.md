# 柏川数据完成5000万元Pre-A轮融资，星海图为投资方兼客户

## 摘要

柏川数据宣布完成5000万元Pre-A轮融资，投资方包括元禾厚望、毅峰资本及星海图。融资将用于物理AI数据管线建设等。星海图既是投资方也是客户，正与柏川数据合作研发具身智能相关技术。
