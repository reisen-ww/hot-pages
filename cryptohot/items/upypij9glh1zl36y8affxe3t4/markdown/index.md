# 中国证监会副主席刘浩凌在2026年上海证券交易所国际投资者大会上致辞

- 发布时间：2026-11-12T04:13:45.000Z

## 摘要

中国证监会副主席刘浩凌在2026年上海证券交易所国际投资者大会上致辞，提出资本市场改革措施、开放进展及维护市场稳定的政策工具运用。结构性货币政策工具第三批操作1000亿元，上市公司回购创历史新高，科创板研发投入同比增长26%。
