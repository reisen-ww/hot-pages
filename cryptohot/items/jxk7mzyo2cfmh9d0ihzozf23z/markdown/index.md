# Stacks推出质押比特币借稳定币计划

> 原标题：Stacks unveils plan for Bitcoin holders to borrow stablecoins against staked BTC

- 来源：Crypto Briefing
- 发布时间：2026-11-18T17:06:10.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/jxk7mzyo2cfmh9d0ihzozf23z

## 摘要

Stacks宣布2027年将推出质押比特币借稳定币系统，允许用户保留质押收益并无需出售BTC。当前质押已吸引约1740 BTC，21Shares等机构参与，系统依赖2027共识升级及USDCx流动性提升。
