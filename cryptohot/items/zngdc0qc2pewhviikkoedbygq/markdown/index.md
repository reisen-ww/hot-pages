# 英伟达新加坡子公司营收超千亿美元，利润仅5300万美元引关注

## 摘要

英伟达自2025年起不再单独披露新加坡地域收入，其新加坡子公司2025年营收达1040亿美元但利润仅5300万美元。原标题已明确主体和核心事件，摘要需补充关键数据：2025财年新加坡地域收入236.84亿美元（占集团18%），2026财年Q2新加坡收入102亿美元（占当季22%且同比增81%）。财务数据表明子公司营收与利润严重失衡，引发对跨国企业地域收入统计真实性的质疑。

## 推荐理由

英伟达调整地域收入披露方式后，新加坡子公司营收与利润严重不匹配，揭示跨国科技企业财务透明度与业务实际交付的差异。
