# 中芯国际第三季度净利润同比增长87.6%，多家公司发布回购股份计划

## 摘要

中芯国际第三季度归母净利润28.47亿元，同比增长87.6%。钧达股份终止阿曼5GW高效电池项目，天赐材料拟回购5000万至1亿元股份。多家公司包括大禹节水、昇辉科技、重庆啤酒等宣布回购股份计划，涉及金额从3000万元至1亿元不等。
