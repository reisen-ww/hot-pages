# 索拉纳政策研究所Kristin Smith：展示实际应用胜过技术解释

## 摘要

索拉纳政策研究所总裁Kristin Smith在伦敦Solana Breakpoint会议上表示，向国会展示索拉纳网络的实际应用比技术解释更有效。她认为，日常实用性是说服立法者的最有力手段。Smith强调，新一届国会中约四分之一成员为新当选者，这为数字资产立法提供了机遇。
