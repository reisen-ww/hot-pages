# Morpho发布支持REST API的开发者平台

> 原标题：Morpho unveils new Developer Platform with REST APIs for integration

- 来源：Crypto Briefing
- 发布时间：2026-11-18T14:27:24.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/kvkpcpgyb9k7536akdces9fhc

## 摘要

Morpho于2026年11月18日推出新版开发者平台，首期上线REST API接口以获取协议历史APY和状态数据（需注意：原文明确说明GraphQL接口将于2027年3月终止）。

## 推荐理由

原文指出新平台通过标准化API降低开发者集成成本，并强调非托管架构以缓解监管担忧，读者可评估其对现有项目的影响。
