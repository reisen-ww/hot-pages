# 2026燃气重卡市场前高后低：气价倒挂与政策转向的双重冲击

## 摘要

2026年燃气重卡销量3月达3.2万辆（+48%），9月骤降至7263辆（-69%）。气价从3月3538元/吨飙升至9月6100元/吨，叠加国家发改委等11部门2026年6月政策明确将新能源重卡列为规模化应用核心，导致燃气重卡核心卖点失效。头部企业中国重汽、一汽解放等通过新能源转型和出口扩产对冲国内市场下滑，新能源重卡渗透率9月突破50%。

原文通过气价波动与政策导向对比，揭示新能源重卡抢占市场份额的底层逻辑，读者可据此预判传统能源车辆与新能源的竞争格局变化。
