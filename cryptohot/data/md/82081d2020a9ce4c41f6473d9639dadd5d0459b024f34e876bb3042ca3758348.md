# CoreWeave 宣布推出 PostgreSQL 兼容的 AI 生产应用数据库服务

## 摘要

CoreWeave 宣布推出 PostgreSQL 兼容的数据库服务，旨在帮助 AI 团队管理生产应用数据。该服务运行于 CoreWeave Kubernetes 服务集群，提供高可用性、每日备份和 Kubernetes Operator 管理功能，默认存储为 50GiB，支持至少三个实例确保数据一致性，可通过 Cloud Console、kubectl 或 GitOps 工具管理。
