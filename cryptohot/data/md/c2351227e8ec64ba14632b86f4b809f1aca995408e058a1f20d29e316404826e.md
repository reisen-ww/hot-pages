## 摘要

OpenAI GPT-6.2 Astra 与 Sol 模型分别位列 Code Arena WebDev 排行榜第3、7名，Astra 单任务成本降低42%（从$9.46降至$5.45），Sol 成本降低21%（从$1.84降至$1.45）。两者均位于性能成本帕累托前沿，Astra 在消费产品类别中排名第一，但代理任务分数尚未公布。
