# S&P分析师指出DeFi最大安全风险不在代码本身

> 原标题：S&P Global Ratings analyst says DeFi’s biggest security risk isn’t the code

## 摘要

S&P全球评级机构发布研究报告，指出DeFi最大安全风险来自人类操作而非代码漏洞。研究显示2024年9月至2026年9月间数字资产质押存款增长超600%，但同期因人为失误导致的损失达600亿美元。框架VRA从六个维度评估风险，其中'馆主风险'（ curator risk）和'权限控制'（access control）被列为关键指标，强调审计代码的局限性。
