# Ledger钱包默认行为泄露用户交易数据与设备信息

> 原标题：Ledger’s SDK snitched users’ transaction data and device info

- 来源：Protos
- 发布时间：2026-11-11T19:56:16.000Z
- 金融热点：https://reisen-ww.github.io/hot-pages/cryptohot/items/eki9al72osfrg2z4jxqpm4sfy
- 原文：https://protos.com/ledgers-sdk-snitched-users-transaction-data-and-device-info/

## 摘要

Ledger硬件钱包默认SDK向服务器传输用户交易签名和设备信息（含型号、软件版本、区块链地址）。2020年曾发生27.2万用户隐私数据泄露，近期马来西亚分销商设备遭黑客窃取超860万美元。用户需手动关闭数据共享功能，但多数未操作。Ledger回应称系性能优化需求，但隐私倡导者质疑默认行为合理性。

## 推荐理由

用户交易数据和设备信息被默认传输至Ledger服务器，存在隐私泄露风险，且该公司此前已有大规模数据泄露记录。
