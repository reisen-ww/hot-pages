# Bravo 等在 bioRxiv 发表基于单时点MRI数据的胶质母细胞瘤迁移-增殖比率估计方法

> 原标题：Estimating glioblastoma migration-to-proliferation ratio from single time-point MRI data via radial density distribution

- 来源：bioRxiv
- 发布时间：2026-10-31T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/igsxl9a6zsvyppocnmtoone98
- 原文：https://www.biorxiv.org/content/10.64898/2026.10.26.761772v1?rss=1

## 摘要

Bravo 等开发基于单时点MRI的胶质母细胞瘤迁移-增殖比率（D/k）估计方法，误差低于5%。该方法发现D/k与患者生存率降低（p=0.01）、年龄增长（p=0.04）及KPS评分下降趋势（p=0.059）相关，并在微阵列数据中发现间质样表型与D/k升高显著相关（p=0.013）。

## 推荐理由

该方法误差低于5%，并发现与患者临床特征及分子分型的相关性，为胶质母细胞瘤治疗提供新评估工具。
