# 某团队在bioRxiv发表海马体靶向非侵入式刺激增强运动记忆巩固的研究

> 原标题：Non-invasive temporal interference stimulation targeting the hippocampus enhances fast motor memory consolidation

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/yxfe4othqjxlxy6alh23cknev
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.766003v1?rss=1

## 摘要

首次直接证据表明，海马体靶向非侵入式时间干扰刺激（TIS）在任务休息期可提升运动序列学习短期记忆巩固效果（微离线增益提升显著，p<0.001），但未改善24小时宏观记忆保留（组间差异不显著）。研究通过双盲对照实验（n=64），发现微离线增益与次日表现改善呈正相关（r=0.32, p=0.004）。

## 推荐理由

论文提供了TIS在休息期间增强短期记忆巩固的直接证据，但未显示24小时后的长期效果，读者可据此评估其在不同时间尺度的适用性。
