# ZNF683阳性组织驻留记忆T细胞揭示包体性肌炎耐药性微环境调控机制

> 原标题：ZNF683-positive tissue-resident memory T cells organize treatment-refractory niches with targetable circuits in inclusion body myositis

- 来源：medRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/auy0lx7shn68sumrcwnndxoe2

## 摘要

该研究首次揭示 ZNF683+IL7R+ 组织驻留记忆 T 细胞在包体性肌炎耐药性微环境中起核心作用，并鉴定了 IL-15、XCL1-XCR1 和 HMGB1/CXCL12-CXCR4 等可靶向信号通路。

## 推荐理由

论文提供了包体性肌炎中 ZNF683+TRM 细胞与治疗耐药性的关联机制，并首次提出 HMGB1/CXCL12-CXCR4 信号通路可作为靶向治疗的新方向
