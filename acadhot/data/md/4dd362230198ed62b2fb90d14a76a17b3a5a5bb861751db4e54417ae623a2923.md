# 图宾根大学与马克斯·普朗克研究所联合发表：技术进步未必提升生活标准

> 原标题：Ancient height trends show technological advances did not always improve living standards

- 来源：Phys.org
- 发布时间：2026-11-16T20:00:26.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/zc0gllcs8m6tn16g1ayggnrbh
- 原文：https://phys.org/news/2026-11-ancient-height-trends-technological-advances.html

## 摘要

该研究基于18,457具欧亚大陆骸骨（覆盖45国），通过股骨长度估算身高变化，发现技术进步与生活标准无必然关联。例如中国11世纪引入高产水稻技术，虽维持帝国主导地位，但人口密度增加导致人均蛋白质摄入下降，身高反而降低至19世纪1.48米（女性）和1.60米（男性）。研究同时指出，欧洲和亚洲部分地区中世纪后身高出现下降趋势，可能与农业模式变化相关。
