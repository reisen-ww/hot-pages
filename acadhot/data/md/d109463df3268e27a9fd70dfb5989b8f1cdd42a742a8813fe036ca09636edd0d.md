# 代尔夫特理工大学团队在 Nature 发表研究：首次直接操控单个原子核磁共振

> 原标题：Against all expectations, researchers control the magnetic core of a single atom

- 发布时间：2026-10-28T14:20:08.000Z

## 摘要

代尔夫特理工大学团队在《自然·通讯》（DOI:10.1038/s41467-026-78801-5）发表研究，首次直接操控单个原子核磁共振。实验采用改进的双磁共振技术，区分电子与核磁共振信号，意外发现核磁共振可控性，为量子信息存储提供新方法。arXiv版本：arxiv.org/abs/2512.11652
