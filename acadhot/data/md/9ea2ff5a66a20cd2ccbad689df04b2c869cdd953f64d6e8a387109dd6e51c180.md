# Pâmela Lima团队在Biology Letters发表恐龙公众认知度研究

> 原标题：Why some dinosaurs get all the attention and others don't

- 来源：Phys.org
- 发布时间：2026-11-11T17:00:17.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/v9dl1rjazxkoshquowahm2r69

## 摘要

研究显示《侏罗纪公园》电影显著提升恐龙公众关注度，生物特征影响较小。该团队分析323个恐龙属的体型、食性、生存时代及首次科学描述时间，结合2015-2025年Wikipedia页面浏览量数据，发现电影关联度比生物学特征更关键。
