# SigMatch 评估样本组织如何影响转录组疾病关系

> 原标题：Systematic evaluation using SigMatch reveals how sample tissues shape transcriptomic disease relationships

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

研究表明，现有计算方法未系统考虑样本组织对转录组疾病关系预测的影响。SigMatch 评估了样本组织对基于相关性和排名方法以及重建方法的影响，发现所有方法的预测结果均受样本组织显著影响，去除组织特异性基因并未改善预测结果。这揭示了样本组织在疾病转录组相似性中的重要影响。
