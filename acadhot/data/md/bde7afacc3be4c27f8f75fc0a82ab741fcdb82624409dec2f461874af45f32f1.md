# Microsoft 出现大规模宕机凸显数字基础设施脆弱性

> 原标题：Microsoft outage shows that big tech can't be treated as too big to fail

## 摘要

Microsoft 最近的宕机事件导致全球超过 4.3 亿用户的服务中断，造成经济影响巨大，每日损失可能高达 8 亿美元。这揭示了现代数字基础设施的脆弱性，依赖少数几家大型科技公司，这些公司已成为“太大而不能倒”的存在。为应对这一问题，欧洲正推动数字主权，通过资助去中心化的云基础设施和本土软件，确保本地医院不会因美国科技公司的失败而瘫痪。
