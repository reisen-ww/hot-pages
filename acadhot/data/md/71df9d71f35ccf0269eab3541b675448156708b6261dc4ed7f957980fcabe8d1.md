# 大阪大学团队用改进荧光法首次定量活细胞中蛋白复合体数量

> 原标题：Researchers count kinetochore proteins in living cells using an improved fluorescence-based method

- 发布时间：2026-11-17T15:40:11.000Z

## 摘要

大阪大学团队通过改进荧光相关光谱法，首次定量分析了活细胞中关键蛋白复合体（kinetochore）的分子数量，发现CENP-C与CENP-T存在冗余结合机制。研究证实CCAN和KMN蛋白网络通过双冗余路径连接，即使单个蛋白结合位点失效仍能维持细胞分裂功能。
