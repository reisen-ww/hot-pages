# RAMA数据库发布：整合入侵四足动物基因组大小与入侵数据

> 原标题：RAMA: a global genome size database of invasive tetrapod species

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/xapgbri1g84284njve9djfgp7
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.766098v1?rss=1

## 摘要

RAMA数据库首次整合了3,539种四足动物的基因组大小与入侵成功及影响数据，时间范围为1883至2024年。主要包含物种级基因组数据、入侵记录及全球分布信息，数据格式为CSV。该数据库填补了基因组与入侵研究结合的空白，为预测入侵物种提供新工具。
