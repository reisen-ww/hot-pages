# 昆士兰大学团队用重力发送穿透性通信消息

> 原标题：Physicists send an unblockable message using gravity

## 摘要

昆士兰大学物理团队通过升降机与重力计实验，首次实现重力场编码信息并成功解码，证明重力通信可行性。实验使用1.8吨重物制造重力波动，数据传输率仅1 bit/分钟，但建模显示量子传感器可将距离扩展至500米。该成果发表于Science Advances（DOI:10.1126/sciadv.aee0802），为极端环境通信提供新思路。
