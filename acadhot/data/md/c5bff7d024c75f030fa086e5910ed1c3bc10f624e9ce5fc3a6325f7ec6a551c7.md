# GENESIS-Value框架通过动态记忆检索支持灵活决策

> 原标题：Constructing value on the fly from episodic memory supports flexible decision-making

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/dusqxbgis2ykn6aevk6lyo988
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.18.767634v1?rss=1

## 摘要

研究者提出GENESIS-Value计算框架，通过动态检索和整合记忆实现灵活决策。该框架在五个模拟实验中验证了其能力：重构经验刺激的价值、基于共有特征泛化到新刺激、估计特征值、指导个体与序列选择，以及处理多奖励风险选择。研究还表明检索可结合刺激特征、时间邻近性、提醒和奖励结果等多因素，无需独立价值函数即可适应不同决策需求，并捕捉到情节记忆决策行为中的定性特征。

## 推荐理由

该框架通过动态检索和整合记忆来构建价值，为多场景决策研究提供了可迁移的方法。
