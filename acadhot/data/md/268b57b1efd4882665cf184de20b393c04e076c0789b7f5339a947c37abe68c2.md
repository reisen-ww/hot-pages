# 自动化连续 LLM 驱动生物医学文献挖掘构建大规模肝毒性知识库

> 原标题：Automated Continuous LLM-driven Biomedical Literature Mining for a Large-Scale Hepatotoxicity Knowledge Base

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/qb84xwqk3c993oecw009z5p7v
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.765369v1?rss=1

## 摘要

该研究开发了一种自动化管道，利用大型语言模型（LLM）从生物医学文献中收集肝毒性和线粒体功能干扰的发现，涵盖1995年至2026年的53,575篇文章，记录了17,002种化学物质的189,212个发现，涉及235种至少被20种化学物质报道的生物标志物。初步手动检查显示，99.5%的发现是正确的。该知识库和管道将公开发布。
