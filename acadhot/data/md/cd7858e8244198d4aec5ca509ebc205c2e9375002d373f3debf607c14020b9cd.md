# 小脑与 medial temporal lobe 电路的交互支持上下文推断与结构学习

> 原标题：Structure learning and context inference emerge from next-state prediction in a cerebellar-medial temporal lobe circuit

- 来源：bioRxiv
- 发布时间：2026-11-16T00:00:00.000Z

## 摘要

该研究在动物模型中揭示小脑与 medial temporal lobe 的交互机制，通过 next-state prediction 模型证明：小脑预测误差驱动 medial temporal lobe 更新潜在状态，从而实现上下文推断与结构化知识存储。实验验证了该机制对记忆保存（savings）、突触可塑性（plasticity）及任务反转（reversal task）的调控作用。

## 推荐理由

该研究首次在动物模型中验证了小脑与海马体关联脑区的协同作用机制，为理解人类学习中的上下文推断与结构化知识存储提供了可复现的实验框架。
