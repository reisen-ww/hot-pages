# 某团队在bioRxiv发表Burkholderia cepacia complex新型分型方案

> 原标题：Development of a core genome Multilocus Sequence Typing (cgMLST) and Life Identification Number (LIN) code schema for the Burkholderia cepacia complex

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/mdok1jo5p3heijanigqpzej63
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.10.765358v1?rss=1

## 摘要

某团队开发了Burkholderia cepacia complex的新型分型方案（cgMLST和LIN代码系统），包含1,925个核心基因和14位LIN编码规则。

## 推荐理由

论文提出了基于1,925个核心基因的cgMLST和14位LIN编码系统，验证了其在暴发调查和谱系分析中的应用价值。
