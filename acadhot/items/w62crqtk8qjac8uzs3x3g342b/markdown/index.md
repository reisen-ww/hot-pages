# SubCellSeg 模型在 bioRxiv 发布：通用3D细胞结构分割模型

> 原标题：SubCellSeg: A generalist model for subcellular structure segmentation in 3D fluorescence microscopy

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/w62crqtk8qjac8uzs3x3g342b

## 摘要

Mishra 等在 bioRxiv 发布 SubCellSeg 模型，该模型在 13 种人类iPS细胞 3D 结构分割中平均Dice系数达 0.909，优于专用模型（专用模型平均 0.773）。

## 推荐理由

SubCellSeg 模型在 3D 细胞结构分割中实现 0.909 的平均Dice系数，其零样本泛化能力可跨不同显微镜和细胞类型，且微调效率优于从零训练
