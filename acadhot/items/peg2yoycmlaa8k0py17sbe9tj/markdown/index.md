# 佛罗里达国际大学（FIU）发现睡眠障碍患者丘脑与前扣带回皮层存在特异性脑结构改变

> 原标题：Scientists discover hidden brain changes linked to common sleep disorders

- 发布时间：2026-11-08T04:47:52.000Z

## 摘要

佛罗里达国际大学研究团队通过整合57项脑成像研究，发现失眠症与阻塞性睡眠呼吸暂停（dyssomnias）患者均存在丘脑体积缩小（thalamus pulvinar region），而梦游症等parasomnias患者后扣带回皮层（posterior cingulate cortex）特异性改变。
