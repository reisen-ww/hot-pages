# 巴西圣卡塔琳娜州Rã-Bugio自然遗产保护区树蛙因 ranavirus 病毒导致种群下降83%

> 原标题：Deadly virus reduces tree frog population by 83% in Atlantic Forest reserve

## 摘要

巴西圣卡塔琳娜州Rã-Bugio自然遗产保护区的树蛙因 ranavirus 病毒导致种群下降83%。研究通过组织病理学分析证实病毒是死因，发现病毒载量高达近10亿拷贝/微升，并指出湿度下降至65%可能促进病毒复制和爆发。

## 推荐理由

论文提供了病毒导致种群下降的组织病理学证据，并指出低湿度可能促进病毒复制和爆发。
