# 以人为本设计优化西非肯尼亚高血压药物递送项目实施细节

> 原标题：Human-centered design can optimize operational details of an implementation strategy: Experiences from a peer-based hypertension medication delivery program in western Kenya

- 发布时间：2026-11-10T00:00:00.000Z

## 摘要

一个由22名代表关键利益相关者的团队使用以人为本设计（HCD）方法，开发了高血压药物递送项目的实施策略细节，涵盖同伴招募培训、健康信息技术、药物交付、支付和利益相关者识别五个方面。所有参与者对该策略的接受度和适宜性评分均较高，高血压患者和同伴的评分尤其高，表明该方法有效提升了实施策略的预实施接受度和适宜性。
