# MDPI（中国）材料科学委员会第三次会议召开

## 摘要

MDPI（中国）材料科学委员会第三次闭门会议在南方科技大学召开，聚焦学术期刊集群化建设与AI时代的出版变革，讨论了培育旗舰期刊、完善办刊机制及深化区域学术合作。会议达成多项共识，MDPI将吸纳建议，助力中国材料科学的发展与国际影响力提升。
