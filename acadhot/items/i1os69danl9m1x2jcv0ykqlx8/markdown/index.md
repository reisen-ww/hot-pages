# 美国超大规模数据中心用电量与部分州相当

> 原标题：美国超大规模数据中心的用电量与部分州的总用电量相当

- 发布时间：2026-11-17T06:11:57.000Z

## 摘要

美国超大规模数据中心在2024年5月至2025年4月期间的用电量在68-99 TWh之间，接近印第安纳州、密歇根州和田纳西州等州的年用电量，占美国总用电量的1.8%，产生约2570万公吨的二氧化碳排放。
