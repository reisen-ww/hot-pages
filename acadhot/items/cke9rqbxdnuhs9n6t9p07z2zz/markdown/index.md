# 巴塞罗那自治大学与西班牙国家研究理事会团队首次验证电喷雾室温浓缩牛奶技术

## 摘要

巴塞罗那自治大学与西班牙国家研究理事会团队首次验证电喷雾室温浓缩牛奶技术，将固体含量从12.3%提升至36.8%，且未改变主要蛋白质结构。实验采用29 kV电压和10 cm间距，发现低流速（0.01 mL/min）时浓缩效果显著，但完全脱水仍需优化参数，如流速、电压及多发射点设计。研究团队已启动专利申请，后续将重点验证规模化生产可行性及微生物稳定性。
