# SpaAxFormer：基于轴向变换器的精细空间转录组学基因建模

## 摘要

SpaAxFormer 是一种空间约束的因子化模型，通过轴向变换器在细胞内和细胞间传递基因状态，支持基因表达重构和细胞水平表示的学习。该模型在多个空间转录组学技术上的表现优于基线方法，特别是在背外侧前额叶皮层数据集上效果显著。
