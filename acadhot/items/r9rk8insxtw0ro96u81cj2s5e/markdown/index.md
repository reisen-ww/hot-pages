# 阿拉巴马大学研究团队发现激光解锁晶体隐藏电性能

> 原标题：Physicists use laser light to unlock a crystal's hidden electrical powers

## 摘要

阿拉巴马大学研究团队在《物理评论快报》发表论文，首次通过超短激光脉冲控制晶体中极化纳米域的排列。实验显示在降温过程中纳米域自发对齐，而高温下激光脉冲可在皮秒级（1万亿分之一秒）强制对齐。研究历时三年，涉及日本国家先进工业科技研究所提供的特殊晶体。论文被列为当期编辑推荐，为量子材料信息操控提供了新范式。
