# 全天候增强现实眼镜原型

> 原标题：Metasurface waveguides for all-day augmented reality glasses

- 来源：Nature
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/tu6xglf0xi26juv5upkdw2oww
- 原文：https://www.nature.com/articles/s41586-026-11277-x

## 摘要

一种基于双层超表面波导和三个匹配光栅图案的全天候增强现实眼镜原型，实现了8×8毫米²二维眼盒内的30°视野，同时保持高亮度效率。
