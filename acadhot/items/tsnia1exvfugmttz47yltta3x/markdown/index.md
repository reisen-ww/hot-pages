# Garcia-Diez 等在 bioRxiv 发表 HERC1 调控蛋白酶体稳态的分子机制研究

> 原标题：HERC1-mediated orphan subunit quality control maintains proteasome homeostasis and is disrupted in HERC1-associated neurodevelopmental disease

- 发布时间：2026-11-12T00:00:00.000Z

## 摘要

Garcia-Diez 等通过生物素标记泛素进行定量蛋白质组学分析，发现 HERC1 依赖的 K48 泛素化修饰调控蛋白酶体 19S 复合体亚基（PSMC6/PSME1/PSME2），并揭示其通过选择性识别未组装亚基促进泛素化降解的机制。

## 推荐理由

论文提供了 HERC1 调控蛋白酶体稳态的分子机制与疾病关联的对比数据，读者可据此分析泛素化修饰通路在神经发育疾病中的潜在治疗靶点
