# 新辅助阿帕鲁胺治疗高风险局部前列腺癌

> 原标题：Perioperative Apalutamide in High-Risk Localized Prostate Cancer

- 来源：NEJM
- 发布时间：2026-11-11T10:00:03.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/x9d1d9cw6j30sndqkjkoncj1o

## 摘要

该研究在《新英格兰医学杂志》上发表，评估了阿帕鲁胺作为新辅助治疗在高风险局部前列腺癌患者中的效果，结果显示可显著降低肿瘤复发风险，主要终点为术后病理完全缓解率，达到42%。
