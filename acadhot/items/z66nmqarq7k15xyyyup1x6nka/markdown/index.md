# 某团队在 bioRxiv 发表酵母核动态重组的 Hi-C 分析

> 原标题：Learning from Hi-C reveals nuclear dynamical reorganization in budding yeast across the cell cycle

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/z66nmqarq7k15xyyyup1x6nka
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.07.764600v1?rss=1

## 摘要

该研究提出一种结合Hi-C数据和物理模拟的模型，成功推断出酿酒酵母全周期核动态重组的三维结构。在5kb分辨率下，模型验证了亚扩散特性与独立测量的染色体运动一致，并预测了染色体异质性移动和端粒依赖的动态组织模式。
