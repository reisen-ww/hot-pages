# 某团队在bioRxiv发表NPlasmid-seq：基于Cas9末端签名的质粒分子级质量控制方法

> 原标题：NPlasmid-seq: Cas9-encoded terminal signatures enable molecule-level nanopore quality control of vector and IVT-template plasmids

## 摘要

某团队开发出基于Cas9末端签名的质粒分子级质量控制方法NPlasmid-seq，可检测0.1%-5%的亚百分比污染。实验显示该方法在计算混合物和物理DNA混合物中均能准确识别污染，且在通过传统质控的样本中发现61.7%的 reads 携带93bp缺失突变。该方法通过Cas9切割产生的末端序列差异实现分子级质控，为质粒生产提供新工具。

## 推荐理由

该方法可检测低丰度污染并揭示传统质控方法忽略的质粒结构异质性
