# 线粒体蛋白质导入缺陷增强肿瘤免疫原性

> 原标题：Mitochondrial protein import defects enhance tumour immunogenicity

- 来源：Nature
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/tltfhxl7lolpza89xz5cfwjkj
- 原文：https://www.nature.com/articles/s41586-026-11249-1

## 摘要

研究发现，线粒体蛋白质导入缺陷可增强肿瘤免疫原性。实验结果显示，这种缺陷导致肿瘤细胞表面抗原暴露增加，从而提高免疫细胞识别和攻击肿瘤的能力。
