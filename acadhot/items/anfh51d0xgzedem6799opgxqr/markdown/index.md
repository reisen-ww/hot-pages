# 高分辨率 Babesia divergens 核糖体结构揭示新型治疗靶点

## 摘要

研究人员利用冷冻电子显微镜解析了 Babesia divergens 的核糖体结构，揭示了其独特的核糖体特征，为未来针对该寄生虫的药物开发提供了重要线索。该结构是首次如此详细地描述此类疟原虫类寄生虫的核糖体，可能包含生物重要且潜在的药物靶点。
