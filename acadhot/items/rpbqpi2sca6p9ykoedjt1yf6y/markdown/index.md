# 某团队提出变分原理解释神经网络几何与贝叶斯行为

> 原标题：A Variational Principle for the Emergence of Neural Geometry Underlying Bayesian-Like Behavior

## 摘要

某团队提出变分原理解释类贝叶斯行为的神经几何形成机制，实验验证了不同刺激统计分布下神经表征的三种几何结构 regime（边界模糊、可测量、跨刺激范围），并发现 affine 正则化后变分坐标与贝叶斯最小二乘均值的几何形状高度吻合。该研究首次将变分原理系统应用于神经几何建模，为理解大脑信息编码提供了新理论框架。
