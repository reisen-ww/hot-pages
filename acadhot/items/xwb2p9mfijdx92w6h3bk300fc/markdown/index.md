# Bloom 模型实现跨模态脑细胞表征统一

## 摘要

Bloom 模型在 300,000 个小鼠脑细胞数据上训练，结合基因表达与染色质可及性双模态输入，其跨模态表征能力优于单模态模型，在细胞注释、回归和标签迁移任务中表现更优。研究首次发现相隔数百万碱基对的基因组位点存在细胞类型依赖性关联，为多模态脑细胞分析提供新工具。
