# 宾夕法尼亚大学牙医学院团队在 Nature Communications 发表口腔细菌突破人体屏障的非经典FOXO1信号通路研究

## 摘要

宾夕法尼亚大学牙医学院团队在 Nature Communications 发表研究，发现口腔细菌通过非经典FOXO1信号通路快速改变上皮屏障蛋白位置。实验显示屏障蛋白E-cadherin和β-catenin从细胞膜内移至细胞核内，导致屏障泄漏；动物模型验证了该机制与系统性疾病如类风湿关节炎、糖尿病并发症及痴呆相关。
