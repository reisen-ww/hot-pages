# Mount Sinai 研究团队在 Science Advances 发表研究：安第斯病毒糖蛋白关键氨基酸差异影响宿主细胞内病毒颗粒释放效率

## 摘要

Mount Sinai 研究团队在 Science Advances 发表研究，发现鼠源与人源安第斯病毒糖蛋白关键氨基酸差异显著影响病毒颗粒释放效率。该差异可能解释病毒人际传播能力差异，为靶向糖蛋白的抗病毒疗法提供新靶点依据。研究还指出，2026年游轮 Hondius 爆发疫情中分离的病毒序列可用于后续研究。
