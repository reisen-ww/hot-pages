# 宾夕法尼亚大学团队在Science Advances发表：TRF2缺失导致肌肉修复异常并引发纤维化

> 原标题：Without this protein, damaged muscle fills with fat and scar tissue

## 摘要

宾夕法尼亚大学团队在Science Advances发表研究，发现TRF2蛋白缺失导致实验鼠肌肉修复失败并出现纤维化。通过基因编辑技术去除小鼠肌肉干细胞中的TRF2蛋白，发现其通过调控基因组G-四联体结构维持干细胞功能，缺失后干细胞失去修复能力并导致脂肪和瘢痕组织堆积。
