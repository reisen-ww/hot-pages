# 模拟食品墨水以优化3D打印

> 原标题：Will it flow? Simulating food inks for 3D printing

## 摘要

来自荷兰埃因霍温理工大学和瓦格宁根大学与研究机构的研究人员在《流体物理学》上发表研究，通过模拟食品墨水的打印过程，预测了不同类型的食品墨水在打印时所需的推力。研究发现，该模型能准确预测富含蛋白质的食品墨水的行为，但对富含纤维的墨水的预测存在偏差，可能是因为模型未考虑墨水中的水分如何影响墨水在打印过程中的滑动。这项工作有助于工程师设计更好的食品打印机和食品墨水。
