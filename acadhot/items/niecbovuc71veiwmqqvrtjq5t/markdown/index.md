# 脊髓损伤的机械性质影响炎症反应的时空动态

## 摘要

本研究系统比较了两种大鼠脊髓损伤模型（挫伤和双侧背侧半切）的炎症反应，发现虽然两种模型在某些炎症模式上相似，但在细胞和分子响应的幅度、组成和时间演变上存在差异。这些炎症动态与轴突可塑性、星形胶质细胞重塑和病灶成熟程度及功能恢复率的不同相关。研究揭示了脊髓损伤的机械原因、相应的免疫反应及其随后的组织重塑过程之间的相互作用，强调了损伤背景及其演变的重要性。
