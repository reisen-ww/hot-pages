# HUS1与RAD9功能差异驱动利什曼原虫基因组可塑性

> 原标题：Replication-stress response shapes Leishmania genome plasticity through non-equivalent RAD9 and HUS1 functions.

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z

## 摘要

HUS1和RAD9在利什曼原虫基因组可塑性中发挥非等效作用，导致不同的复制压力响应和基因组重排模式。HUS1缺失限制DHFR-TS扩增并偏好线性扩增，RAD9缺失则伴随广泛环状扩增。

## 推荐理由

论文对比了 HUS1 和 RAD9 缺失对利什曼原虫基因组可塑性的不同影响，揭示了复制压力监控机制如何塑造基因组变异
