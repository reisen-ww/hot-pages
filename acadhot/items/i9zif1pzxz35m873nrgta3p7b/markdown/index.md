# 德国2022年至2060年不同社会经济地位的2型糖尿病患病率预测

> 原标题：Projected prevalence and number of persons with diagnosed type 2 diabetes by socioeconomic position in Germany between 2022 and 2060

- 来源：medRxiv
- 发布时间：2026-11-15T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/i9zif1pzxz35m873nrgta3p7b
- 原文：https://www.medrxiv.org/content/10.64898/2026.11.12.26367900v1?rss=1

## 摘要

该研究使用偏微分方程模型预测德国2022年至2060年不同性别和社会经济地位的2型糖尿病患病率，发现患病率随年龄增加并在80至90岁达到峰值，且社会经济地位差异持续存在，患病人数预计从2022年的840万增加到2060年的1120万至1920万。
