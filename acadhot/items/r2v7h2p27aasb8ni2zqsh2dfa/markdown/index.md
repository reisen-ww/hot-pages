# 新生儿大脑功能连接组的后natal成熟转变几何分析

> 原标题：Geometric analysis of postnatal maturational transformations in brain's functional connectome

## 摘要

研究通过几何框架分析新生儿大脑的功能连接组，发现出生后月龄与前额叶-顶叶网络和显著网络的出现相关，而出生后年龄则与初级感知觉和运动系统在功能层次中的分化相关。性别差异显示女性新生儿的功能架构成熟度高于男性，支持出生后大脑功能重组的模型。
