# 某团队在 bioRxiv 发布关于 PFN 缩放与 22q11.2 缺失综合征关联的研究

> 原标题：Personalized functional networks scale with brain size beyond anatomy and are altered in 22q11.2 deletion syndrome

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/v8288mte8q98abgd1mjx29ohv
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.767099v1?rss=1

## 摘要

某团队在 bioRxiv 发布研究，发现 PFN 在脑大小变化中的缩放模式与解剖结构不同，并在 22q11.2 缺失综合征中观察到视觉皮层相对缩小和边缘-扣带回网络相对扩大（n=62病例，153对照；年龄10-24）。研究通过对比典型发育与综合征患者的 PFN 变化，验证了脑体积缩放对功能网络重组的调节作用，为神经发育障碍的精准干预提供了新视角。

## 推荐理由

研究揭示了 PFN 缩放与脑解剖结构的差异机制，为神经发育障碍的个性化干预提供了可迁移的方法框架
