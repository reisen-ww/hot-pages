# 高盛预美联储12月再次加息，明年3月第三次加息

## 摘要

高盛预计美联储将在12月再次加息25个基点，并预测2027年3月将进行第三次加息。通胀报告预计在11月和12月将较为温和，但年初成本压力将推高1月份通胀。高盛认为，随着影响因素逐渐消退，明年底价格将显著下降。
