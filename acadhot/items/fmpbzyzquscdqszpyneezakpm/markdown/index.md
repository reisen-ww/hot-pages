# 企业如何利用政治关系举报竞争对手违规

> 原标题：How firms can use political access to target rivals' violations

- 发布时间：2026-11-18T16:00:22.000Z

## 摘要

研究表明，企业通过向监管机构提供竞争对手可能违规的信息，可以在监管执法中获得竞争优势。分析了8000多个设施超过90个行业的12年数据，发现处理更多有毒化学品的设施在竞争对手加大游说力度时更可能被罚款。这表明监管执法也是竞争的一部分，企业的政治关系会影响监管机构的执法重点。
