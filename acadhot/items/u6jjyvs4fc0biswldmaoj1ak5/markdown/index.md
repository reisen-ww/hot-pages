# BioMeme虚拟细胞响应记忆模型在九组预注册测试中优于传统神经网络

> 原标题：BioMeme: biological response memory for virtual cells

- 来源：bioRxiv
- 发布时间：2026-11-09T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/u6jjyvs4fc0biswldmaoj1ak5

## 摘要

某团队在bioRxiv预印本平台发布BioMeme虚拟细胞响应记忆模型，该模型通过实验记忆替代传统神经网络，在九组预注册测试中预测方向准确率优于输入匹配脊线、自适应化学CPA和纯神经网络模型，误差率控制在3.4%以内。

## 推荐理由

该预印本提出基于实验记忆的虚拟细胞预测方法，在九组预注册比较中表现优于传统神经网络模型，且计算效率提升420倍，支持实验室快速部署与验证。
