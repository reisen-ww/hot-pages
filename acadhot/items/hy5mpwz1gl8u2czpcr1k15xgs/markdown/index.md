# Alteromonas macleodii MIT1002 的代谢模型及其生态意义

## 摘要

研究团队构建了异养细菌 Alteromonas macleodii MIT1002 的代谢模型，通过51种不同培养基的实验验证，揭示了钠在电子传递链中的作用、不同糖酵解途径的代谢意义、与 Prochlorococcus 互养过程中氮的循环机制，以及微生物对碳的利用效率。
