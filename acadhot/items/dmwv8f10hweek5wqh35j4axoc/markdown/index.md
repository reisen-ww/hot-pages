# 甲苯胺蓝通过抑制G3BP1凝聚体减少Kras驱动胰腺癌前病变的机制研究

> 原标题：Methylene blue modulates G3BP1-associated condensation and attenuates Kras-driven pancreatic preneoplastic lesions

- 来源：bioRxiv
- 发布时间：2026-11-12T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/dmwv8f10hweek5wqh35j4axoc
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.765332v1?rss=1

## 摘要

某团队的研究发现，甲苯胺蓝在砷诱导应激、营养剥夺和热休克条件下抑制多种胰腺导管腺癌细胞系的G3BP1凝聚体，且不降低主要SG相关蛋白丰度。分子对接与动力学模拟显示MB与G3BP1 NTF2L结构域潜在结合位点。

## 推荐理由

论文提供了甲苯胺蓝调节G3BP1凝聚体的结构生物学证据，并展示了其在Kras驱动小鼠模型中抑制胰腺癌前病变的体内效果。
