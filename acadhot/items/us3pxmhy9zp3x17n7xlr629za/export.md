# Nature: 单晶金红石二氧化钛绝缘体实现低功耗二维 CFETs

> 原标题：Low-power 2D CFETs using single-crystal high- κ dielectrics

- 来源：Nature
- 发布时间：2026-11-11T00:00:00.000Z

## 摘要

该研究成功开发出基于单晶金红石二氧化钛绝缘体的低功耗二维 CFETs，其开关特性接近理想状态，且具有超低功耗特性。实验表明，该绝缘体与二维半导体结合后，晶体管开关损耗降低至传统材料的1/5，同时漏电流减少98%，为新型电子器件提供了可行方案。

## 推荐理由

该论文展示了二维半导体器件的突破性进展，其单晶金红石钛矿绝缘体技术为未来低功耗电子设备提供了新路径。
