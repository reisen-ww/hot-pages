# 某团队利用高通量微阵列分析揭示不同植物来源核酮糖羧化酶的优化路径

> 原标题：High-throughput microarray analysis provides new insight into optimising Rubisco yield from diverse plants

## 摘要

某团队利用高通量微阵列分析（MAPP）系统评估了不同植物来源叶绿体生物质中核酮糖羧化酶（Rubisco）的提取效率，发现种间差异和糖蛋白互作显著影响提取效果。该技术还可通过靶向细胞壁修饰酶评估碳水活性酶对Rubisco回收率的影响，为生物质选型与提取协议优化提供实验依据。
