# SK海力士今年前三季度资本支出达31.216万亿韩元

- 发布时间：2026-11-17T03:14:24.000Z

## 摘要

SK海力士今年1-9月资本支出达31.216万亿韩元，超过2025年全年创纪录的30.173万亿韩元。公司此前预测全年资本投资额将超过40万亿韩元，较去年增加逾10万亿韩元。
