# 深海海猪体内发现独特细菌

> 原标题：Sea pigs from the abyss host unusual bacteria

## 摘要

日本东京大学研究人员在深海海猪体内发现了一种独特的细菌 Candidatus Abyssoplasma scotoplanesicola，其基因组极小但含有大量长蛋白质编码基因，占比达 27.6%。该研究发表在 ISME Host Microbe 上，揭示了共生细菌与宿主紧密关系下的生存策略。海猪不仅在深海生态系统中扮演重要角色，还为幼小的帝王蟹提供庇护。
