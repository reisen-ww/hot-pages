# 第九届进博会上海交易团国资分团达成意向采购金额28.62亿美元

- 发布时间：2026-11-08T01:12:13.000Z

## 摘要

第九届中国国际进口博览会上，上海交易团国资分团在大宗商品、医疗器械、农食产品等领域达成137笔意向采购订单，意向采购金额达28.62亿美元，实现了采购质量和成交金额的双提升。
