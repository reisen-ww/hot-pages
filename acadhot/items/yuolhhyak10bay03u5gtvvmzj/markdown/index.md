# 某研究团队在 PNAS 发表 tRNA 早期遗传代码残留研究

> 原标题：Protein-building RNA molecules reveal possible remnants of an ancestral genetic code

- 来源：Phys.org
- 发布时间：2026-11-10T20:50:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/yuolhhyak10bay03u5gtvvmzj
- 原文：https://phys.org/news/2026-11-protein-rna-molecules-reveal-remnants.html

## 摘要

某研究团队通过分析超7万条tRNA基因序列（覆盖细菌、古菌和真核生物近5,000基因组），发现现代tRNA的接受茎区域存在高频三联体信号残留，且首次在tRNA其他臂检测到三联体信号。
