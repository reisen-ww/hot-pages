# 俄亥俄州立大学研究团队在《环境研究》发表污水细菌与慢性疾病关联成果

> 原标题：Study finds links between bacteria in wastewater and chronic disease

- 来源：Phys.org
- 发布时间：2026-11-10T19:20:12.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/lp56opb95jk5j9rwysovu3lck
- 原文：https://phys.org/news/2026-11-links-bacteria-wastewater-chronic-disease.html

## 摘要

俄亥俄州立大学研究团队在《环境研究》(DOI:10.1016/j.envres.2026.125332)发表成果，基于2022年分析的27份污水样本（覆盖8个俄亥俄州城市、超130万人口），发现Desulfovibrio菌群丰度与肥胖、高血压、中风等8类慢性疾病显著相关。研究显示农村社区该菌群比例更高且慢性病发病率更突出，为公共卫生资源精准投放提供新指标。
