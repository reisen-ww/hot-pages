# 辉瑞与黑石达成15亿美元减肥药研发资助协议

## 摘要

辉瑞与黑石生命科学达成协议，黑石将出资15亿美元支持辉瑞一款正在测试的月度减肥注射药物的研发至2028年，辉瑞保留项目运营控制权。
