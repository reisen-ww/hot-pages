# 密歇根州立大学团队发表蝗虫嗅觉系统检测生物膜新方法

> 原标题：Could locusts help detect difficult-to-treat bacterial infections?

- 来源：Phys.org
- 发布时间：2026-11-18T15:40:05.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/uadhn4bh10w5w7el2kyyo05wu
- 原文：https://phys.org/news/2026-11-locusts-difficult-bacterial-infections.html

## 摘要

密歇根州立大学研究团队首次利用蝗虫嗅觉系统区分细菌生物膜与游离生长状态，通过记录脑部神经电信号，在实验室条件下实现96%准确率。该成果发表在《Communications Biology》DOI:10.1038/s42003-026-10943-0，为非侵入性检测耐药性肺部感染提供新途径。研究需进一步验证临床样本和更多菌种适用性，长期目标开发便携式生物传感器。
