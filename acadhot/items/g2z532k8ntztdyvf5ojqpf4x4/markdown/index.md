# PCAF-1 耦合应激响应转录与蛋白稳态延长寿命的机制研究

## 摘要

本研究通过提高线虫 PCAF-1 剂量，发现其增强应激响应并延长寿命，同时改善神经退行性疾病模型中的蛋白聚集问题。机制上，PCAF-1 通过激活 DAF-16/FOXO 通路发挥作用，该通路对延长寿命和对抗多谷氨酰胺蛋白聚集至关重要。
