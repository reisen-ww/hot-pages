# 基于门控渐进高斯滤波网络的人体运动估计

## 摘要

本文提出一种基于门控渐进高斯滤波网络（GPGF-net）的人体运动估计方法，通过设计门控记忆机制和引入渐进式观测更新策略，显著提高了估计精度，均方根误差降低15.62%，相关系数R2提升5.08%。
