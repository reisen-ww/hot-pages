# Nimac 等在 bioRxiv 发表 TDP-43 时空互作图谱揭示压力后网络重塑持续存在

> 原标题：A temporal atlas of TDP-43 interactions reveals persistent network remodelling beyond stress granule clearance

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/v99rrsrd1vs6499a4ed6zcm9g
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.766431v1?rss=1

## 摘要

该研究通过APEX2近邻标记结合定量质谱，构建了野生型TDP-43及病理模拟突变体（TDP-43dNLS/CTF）在稳态、氧化应激及恢复期的互作网络图谱，发现清除应激颗粒后仍存在持续网络重塑，提示分子记忆效应。研究系统揭示了TDP-43蛋白互作网络的动态时空特征及其病理意义。

## 推荐理由

该研究首次通过时空图谱技术解析TDP-43蛋白在应激及恢复过程中的动态互作网络，为神经退行性疾病机制提供了可验证的分子基础
