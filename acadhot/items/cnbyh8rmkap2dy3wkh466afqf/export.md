# 某团队在bioRxiv发表跨模态锚定批量校正方法

> 原标题：Batch Correction via Cross-Modal Anchoring

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/cnbyh8rmkap2dy3wkh466afqf
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.766280v1?rss=1

## 摘要

某团队提出基于跨模态锚定的批量校正方法，在乳腺癌数据集上AUC提升至0.72，CpG信号恢复率达82.8%。该方法无需预定义临床协变量，在七组TCGA标准队列、受控混淆基准测试和模拟实验中均优于ComBat，处理1091个肿瘤样本仅需3秒单CPU计算。

## 推荐理由

该论文提供了跨模态锚定批量校正方法与ComBat的对比实验数据，包括在乳腺癌数据集上的AUC提升（0.37→0.72）和CpG信号恢复率（73.2%→82.8%）
