## 摘要

开发者 Iain Kay 为 Linux 系统开发了一个 BASH 脚本 Ram Altman，监测 PC 闲置内存并发送讽刺邮件给 OpenAI CEO Sam Altman，当闲置内存超过 10% 时，会从预设模板中随机选择一条发送。
