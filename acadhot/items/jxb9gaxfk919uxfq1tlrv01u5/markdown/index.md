# Ferreira 等提出基于进化树与空间分布的优化运输方法整合单细胞与空间转录组数据

> 原标题：Phylospatial optimal transport for single-cell and spatial transcriptomics data integration

## 摘要

Ferreira 等提出 SpOTr 方法，通过结合进化树与空间分布优化运输，在模拟和真实肿瘤数据中优于传统方法，并成功映射结直肠癌肝转移模型的进化历史。该方法采用去卷积模型与融合格罗莫夫-瓦瑟斯坦最优传输，在结直肠癌肝转移样本中验证了单细胞数据与空间定位的整合效果。
