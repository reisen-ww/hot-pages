# Cornell 实验室首次验证分布式声学传感技术可捕捉弓头鲸高频叫声

> 原标题：Repurposing the internet's backbone to advance whale monitoring

- 发布时间：2026-11-11T00:20:02.000Z

## 摘要

Bouffaut 团队通过分析 Quintillion 公司海底光纤电缆的数TB数据，首次在分布式声学传感（DAS）数据中检测到弓头鲸（Balaenoptera bowhead）150-300赫兹的高频叫声。

## 推荐理由

论文首次验证分布式声学传感技术可捕捉弓头鲸高频叫声，为全球须鲸监测提供新方法
