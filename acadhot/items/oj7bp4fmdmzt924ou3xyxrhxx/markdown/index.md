# 果蝇Drosophila sechellia在非i果 diet下的性别特异性适应研究

> 原标题：Evolution of sex-specific hormesis in a toxic niche specialist

## 摘要

果蝇Drosophila sechellia在非i果饮食下表现出性别特异性适应：雌性繁殖力、寿命和抗应激能力提升，且辛酸（octanoic acid）通过剂量依赖的双相效应（hormetic effect）复现了这些现象。研究证实辛酸的益处需依赖Alkbh7（脂肪酸代谢相关蛋白），并发现繁殖力与雌性偏倚共同最大化种群增长。
