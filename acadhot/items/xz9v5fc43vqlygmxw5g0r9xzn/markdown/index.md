# 泰国、法国、加拿大联合研究在 Nature 发表史前巨鼠体重达30公斤

> 原标题：30 公斤的巨鼠曾在三千万年前生活在今天的泰国

## 摘要

泰国甲米省煤矿发现的化石牙齿经泰国、法国、加拿大研究团队分析，确认三千万年前该地区存在体重约30公斤的史前巨鼠 Yakamys sirindhornae（属古鼠科），其体型相当于现存最大啮齿动物水豚的一半。研究团队通过显微CT和三维重建技术解析牙齿形态，填补了该区域大型啮齿动物化石记录空白。论文发表于 Nature（DOI: 10.1038/s41598-026-76711-6）
