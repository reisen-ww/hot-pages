# spicyR v2 提升空间组学共定位分析的准确性和统计功效

## 摘要

spicyR v2 是一种快速、无需置换的共定位测试方法，能有效控制假发现，比 v1 版本更具统计功效，并能准确评估共定位分析所需的患者数量。该方法适用于大规模空间组学数据集，可在几分钟内分析上亿个细胞。
