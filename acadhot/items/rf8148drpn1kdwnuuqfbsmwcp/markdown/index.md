# 某研究团队在 bioRxiv 发表 UBQLN2 通过 STI1-I 域保护 RTL8 的分子机制

> 原标题：UBQLN2, but not an ALS-linked variant, protects client protein from temperature-induced self-association

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

某研究团队在 bioRxiv 发表 UBQLN2 通过 STI1-I 域保护 RTL8 的分子机制，发现 ALS 相关突变使 UBQLN2 与 RTL8 结合能力降低10倍，并削弱其抑制 RTL8 自聚集的能力。研究通过低温电子显微镜解析了 UBQLN2 与 RTL8 的结合模式，并验证了突变体在体外及细胞中的功能缺陷

## 推荐理由

论文揭示了 UBQLN2 通过 STI1-I 域结合 RTL8 的分子机制，并证明 ALS 相关突变显著降低 UBQLN2 对 RTL8 的保护能力
