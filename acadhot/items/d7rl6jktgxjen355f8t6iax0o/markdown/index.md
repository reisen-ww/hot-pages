# 审计揭示物理、化学、工程和计算机科学领域中大量引用的虚假文献问题

> 原标题：Audit reveals suspected fabricated references across physics, chemistry, engineering and computing journals

- 来源：Phys.org
- 发布时间：2026-10-26T19:00:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/d7rl6jktgxjen355f8t6iax0o
- 原文：https://phys.org/news/2026-10-reveals-fabricated-physics-chemistry-journals.html

## 摘要

哥伦比亚大学护理学院的研究团队在《美国国家科学院院刊》(PNAS) 上发表论文，发现物理、化学、材料科学、计算机科学和工程领域的论文中存在大量虚假引用。2026年第一季度，每435篇论文中有一篇引用了无法在线找到的研究。研究还发现，自动引用检查对于防止此类问题至关重要。

## 推荐理由

论文揭示了物理、化学、工程和计算机科学领域中大量引用的虚假文献问题，强调了自动引用检查的重要性。
