# 佛罗里达州立大学团队在 JACS 发表光催化转化磺胺类药物新方法

> 原标题：Light-powered method resurrects 'dead-end' compounds for drug discovery

- 来源：Phys.org
- 发布时间：2026-11-06T20:40:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/veely1jyk2b7aahnokkstqvhw
- 原文：https://phys.org/news/2026-11-powered-method-resurrects-dead-compounds.html

## 摘要

佛罗里达州立大学团队在《Journal of the American Chemical Society》发表研究，利用光化学反应将磺胺类药物转化为有价值的合成原料。实验通过激光光谱技术捕捉单微秒内的分子反应过程，合作方包括宾夕法尼亚州立大学和GSK公司。该成果为结构导向药物设计提供了新工具，适用于其他化学组分的转化研究。
