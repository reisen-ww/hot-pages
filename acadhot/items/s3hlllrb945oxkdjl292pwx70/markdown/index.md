# 公众对社区药剂师服务自付费的接受度：一项全国在线调查

## 摘要

一项针对美国成年人的在线调查显示，2026年春季，公众对某些社区药剂师服务的自付费接受度较高，尤其是骨质疏松筛查和旅行相关疫苗接种。20美元的固定费用比任意金额的费用更受欢迎。男性和对药剂师信任度较高的受访者更倾向于接受自付费，而老年人和西班牙裔受访者则更不愿意接受自付费。
