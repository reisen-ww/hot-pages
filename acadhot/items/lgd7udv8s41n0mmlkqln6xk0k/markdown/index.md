# UC Berkeley 团队在 Nature 发表AI识别心脏隐性信号预测猝死风险研究

## 摘要

UC Berkeley 研究团队在 Nature 发表AI识别心脏隐性信号预测猝死风险研究。该AI系统通过分析超过44万份瑞典、美国和台湾地区心电图数据，发现传统心脏泵血量评估方法（年猝死风险4.6%）无法识别的7%高危人群，准确率提升2.4倍。研究团队已与医疗系统合作部署算法，计划通过可穿戴设备持续监测高危患者心脏电信号，最终推动植入式除颤器精准投放。
