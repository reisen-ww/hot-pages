# 50岁男子反复心肌病病例报告

> 原标题：Case 32-2026: A 50-Year-Old Man with Recurrent Cardiomyopathy

- 来源：NEJM
- 发布时间：2026-11-11T10:00:03.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ffjki7powfsu9x8mzltivbmhe
- 原文：https://www.nejm.org/doi/full/10.1056/NEJMcpc2301034?af=R&rss=currentIssue

## 摘要

一名50岁男子反复出现心肌病症状，经过详细检查发现其携带MYBPC3基因突变。研究团队通过基因检测和临床分析，确认了该突变与患者病情的关系，并提出针对性治疗建议。
