# 某团队在 bioRxiv 发表非编码RNA调控远距离增强子-启动子相互作用的新机制

> 原标题：Non-coding RNA controls long-range enhancer-promoter interactions

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/h1o4x7jsh0esi5783h4qbbi28
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.10.765568v1?rss=1

## 摘要

某团队通过急性遗传和化学干扰方法，结合高分辨率3D基因组映射、转录组学、蛋白质组学、生化分析和活细胞超分辨率成像，发现非编码RNA水平变化影响远距离增强子-启动子相互作用。研究证实RNA介导的干扰机制与转录起始过程无关，且该机制通过反馈调节降低目标基因转录活性。

## 推荐理由

论文展示了分离-of-function的扰动方法，为后续研究调控非编码RNA介导的远距离基因表达调控提供了技术参考。
