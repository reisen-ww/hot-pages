# 厄瓜多尔发现皮革背海龟新繁殖海滩，成功孵化率达91.8%

> 原标题：Endangered leatherbacks find new nesting beaches in Ecuador as Pacific Ocean warms

## 摘要

厄瓜多尔发现太平洋海龟在厄瓜多尔海岸建立新繁殖地的证据，跟踪45年记录显示其孵化率（91.8%）与墨西哥传统繁殖地相当。研究追踪了厄瓜多尔沿海的 nesting attempts（2025-2026年）与 La Niña 冷事件周期，发现海龟通过迁移适应海洋变暖。
