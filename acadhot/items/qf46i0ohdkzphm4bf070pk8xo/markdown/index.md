# 猫初级视觉皮层中PV中间神经元回路通过外经典周围增强取向调制的机制研究

> 原标题：Parvalbumin interneuron circuit sharpens orientation tuning via the extraclassical surround in cat V1

## 摘要

Foik 等团队在 bioRxiv 发布预印本，通过光遗传学激活或抑制猫初级视觉皮层（V1）中PV中间神经元回路，发现激活仅在经典感受野刺激下增强取向特异性，抑制则在外经典周围刺激下拓宽取向范围。研究首次在非啮齿类动物中验证PV回路通过外经典周围抑制实现取向调制的动态平衡机制。
