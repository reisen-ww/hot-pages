# 某研究团队在bioRxiv发表阴道网片暴露与肌成纤维细胞表型关联研究

> 原标题：When fibers crowd: Mesh burden and myofibroblast phenotypes in women with vaginal mesh exposure

- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

某研究团队在bioRxiv发表文章，分析17例阴道网片暴露患者的样本，发现高网片负担与巨噬细胞浸润及胶原蛋白含量降低相关，并揭示MMT相关表型特征（如肌成纤维细胞密度分层、巨噬细胞标记物共表达）。蛋白质组学分析显示，暴露组样本中与巨噬细胞相关及基质重塑蛋白存在显著差异。
