# University Hospital of Zurich 提出血液加速度指标（BAM）作为颈动脉狭窄功能评估的替代方案

## 摘要

苏黎世大学医院团队提出血液加速度指标（BAM）用于评估颈动脉狭窄的功能严重程度。初步评估显示 BAM 与 FFRCT 存在强负相关（R=-0.85），且 BAM 通过测量最小狭窄直径和峰值收缩速度等可及参数实现计算。该指标有望替代传统 FFR 测量方法，为临床提供非侵入性评估工具。
