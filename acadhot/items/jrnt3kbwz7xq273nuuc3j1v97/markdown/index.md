# Bogong 蛾依靠光依赖的地磁场倾斜罗盘导航

> 原标题：Bogong moths navigate with a light-dependent geomagnetic inclination compass

- 来源：Nature
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/jrnt3kbwz7xq273nuuc3j1v97
- 原文：https://www.nature.com/articles/s41586-026-11322-9

## 摘要

Bogong 蛾在每年两次的迁徙中依赖恒星和地磁场导航，即使缺少其中一个线索也能保持迁徙方向。研究表明，它们使用一种光依赖的地磁场倾斜罗盘进行导航。
