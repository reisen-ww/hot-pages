# 考虑非洲草原大象保护作为基于自然的气候解决方案

> 原标题：Considering African savanna elephant conservation as a nature-based climate solution

## 摘要

研究通过碳循环模型评估了大象对碳捕获和储存的净影响，发现密度约为每平方公里0.5只的大象可使平均净生态系统碳捕获量增加1.4倍，长期地上碳储量增加6.5倍，长期土壤碳储量增加1.7倍，表明非洲草原大象保护可被视为基于自然的气候解决方案。
