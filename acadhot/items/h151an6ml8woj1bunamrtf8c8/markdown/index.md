# Radboud University 研究团队发现甲烷降解菌通过纳米线传导电流的机制

> 原标题：Methane-eating microbes grown on electrodes build electrically conductive nanowires

- 来源：Phys.org
- 发布时间：2026-11-10T00:10:14.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/h151an6ml8woj1bunamrtf8c8

## 摘要

Cornelia Welte 团队首次在实验室纯培养甲烷降解菌 ANME 并发现其通过 OmcZ 型细胞色素纳米线传导电流。研究通过电极关联生长揭示纳米线结构，纯培养度达95%，合作方包括耶鲁大学。该机制为生物电化学转化提供新模型，但当前技术成本过高，预计20年内实现实用化。
