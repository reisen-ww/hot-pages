# 新英格兰医学杂志报道H7N7禽流感致死与I型干扰素抗体相关

> 原标题：Autoantibodies against Type I Interferons and Death from H7N7 Avian Influenza

- 来源：NEJM
- 发布时间：2026-11-11T10:00:03.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/xqtt7beftlqz5blaypa6wr19o
- 原文：https://www.nejm.org/doi/full/10.1056/NEJMc2608446?af=R&rss=currentIssue

## 摘要

新英格兰医学杂志报道，H7N7禽流感患者体内存在针对I型干扰素的自身抗体与死亡风险增加相关。研究纳入42名患者，结果显示抗体阳性患者的死亡率显著高于阴性患者（p < 0.001）。
