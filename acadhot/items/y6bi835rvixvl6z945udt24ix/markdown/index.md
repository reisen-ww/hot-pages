# 果蝇dEAAT2转运蛋白揭示高阶离子耦合机制

> 原标题：One high-order ion-coupling mechanism generates multiple SLC1A stoichiometries

## 摘要

果蝇dEAAT2转运蛋白研究揭示高阶离子耦合机制，通过冷冻电镜和计算模拟证实其无法转运阳离子，但两个点突变即可恢复人类转运蛋白的Na+/H+协同转运特性。该研究首次在果蝇模型中解析Cl-依赖的taurine转运新路径，为神经退行性疾病研究提供结构基础。DOI: https://doi.org/10.64898/2026.11.07.764996
