# MTG-I2 卫星捕捉欧洲每 2.5 分钟一次的气象图像

## 摘要

欧洲气象卫星 MTG-I2 的 Flexible Combined Imager (FCI) 在发射两个月后首次捕捉到全盘图像，展示了欧洲、非洲和大西洋的详细气象情况，每 2.5 分钟提供一次高分辨率观测。这将帮助气象预报员更早、更准确地监测快速发展的天气变化，特别是在极端天气事件中提供及时预警。
