# 某团队在 Royal Society Open Science 发表新恐龙 Nyana rooiwalensis 的骨骼分析及生长推断

## 摘要

某团队通过化石分析发现新恐龙物种 Nyana rooiwalensis，其成年体重可能达多吨。研究采用 X 射线 3D 模型重建颅骨、显微镜观察四肢骨骼切片，结合 sauropodomorphs 的生长曲线推演，揭示该恐龙在死亡时仍处于快速生长期。该发现填补了南非晚三叠世 sauropodomorphs 骨骼化石记录空白，为早期恐龙演化与地理分布研究提供新数据。
