# 血清BD-tau区分急性脑损伤与脊髓损伤

> 原标题：Serum brain-derived tau distinguishes acute neurotrauma diagnoses

- 来源：medRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/hyd6yqdxdu7mp8b6fm41w662m

## 摘要

某研究团队在medRxiv发表预印本，发现血清BD-tau可区分创伤性脑损伤与脊髓损伤（AUC=0.91），优于神经丝轻链等传统生物标志物（AUC=0.82）。纵向数据显示BD-tau在144小时内持续区分两类损伤，且血清检测优于脑脊液检测（AUC=0.95 vs 0.80）。研究由美国匹兹堡大学伦理委员会批准，资助方包括美国国立卫生研究院（NIH）等机构。

## 推荐理由

该研究提供了BD-tau在区分创伤性脑损伤和脊髓损伤中的高准确性和临床应用潜力
