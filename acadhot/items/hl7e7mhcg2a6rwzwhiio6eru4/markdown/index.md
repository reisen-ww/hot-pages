# 北方龙头草的染色体水平基因组组装

## 摘要

研究人员组装了北方龙头草的染色体水平基因组，包含两个伪单倍型hap1和hap2，长度分别为661 Mb和681 Mb，分别包含38,141和38,617个注释过的蛋白质编码基因。该组装为北方龙头草及其依赖其繁殖的濒危北方龙头草鞘甲虫的未来研究和保护提供了高质量的基因组资源。
