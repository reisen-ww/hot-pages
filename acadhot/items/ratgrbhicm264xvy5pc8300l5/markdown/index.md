# Skoltech 团队首次直接观测光子自旋霍尔效应，推动纳米光子学与先进雷达/激光雷达发展

## 摘要

Skoltech 研究团队首次直接观测到光子自旋霍尔效应，使用微波辐射的陶瓷颗粒验证了其可扩展性。该成果为纳米光子学技术、高精度雷达/激光雷达系统及光控纳米天线开发提供了新路径。
