# 杜兰大学研究团队在Scientific Sessions 2026发布大麻使用与中风风险关联的初步研究

> 原标题：Even occasional marijuana use linked to 40% higher odds of stroke

- 发布时间：2026-11-11T03:47:25.000Z

## 摘要

杜兰大学研究团队在2026年科学会发布大麻使用与中风风险关联的初步研究，显示1-5天/月使用者中风风险增加40%，16-30天/月使用者风险增加25%。研究基于442,906名美国成人电话调查数据，排除吸烟、肥胖等因素后仍发现显著关联。但受限于横断面设计、回忆偏差及未采集THC浓度数据，无法确定因果关系。专家呼吁将大麻使用纳入心血管健康常规讨论。
