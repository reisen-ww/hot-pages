# Barducci 团队提出整合进化与蛋白质语言模型的稳定性预测新方法

> 原标题：Integrating evolutionary and protein language model representations for thermodynamically consistent stability prediction

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/kb0l63xhcg41xvso9rs6tpbdn
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.765390v1?rss=1

## 摘要

Barducci 团队公布无需额外训练的蛋白质稳定性预测方法，通过整合进化信息与蛋白质语言模型，在 S669 和 S96 两个靶点中实现 Pearson 相关系数 0.59（较单一模型 0.53 提升）和 0.55（较单一模型 0.48 提升），并在 PTmul-NR 多位点测试中达到 0.66 的相关性，同时保证热力学可逆性与路径独立性。

## 推荐理由

该论文提出无需额外训练的蛋白质稳定性预测方法，通过整合进化信息与蛋白质语言模型，在多个基准测试中实现比单一模型更高的预测精度（如 Pearson 相关系数 0.59 vs 0.53），同时保持热力学一致性。
