# 基于CRISPR-Cas9的荧光蛋白标记增强EGFR突变肺癌细胞移植瘤免疫原性及奥希替尼响应研究

## 摘要

某团队通过CRISPR-Cas9技术构建荧光蛋白标记的EGFR突变小鼠肺癌细胞系，发现标记蛋白增强免疫原性并影响奥希替尼响应。研究显示删除标记（mC3-deleted）的细胞系仍能形成移植瘤并呈现部分药物响应，提示宿主免疫参与药物响应机制。

## 推荐理由

研究揭示了荧光蛋白标记对EGFR突变肺癌细胞移植瘤免疫原性的增强作用，并发现删除标记后细胞系对奥希替尼的响应差异，为模型优化提供新思路。
