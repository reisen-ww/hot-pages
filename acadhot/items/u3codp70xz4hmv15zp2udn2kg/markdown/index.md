# Barbosa团队通过时间分辨SAXS揭示细胞色素c结合后脂膜呈现两种结构差异

> 原标题：Time-Resolved SAXS Unveils Two Structurally Distinct Membranes upon Cytochrome c Binding

## 摘要

该研究利用时间分辨小角X射线散射（SAXS）技术，首次揭示细胞色素c结合后脂膜形成两种结构差异的种群。通过扩展SASBIN模型，结合分子约束的层间电子密度分布、横向脂质异质性及层间关联性分析，证实了两种种群的结构特征：蛋白结合种群呈现POPG富集的横向关联和层状有序性递增，而游离种群具有分子尺度有效异质性。

## 推荐理由

提出了一种结合分子约束和层间关联的SASBIN扩展模型，为研究蛋白质与脂膜动态相互作用提供定量分析框架。
