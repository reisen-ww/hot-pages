# GATA2 SUMO 修饰通过稳定性调控抑制子宫浆液性癌侵袭的机制研究

> 原标题：GATA2 SUMOylation Regulates GATA2 Stability to Control Uterine Serous Carcinoma Invasion

## 摘要

某团队在 bioRxiv 发表研究，揭示 SUMO 修饰动态调控 GATA2 水平的机制。实验显示 GATA2 蛋白半衰期仅 128 分钟，且 SUMO-2/3 水平升高与癌细胞侵袭能力正相关。

## 推荐理由

研究提供了 SUMO 修饰动态调控 GATA2 水平的分子机制，并验证了 SUMO 靶向抑制剂对抑制癌细胞侵袭的可行性
