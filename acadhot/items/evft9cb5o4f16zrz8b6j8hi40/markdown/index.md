# 日本探测器因发动机故障更改目标

> 原标题：Japan space probe changes target over engine trouble

- 来源：Phys.org
- 发布时间：2026-11-17T10:38:13.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/evft9cb5o4f16zrz8b6j8hi40
- 原文：https://phys.org/news/2026-11-japan-space-probe.html

## 摘要

日本探测器Hayabusa-2因发动机老化问题更改了其延伸任务的目标，原计划飞往1998 KY26小行星，现改为飞往2015 BM510小行星，预计2028年飞掠。新目标是直径17至74米的小行星，旋转周期为49分钟。此次调整有助于未来的小行星防御任务。
