# 中国科学院生物物理所与发育生物学研究所联合发表有机铁硫框架促进光合作用与碳固定的论文

> 原标题：New organic iron-sulfur framework boosts photosynthesis and carbon fixation

- 来源：Phys.org
- 发布时间：2026-11-11T00:40:06.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/q2slsok2y2uc2dao4tkf8y2nb

## 摘要

中国科学院生物物理所与发育生物学研究所设计的有机铁硫框架（OISF）显著提升光合作用与碳固定效率。通过水热合成策略，结合苯三酸作为配位体，构建出纳米片状框架并验证了[2Fe-2S]核心结构。
