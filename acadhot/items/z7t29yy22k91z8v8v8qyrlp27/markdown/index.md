# 某研究团队在medRxiv发表老年人受骗倾向与中颞叶神经突微结构关联研究

> 原标题：Middle Temporal Gyrus Neurite Microstructure and Scam Susceptibility in Older Adults Without Dementia

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

某研究团队通过7特斯拉超磁场成像技术，在116名无痴呆老年人中量化了7个预设脑区的NODDI指标（神经突密度NDI、方向离散度ODI、胞外自由水比例），发现中颞叶（MTG）的神经突密度（NDI）升高和方向离散度（ODI）降低与受骗倾向呈正相关（β=0.30, pFDR=0.025；β=-0.28, pFDR=0.044），且该关联独立于宏观脑结构测量。

## 推荐理由

论文提出了利用NODDI技术评估老年人受骗倾向的新方法，为后续研究提供了可迁移的技术框架。
