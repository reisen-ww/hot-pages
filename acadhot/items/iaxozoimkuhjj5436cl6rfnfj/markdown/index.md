# University of Bath 在 PLOS Biology 发表研究，挑战进化论中重要基因突变率较低的理论

> 原标题：Large mutation analysis challenges claim that evolution shields important genes from changes

- 来源：Phys.org
- 发布时间：2026-11-12T19:00:08.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/iaxozoimkuhjj5436cl6rfnfj

## 摘要

某大学研究团队在 PLOS Biology 发表研究，通过分析大肠杆菌和酿酒酵母的突变积累实验，发现重要基因的突变率并未低于其他基因，挑战了进化论中认为自然选择会减少重要基因突变的理论。研究采用三种独立实验验证突变率，并排除了基因表达量、进化时间等因素的影响。
