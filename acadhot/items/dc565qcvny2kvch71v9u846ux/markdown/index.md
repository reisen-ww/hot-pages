# ESM2模型预测四螺旋束结构的序列规律研究

## 摘要

论文通过合成序列库验证了ESM2模型对四螺旋束结构的预测能力。主成分分析显示模型能捕捉疏水模式、螺旋-环边界和七联重复相位特征，但未区分单个设计的成功与否。几何特征依赖氨基酸化学、重复次数和连接序列，当使用任意分类替代物理化学属性时模型失效。该研究为蛋白质语言模型优化提供实验验证框架。
