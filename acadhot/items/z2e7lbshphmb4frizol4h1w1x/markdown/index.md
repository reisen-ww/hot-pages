# 纹状体神经元的功能取决于更广泛电路的上下文

## 摘要

研究通过结合皮层-基底节-丘脑模型和小鼠行为数据，发现纹状体直接和间接通路的棘状投射神经元在不同电路状态下扮演不同角色，包括维持不确定性、表明选择承诺和减慢决策速度。这些发现支持了纹状体神经元功能依赖于更广泛电路状态的观点。
