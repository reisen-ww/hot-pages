# Alpha-beta 谐振动态在儿童听觉抑制控制中的作用

> 原标题：Alpha-beta oscillatory dynamics underlying auditory inhibitory control in children

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/w7jznv4u3v0w6k2xaanxwfjot

## 摘要

研究者使用磁源成像技术在67名儿童和16名成人中检测了听觉Go/Nogo任务中的α（8-12 Hz）和β（13-20 Hz）振荡。结果显示，儿童在抑制任务中表现出早期、持续的β功率下降，而成人则表现出晚发的α-β同步振荡。这表明儿童和成人抑制控制的神经动态存在差异：儿童的抑制调节更早出现且主要由感觉运动区的β下降主导，而成人则在执行网络中募集同步的α-β振荡，可能反映了更高效的评估性抑制处理。
