# 皮质锥体束神经元（cortical pyramidal tract neurons）调控帕金森病运动异常的机制研究

> 原标题：Cortical pyramidal tract neurons constrain pathological dopaminergic motor responses

## 摘要

激活皮质锥体束神经元可限制帕金森病模型小鼠的异常运动反应，并减少左旋多巴诱导的 axial dyskinesia。机制上，该刺激减少了多巴胺耗竭纹状体急性 D1 介导的 c-Fos 表达，但不影响重复左旋多巴暴露引起的慢性 ΔFosB 积累。研究首次揭示皮质锥体束神经元与纹状体 D1 受体信号通路间的功能关联，为帕金森病电路靶向治疗提供新思路。
