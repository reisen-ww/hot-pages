# Beam Therapeutics 宣布碱基编辑疗法在 I/II 期临床试验中成功

## 摘要

Beam Therapeutics 宣布其碱基编辑疗法在 I/II 期临床试验中达到主要终点，患者血红蛋白水平显著提升（中位提升达12.5 g/dL）。试验纳入42名患者，未报告严重不良事件。公司计划推进后续治疗开发，可能成为首个获批的基因编辑疗法之一。
