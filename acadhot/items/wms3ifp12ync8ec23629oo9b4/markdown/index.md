# 术中拉曼探针为颞下颌关节组织成分提供生物标志物

> 原标题：Arthroscopic Raman Probe Provides Biomarkers of TMJ Tissue Composition that Account for Tissue Function

## 摘要

某团队在15头猪和11例人体颞下颌关节软骨中开发术中拉曼探针技术，发现其通过糖胺聚糖（GAG）和水（H2O）生物标志物解释软骨压缩模量的能力（R²=0.86）远超传统 Outerbridge 评分（R²=0.04）。该技术为术中决策提供客观数据支持，并验证了活体术中拉曼成像与离体检测质量相当。

## 推荐理由

论文给出了术中拉曼光谱检测与 Outerbridge 评分在颞下颌关节软骨压缩模量解释力对比数据（R²=0.86 vs 0.04），读者可据此评估该技术能否用于术中决策支持。
