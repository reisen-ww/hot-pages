# 未培养Roseilinea物种细菌叶绿素合成途径的解析

> 原标题：Unravelling bacteriochlorophyll biosynthesis in the uncultured Roseilinea

## 摘要

研究解析未培养Roseilinea物种的细菌叶绿素合成途径，发现其代谢组基因组（MAGs）缺失常见合成酶基因。通过将Roseilinea sp. NK_OTU-006的5个末端合成酶基因导入紫色非硫细菌Rhodobacter sphaeroides突变体，成功恢复色素合成与光合生长。作者推测该物种可能依赖群落内其他微生物分泌的叶绿素前体或分解产物获取所需色素，并建议后续培养需补充叶绿素前体
