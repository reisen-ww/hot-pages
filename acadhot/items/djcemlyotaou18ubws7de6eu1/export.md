# Robust Cluster Typing 提供高效可靠的细菌种群分类工具

> 原标题：Robust Cluster Typing, a computationally accessible tool for species designation from whole genome data, exemplified with the genus Campylobacter

- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

该研究开发了一种基于核糖体蛋白的高效计算工具 Robust Cluster Typing，用于细菌种群分类。通过分析 39 种已知的 Campylobacter 种群，该工具成功区分了所有菌株，尤其适用于新菌种的鉴定。研究团队在 Terra 平台上提供了该工具的工作流程和在线培训课程，便于微生物学实验室使用。
