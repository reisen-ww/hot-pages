# FDA批准拜耳新药Sunharbo降低中风复发风险

## 摘要

FDA批准拜耳研发的XIa蛋白抑制剂Sunharbo用于中风复发预防。III期试验纳入已中风且接受常规治疗患者，结果显示安慰剂组1年内53例/千例复发，Sunharbo组为38例/千例，风险降低26%。该药物通过阻断XIa蛋白减少有害血栓形成，同时避免增加出血风险。

## 推荐理由

III期临床试验数据显示Sunharbo可将中风复发风险降低26%，为出血风险敏感患者提供了新治疗选择。
