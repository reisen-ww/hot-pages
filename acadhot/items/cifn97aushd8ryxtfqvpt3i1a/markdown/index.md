# 我国成功实现Q/V频段最高码速率无线通信实验验证

- 发布时间：2026-11-17T02:39:35.000Z

## 摘要

中国科学院空天信息创新研究院等单位近日在中国遥感卫星地面站丽江站，成功实现我国Q/V频段最高码速率无线通信实验验证，关键指标达到国内领先、国际先进水平，将为我国6G通信与卫星互联网技术发展提供技术支撑。
