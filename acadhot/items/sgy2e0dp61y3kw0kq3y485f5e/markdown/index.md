# 黑色素体抑制黄瓜和番茄多种病原体引发疾病的实验研究

## 摘要

本研究发现黑色素体能有效抑制黄瓜和番茄因卵菌、细菌及病毒（包括ToBRFV）引发的多种病害。实验通过叶面喷施和灌根处理（浓度0.03%-0.1%），在11周长期应用中验证了其效果，并扩展了之前针对灰霉病的发现。
