# Sortilin 被确认为细胞外蛋白质量控制的新型受体

> 原标题：Sortilin is a scavenger receptor for cytosolic proteins mislocalized to the extracellular milieu

- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

研究首次揭示Sortilin通过表面快速循环机制识别并降解外定位的细胞质蛋白。该受体通过多个疏水表位广泛结合非糖基化细胞质底物（如血红蛋白），同时排除糖基化分泌蛋白。其'击跑'转运模式（sortilin在细胞表面仅短暂驻留）结合广谱识别能力，使低亲和力底物也能被清除。这一发现为细胞外蛋白质量控制机制研究提供新工具。

## 推荐理由

论文揭示了sortilin通过快速循环机制清除细胞质蛋白的分子原理，为研究细胞外蛋白质量控制提供新视角。
