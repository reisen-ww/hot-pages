# 某团队开发AI虫害监测工具RRWIT用于识别相似甲虫物种

> 原标题：Automated detection and classification of morphologically similar weevil species using AI for precision pest monitoring

- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

某团队开发基于YOLO11n的轻量级AI工具RRWIT，使用16000张专家标注图像区分14种甲虫物种（含棉铃虫和核桃象甲）。经三次独立训练种子验证，工具在测试集上达到mAP50 0.938，虽略低于最新YOLO26n的0.976，但模型体积更小（10.09 MiB）。
