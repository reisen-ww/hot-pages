# 某团队在 bioRxiv 发表静止细胞分泌表型研究

> 原标题：Quiescent Cells Exhibit a Senescence-Like Secretory Phenotype

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/r3c6xjo06fgednh5xej8lr91n
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.15.766855v1?rss=1

## 摘要

某团队发现静止细胞具有与衰老细胞相似的分泌特征（QASP），通过比较接触抑制与血清移除两种诱导方法，证实前者能更显著激活IL-1β、IL-6等炎症因子分泌。单细胞转录组学进一步揭示该表型在肺纤维化（IPF）患者成纤维细胞中的高表达，提示QASP可能参与炎症信号传导和细胞外基质重塑。

## 推荐理由

论文通过单细胞测序和 bulk RNA-seq 数据比较静止细胞与衰老细胞的分泌特征，发现接触抑制诱导的炎症因子分泌水平显著高于血清移除法，为后续研究提供可迁移的方法学对比框架。
