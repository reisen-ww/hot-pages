# Stress granule 跨结直肠癌亚区的转录对比受评分方法和测序深度影响

## 摘要

某研究团队在 bioRxiv 发表预印本，对比了四种 Stress granule 基因集评分方法在结直肠癌单细胞组（含 195,527 细胞、85 名供体）中的表达差异。

## 推荐理由

论文对比了不同评分方法和测序深度对 Stress granule 基因表达对比的影响，为后续研究提供可复现的方法框架。
