# 福事特拟发行可转债募资不超4.46亿元

## 摘要

福事特董事会审议通过发行可转换公司债券议案，总额不超过4.46亿元，用于流体传动智能制造基地项目、数据中心管路项目及补充流动资金。方案尚需股东会审议及监管部门注册。
