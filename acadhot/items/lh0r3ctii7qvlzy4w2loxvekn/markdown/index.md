# 11,000年前的陶土碎片揭示早期制陶实验

> 原标题：11,000-year-old clay fragments reveal early experiments in pottery-making

## 摘要

研究团队在土耳其东南部的 Çemka Höyük 发现了约11,000年前的陶土碎片，揭示了早期人类制陶技术的实验过程。通过双目显微镜和X射线衍射分析，发现陶器在600-700°C下经控制明火烧制，且陶土混合物含植物碎屑和动物粪便。
