# 人类与自主AI协作工作流分析ChatGPT在医疗领域的应用趋势

> 原标题：Human-Agentic AI Collaboration Workflow for Trend Analysis of ChatGPT Applications in Healthcare

- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

该研究通过系统检索PubMed和Web of Science数据库，分析了192篇论文中的511种ChatGPT应用类型、690项关注点和368个使用因素，发现自主AI与人类专家协作的工作流能有效整合医疗知识，提供ChatGPT在医疗领域的应用趋势和相关机制见解。
