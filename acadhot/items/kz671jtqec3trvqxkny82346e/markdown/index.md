# 侧向磁场在多模光纤中引发的新型法拉第效应

> 原标题：A standard shortcut, used since the 1970s, hides a magneto-optic effect in ordinary glass fiber

- 来源：Phys.org
- 发布时间：2026-11-11T13:40:04.000Z

## 摘要

南非威特沃特斯兰德大学的研究人员发现，将磁铁置于多模光纤旁边而非沿其放置，可以改变光纤中传输的光波。这一“侧向法拉第效应”揭示了标准光纤描述方法中被忽略的光波成分。该发现可能为工程师提供一种新的磁场检测方法，无需像传统传感器那样缠绕导体，而只需将光纤置于磁场旁。
