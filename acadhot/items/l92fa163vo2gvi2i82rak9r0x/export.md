# 某研究团队在arXiv发表利用月食阴影与太阳能板电压导航深空论文

> 原标题：Navigating lunar orbit using nothing but shadows and a power meter

## 摘要

某研究团队提出利用月食阴影和太阳能板电压变化实现深空导航，误差控制在15秒内。方法基于22,000条历史月食数据建立地球阴影映射模型，并通过CAPSTONE任务实测验证。该技术无需额外硬件（zero-SWaP），可为深空任务提供低成本导航备选方案。
