# 中国农业大学团队在《Acta Microbiologica Sinica》发表盐碱地作物促生菌群研究

> 原标题：Earthworm gut bacteria show promise for helping crops grow in salt-affected soil

- 来源：Phys.org
- 发布时间：2026-11-17T15:30:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/cfuwlhhsp97t688trtii73nj9
- 原文：https://phys.org/news/2026-11-earthworm-gut-bacteria-crops-salt.html

## 摘要

中国农业大学团队从蚯蚓肠道分离出45株耐盐碱细菌，筛选出5株实验室条件下可在pH6.0-10.0、盐浓度0-75g/L中生长的菌株（属Myroides/Bacillus/Alcaligenes/Pseudochrobactrum）。
