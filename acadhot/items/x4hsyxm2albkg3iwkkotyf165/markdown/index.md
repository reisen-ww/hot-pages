# 可用空间重塑合作与生存的新博弈理论模型

> 原标题：Available space reshapes cooperation and survival in new game theory model

- 发布时间：2026-11-17T17:20:05.000Z

## 摘要

该研究扩展了经典博弈理论模型，通过引入可用空间的变化来调整博弈的收益规则。研究发现，可用空间的增加会提高合作收益并降低背叛收益，从而影响生态演化结果。该模型有助于理解生态条件如何塑造进化结果，相关成果发表在 PNAS Nexus 上。
