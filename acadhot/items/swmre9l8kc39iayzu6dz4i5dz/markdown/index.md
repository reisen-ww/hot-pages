# 英国智库预测通胀明年达到4.4%峰值，2030年才能回落至目标水平

## 摘要

英国国家经济社会研究院预测，受伊朗冲突影响，英国通胀率将于2027年2月达到4.4%的峰值，直到2030年下半年才会回落至2%的目标水平，比此前预测晚一年。
