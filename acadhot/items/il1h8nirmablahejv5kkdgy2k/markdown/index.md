# 某团队在 bioRxiv 发表超导过渡边传感器活细胞成像研究成果

> 原标题：Confocal Live-Cell Imaging Under Ultralow Irradiance Using Superconducting Transition-Edge Sensor

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/il1h8nirmablahejv5kkdgy2k
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.767203v1?rss=1

## 摘要

该研究展示了超导过渡边传感器（TES）结合共聚焦激光扫描荧光显微镜（CLSFM）能以常规方法所需1/400的激光强度区分两种产油酵母物种。实验证实该技术可抑制光漂白和细胞分裂停滞，支持长期活细胞观测，为减少细胞损伤和维持生理状态提供新工具。

## 推荐理由

该研究提出了一种基于超导过渡边传感器的低光活细胞成像技术方案，为减少细胞损伤和长期观察提供了新方法。
