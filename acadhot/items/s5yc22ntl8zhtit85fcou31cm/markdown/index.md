# 智利生态与生物多样性研究所联合团队在《Journal of Environmental Management》发表多目标生态恢复优先区域模型

> 原标题：New model identifies priority areas for large-scale ecological restoration in Chile

- 发布时间：2026-11-17T22:40:01.000Z

## 摘要

智利生态与生物多样性研究所（IEB）联合多机构团队开发了一款多目标优化模型，用于确定智利大规模生态恢复的优先区域。研究将812,910个1平方公里规划单元划分为北部（生态可行性为主）、中部（物种灭绝风险优先）和南部（碳汇储备关键）三个区域，80.4%的规划单元同时满足两个以上生态目标。
