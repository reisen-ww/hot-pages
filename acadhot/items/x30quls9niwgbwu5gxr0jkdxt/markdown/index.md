# 某研究团队在bioRxiv发表青少年大脑微架构与性激素关联研究

> 原标题：Beyond morphometry: Adolescent brain microarchitecture reflects sex differences in pubertal timing and hormones

## 摘要

某研究团队在7,457名9-13岁青少年中通过限制光谱成像（RSI）技术发现，大脑微架构差异与性激素水平相关，女性青少年细胞密度差异随年龄增长扩大，男性青少年神经突密度差异在青春期早期更显著。研究重点区域包括奖赏处理相关脑区（如苍白球、伏隔核、眶额叶皮质）。样本量、技术方法、统计模型及关键结果均来自ABCD研究数据集。
