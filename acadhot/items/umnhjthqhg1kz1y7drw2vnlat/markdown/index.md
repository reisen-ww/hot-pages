# 多价 BBSome-IFT 接近支持 IFT-A-IFT-B 在体内的协调

> 原标题：Multivalent BBSome-IFT proximities support IFT-A-IFT-B coordination in vivo

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/umnhjthqhg1kz1y7drw2vnlat
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.765876v1?rss=1

## 摘要

研究通过荧光标记、FLIM-FRET 映射和结构建模，发现 BBSome 与 IFT-A 和 IFT-B 的多价接近有助于纤毛运输中的协调。BBSome 功能丧失导致 IFT-A-IFT-B 接近信号减弱和亚复合体运输动力学差异，表明 BBSome 在体内协调 IFT 中的作用。
