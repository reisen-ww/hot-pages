# 某团队在arXiv预印本发表：基于SypHer3和R-GECO1的离体心脏线粒体基质pH动态监测新方法

> 原标题：Determination of mitochondrial matrix pH during ischemia-reperfusion injury in the isolated mouse heart using a genetically encoded fluorescent sensor

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/re6j5mh0ct8dmkayk5au29um7

## 摘要

某团队开发了一种基于SypHer3荧光蛋白的离体心脏线粒体基质pH动态监测方法，通过AAV递送技术实现稳定表达，并首次在缺血再灌注损伤模型中测得pH从7.45±0.01（n=5）降至6.61±0.20（n=5）后20分钟。

## 推荐理由

该论文提出了基于荧光蛋白的线粒体基质pH测量新方法，并首次在离体心脏实验中量化了pH变化与钙离子浓度的动态关联
