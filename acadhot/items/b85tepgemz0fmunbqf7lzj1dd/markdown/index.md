# 美国技术故障源自为修复 AI 发现的漏洞

## 摘要

近日美国发生一系列技术故障，包括航班停飞和银行服务中断，原因是在修复 AI 发现的系统漏洞时一次性推送了大量补丁，超出系统承载能力。摩根大通和 NSA 分别将故障归咎于软件 bug 和例行维护。
