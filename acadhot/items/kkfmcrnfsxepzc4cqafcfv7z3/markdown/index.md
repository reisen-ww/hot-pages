# Solomon 等在 bioRxiv 发表多模态融合框架 PROGMF

> 原标题：PROGMF: Progressive Multimodal Fusion and Representation Learning for Incomplete Neuroimaging Data

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/kkfmcrnfsxepzc4cqafcfv7z3
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.17.767205v1?rss=1

## 摘要

Solomon 团队提出多模态融合框架 PROGMF，在数据不完整时通过渐进式融合方法实现更优的源表征恢复，并验证其在阿尔茨海默病神经影像数据中的有效性。实验显示该方法在四个合成神经影像模态上的源恢复误差低于传统完整数据 IVA 方法及填补缺失值基线方法，尤其当多模态数据重叠度降低时优势更明显。
