# 某研究团队发现原核生物 MVP 同源物可形成工程化 vault 纳米胶囊

> 原标题：Prokaryotic homologs of the major vault protein form engineerable vault nanocapsules

- 来源：bioRxiv
- 发布时间：2026-11-05T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/gdcq2tl3kyfuf0a3fzpn8sciw
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.04.764334v1?rss=1

## 摘要

某团队在 bioRxiv 发表预印本，首次证明原核生物 MVP 同源物能组装成 vault 颗粒，并利用尺寸排阻色谱筛选出 8 种大肠杆菌表达的 MVP 同源体。冷冻电镜解析出噬菌体同源物 L05 的壳层结构，其 MVP 链数量与真核生物不同，且可通过增加壁重复单元调控 vault 体积，为纳米胶囊载体开发提供新模型。

## 推荐理由

研究提供了原核生物 MVP 同源物形成 vault 颗粒的实验方法，其可调控的纳米胶囊结构为药物递送系统开发提供了新思路。
