# ProClust 提供单细胞转录组数据聚类的统计显著性评估

> 原标题：ProClust provides reliable statistical significance of clusters for single-cell transcriptomic data

## 摘要

ProClust 是一种用于单细胞 RNA 测序数据聚类显著性检验的新方法，通过定义单聚类为对数凹分布并采用投影方法量化聚类不确定性，避免过度分割并保留支持的亚群结构。在模拟和真实数据集中的表现表明，ProClust 能够准确识别细胞异质性，提供统计上合理且可解释的聚类框架。
