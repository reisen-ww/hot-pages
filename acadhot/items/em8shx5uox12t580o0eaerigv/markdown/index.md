# 某团队在阿尔茨海默病中揭示高神经纤维缠结颞叶内侧网络连接的功能-突触级联机制

> 原标题：Tau-vulnerable medial temporal lobe connectivity drives a functional-to-synaptic cascade in Alzheimer's disease

## 摘要

某团队在阿尔茨海默病中发现高神经纤维缠结颞叶内侧网络连接功能异常可导致突触功能障碍和认知衰退。研究基于ADNI队列（386人）和本地医院验证队列（100人），通过静息态fMRI分离出高tau病理颞叶内侧亚区，发现其功能连接异常与tau病理负荷、突触生物标志物及认知表现相关。
