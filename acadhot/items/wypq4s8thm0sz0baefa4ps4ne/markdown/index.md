# Peacock Eye Disease Management System (PedMan) 扩展至不同抗病性橄榄品种

## 摘要

研究扩展了针对不同抗病性橄榄品种的 Peacock Eye Disease Manager (PedMan) 系统，并在商业橄榄园中进行了评估。通过调整降雨和温度阈值，系统在 33 项试验中正确推荐了 30 次，准确率为 90.9%。这表明 PedMan 可以提高喷药时机的准确性，减少不必要的杀菌剂使用，适用于不同抗病性橄榄品种的病害管理。
