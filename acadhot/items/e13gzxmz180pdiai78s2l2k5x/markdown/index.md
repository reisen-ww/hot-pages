# 某团队在 bioRxiv 发表抗真菌药与 Parechovirus-A3 病毒衣壳互作机制研究

> 原标题：Structural characterization of Posaconazole- parechovirus A3 capsid interaction using molecular simulations and cell infection assays

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/e13gzxmz180pdiai78s2l2k5x
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.765989v1?rss=1

## 摘要

某团队通过分子模拟和细胞感染实验，揭示了抗真菌药Posaconazole与Parechovirus-A3病毒衣壳的两种不同结合位点（VP0-VP1界面和VP3-VP1沟槽），并发现2022年分离株及耐药突变株的VP0结合位点贡献率降为零。
