# HIV-1 ASP 蛋白质组学筛选揭示宿主细胞稳态的多维调控作用

> 原标题：A proteomics screen of HIV-1 ASP interactors reveals multifaceted effects on host cell homeostasis

- 发布时间：2026-11-11T00:00:00.000Z

## 摘要

某团队通过质谱蛋白质组学筛选发现，HIV-1 ASP蛋白与宿主细胞核、胞质及线粒体的多种蛋白相互作用，并验证其在DNA损伤修复和线粒体功能维持中的关键作用。研究揭示了 ASP 调控宿主细胞稳态的两个主要通路，为理解HIV-1持久性及病毒库长期存活机制提供新证据。
