# Gemma 4 和 Claude Sonnet 5 在工具主导型生物医药发现平台中的表现比较

## 摘要

一项研究构建了一个工具主导的多代理科学发现系统，比较了三种不同规模的语言模型（Gemma 4、Gemini 2.5 Flash 和 Claude Sonnet 5）作为协调器的效果。在单轮任务中，三种模型表现相当，专家评审也未对小型模型（SLM）给出较低评价。但在多轮任务中，Claude Sonnet 5 在证据有效性方面略胜一筹，而Gemma 4 在参数跨轮组装时表现较弱。
