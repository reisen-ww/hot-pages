# 水稻分枝调控模块的反复进化

> 原标题：Recurrent evolution of an APO1 cis-regulatory module that shapes rice panicle branching

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/a21jzty1mhe14219zqa4xkav9
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.18.767244v1?rss=1

## 摘要

研究发现水稻中一个保守非编码序列内的两个 CArG 盒调控分枝，基因编辑删除这两个盒产生不同强度的分枝增加，表明 APO1 表达受到该模块调控，支持分枝调控机制的反复进化。
