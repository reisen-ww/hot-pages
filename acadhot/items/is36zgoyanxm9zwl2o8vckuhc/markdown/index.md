# Oluk 等在 bioRxiv 发布全局运动辨别信心预测研究

> 原标题：Confidence in global motion discrimination is better predicted by perceptual reliability than by stimulus-based heuristics

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/is36zgoyanxm9zwl2o8vckuhc
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.766172v1?rss=1

## 摘要

Oluk 等通过对比两种运动整合模型，发现全局运动辨别信心主要依赖感知可靠性而非刺激启发式。研究显示标准化模型无法解释反向运动错误及信心模式，而调整型模型通过方向通道抑制和未调谐增益控制能解释90%的决策与信心差异。该模型还首次揭示元认知行为可通过感知计算机制实现。

## 推荐理由

该研究通过对比标准化与调整型运动能量模型，揭示了全局运动辨别信心与感知可靠性的强关联，为元认知行为提供了新的计算模型解释框架。
