# CTCF-anchored cohesin loops 被证实为脊椎动物特异性创新

> 原标题：CTCF-anchored cohesin loops are a vertebrate-specific innovation

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/v5qt1p9xk6oimwz63nxghxpz6
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.767090v1?rss=1

## 摘要

研究通过果蝇、七鳃鳗和脊椎动物CTCF N-terminus的跨物种比较，发现七鳃鳗CTCF N-terminus能抑制cohesin loop形成，而其他物种版本不具备此功能。微环图谱显示七鳃鳗存在独特的CTCF位点排列模式，且其启动子/增强子区域的cohesin富集程度高于有颌脊椎动物。

## 推荐理由

通过跨物种比较发现七鳃鳗的CTCF N-terminus具有抑制cohesin loop功能，而果蝇和脊椎动物的版本不具备此功能，为理解脊椎动物特异性基因调控机制提供了新证据。
