# 中国科学院合肥物质科学研究院团队在 Newton 发表新型磁体统一分类框架

> 原标题：Unified framework establishes rules for classifying unconventional magnets

- 发布时间：2026-11-12T16:00:49.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/hsyhc0yckgdkr8eqkjseujhax

## 摘要

中国科学院合肥物质科学研究院团队在 Newton (2026) 发表研究，提出基于动量空间自旋结构的统一分类框架，通过六种对称操作判定磁体类型。该框架在 MAGNDATA 数据库中筛选出93个候选磁体（排除已知反铁磁体），并发现奇数对称性磁体可能支持拓扑量子边缘态，为新型量子计算材料设计提供理论支持。DOI:10.1016/j.newton.2026.100735

## 推荐理由

该框架统一了两种非常规磁体的分类标准，解决了现有碎片化规则的问题，并成功筛选出93个候选磁体，为拓扑量子现象研究提供了新工具。
