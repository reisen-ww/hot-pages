# NTNU团队开发新型仇恨言论检测工具，实现动态网络可视化与实时预警

> 原标题：New tool maps and analyzes online hate speech

- 发布时间：2026-11-12T14:00:07.000Z

## 摘要

NTNU团队在《机器学习与知识提取》发表研究，开发工具可分析Facebook、Reddit等平台14,000条挪威及英语数据，识别涉及种族、性别认同、宗教或性取向的仇恨言论，并标注毒性等级。研究强调工具需结合人类反馈持续优化，目前正推进自动化实时检测功能。
