# 小鼠基底前脑水平对角带（HDB）与大细胞核（SI）的输入输出关系及其胆碱能调节异质性研究

> 原标题：Distinct input-output relationships between basal forebrain subnuclei underlie heterogeneous cholinergic modulation of the mouse cortex

## 摘要

某团队在 bioRxiv 发表小鼠基底前脑水平对角带（HDB）与大细胞核（SI）的解剖连接与功能异质性研究。通过抗逆行与顺行追踪技术，发现HDB和SI的投射区域高度分离但输入部分重叠。结合光遗传学刺激和全脑钙成像，证实激活前额叶皮层投射至HDB或SI可引发差异化的皮层活动模式，揭示胆碱能神经系统的功能可塑性调控机制。
