# Rhodoferax 和 Allorhodoferax 基因组大小变异反映生态策略分化

> 原标题：Genome size variability reflects contrasting ecological strategies in Rhodoferax and Allorhodoferax

## 摘要

某团队分析 345 个高质基因组（2.41-6.92 Mbp），发现 Rhodoferax 和 Allorhodoferax 在瑞典湖 Lomtjarnan 中相对丰度达 20.4%。

## 推荐理由

论文通过比较 Rhodoferax 和 Allorhodoferax 的基因组大小与代谢潜力，揭示了不同水深氧条件下的生态适应策略差异。
