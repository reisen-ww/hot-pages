# 某团队在 bioRxiv 发表陆生无脊椎动物贸易脆弱性评估框架

> 原标题：A vulnerability assessment framework for terrestrial invertebrate species threatened by wildlife trade

- 来源：bioRxiv
- 发布时间：2026-11-12T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/o3zt54byn7n7dibrwhbtlk8xw
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.766051v1?rss=1

## 摘要

某团队首次提出陆生无脊椎动物贸易脆弱性综合评估框架，基于澳大利亚多年贸易记录数据，识别出266个分布面积小于500平方公里的物种（其中蜘蛛纲占比最高），并建立透明的方法筛选贸易压力与生物脆弱性叠加的物种。该框架可迁移至其他受贸易威胁的物种评估中。

## 推荐理由

该框架为评估野生动物贸易对陆生无脊椎动物的影响提供了可迁移的方法，适用于其他受贸易威胁的物种。
