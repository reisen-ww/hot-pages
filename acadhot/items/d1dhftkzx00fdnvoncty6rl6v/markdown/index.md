# CD38-NAMPT-p21信号通路促进慢性淋巴细胞白血病应激适应机制研究

> 原标题：CD38-NAMPT-p21 signaling promotes stress adaptation in CLL

## 摘要

某团队在预印本平台发表研究，揭示CD38通过NAMPT-p21信号通路促进慢性淋巴细胞白血病（CLL）细胞应激适应。实验使用工程化MEC-1细胞验证CD38依赖性表型，并通过药理学抑制NAMPT（FK866）和p21（UC2288）证实通路作用。

## 推荐理由

论文揭示了CD38通过NAMPT-p21信号通路促进慢性淋巴细胞白血病（CLL）细胞应激适应的机制，并指出靶向NAD代谢和p21通路的潜在治疗策略。
