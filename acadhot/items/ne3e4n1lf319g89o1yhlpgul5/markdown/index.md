# 某研究团队在bioRxiv发表检测胶原蛋白IV三聚体的单克隆抗体

> 原标题：Monoclonal antibodies for detecting collagen IV α3α4α5 in basement membranes

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ne3e4n1lf319g89o1yhlpgul5
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.18.767278v1?rss=1

## 摘要

某研究团队开发出可特异性识别胶原蛋白IV 345三聚体的单克隆抗体，通过生物层干涉仪、天然点印法、变性Western印迹和荧光免疫组化验证抗体性能，并成功从敲除COL4A3/COL4A5/COL4A6的小鼠肾脏组织中富集该三聚体。
