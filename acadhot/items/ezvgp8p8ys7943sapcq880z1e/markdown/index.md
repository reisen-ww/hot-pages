# DAB2调控微胶质状态关联APOE基因型与阿尔茨海默病风险

> 原标题：The adaptor protein DAB2 cell-autonomously links APOE with disease-associated microglia (DAM)/TREM2 state dysregulation associated with Alzheimer's disease

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ezvgp8p8ys7943sapcq880z1e

## 摘要

某团队在bioRxiv发表预印本，揭示DAB2调控微胶质状态关联APOE基因型与阿尔茨海默病风险。研究发现DAB2在微胶质中随淀粉样病理进展动态失调，其转录网络与DAM/TREM2相关疾病状态及APOE4携带者微胶质炎症信号通路改变一致。动物模型显示RELN缺失导致微胶质树突分支减少和CD68表达升高。

## 推荐理由

论文揭示了DAB2通过调控微胶质状态影响APOE基因型与阿尔茨海默病风险的分子机制，为靶向DAB2的干预手段提供了理论依据。
