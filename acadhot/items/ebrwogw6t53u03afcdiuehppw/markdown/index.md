# 利用昼夜韧性实现需求灵活的受控环境农业

> 原标题：Harnessing Circadian Resilience for Demand-Flexible Controlled Environment Agriculture

## 摘要

研究表明，通过动态调整光照周期，可以在保持作物产量的同时，最大化利用可再生能源并减少运营成本。商业规模试验显示，需求灵活的光照策略对 basil、lettuce、mustard greens 和 rocket 的收获量影响甚微。昼夜系统的韧性表明，受控环境农业可以为低碳农业系统提供有效的可需求灵活性，支持可再生能源的整合。
