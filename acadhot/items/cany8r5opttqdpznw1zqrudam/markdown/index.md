# 圣米尼阿山大学百万健康发现计划研究团队：罕见获得性与失功能性变异的表型景观分析

## 摘要

圣米尼阿山大学百万健康发现计划研究团队在 medRxiv 发表研究，系统分析 18,214 个基因中罕见预测获得性与失功能性变异与 1,244 种二分类及 202 种定量表型的关联，发现基因-表型关联在组合不同功能效应的变异时会被掩盖，并通过蛋白质组学验证了 VNN1 失功能变异与体质量指数的关联。

## 推荐理由

论文提出了通过功能分层分析变异来避免传统聚合方法的干扰，该方法可迁移至其他多效性变异的研究中。
