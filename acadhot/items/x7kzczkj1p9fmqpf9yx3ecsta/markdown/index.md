# B7-H3调控胰腺癌纤维-免疫空间组织新机制

## 摘要

研究揭示B7-H3在未经治疗的胰腺癌样本中呈现区域性表达，并调控肿瘤微环境的纤维-免疫空间组织。该分子从上皮内源性肿瘤架构向纤维-免疫状态转变，与免疫抑制、疾病进展及预后不良相关。新辅助治疗中观察到该调控模式的保守性。研究采用整合多尺度空间谱系分析技术，首次在人类实体瘤中建立B7-H3表达与微环境状态的空间关联模型。
