# 某团队在bioRxiv发表糖尿病神经痛的线粒体功能障碍与翻译调控机制研究

> 原标题：Mitochondrial dysfunction activates a translational stress response that drives diabetic pain

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/r6182164977qtix34vhckf9r4
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.765941v1?rss=1

## 摘要

某团队发现GCN2激酶通过线粒体功能障碍激活翻译应激反应，驱动糖尿病神经痛。实验表明抑制GCN2或过表达线粒体靶向NADH氧化酶mitoLbNOX可缓解小鼠模型中的机械性超敏反应，钙成像证实GCN2基因敲除减少TRPA1受体激活引发的钙内流。研究首次揭示线粒体代谢紊乱与神经痛的分子连接点。

## 推荐理由

论文提出了通过抑制GCN2激酶或过表达mitoLbNOX来缓解糖尿病神经痛的干预方法，为同类代谢相关疾病提供可迁移的分子调控思路。
