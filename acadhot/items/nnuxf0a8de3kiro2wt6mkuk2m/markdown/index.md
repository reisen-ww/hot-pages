# 扬州大学与南京农业大学团队在JIA发表萝卜原生质体高效分离与瞬时转化体系

## 摘要

扬州大学与南京农业大学团队在《农业科学学报（英文）》（JIA）发表研究，建立萝卜子叶和下胚轴原生质体高效分离与瞬时转化体系。优化条件下，子叶原生质体产量达3.28×10⁶个/g⁻¹FW，转化效率76.62%；下胚轴原生质体产量1.48×10⁶个/g⁻¹FW，转化效率69.33%。
