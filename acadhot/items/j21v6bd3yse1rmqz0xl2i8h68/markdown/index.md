# 哥伦比亚某研究团队在Puerto Carreño地区发现库蚊属C. insignis、C. pusillus和C. ignacioi携带OROV病毒RNA，其中C. insignis的携带率为3.61/1000人

## 摘要

哥伦比亚某研究团队在Puerto Carreño地区开展两季生态调查，采集1639只库蚊标本，通过COI条形码鉴定出8个物种。其中C. insignis占捕获量的70%以上，且在C. insignis、C. pusillus和C. ignacioi中检出OROV RNA，经RT-qPCR和纳米孔测序确认。
