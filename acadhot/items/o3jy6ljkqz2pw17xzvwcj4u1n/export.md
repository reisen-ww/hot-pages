# Windows 收集用户编程智能体和开发工具使用记录

## 摘要

Windows 通过 MissionControlAggregator.dll 记录用户使用的编程智能体（如 codex.exe、claude.exe）和开发工具（如 python.exe、dotnet.exe），除非用户选择退出，默认这些数据会发送给微软。
