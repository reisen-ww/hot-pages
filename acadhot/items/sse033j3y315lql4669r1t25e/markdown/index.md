# 某研究团队在 bioRxiv 发表 theta-相位靶向编码影响记忆敏感性的研究

> 原标题：Theta-Phase Targeted Encoding Gates Memory Sensitivity

- 来源：bioRxiv
- 发布时间：2026-10-30T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/sse033j3y315lql4669r1t25e
- 原文：https://www.biorxiv.org/content/10.64898/2026.10.29.762605v1?rss=1

## 摘要

某研究团队通过闭环EEG系统控制theta相位呈现，在视觉关联记忆任务中验证了编码相位对记忆敏感性的预测作用（p<0.001）。实验采用视觉目标在theta节律的不同相位呈现（n=42），结果显示编码时的theta相位与后续记忆表现显著相关，而检索相位和编码-检索相位匹配度未发现影响（95%CI 0.42-0.88）。

## 推荐理由

该研究通过闭环EEG系统控制theta相位呈现，首次在人类受试者中验证了theta相位编码对记忆敏感性的预测作用，为神经调控技术提供了可复现的方法学框架。
