# MLL4（KMT2D）调控腭唾液腺发育机制研究

> 原标题：MLL4 regulates palatal salivary gland development

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/d4x544p9fgzfoh4dhrb5cahd4

## 摘要

研究团队通过构建 Mll4fl/fl;Osr2-Cre 条件敲除小鼠模型，发现 MLL4 缺失导致出生至成年期腭唾液腺发育不良并伴随软腭异位软骨形成。RNA-seq 分析显示腭腺发育相关基因（如 FGF10、SOX9）表达下调，而软骨增殖相关通路上调。原位杂交和免疫荧光证实 MLL4 通过调控间充质-上皮信号协调腭部正常发育。该成果首次阐明 MLL4 在腭部形态发生中的分子机制

## 推荐理由

论文通过条件敲除小鼠模型和转录组分析，首次揭示 MLL4（KMT2D）在腭唾液腺发育中通过调控成纤维细胞增殖和FGF/WNT信号通路起关键作用，为颅面发育相关疾病治疗提供新靶点
