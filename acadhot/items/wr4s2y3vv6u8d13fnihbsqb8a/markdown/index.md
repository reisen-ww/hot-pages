# DGIST 与 POSTECH 联合开发3D仿生衰老肌肉模型，可替代动物实验

> 原标题：Team develops 3D biomimetic aging muscle model that can replace animal experiments

- 来源：Phys.org
- 发布时间：2026-11-16T16:20:35.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/wr4s2y3vv6u8d13fnihbsqb8a
- 原文：https://phys.org/news/2026-11-team-3d-biomimetic-aging-muscle.html

## 摘要

DGIST 与 POSTECH 联合开发出可模拟人类肌肉衰老变化的3D人工肌肉微组织模型。研究使用17岁和68岁男性供体的肌肉细胞，混合脱细胞外基质生物材料后通过3D打印成型。

## 推荐理由

该模型为替代动物实验提供了新工具，符合FDA新规要求，可能加速抗衰老疗法开发
