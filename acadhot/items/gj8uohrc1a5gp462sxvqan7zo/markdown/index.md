# Corvex签署1.03亿美元英伟达Blackwell算力保底采购协议

- 发布时间：2026-11-16T23:32:06.000Z

## 摘要

AI云计算公司Corvex与大型AI推理平台客户签署为期三年的1.03亿美元算力服务协议，采用“照付不议”模式。部署成本预计为7800万美元，其中客户预付款2600万美元，贷款融资3800万美元。相关设备预计于2027年第一季度投入服务，届时Corvex美国中大西洋1号数据中心的年度合同经常性收入将增至约5600万美元。
