# 某研究团队在 bioRxiv 发表 GBA1 变体功能参考框架

> 原标题：A harmonized functional reference framework for GBA1

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/vcci79yuo0sfaxwgdnfwq1urt
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.15.766795v1?rss=1

## 摘要

某研究团队通过MAVE方法建立了GBA1变体的功能参考框架，覆盖超过10400个单氨基酸替换变体，发现94个临床意义不明确的变体存在显著功能缺陷，并与Gaucher病严重程度相关。整合全球帕金森病遗传计划数据，证实功能缺陷程度与帕金森发病时间及风险比呈正相关。独立验证实验在稳定细胞系中复现了MAVE分析结果，并解决了野生型附近变体的细微功能差异问题。

## 推荐理由

该研究提供了GBA1变体功能评估的标准化方法，其MAVE分析框架可迁移至其他溶酶体相关疾病的功能变体解析。
