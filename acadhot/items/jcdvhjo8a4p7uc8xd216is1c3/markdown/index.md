# 某团队在 Scientific Reports 发表深海采矿破坏独特栖息地的研究

> 原标题：Deep-sea mining could destroy unique habitats hidden inside metal-rich nodules

- 来源：Phys.org
- 发布时间：2026-11-11T10:00:08.000Z

## 摘要

某研究团队在 Scientific Reports 发表论文，揭示深海多金属结核中存在独特微小生物群落。分析244个结核样本发现平均每结核17个生物体，单结核最高达245个。遗传学显示这些群落与周边沉积物生物群差异显著，且在1000公里范围内相似度高。研究强调采矿将永久摧毁此类地质时间尺度的特殊栖息地，为制定深海保护区规划提供依据。
