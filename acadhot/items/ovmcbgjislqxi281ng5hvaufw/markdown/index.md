# 得州农工大学团队通过海豹幼崽神经学评估揭示汞暴露影响

> 原标题：What seal pups can reveal about the effects of mercury exposure

- 来源：Phys.org
- 发布时间：2026-11-10T12:20:14.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ovmcbgjislqxi281ng5hvaufw

## 摘要

得州农工大学团队通过标准化神经学检查方法，发现海豹幼崽出生前汞暴露与其触觉反应及康复时间相关。研究显示汞和PCB/DDT等污染物通过食物链富集，幼崽神经功能异常可能影响野外生存能力。该检查方法可同时用于评估海洋哺乳动物及人类的神经毒性暴露影响，并建立One Health跨物种研究框架。
