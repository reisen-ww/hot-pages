# 两种新物种和两种暗色真菌扩展单种属 Innospora

## 摘要

研究基于部分 rDNA 序列的形态和系统发育分析描述了两种新物种 Innospora atollensis 和 Innospora fodinalis，扩展了单种属 Innospora。
