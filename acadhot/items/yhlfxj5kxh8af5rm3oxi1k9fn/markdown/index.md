# Egami 等提出质粒丢失频率的高效估算新方法

## 摘要

Egami 等提出基于抗生素筛选的质粒丢失频率量化新方法，该方法无需修改质粒序列且能明确区分低拷贝质粒细胞。研究显示该技术适用于自然存在小拷贝质粒的稳定性研究及筛选影响稳定性的调控因子，并验证了质粒序列非ori区适度改造对早期质粒丢失影响有限。
