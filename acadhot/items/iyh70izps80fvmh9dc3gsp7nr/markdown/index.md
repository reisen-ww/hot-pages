# 双动机选择范式揭示内在与外在动机药物反应差异

> 原标题：A Dual Effort Choice paradigm reveals pharmacological divergence between intrinsic and extrinsic motivation within the same task environment

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

该研究开发了一种同时量化内在和外在动机行为的新任务，发现多巴胺信号减少在新任务中同时降低了两种动机的行为动机，而急性血清素和多巴胺信号增加则表现出更复杂的机制差异。这一任务为表征不同动机形式的药物效应提供了新方法。
