# 生物干预性房水流出增强术后12个月安全结果：来自395眼的CREST研究

## 摘要

某研究团队在CREST试验中评估了生物干预性房水流出增强术的12个月安全性，结果显示无内皮细胞衰竭或眼内炎发生（395眼，平均年龄72.8岁）。主要终点包括用药减少42%（从1.9降至1.2次/周）、IOP从19.1降至14.5 mmHg（p<0.001），34眼（8.6%）出现IOP持续升高，15眼（3.8%）BCVA下降≥2行，6眼（1.5%）出现血肿。
