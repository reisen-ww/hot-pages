# 果蝇与土壤线虫的水平基因转移推动功能趋同：基于代谢与进化分析

> 原标题：Extensive HGT between soil-living hexapods contributes to functional convergence

- 发布时间：2026-11-16T00:00:00.000Z

## 摘要

该研究鉴定了果蝇与土壤线虫间440次水平基因转移事件，其中352次涉及碳水化合物代谢相关基因（n=264）。发现线虫获得的非动物源基因在果蝇中同样具有代谢功能，且幼虫期表达量显著升高。研究证实土壤线虫的基因转移可能加速了果蝇在陆地生态位的定植，并揭示动物间水平基因转移的普遍性。

## 推荐理由

该研究揭示了线虫与果蝇间水平基因转移对代谢功能的关键作用，为解析无脊椎动物进化中的功能趋同提供了新证据链。
