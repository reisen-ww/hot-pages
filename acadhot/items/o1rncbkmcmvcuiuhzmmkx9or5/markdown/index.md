# 基因解析宏基因组揭示垃圾填埋场渗滤液SBR微生物群中氮转化潜力的分布

> 原标题：Gene-resolved metagenomics reveals partitioned nitrogen transformation potential in a landfill leachate sequencing batch reactor microbiome

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/o1rncbkmcmvcuiuhzmmkx9or5
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.763769v1?rss=1

## 摘要

该研究应用基因解析宏基因组技术分析了英国垃圾填埋场渗滤液SBR污泥样本，发现氮转化潜力在主要和次要微生物类群间分布。Nitrospirota和Pseudomonadota是主要类群，而Actinomycetota尽管占4%，但包含高比例氮代谢基因。
