# 乌鸦决策速度是人类的2倍，图宾根大学研究揭示鸟类大脑快速处理机制

> 原标题：Crows can make decisions twice as fast as humans, scientists discover

## 摘要

图宾根大学研究团队发现乌鸦的视觉决策速度是人类的2倍，其大脑在70毫秒内启动决策相关神经元活动。实验显示乌鸦通过视触屏判断运动方向，准确率达近100%。神经活动记录表明，乌鸦在dots出现后70毫秒即激活对应决策的神经元模式，且神经信号强度与决策清晰度正相关。该成果为理解不同进化路径动物的大脑决策机制提供了新证据，特别揭示了鸟类缺乏皮质层却实现快速决策的神经基础差异。
