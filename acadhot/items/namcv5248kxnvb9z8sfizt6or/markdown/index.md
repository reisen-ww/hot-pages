# 对象特征在扫视速度下幸存但与特定对象的关联丢失

> 原标题：Object features survive motion at saccadic speed but lose their link to specific objects

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/namcv5248kxnvb9z8sfizt6or
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.765345v1?rss=1

## 摘要

在两项实验中，当眼睛固定时，两个Gabor斑点携带数字并以扫视速度移动，研究发现对象特征在扫视速度下幸存，但与特定对象的关联丢失。较长持续时间下复制了对象特定预览益处，但在扫视持续时间内该益处消失，添加区分表面特征也无法恢复。
