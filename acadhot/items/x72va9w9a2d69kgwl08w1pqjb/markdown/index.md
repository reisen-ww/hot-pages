# 约翰霍普金斯大学在《NeuroImage Reports》发表阿尔茨海默病早期脑区萎缩研究成果

> 原标题：Alzheimer’s may start shrinking two brain regions years before memory loss

- 来源：ScienceDaily 综合
- 发布时间：2026-11-15T04:31:56.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/x72va9w9a2d69kgwl08w1pqjb
- 原文：https://www.sciencedaily.com/releases/2026/11/261114202130.htm

## 摘要

约翰霍普金斯大学研究发现，阿尔茨海默病早期即可在杏仁核（amygdala）和边缘皮层（entorhinal cortex）观察到脑萎缩，较传统海马体检测提前10年。
