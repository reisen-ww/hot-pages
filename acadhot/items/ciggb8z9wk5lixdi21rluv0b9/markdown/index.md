# 内在动机的神经认知标记：自然主义 fMRI 模式下的信息寻求与记忆形成机制

> 原标题：Neurocognitive signatures of intrinsic motivation in naturalistic information seeking and memory

- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

某团队通过自然主义 fMRI 模式发现，内在动机的‘渴望’和‘愉悦’维度分别激活了目标导向认知和情感相关脑区，并共同影响记忆形成。被动浏览虽削弱动机强度，但两者仍通过默认模式网络预测记忆和跨个体神经相似性。
