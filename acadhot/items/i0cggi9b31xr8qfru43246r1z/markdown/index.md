# 新型脑膜炎球菌B疫苗预防淋病

> 原标题：Meningococcal B Vaccine to Prevent Gonorrhea

- 来源：NEJM
- 发布时间：2026-11-18T10:00:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/i0cggi9b31xr8qfru43246r1z

## 摘要

新英格兰医学杂志报道，一种新型脑膜炎球菌B疫苗在预防淋病方面显示出潜力。该研究显示，接种该疫苗的受试者中淋病发病率显著降低，为预防性用药提供新途径。
