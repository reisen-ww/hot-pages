# 华中科技大学同济医学院潘安团队：BMI诊断误差导致临床肥胖风险被低估

> 原标题：BMI 误判数百万人肥胖

## 摘要

潘安团队基于4国84万人数据证实，BMI将22.7%-31.3%临床前肥胖者误判为健康，且临床前肥胖者全因死亡风险增加19%（进展为临床肥胖者达69%）。研究提出需区分BMI数值与实际内脏脂肪堆积程度，建议临床前肥胖阶段（BMI 25-30）即启动生活方式干预。

## 推荐理由

研究提供了BMI诊断的误差范围（5.2%-8.6%被低估）和临床前肥胖的转化率（77%-91%未进展），为肥胖干预提供分层依据
