# 自闭症谱系障碍者在基本级与超级视觉搜索中的反应时间差异研究

> 原标题：Visual Search and ASD: Basic vs. Superordinate Category Search

- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

研究比较了26名自闭症患者与11名典型神经组在基本级和超级视觉搜索任务中的反应时间，发现超级分类在ASD组中显著更慢（99 ms/item vs 70.8 ms/item）。实验包含4/16/36/64元素组规模的视觉搜索任务，并分析典型性对分类和检测速度的影响。样本量、年龄和智商测试得分与NT组无显著差异。
