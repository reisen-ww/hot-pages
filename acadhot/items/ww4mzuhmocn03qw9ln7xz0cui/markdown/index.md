# 鳄鱼幼崽的休息痕迹被保存了逾百万年

> 原标题：Dinosaur’s rest break leaves a lasting impression

- 来源：Nature
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ww4mzuhmocn03qw9ln7xz0cui
- 原文：https://www.nature.com/articles/d41586-026-03749-x

## 摘要

一块化石记录了一只一米高的幼年爬行动物坐下休息时留下的足迹和臀部印记，这些印记在秘鲁的岩石中保存了超过一亿年。
