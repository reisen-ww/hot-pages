# 日本东京大学与国立理工学院合作发表金-铜策略合成氮掺杂碳纳米环链研究

> 原标题：A gold–copper strategy for building interlocked nitrogen-doped carbon nanohoops

## 摘要

日本东京大学与国立理工学院合作开发金-铜动态键合系统，将氮掺杂碳纳米环链的合成步骤从传统超过10步简化至8步，产率达2.9%。该结构具有可调控的手性特性，通过结合不同旋性的铝配合物试剂，可实现分子构型的定向选择。
