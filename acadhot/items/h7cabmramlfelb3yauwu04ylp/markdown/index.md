# 亲代基因型通过调控蜕皮激素合成影响蚂蚁幼虫体型及分工

## 摘要

某团队在 bioRxiv 发表研究，揭示亲代基因型通过调控蜕皮激素合成影响 Ooceraea biroi 幼虫体型及社会分工。研究发现幼虫转录组中神经肽（如 octopamine 和 serotonin）及蜕皮激素合成基因（如 ecdysone) 存在亲代基因型差异，脂代谢相关载体蛋白基因表达受此调控。该机制首次阐明亲代基因型通过神经激素-脂代谢轴影响幼虫发育的分子通路，为昆虫发育研究提供新视角。

## 推荐理由

论文揭示了神经激素调控蚂蚁幼虫体型和分工的分子机制，为昆虫发育研究提供新思路。
