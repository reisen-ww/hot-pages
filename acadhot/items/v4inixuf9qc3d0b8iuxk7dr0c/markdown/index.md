# McSweeney等在《Nature Astronomy》发现白矮星脉冲星每8分钟闪射无线电波，伴星酷似太阳

## 摘要

澳大利亚莫西逊宽场阵列射电望远镜团队在《Nature Astronomy》发表研究，首次确认白矮星脉冲星围绕类太阳恒星运行，并揭示其脉冲周期与轨道参数的关联。通过分析脉冲信号的时间窗口（每32小时周期内6小时脉冲窗口）和光谱特征（确定伴星为G型恒星），计算出脉冲星质量约为太阳的2/3，排除了中子星的可能。该发现为Type Ia超新星标准烛光机制研究提供新线索，未来SKA望远镜有望发现更多类似系统。
