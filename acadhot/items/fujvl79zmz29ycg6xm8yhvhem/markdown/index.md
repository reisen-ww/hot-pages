# 某团队提出基于迭代优化的新型蛋白质序列结构优化方法

## 摘要

某团队提出基于迭代优化的蛋白质序列结构优化方法，在224个蛋白测试中使平均RMSD从8.097 Å降至4.570 Å（降幅43.6%），显著优于ProteinMPNN（降幅46.2%）和原生ESMFold序列（降幅27.2%）。 paired t-test验证p < 0.001（显著差异）。研究证明后预测迭代优化可有效提升人工设计蛋白的结构精度。
