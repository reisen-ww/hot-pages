# 21世纪天气研究团队在EGUsphere发表热带暴雨与干燥大气关系研究

> 原标题：Why fierce tropical downpours thrive in a relatively dry atmosphere

## 摘要

21世纪天气研究团队在EGUsphere发表研究，揭示干燥大气中因温度垂直递减快导致不稳定条件，从而形成强烈局部暴雨。该模型通过结合20年天气雷达观测数据和大气温湿度数据，量化了云体与周围环境的混合程度，并指出混合强度与暴雨强度无直接关联。研究为改进天气气候模型提供了新思路，后续将验证模型在达尔文以外的适用性。
