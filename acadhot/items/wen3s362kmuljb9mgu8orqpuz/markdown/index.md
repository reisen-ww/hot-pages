# 芝加哥大学团队在《Nature Communications》揭示海洋酸化导致硅溶解度下降及浮游植物生产力受损

> 原标题：At base of ocean food chain, scientists uncover impacts of a changing atmosphere

- 来源：Phys.org
- 发布时间：2026-11-17T23:40:06.000Z

## 摘要

芝加哥大学研究团队基于华盛顿州Tatoosh岛40年数据，发现海洋酸化通过降低硅溶解度，导致浮游植物生产力下降，并影响太平洋鲱鱼资源。该研究发表于《Nature Communications》，为理解二氧化碳排放的生态效应提供了新机制。
