# 中国科学院与华中农业大学合作在 Cell 发表论文，揭示谷物中镍的长距离运输机制

> 原标题：Tiny nutrient, big mystery: Key gene reveals how cereal crops transport nickel

- 来源：Phys.org
- 发布时间：2026-11-10T16:00:10.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/jk9a7jf6cwv9rh97la4encvue
- 原文：https://phys.org/news/2026-11-tiny-nutrient-big-mystery-key.html

## 摘要

研究团队通过全基因组关联分析（GWAS）在1404份玉米材料中发现 ZmNAET1 基因，证实其调控籽粒镍含量、穗重、淀粉含量及发芽率。基因功能受阻时，籽粒镍含量下降60%，发芽率降低。
