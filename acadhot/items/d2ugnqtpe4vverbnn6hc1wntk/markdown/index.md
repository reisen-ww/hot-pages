# 电子病历中床边疼痛评估的时间标注及其对止痛药起效时间估计的影响

## 摘要

在重症监护病房（ICU），68% 的疼痛评分和 76% 的镇静评分在整点时间记录，延迟约 41-44 分钟。整点记录中约 32-34% 的重新评估时间在用药前，而非整点记录中这一比例为 12-14%。
