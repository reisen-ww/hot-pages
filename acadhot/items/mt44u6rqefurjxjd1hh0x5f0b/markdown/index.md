# 工作与展示用德国牧羊犬基因差异显现

## 摘要

瑞典乌普萨拉大学和瑞典农业科学大学的研究发现，工作用和展示用德国牧羊犬在行为和基因上存在差异。工作犬表现出更少的恐惧和更多的好奇心，且研究识别出与好奇心和玩耍行为相关的基因。该研究发表在《动物遗传学》期刊上。
