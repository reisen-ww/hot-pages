# 基于解剖感知的3D GAN及其局部掩码精修在脑MRI修复中的应用

## 摘要

该研究提出了一种基于解剖感知的三维生成对抗网络，结合了掩码感知卷积、镜像对侧上下文、注意力调节跳跃融合、边界感知精修和局部掩码区精修等技术，用于脑肿瘤MRI修复。该模型在BraTS 2026挑战赛中获得0.658的平均SSIM和14.81 dB的平均PSNR，但未超过Pix2Pix3D基线。研究透明地报告了结果，并分析了可能的影响因素。
