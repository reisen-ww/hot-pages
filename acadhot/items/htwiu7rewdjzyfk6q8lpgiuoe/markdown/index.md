# 某团队在bioRxiv发表UCN2肽促进减脂同时保留肌肉功能的研究

> 原标题：Modified Long-Acting UCN2 Promotes Fat Mass Loss While Preserving Skeletal Muscle Mass and Function in Mouse Models of Pharmacological Weight Loss and Sarcopenic Obesity

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/htwiu7rewdjzyfk6q8lpgiuoe

## 摘要

某团队在小鼠模型中证明UCN2肽可减少脂肪质量（平均降低42%）同时保持骨骼肌质量和功能，与semaglutide联用减脂效果提升至58%，且停药4周后仍有效。研究首次展示UCN2通过激活CRHR2受体抑制脂肪生成并促进脂肪酸氧化，为肥胖合并肌肉萎缩的联合疗法提供了实验依据。

## 推荐理由

论文提供了UCN2肽与GLP-1受体激动剂联用后4周内仍保持减脂效果的关键数据，为肥胖合并肌肉萎缩的联合疗法提供了实验依据。
