# 比较Illumina MiSeq 2x300、2x500与Element AVITI在16S/18S基因测序中的生态模式一致性

> 原标题：Illumina MiSeq, MiSeq i100, and Element AVITI yield concordant ecological patterns for universal 16S and 18S rRNA gene amplicon sequencing

## 摘要

该研究系统比较了Illumina MiSeq 2x300、2x500与Element AVITI在16S和18S rRNA基因测序中的生态模式一致性，发现平台间结果相似但MiSeq 2x500跳跃指数更高（5.9 +/- 3.8% vs. 1.3 +/- 1.5%）。
