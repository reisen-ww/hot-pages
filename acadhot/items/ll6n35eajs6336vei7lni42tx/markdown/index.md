# GEAR 算法提前确认青光眼进展

> 原标题：Earlier confirmation of glaucoma progression with risk-weighted visual field and OCT scheduling

- 来源：medRxiv
- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

GEAR 算法通过风险加权视网膜视野和 OCT 检查间隔策略，使青光眼进展确认提前 3.4 个月，与每年一次的 VF 和 OCT 测试相比，且测试频率相似。该算法在多个比较中保持优势，验证了其在青光眼监测中的有效性。
