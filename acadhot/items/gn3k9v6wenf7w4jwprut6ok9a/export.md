# SRAscout: 统一元数据的公共测序数据语义检索平台

## 摘要

SRAscout 是一个基于 web 的平台，通过整合 SRA 运行元数据和相应的 BioProject 记录，实现语义化的数据集检索。该平台收集并索引了约 714,000 个 BioProject 的元数据，将样本属性如细胞系、组织、年龄、性别和治疗统一到一个紧凑且一致的模式中。
