# 重新评估澳大利亚棉属物种的同倍体杂交物种形成

> 原标题：Revisiting homoploid hybrid speciation in Australian cotton (Gossypium) species

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/x2r0r262zq5omqb00yem9pccz
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.765769v1?rss=1

## 摘要

研究者基于18,784个单拷贝核基因和整个叶绿体序列，重新评估了澳大利亚棉属物种G. bickii的进化历史，发现虽然叶绿体数据与早期研究一致显示核基因和叶绿体的分歧，但全基因组核数据未发现显著的种间杂交证据，表明早期快速分化伴随叶绿体的早期交联，但核基因组中无残留证据。
