# NIGMS 研究团队在 bioRxiv 发布RhoA膜定位的分子机制研究

> 原标题：Catalytic domain-lipid interactions negatively regulate RhoA signaling by modulating conformational dynamics

- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/jvhy1p9mcpp0v4x789ba08fkk

## 摘要

某研究团队通过分子动力学模拟和实验发现RhoA膜定位受C末端疏水相互作用和G域/N末端与阴离子脂质的电负性相互作用共同调控。突变R5/K6/K7为Ala后，RhoA介导的F-actin积累和效应器激活显著增加。分子模拟显示突变体保留了野生型RhoA的膜整体构象，但关键蛋白-脂质相互作用改变，导致协同脂质结合失效和蛋白内动态网络重排，可能影响效应器识别。

## 推荐理由

论文提供了RhoA膜定位的关键电负性相互作用数据，可作为类似蛋白结构解析的参考方法。
