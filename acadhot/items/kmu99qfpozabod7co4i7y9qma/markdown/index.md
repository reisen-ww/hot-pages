# Garside等团队发现基于UV激发自荧光的多拷贝 suppressor筛选方法揭示Cdc14相关减数分裂缺陷的调控机制

> 原标题：UV-excited autofluorescence uncovers multicopy suppressors of a Cdc14-associated meiotic defect

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/kmu99qfpozabod7co4i7y9qma
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.14.766682v1?rss=1

## 摘要

Garside等团队在Saccharomyces cerevisiae中通过UV激发自荧光技术进行多拷贝 suppressor筛选，发现四个增强减数分裂的基因组库质粒。

## 推荐理由

该研究提出基于UV激发自荧光的多拷贝 suppressor筛选方法，为后续研究提供可迁移的技术框架。
