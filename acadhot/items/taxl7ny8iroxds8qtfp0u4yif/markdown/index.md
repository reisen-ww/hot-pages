# 某团队提出共享编码器残差任务桥接网络，实现脑机接口中运动执行到想象的知识转移

> 原标题：Shared-Encoder Residual Task-Bridging Network for Motor Execution to Motor Imagery EEG Transfer in Brain-Computer Interfaces

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

某团队在 bioRxiv 发表论文，提出 SE-RTBNet 模型用于脑机接口中运动执行（ME）向想象（MI）的跨任务知识迁移。该模型在三个公开数据集上分别达到 69.39%、74.61% 和 98.94% 的分类准确率，优于现有迁移学习算法。论文公开代码于 https://github.com/Daisyzyx2002/SE-RTBNet
