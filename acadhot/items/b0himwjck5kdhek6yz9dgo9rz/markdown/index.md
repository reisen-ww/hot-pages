# 哈佛教育政策研究中心发布手机禁令对成绩影响研究

> 原标题：Q&A: Schools that ban cellphones see uptick in test scores

## 摘要

哈佛教育政策研究中心（CEPR）通过多州自然实验发现，采用Yondr手机锁袋等严格禁令的学校，学生成绩年增长率提升0.01标准差（约1-2周教学时间）。研究特别指出，对低分学生成绩下滑的遏制效果更显著，但长期影响仍需更多数据支持。该研究未纳入2025年前实施禁令或政策特殊的州，样本量覆盖全美多所公立学校。
