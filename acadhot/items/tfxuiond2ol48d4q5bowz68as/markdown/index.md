# 熟地炮制经验从意会到言传的三次化学翻译

## 摘要

某团队通过化学分析拆解熟地‘九蒸九晒’工艺，将传统经验转化为多糖水解、环烯醚萜苷转化及美拉德反应等可表征的化学事件。研究发现低聚糖组分促进能量代谢（温性药效），多糖组分抑制代谢（寒凉药效），揭示药性由组分比例决定。
