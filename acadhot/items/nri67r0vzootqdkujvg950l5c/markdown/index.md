# Saruparib 重现 PARP-BRCA 合成致死性且减少细胞毒性

> 原标题：Saruparib recapitulates PARP-BRCA synthetic lethality with PARP1-trapping properties limiting its cytotoxicity

- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

研究显示，Saruparib 具有不同于传统 PARP 抑制剂的捕获特性，对同源重组（HR）功能正常的细胞毒性较小，对 XRCC1 缺陷细胞（HR 敏感细胞）的毒性也较低。
