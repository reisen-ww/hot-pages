# IBM将停止为美国咨询部门大部分岗位提供签证和绿卡担保

- 来源：36氪
- 发布时间：2026-11-11T00:34:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/qsrinmxh7i0e8owoq3m10f8wd
- 原文：https://36kr.com/newsflashes/4064621755077513?f=rss

## 摘要

IBM决定停止为IBM咨询部门大多数职位提供签证和绿卡担保。受影响员工可以选择在美国以外地区工作或离职。咨询业务是IBM规模最大的部门，拥有逾15万名员工。
