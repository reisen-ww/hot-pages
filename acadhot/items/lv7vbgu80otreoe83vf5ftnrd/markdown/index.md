# REDUCE试验与OPTIMAL系列研究：卒中及糖尿病患者血压管理目标对比分析

## 摘要

REDUCE试验显示，卒中后早期使用螺内酯可显著降低3个月后血压至<130/80 mmHg（n=324），而OPTIMAL-DIABETES研究（n=4,736）未发现糖尿病患者的血压目标<120 mmHg能减少主要心血管事件。
