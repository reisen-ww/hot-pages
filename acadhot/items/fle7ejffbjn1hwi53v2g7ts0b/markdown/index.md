# Sun等在bioRxiv发表适应性实验室进化基因互作统计框架

> 原标题：A statistical framework for identifying candidate genetic interactions from adaptive laboratory evolution data

## 摘要

Sun等开发了计算框架，用于从适应性实验室进化数据中识别候选基因互作对。应用该方法分析141个大肠杆菌实验数据，通过Fisher精确检验和DISCOVER互补筛选，发现74对显著互作（36共现，38互斥），其中5对在两种方法中均显著。研究强调需结合菌株背景和突变来源解读结果，并指出Fisher检验需至少70独立终点以维持效力。

## 推荐理由

该框架可辅助筛选需实验验证的基因互作对，为微生物进化研究提供新工具
