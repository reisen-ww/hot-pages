# 某团队在 bioRxiv 发表葡萄糖毒性导致β细胞核糖体重塑的研究

> 原标题：Ribosome remodeling under glucotoxic conditions impairs beta-cell function

## 摘要

某团队在 bioRxiv 发表葡萄糖毒性导致β细胞核糖体重塑的研究，通过定量质谱分析发现高血糖条件下核糖体蛋白RPLP1水平下降，敲低RPLP1导致胰岛素mRNA翻译减少和葡萄糖刺激胰岛素分泌受损，体内实验证实RPLP1缺失导致葡萄糖不耐受，提示核糖体重塑是糖尿病新机制。

## 推荐理由

该研究揭示了葡萄糖毒性通过核糖体重塑影响胰岛素分泌的新机制，为糖尿病治疗提供了潜在靶点
