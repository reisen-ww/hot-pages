# Mendelnoulli 模型揭示遗传变异如何影响疾病轨迹

## 摘要

Mendelnoulli 模型通过整合多基因和单基因变异的年龄依赖性效应，首次量化了遗传变异对常见疾病轨迹的长期影响。研究显示该模型在28种测试疾病中AUC值（中位数0.95）显著优于固定年龄效应模型（0.92），且对未确诊个体的新病例识别率提升8.6%。

## 推荐理由

该模型在疾病预测中优于传统方法，其可迁移性为多基因和单基因研究提供新工具
