# 小鼠胚胎二细胞期细胞核变软促进基因组激活

## 摘要

2026年11月11日，《Nature》发表的研究发现，小鼠胚胎发育到二细胞期时，细胞核会暂时变软，这一变化与基因组激活密切相关。研究通过力学测量和分子干预证明，细胞核的机械性质影响基因表达。该发现有助于理解早期胚胎发育机制，并可能为辅助生殖技术提供新思路。
