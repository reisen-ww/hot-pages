# EPFL团队在Nature绘制小鼠脑脂质图谱，发现539个化学区域

> 原标题：Scientists uncover a hidden map of the brain with 539 distinct regions

- 来源：ScienceDaily 健康医学
- 发布时间：2026-10-13T05:00:55.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ga8r9bcibkw45ohd170301vwb
- 原文：https://www.sciencedaily.com/releases/2026/10/261012185011.htm

## 摘要

EPFL团队绘制了小鼠脑脂质图谱，发现539个具有独特脂质组合的化学区域。研究使用质谱成像分析11只小鼠的109个脑切片和172种脂质，生成约700万次测量，并通过机器学习重建三维图谱。妊娠小鼠多个脑区的脂质组成发生明显变化，图谱已免费在线开放，可用于研究脑发育、衰老及阿尔茨海默病和抑郁症相关变化。

## 推荐理由

研究将脂质分布与脑区结构联系起来，并展示妊娠期小鼠脑脂质的广泛变化，为研究脑衰老和疾病提供了新的空间参照。
