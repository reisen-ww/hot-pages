# Lalitha Regi 和 Regi George 加强农村社区健康

## 摘要

来自印度泰米尔纳德邦农村医院的医生夫妇 Lalitha Regi 和 Regi George 认识到临床治疗无法解决患者的根本问题。他们意识到需要加强社区健康，以防止患者两年后再次回到医院时仍面临相同的问题。
