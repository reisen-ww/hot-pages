# Nature 发表单一步骤集成钙钛矿极化子电路研究成果

## 摘要

意大利团队在《Nature》发表单一步骤集成钙钛矿极化子电路研究成果，该电路同时具备室温波导激光发射、可控光学路由和信号放大功能。平台通过单一步骤生长制备，实现了光电子器件的多功能集成。
