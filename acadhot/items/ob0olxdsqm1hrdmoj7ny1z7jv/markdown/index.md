# FULL-seq 揭示单细胞中异构体特异性调控架构

> 原标题：FULL-seq reveals isoform-specific regulatory architecture in single cells

- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

预印本研究提出单细胞多组学平台 FULL-seq，可同时分析染色质可及性与全长转录覆盖，精准定位基因异构体调控位点。在结直肠癌细胞中发现CALB1异构体激活与转移相关，并通过独立数据集验证。实验证实CRISPRi介导抑制该异构体可减少细胞迁移，为靶向异构体治疗提供新思路。

## 推荐理由

该研究提出单细胞多组学平台 FULL-seq，可精准解析基因异构体调控机制，为癌症转移相关基因研究提供新方法
