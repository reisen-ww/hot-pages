# Boise State University 研究发现阿拉斯加冰川单日速度激增251%

> 原标题：Heavy rain can more than double glacier speeds in Alaska

- 来源：Phys.org
- 发布时间：2026-11-07T15:40:05.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/i67d2nai5izg9v1tf9q2qq1n1
- 原文：https://phys.org/news/2026-11-heavy-glacier-alaska.html

## 摘要

Boise State University 研究团队通过 GPS 测量发现，阿拉斯加特纳冰川在单日降雨量达60毫米时，速度可增加251%，且加速与降雨滞后12小时相关。研究揭示动态排水效率是冰川加速的关键机制，为气候模型中的冰川动力学参数提供验证方法。
