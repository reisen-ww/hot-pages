# 新发现的魁北克寄生蜂攻击传播作物疾病的叶蝉

> 原标题：Newly identified Quebec wasp attacks leafhoppers that spread crop diseases

## 摘要

研究人员在魁北克发现了一种新的寄生蜂 Gonatopus quebecensis，该蜂寄生在传播作物疾病的叶蝉上。研究人员通过实验室培养和DNA条形码技术确认了这一新物种，并发现该物种在加拿大至少两个省份存在。寄生蜂可作为生物防治的重要候选者，但其控制叶蝉的效果和寄生频率仍需进一步研究。
