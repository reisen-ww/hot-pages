# 新发现的超新星 SN 2026ahvu 在附近螺旋星系 NGC 1433 中

## 摘要

在距离地球约 50 光年的螺旋星系 NGC 1433 中发现了一颗新的超新星 SN 2026ahvu，这是 Type Ia 超新星，发生在白矮星吸积物质超过钱德拉塞卡极限后爆炸。该超新星的亮度在几天内从 17 降至 13.5，为天文学家提供了早期观测机会。超新星爆发后约两个月，观测者将能够看到整个爆炸星体的光谱，这有助于更准确地构建宇宙距离阶梯。
