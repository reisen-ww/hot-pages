# 马克龙将召集科技企业会议，推动欧洲科技自主

## 摘要

法国总统马克龙宣布将于下月在巴黎与荷兰首相共同召集科技企业负责人，推动欧洲科技自主。他强调欧洲在人工智能领域具备参与竞争的条件，需加大投资和加快决策，确保企业在欧洲获得所需资源和支持。
