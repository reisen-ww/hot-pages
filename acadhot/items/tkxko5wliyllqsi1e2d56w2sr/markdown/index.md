# 某研究团队在bioRxiv发表多巴胺稳态调控奖赏行为的研究

> 原标题：Tonic dopamine regulates cell-type-specific PKA activity and motivated behavior

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/tkxko5wliyllqsi1e2d56w2sr

## 摘要

某研究团队发现多巴胺稳态水平通过调控D1R/D2R神经元活性影响动物奖赏动机行为。采用FLIPR和光遗传学技术量化多巴胺释放，并验证其对奖赏行为的影响，同时建立多巴胺稳态追踪新方法。

## 推荐理由

论文提出了基于FLIPR和光遗传学的新方法，可量化多巴胺稳态水平并验证其对动物奖赏行为的影响。
