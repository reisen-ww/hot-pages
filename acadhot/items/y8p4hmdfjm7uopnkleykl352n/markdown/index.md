# 斑腿夜蛾利用地球磁场导航机制发表于《Nature》

> 原标题：Migrating moth uses Earth's magnetic field as a compass

- 来源：Phys.org
- 发布时间：2026-11-18T19:40:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/y8p4hmdfjm7uopnkleykl352n
- 原文：https://phys.org/news/2026-11-migrating-moth-earth-magnetic-field.html

## 摘要

该研究首次揭示斑腿夜蛾通过磁场倾角角导航，实验显示磁场反转时夜蛾飞行方向随之改变。研究同时发现该机制与鸟类磁场导航存在相似性，为理解生物磁感应提供了新证据。研究团队来自隆德大学、奥登堡大学等机构，实验在非磁性实验室完成，通过磁线圈系统模拟地球磁场变化并记录夜蛾飞行方向。

## 推荐理由

该研究通过实验室实验证实斑腿夜蛾利用磁场倾角角导航，并发现其机制与鸟类存在相似性，为多物种磁感应机制比较提供了直接证据。
