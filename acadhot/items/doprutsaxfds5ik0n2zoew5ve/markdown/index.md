# Khodaei等在bioRxiv发表基于机器学习的病原体系统发育树未采样区域定位方法

> 原标题：Localizing Unsampled Regions in Partially Sampled Pathogen Phylogenies Using Machine Learning

- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

Khodaei等团队在bioRxiv发表基于机器学习的病原体系统发育树未采样区域定位方法。该方法在5000个模拟数据集上测试，成功恢复89.9%的缺失末端，并在真实SARS-CoV-2数据中验证，通过beam search定位缺失区域并估算候选最近共同祖先（MRCA），为实时追踪未采样病原体提供新工具。
