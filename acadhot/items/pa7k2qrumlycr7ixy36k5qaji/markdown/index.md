# 资源富集与利用驱动广泛观察到的生物量与生产力缩放关系

> 原标题：Resource enrichment and utilization underlie widely observed production and biomass scaling relationships

## 摘要

我们提出了一种模型，描述了浮游植物和浮游动物之间的生态互动，该模型通过资源富集的累积效应产生了广泛观察到的缩放关系，而无需考虑表型或基因型多样性对系统结构的影响。模型整合了所有生态系统共有的过程：资源富集、摄食、生长、维持和死亡，为陆地和水生环境中的生态系统结构与元素循环之间的耦合提供了约束条件。
