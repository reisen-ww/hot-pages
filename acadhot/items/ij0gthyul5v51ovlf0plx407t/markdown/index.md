# 某团队在npj Biodiversity发表南方库博雷蛙基因组选择提升疾病抗性的突破

> 原标题：Genomic breakthrough offers new hope for southern corroboree frog

- 来源：Phys.org
- 发布时间：2026-11-18T11:20:04.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ij0gthyul5v51ovlf0plx407t
- 原文：https://phys.org/news/2026-11-genomic-breakthrough-southern-corroboree-frog.html

## 摘要

某团队在npj Biodiversity发表研究，首次应用基因组选择技术于濒危蛙类保护，结果显示部分个体在接触致病真菌后存活率差异可遗传，通过选择性繁育可使下一代存活率提高约9%，同时维持遗传多样性。后续计划验证实验室成果在野外环境的效果。
