# 尼安德特人脑基因变体或降低欧洲血统人群精神分裂症风险

## 摘要

Science 报道携带尼安德特人脑基因变体的欧洲血统人群，其精神分裂症发病率可能降低。该变体影响脑结构，研究样本量为20%携带者群体，未明确提及具体风险数值或实验验证方法。
