# 双层工程提高作物抗除草剂能力

> 原标题：Dual-layer engineering of herbicide resistance in crops

- 来源：Nature Biotechnology
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/zjabery09k9912ojudeaxblhd
- 原文：https://www.nature.com/articles/s41587-026-03391-y

## 摘要

通过双层基因编辑技术，研究人员成功增强了作物对除草剂的抗性。该研究使用 CRISPR 技术在两个不同基因位点进行编辑，显著提高了作物的抗除草剂效果，为农业生产提供新策略。
