# 可计算基因组：非编码DNA和细胞行为的分层计算框架

## 摘要

研究提出了一种分层计算框架，将基因组分解为序列作为形式语言、信息承载信号、移动元素作为运行时、编译为交互网络并通过热力学和基于规则的模型，以及执行为细胞和多细胞动力学。在一项饱和诱变报告实验中，分析了38,556个单核苷酸变异，发现局部压缩性与测量效应大小相关（标准化β = -0.030，p = 0.0014），但在完全控制碱基组成后，这种关联变得不显著。
