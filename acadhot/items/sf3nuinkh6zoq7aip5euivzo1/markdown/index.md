# Ousselin等在红树林土壤中发现降解氯代农药的关键菌群特征

## 摘要

某研究团队在加勒比海小安的列斯群岛红树林土壤中发现降解氯代农药的关键菌群，其中 Dehalogenimonas 和 Desulfomonile 两种菌属在低浓度氯代农药区域占比达60%-90%。功能分析显示这些菌群携带维生素 B12 合成通路，且与土壤氯代农药浓度（<5-118.8 g kg-1）无显著相关性。研究证实红树林土壤具备天然降解氯代农药的潜力，为污染治理提供新思路。

## 推荐理由

该研究首次在红树林土壤中鉴定出降解氯代农药的关键菌群，为后续生物修复技术提供潜在菌种资源
