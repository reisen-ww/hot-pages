# Rachel Taylor 等在 npj Sustainable Agriculture 发表澳大利亚北部牧场牛群高温风险研究

> 原标题：Overheating cattle: More and more dangerous heat is coming for northern Australia's herds

## 摘要

Rachel Taylor 等在 npj Sustainable Agriculture 发表研究，指出澳大利亚北部牧场牛群高温危险日数将在2090年前增至年均195天（低排放情景143天），Bos taurus亚种（如Angus、Hereford）在热负荷指数86时已濒临危险，而Bos indicus亚种（如Brahman）可耐受至96。
