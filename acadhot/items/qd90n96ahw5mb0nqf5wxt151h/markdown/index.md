# GFP-Tel1揭示酵母中DNA复制叉逆转的跨物种机制

> 原标题：GFP-Tel1 is a marker of reversed replication forks that reveals constant fork backtracking during deoxyribonucleotide imbalance

## 摘要

某团队在酵母中发现GFP-Tel1标记的复制叉逆转现象，提出跨物种的复制压力耐受机制。研究显示Tel1在核膜附近形成焦点，与DNA损伤修复相关；首次在单细胞生物中发现复制叉逆转的保守功能，挑战了此前认为该机制仅存在于真核生物的结论。
