# 某团队在bioRxiv发布新一代基因组数据分析工具deepTools4

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

新一代基因组数据分析工具deepTools4发布，该工具通过核心算法重写和基准测试实现计算速度显著提升，支持多测序模态的可重复基因组分析。工具已开源至GitHub，包含基因组信号总结、广泛 normalization方法应用及可视化增强功能。

## 推荐理由
