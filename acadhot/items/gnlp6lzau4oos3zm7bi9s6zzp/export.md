# CbrA-CbrB双组分系统活性受假单胞菌细胞还原状态影响的机制研究

> 原标题：CbrA-CbrB Activity is Sensitive to Changes in Pseudomonas aeruginosa Cellular Redox State

## 摘要

Conaway等在bioRxiv发表预印本，通过转座子突变筛选发现CbrA-CbrB活性与胞内半胱氨酸水平正相关，且受高/低还原力双重抑制。研究证实静止期信号通路通过调控该系统活性影响ΔlasR突变株的竞争能力，并揭示其通过磷酸酶活性反馈抑制细胞还原状态。关键数据包括：ΔlasR突变株在野生型竞争中需维持CbrA-CbrB活性（实验验证周期240周）。

## 推荐理由

该研究揭示了CbrA-CbrB双组分系统活性与细胞还原状态（高/低还原力）的负反馈调节机制，为病原体代谢-适应性协同调控提供了可迁移的分子信号解析方法。
