# MIT团队与哈佛等机构在《天体物理期刊》发表研究：参宿四伴星Siwarha扰动其大气的多频段射电证据

## 摘要

MIT哈德利天文台Lynn D. Matthews博士团队联合哈佛-史密森天体物理中心、曼彻斯特大学及欧洲南方天文台，利用NSF VLA（国家科学基金会射电天文阵列）和ALMA（大型毫米/亚毫米波阵列）在22-485 GHz七频段观测中，发现参宿四大气层存在周期性椭圆变形（伴星过境时变圆）。

## 推荐理由

论文通过多频段射电观测揭示了伴星Siwarha对参宿四大气形状和温度分层的扰动机制，为未来观测提供依据。
