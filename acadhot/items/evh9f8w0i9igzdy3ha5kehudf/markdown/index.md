## 摘要

OpenAI 发布了 GPT-6.2 Astra 和 Sol 两款模型，Astra 面向复杂专业任务，提升文档、编程及科学研究等方面表现；Sol 为日常通用模型，更智能高效，可在相同付费套餐使用额度内完成更多任务。Astra 在专业工作和科学研究基准测试中取得新高，API 输入和输出 Token 价格降低 20%，缓存输入价格降低 60%。
