# 陈学思与孙静在Green Carbon发表研究：仿生微环境调控提升葡萄糖向HMF转化效率

## 摘要

陈学思与孙静团队在Green Carbon发表研究，通过仿生聚类肽构建的动态微环境调控Sn(Ⅳ)催化活性位点的电子状态、酸性和疏水性，使葡萄糖向5-羟甲基糠醛（HMF）转化效率提升，并验证了该设计适用于果糖、蔗糖等多种糖类原料。研究结合光谱表征和理论计算，揭示了聚类肽通过双酸协同（路易斯酸与羧酸）促进葡萄糖异构化及脱水生成HMF的机制，为绿色化学催化剂设计提供新思路。
