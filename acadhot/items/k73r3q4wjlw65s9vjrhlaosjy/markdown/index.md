# MetaCardis 研究团队发表代谢组学预测心血管-肾脏-代谢综合征风险的新方法

> 原标题：Metabolome-derived kidney function scores as prognostic readouts of cardiovascular-kidney-metabolic health.

- 发布时间：2026-11-10T00:00:00.000Z

## 摘要

MetaCardis 研究团队开发基于代谢组学的 CKM 风险预测模型（mKFGs），并在加拿大和德国队列中验证其优于传统 eGFRcr 指标。模型通过筛选 40-98 个代谢物（含性别分层特征），发现肉类消费和雄激素水平与 CKM 风险相关。研究提供 β-coefficient 数据供复现，原始测序数据存于 ENA（PRJEB37249 等）。
