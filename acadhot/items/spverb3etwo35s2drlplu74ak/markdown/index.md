# 圣安德鲁斯大学与牛津大学团队揭示锡矿形成源于源岩而非冷却

> 原标题：Tin deposits are formed from source rocks, not cooling

- 来源：Phys.org
- 发布时间：2026-11-09T23:20:19.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/spverb3etwo35s2drlplu74ak

## 摘要

圣安德鲁斯大学与牛津大学团队在《Geology》发表研究，推翻传统理论，指出锡矿形成的关键在于源岩的初始锡富集和还原特性，而非冷却结晶过程。通过地质建模与实验结合，发现熔融岩的还原性直接继承自源岩，且锡富集与还原环境存在于同一地质条件带。该成果为缩小锡矿勘探区域提供新方法，对能源转型中的关键金属供应有指导意义。

## 推荐理由

论文给出了地质建模与实验结合的方法，揭示锡矿形成的关键在于源岩的初始锡富集和还原特性，为矿产勘探提供新约束条件。
