# 某研究团队在 Nature 发表 TransA-MERFISH 揭示视网膜后方向选择性神经回路分化

> 原标题：TransA-MERFISH reveals divergent post-retinal direction-selective circuits

- 来源：Nature
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/pcytp9gx0p6bv3gi91049yods
- 原文：https://www.nature.com/articles/s41586-026-11235-7

## 摘要

某研究团队在 Nature 发表 TransA-MERFISH 揭示视网膜后方向选择性神经回路分化。该技术结合抗逆向追踪与空间转录组学，首次在顶盖核层区分出依赖和独立于视网膜方向选择性的神经回路，为早期视觉处理接线图重构提供了高分辨率细胞类型分辨率框架。

## 推荐理由

该技术框架可迁移至其他视觉通路研究
