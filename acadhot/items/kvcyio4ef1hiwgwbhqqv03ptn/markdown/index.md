# 神经元群体信息格式化预测不同功能对行为的贡献

> 原标题：Information formatting in neuronal populations predicts differential functional contributions to behavior

- 来源：Nature Neuroscience
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/kvcyio4ef1hiwgwbhqqv03ptn
- 原文：https://www.nature.com/articles/s41593-026-02514-7

## 摘要

研究发现，神经元群体中信息的格式化方式预测了其在不同行为中的功能贡献。该研究通过分析神经元活动模式，揭示了特定神经网络在行为执行中的独特作用。
