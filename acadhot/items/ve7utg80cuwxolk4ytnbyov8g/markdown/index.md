# 某团队在 bioRxiv 发表神经信号双向校正的 BRIDGE 模型

> 原标题：Glutamate/GABA Resource Asymmetry Enables Bidirectional Activity Correction

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

某团队在 bioRxiv 发表神经信号双向校正的 BRIDGE 模型，揭示谷氨酸/GABA释放不对称性对神经回路活动的双向调节机制。该模型通过模拟共享输入下的资源耗竭与恢复，重现了重复刺激下的谷氨酸能递质抑制现象，并发现晚期GABA能响应频率依赖性较弱。

## 推荐理由

该模型揭示了谷氨酸/GABA释放不对称性对神经回路活动的双向调节机制，为神经科学中的信号调控研究提供了可复用的分析框架。
