# 某团队在 medRxiv 发表时间嵌入3D ECG重建QRS波的研究

> 原标题：Reconstructing the range-normalized terminal QRS from V1 and V6 using the time-embedded 3D ECG

- 发布时间：2026-11-16T00:00:00.000Z

## 摘要

某团队在 medRxiv 发表研究，提出固定 V1/V6 投影的时序嵌入 3D ECG QRS 波重建方法，并通过 118 名患者验证。结果显示该方法在 V3 和 V4 导联的误差减少达 3.23 和 2.85 百分点，但 V2 改进不显著（误差减少 0.35 百分点，置信区间 -0.35 至 1.05）。

## 推荐理由

论文提供了基于时间嵌入的3D ECG重建方法在V3-V5导联的误差对比数据，为临床心电分析提供新的参考模型。
