# 机械调控在肠道手性形态发生中的作用

> 原标题：Mechanical canalization of chiral gut morphogenesis

## 摘要

通过多视角光片成像、三维几何分析和物理建模，研究发现果蝇胚胎肠道的手性由邻近器官的上皮细胞决定，并通过所有三个胚层传递，最终由肠道受限延伸的力学特性放大和固定。肌动蛋白-肌球蛋白1C在后肠上皮中的表达控制着数百微米外肠道的手性，通过迁移形成纵向肌肉的细胞传递手性偏置。随着肠道的延伸，弯曲不稳定性放大了早期的左右不对称收缩，限制性将器官导向一种特定的手性螺旋。
