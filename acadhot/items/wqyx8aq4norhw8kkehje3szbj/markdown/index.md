# Eli Lilly 的 GLP-1 片剂 Foundayo 在治疗睡眠呼吸暂停方面效果有限

## 摘要

在一项为期一年的 III 期临床试验中，Eli Lilly 的 GLP-1 片剂 Foundayo 使睡眠呼吸暂停患者的 AHI 指数平均每小时减少 17.8 个事件，而安慰剂组为 4.5 个事件。治疗组中有 28% 的患者达到缓解或轻度疾病，安慰剂组为 13%。尽管 Foundayo 在两项晚期研究中显示出减轻睡眠呼吸暂停的效果，但其效果不如 Lilly 的注射药物 Zepbound。
