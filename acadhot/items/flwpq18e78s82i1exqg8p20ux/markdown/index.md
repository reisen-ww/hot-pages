# 沃利基亚自然公园发现99种蝙蝠新物种

> 原标题：Bolivia's Madidi National Park shelters 99 bat species, including 7 new to the country

## 摘要

科学家在玻利维亚沃利基亚自然公园发现了100种蝙蝠种类，其中包括99种已知物种和可能的新物种。研究团队通过多种方法调查了该公园的蝙蝠多样性，确认了公园内蝙蝠种类占玻利维亚已知蝙蝠种类的68%。研究结果发表在开放获取期刊ZooKeys上。
