# Enfortumab Vedotin 联合 Pembrolizumab 治疗可选顺铂膀胱癌

> 原标题：Enfortumab Vedotin and Pembrolizumab for Cisplatin-Eligible Bladder Cancer

- 来源：NEJM
- 发布时间：2026-11-18T10:00:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/famdcm3bplcxfrqcvpmiy3x3a
- 原文：https://www.nejm.org/doi/full/10.1056/NEJMc2610895?af=R&rss=currentIssue

## 摘要

本研究评估了 Enfortumab Vedotin 联合 Pembrolizumab 对可选顺铂膀胱癌患者的疗效，结果显示客观缓解率 (ORR) 为 42%，95% CI 为 34%–50%，显著优于单药治疗。
