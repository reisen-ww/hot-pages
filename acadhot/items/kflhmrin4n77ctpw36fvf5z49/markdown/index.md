# 清华大学邓兵课题组在《Nature Reviews Clean Technology》发表退役风电叶片闪电解热再生研究

> 原标题：几千度电光一闪，退役叶片成了新叶片的“填料”

## 摘要

清华大学邓兵课题组在《Nature Reviews Clean Technology》发表研究，通过闪光焦耳热技术将退役风电叶片转化为碳化硅-石墨烯复合填料，实验室数据显示掺量0.3%时可使环氧树脂基材杨氏模量提升27%，拉伸强度提高11%，热扩散系数同步改善。
