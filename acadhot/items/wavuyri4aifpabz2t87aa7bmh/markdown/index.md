# 神经外科医生与私人股权投资关联的医疗保险专业支付差异

## 摘要

2013-2024年间，神经外科医生与私人股权投资关联的医疗保险专业支付显著高于无关联医生，几何均值比为1.38（95% CI 1.11-1.72，P=0.004）。年龄和风险平衡后，比值降至1.25。医院运营商的支付较低，但纵向估计不精确，未证实收购效应。
