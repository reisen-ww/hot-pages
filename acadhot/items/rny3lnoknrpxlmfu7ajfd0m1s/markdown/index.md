# 自然叙事研究的可重复大型语言模型工具

> 原标题：Scaling up naturalistic narrative research: A reproducible large language model-based tool for evaluating contextual information gain

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

该研究引入了一种使用开放权重大型语言模型计算上下文信息增益的度量方法，该方法与人类对事件重要性和因果中心性的评分高度相关，能够区分因果中心性和语义中心性，克服了现有自动化工具的局限性。该工具还捕捉到了默认模式网络中的共同激活，验证了其在自然叙事刺激中识别行为和神经相关计算量的有效性。
