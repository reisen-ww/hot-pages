# Drosophila 蛋白组学比较揭示 SERPINE1 功能类似物分布特征

> 原标题：Comparative functional genomics reveals distributed SERPINE1 like characteristics among Drosophila serpins

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/rhylhnutn3jstg860g6dhhbb3
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.02.763793v1?rss=1

## 摘要

该研究通过多组学框架比较了人类 SERPINE1 和果蝇 Serpins，发现多个候选蛋白（Spn42Da 和 Spn42Db）在序列和结构上与 SERPINE1 相似，但未找到单一最接近的对应物。研究结果提供了一种定量方法来优先选择功能类似物。
