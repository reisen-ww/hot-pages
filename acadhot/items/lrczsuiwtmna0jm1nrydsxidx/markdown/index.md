# UC Davis 测试农业光伏系统能否帮助农民适应更热更干燥的气候

> 原标题：Researchers are testing whether agrivoltaics can help farmers adapt to hotter, drier conditions

## 摘要

UC Davis 农业研究团队正在测试四种不同设计的太阳能面板在相同土壤、气候和作物条件下对番茄作物的影响，评估其在遮荫和节水方面的效果。研究通过对比完全灌溉和半灌溉的番茄田，测量水利用效率，并建立模型以优化光照和光谱使用，旨在探索农业光伏系统是否能帮助农民在水资源紧张的情况下保护作物并提高产量。
