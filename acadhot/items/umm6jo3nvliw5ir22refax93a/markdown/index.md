# 小鼠自由活动状态下皮层和深脑钙成像的Mini2P系统操作协议

## 摘要

本文提供了一套全面的Mini2P钙成像操作协议，适用于小鼠自由活动状态下的皮层和深脑成像。该协议覆盖了系统准备、光学对准、视野选择、基板安装及成像稳定性维护等关键步骤，旨在提高实验的可重复性并促进Mini2P技术在研究神经元电路动态中的应用。
