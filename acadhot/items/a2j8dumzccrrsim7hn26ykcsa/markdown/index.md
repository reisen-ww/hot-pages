# 亚利桑那大学 Charlotte Pearson 团队在 PNAS 发表研究，通过古树轮与冰芯数据确定巴比伦王国灭亡时间为公元前1587年

## 摘要

亚利桑那大学 Charlotte Pearson 团队通过分析土耳其出土古树轮的碳定年数据，结合冰芯中 Aniakchak 火山（1628–1627 BC）的硫化物记录，确定巴比伦王国灭亡时间为公元前1587年。研究还发现公元前1228–1188年期间存在异常干旱，可能与哈吐莎古城被毁事件相关，为其他历史时期的时间线校准提供了新方法。
