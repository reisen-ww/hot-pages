# Curtin University 研究团队揭示地球板块构造系统启动时间

> 原标题：Ancient rocks reveal when Earth's tectonic engine 'switched on'

- 来源：Phys.org
- 发布时间：2026-11-11T00:10:08.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/i8jfwno3msl8t96rfg5ong6gu

## 摘要

Curtin University 研究团队通过分析全球范围内约4亿年历史的岩石样本，发现地球板块构造系统约2.5亿年前开始形成，并首次在岩石中检测到古代地壳化学指纹的消失现象，为理解地球地质演化提供了关键证据。
