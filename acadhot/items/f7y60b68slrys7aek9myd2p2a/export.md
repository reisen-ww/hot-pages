# 精神分裂症患者扩展默认模式网络的因果连接差异及认知关联研究

> 原标题：The extended default mode network dysconnectivity in schizophrenia

- 来源：bioRxiv
- 发布时间：2026-11-12T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/f7y60b68slrys7aek9myd2p2a
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.10.765658v1?rss=1

## 摘要

某研究团队通过功能磁共振成像发现精神分裂症患者扩展默认模式网络的因果中心性分布存在显著差异。比较了74名健康对照和66名精神分裂症患者的有效连接，使用空间约束的独立成分分析（SCICA）和频谱动态因果建模（SDCM），发现患者颞叶（尤其是前额叶和基底前脑）的因果中心性高于对照组，而顶叶皮层则低于对照组。

## 推荐理由

该研究揭示了精神分裂症患者与正常人在扩展默认模式网络因果连接上的差异，并发现这些差异与认知功能评分显著相关，为神经影像学评估提供了新的生物标志物参考。
