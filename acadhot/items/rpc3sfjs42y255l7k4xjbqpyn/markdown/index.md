# 某团队在 Nature 发表 TDP-43 缺失诱导突触功能障碍的 UNC13A 剪接纠正疗法

> 原标题：UNC13A splice correction rescues synaptic dysfunction induced by TDP-43 loss

- 发布时间：2026-11-11T00:00:00.000Z

## 摘要

某团队在 Nature 发表 TDP-43 缺失诱导突触功能障碍的 UNC13A 剪接纠正疗法。该疗法通过使用剪接开关反义寡核苷酸纠正 UNC13A 的隐性剪接错误，恢复神经元突触通信功能。

## 推荐理由

论文提出使用剪接开关反义寡核苷酸纠正 UNC13A 剪接错误，为神经退行性疾病治疗提供了可迁移的方法。
