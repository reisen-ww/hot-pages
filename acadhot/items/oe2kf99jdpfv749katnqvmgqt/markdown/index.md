# 比利时微电子研究中心将在日本设基地，推进下一代半导体研发

- 来源：36氪
- 发布时间：2026-11-17T08:46:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/oe2kf99jdpfv749katnqvmgqt

## 摘要

比利时微电子研究中心（Imec）将在北海道大学设立日本首个研究基地，与日本大学和研究机构合作，推进下一代半导体研发，并计划应用于日本半导体公司Rapidus的业务中。
