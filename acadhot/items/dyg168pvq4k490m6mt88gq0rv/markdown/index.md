# 某团队在 bioRxiv 发表听觉皮层神经元适应性研究

> 原标题：Adaptation can explain cortical responses to sound deviance without requiring prediction

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/dyg168pvq4k490m6mt88gq0rv
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.14.766627v1?rss=1

## 摘要

某团队通过小鼠听觉皮层实验发现神经元适应性可解释声音偏差反应，无需依赖预测模型。实验采用改进的 oddball范式分离近期声音历史与长期统计，结果显示适应性机制独立于预测模型。研究提出输入适应的归一化模型能生成偏差信号（包括增强效应），无需预设预测框架。

## 推荐理由

该研究通过改进的声学偏差范式实验设计，区分了神经元适应性与预测误差的作用，为神经科学机制研究提供新方法参考。
