# 基准化荣誉学术认可与引用指标

> 原标题：Benchmarking honorific academic recognitions against citation metrics

## 摘要

研究评估了14个主要学术院所和荣誉学会新入会的2038名成员，以及斯坦福大学和密歇根州立大学的教授，发现单人/第一/最后作者论文的引用次数和综合引用指标（c-score）在顶级科学家中的百分位数最高。荣誉认可的知名度与其在顶级科学家数据库中的引用覆盖率呈正相关，诺贝尔奖和图灵奖得主在顶级科学家中的引用覆盖率最高，达99%。
