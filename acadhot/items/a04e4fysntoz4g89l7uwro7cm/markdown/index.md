# 聚乙烯包装及其替代品在美国和欧洲的生命周期评估

## 摘要

研究评估了五种主要的聚乙烯包装应用，并比较了其与纸、玻璃和金属替代品的环境影响。结果显示，聚乙烯包装在大多数环境指标上通常具有较低的潜在环境影响。然而，回收利用率的提高并不总是降低所有环境指标的影响，具体效果取决于材料类型和回收过程。
