# 某研究团队在动物行为学期刊发表猫叫声与人类互动研究

> 原标题：猫围着你叫是叫你去解决问题

## 摘要

巴西研究团队通过对比人类在场（86次/天）与离场（20次/天）时38只猫的叫声频率，发现猫通过叫声主动寻求人类介入解决困境。实验设计包含有孔食物盒对照组，研究发表于动物行为学期刊（DOI:10.1016/j.anbehav.2026.123756）
