# 基于髓鞘靶向的CAR T细胞模型构建中枢神经系统炎症性脱髓鞘

> 原标题：Modeling CNS inflammatory demyelination using myelin-directed CAR T cells

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/xvzxn7lp3llr8whuqeonoog9l
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.767139v1?rss=1

## 摘要

Cordano团队构建的髓鞘靶向CAR T细胞模型在中枢神经系统中成功诱导炎症性脱髓鞘病变，该模型在脊髓、脑干和视神经均产生可复现的血管周围脱髓鞘病变。实验显示，尽管存在持续炎症，使用脱髓鞘治疗药物clemastine仍能缩小视神经病变体积并改善神经传导功能。该模型首次实现了中枢神经系统炎症脱髓鞘的精准建模，为髓鞘再生疗法提供了标准化测试平台。

## 推荐理由

该模型首次在中枢神经系统中成功诱导炎症性脱髓鞘病变，并验证了clemastine对病变的缩小效果，为髓鞘再生疗法提供了可重复的病理模型。
