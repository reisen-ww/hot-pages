# 哈勃2号目标小行星1998 KY26的‘暗彗星’假说受质疑

> 原标题：Simulations cast doubt on unusual asteroid's 'dark comet' status

- 来源：Phys.org
- 发布时间：2026-11-10T14:20:10.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/cxaoau4u1abz9s8vfgsgc4ntt
- 原文：https://phys.org/news/2026-11-simulations-unusual-asteroid-dark-comet.html

## 摘要

佐治亚理工学院团队通过三维模拟计算发现，1998 KY26小行星表面及内部温度均高于保存冰的临界值（-128°C），无法维持暗彗星所需冰层，从而质疑其‘暗彗星’假说。研究通过调整小行星大小、反照率等13种参数模拟太阳热辐射传导，发现即使含1%水分，冰层也会在2000年内完全蒸发。该成果发表于 Icarus 期刊，为2023年哈勃2号探测器后续观测提供了理论依据。
