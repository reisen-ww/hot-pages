# 某团队提出通过粗调优化蛋白质基础模型的方法，以外膜β-折叠蛋白为例

> 原标题：Coarse-tuning to improve a protein foundation model for a domain of proteins: the example of outer membrane beta barrels

- 发布时间：2026-11-12T00:00:00.000Z

## 摘要

某团队在 bioRxiv 发表预印本，提出针对蛋白质基础模型的粗调优化方法，并以外膜β-折叠蛋白（OMBBs）为例验证其有效性。结果显示，粗调模型在多种迁移学习任务中表现优于原模型，并分析了注意力矩阵与接触图预测的差异。该研究使用小于10万条序列的中等规模数据集，证明基础模型可通过定向微调实现领域专业化。

## 推荐理由

论文提出了针对蛋白质基础模型的粗调优化方法，并以外膜β-折叠蛋白为例验证了其在迁移学习任务中的有效性，为其他蛋白结构建模提供可迁移的技术路径
