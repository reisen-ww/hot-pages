# 东京物质研究所团队在《Communications Physics》首次通过超导涡旋实验证实堵塞是准静态相变

> 原标题：Superconducting vortices provide experimental evidence that clogging is a phase transition

## 摘要

东京物质研究所团队在《Communications Physics》发表研究，首次通过超导涡旋实验证实堵塞现象属于准静态相变。实验采用改进的两步测量协议，区分常规涡旋钉扎与堵塞效应，发现两者临界电流值一致且临界指数符合二维定向渗滤 universality class 预测。该成果为工业管道堵塞、生物运输系统流量控制等跨学科问题提供新判据，并揭示超导涡旋运动与颗粒材料堵塞存在共性物理机制。
