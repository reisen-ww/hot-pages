# Potsdam气候研究所（PIK）在《Nature Sustainability》发表研究：土地作为稀缺资源对气候保护的关键作用

## 摘要

Potsdam气候研究所（PIK）在《Nature Sustainability》发表研究，量化土地措施与能源转型之间的成本冲突，提出通过碳定价和有限生物质能源种植实现气候目标的平衡政策建议。
