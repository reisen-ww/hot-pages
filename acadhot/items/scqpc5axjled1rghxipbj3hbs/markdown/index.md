# 某团队在 bioRxiv 发表关于Leigh综合征中PKR驱动神经病理机制的研究

> 原标题：PKR drives neuropathology in a mouse model of Leigh syndrome

- 来源：bioRxiv
- 发布时间：2026-11-12T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/scqpc5axjled1rghxipbj3hbs
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.10.765677v1?rss=1

## 摘要

某研究团队发现PKR蛋白通过感知双链RNA参与Leigh综合征的神经病理进程，基因敲除可延缓小鼠模型病情并延长生存期，但不会恢复线粒体呼吸功能。研究揭示了PKR介导的RNA感应是致病机制，并指出PKR可能成为线粒体脑病的治疗靶点。

## 推荐理由

论文提供了PKR在Leigh综合征中作为关键介质的具体作用机制，并指出其与线粒体呼吸的关系，为后续治疗靶点研究提供依据。
