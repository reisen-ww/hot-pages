# 某团队在 medRxiv 发表老年人视觉预览与步态及认知成本关联研究

> 原标题：Previewing gaze behaviours predict gait speed, risky stepping strategies and cognitive dual task cost in older adults

- 来源：medRxiv
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/r4q54n0wc5g5mfh8tj0f1kadv
- 原文：https://www.medrxiv.org/content/10.64898/2026.11.16.26368206v1?rss=1

## 摘要

某团队对 29 名老年人（平均年龄 73.9 岁）进行实验，发现视觉预览序列复杂度（LZC_task）与认知双任务成本呈负相关（p=0.003），而视觉转换幅度与步速负相关（p=0.012）。研究证实有效预览需整合近远距离信息，为降低老年人双任务步态障碍提供了新干预靶点。

## 推荐理由

该研究提供了视觉预览行为与步态速度及认知双任务成本之间的定量关联数据，读者可据此评估视觉预览干预对老年人运动协调能力的改善潜力。
