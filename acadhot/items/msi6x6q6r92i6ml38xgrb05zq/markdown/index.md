# 基于计算设计的选择性C-H羟基化酶开发

> 原标题：De Novo Design of C-H Hydroxylation Enzymes with Programmed Selectivities

## 摘要

某团队通过计算设计开发出选择性C-H羟基化酶，并验证了其催化效率与结构准确性。研究从简单荧光模型化合物到雌激素（雌二醇）的C6位（93%对映体过量）和未激活C16位（99%对映体过量）氧化进行验证，晶体结构确认了设计流程的有效性。
