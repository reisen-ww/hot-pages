# 某研究团队在 Chemical Engineering Journal 发表重稀土元素高效利用的磁体制造新方法

## 摘要

某研究团队在 Chemical Engineering Journal 发表成果，通过优化扩散源成分将重稀土元素镝的使用量减少80%同时保持磁性能。研究显示调整轻稀土元素配比可抑制表面富集，形成均匀薄膜，为下一代仅用轻稀土元素制造高性能磁体提供技术路径。
