# 某团队在 bioRxiv 发表肾细胞癌亚型特异性自噬特征研究

> 原标题：Subtype-specific autophagy profiles in Renal Cell Carcinoma

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/psfvu1i3ufyx00b0l92ctl67t

## 摘要

某团队在 bioRxiv 发表肾细胞癌亚型特异性自噬特征研究，发现透明细胞肾细胞癌（ccRCC）中 LC3B 和 GABARAPL1 水平显著低于其他亚型及良性肿瘤，并证实自噬依赖性在转移性 ccRCC 细胞球中的存在。研究通过免疫染色、Western blot 和定量 PCR 分析生物样本库中的新鲜冷冻肿瘤及配对正常组织样本，揭示自噬水平在肾癌亚型间的差异，为靶向治疗提供新思路。

## 推荐理由

论文提供了不同肾细胞癌亚型间 LC3B 和 GABARAPL1 自噬标志物水平的对比数据，读者可据此评估自噬机制在转移性肾癌治疗中的潜在靶向价值。
