# SpaceX星舰助推器捕获失败，原定周六返航计划受挫

> 原标题：SpaceX's Starship set for return to Earth after booster catch aborted

## 摘要

SpaceX星舰助推器在返航测试中因导航控制问题自动弃载，原定周六回收计划失败。星舰成功进入地球轨道，但NASA依赖的Artemis登月计划关键测试受阻。SpaceX称将按计划在22小时后尝试回收，若失败将坠入太平洋。
