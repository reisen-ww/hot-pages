# 保护公园外的森林有助于保护鸟类

> 原标题：Protecting forests outside parks benefits the birds within

- 来源：Phys.org
- 发布时间：2026-11-16T18:40:23.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/xwg9kgob71h3va4xne16w18x2
- 原文：https://phys.org/news/2026-11-forests-benefits-birds.html

## 摘要

一项发表在《景观生态学》期刊上的研究发现，保护北美鸟类的关键不仅在于国家公园内的森林质量，更在于公园周边的森林状况。研究团队分析了2006年至2023年间美国东北部八个公园的鸟类监测数据，发现公园外的大片成熟森林和开阔的林下植被对多种鸟类的栖息更为重要。研究强调，保护公园周边的自然环境同样关键。
