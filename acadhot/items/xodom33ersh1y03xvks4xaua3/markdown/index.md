# 澳大利亚政府评估监控摄像头在儿童保育中的效果及监管建议

## 摘要

澳大利亚政府评估显示监控摄像头仅能检测3%的低风险隐患，无法有效预防性侵，并拨款11.5亿澳元推广摄像头但被专家质疑可能形成安全错觉。该评估由Nous Group实施并经KPMG独立验证，指出摄像头无法覆盖浴室等私人空间，且存在数据存储合规性风险。
