# 四态开关实现复杂电控，超越简单开闭控制

> 原标题：Tiny switch harnesses four electrical states, moving beyond simple on-off control

- 来源：Phys.org
- 发布时间：2026-11-16T23:20:06.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/wea1fxm8z9spl6sefyi5sizb1

## 摘要

研究人员开发了一种新型四态开关，通过改变材料的电极化状态，可以在四种不同的状态之间切换。这种开关利用材料中的非传统特性，可以在不同路径之间灵活转换，为信息处理和存储开辟了新途径。相关研究发表在《通讯材料》期刊上。
