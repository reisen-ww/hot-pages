# 基于多组学配对分析定义健康人类滑膜与脂肪垫的基质连续体

## 摘要

研究通过配对多组学分析，首次系统定义了健康人类膝关节滑膜与脂肪垫的基质细胞连续体，包含23类滑膜细胞和20类脂肪垫细胞亚群。关键发现包括：滑膜与脂肪垫共享转录连续的基质亚群，但分泌抑制性调节因子（如TIMP3）显著多于促分泌因子（如MMP14），且TIMP3在43个单细胞样本中均高于MMP14。

## 推荐理由

论文建立了健康滑膜和脂肪垫的多组学参考标准，为骨关节炎研究提供定量基准
