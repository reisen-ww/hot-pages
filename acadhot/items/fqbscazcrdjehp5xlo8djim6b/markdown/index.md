# 单次会话心率变异性生物反馈改变神经活动但不缓解主观焦虑

> 原标题：Single-Session HRV Biofeedback Alters Neural Activity but Not Subjective Anxiety

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

健康成人完成Stroop任务诱发焦虑后，进行有或无生理反馈的呼吸练习，结果显示HRV生物反馈未额外改善主观焦虑，但EEG分析显示生物反馈组的δ和θ波功率增加，α和β波功率广泛增加。这些发现表明，HRV生物反馈可引起神经振荡活动的特定变化，而主观焦虑缓解并未进一步增强。
