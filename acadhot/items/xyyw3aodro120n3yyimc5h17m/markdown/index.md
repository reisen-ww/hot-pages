# 某团队在 bioRxiv 发表花粉装饰形态量化框架

## 摘要

某团队提出基于持久同调的三维花粉形态量化框架，包含强度、密度、极性三个可解释指标。该框架成功区分了昆虫传粉与风媒传粉花粉的形态差异，并在菊科植物进化分析中验证了其适用性。新花粉数据可直接代入该框架无需重新定义坐标轴。
