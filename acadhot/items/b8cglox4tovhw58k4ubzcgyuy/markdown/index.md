# 国家发改委：深入实施共建“一带一路”科技创新行动计划

- 来源：36氪
- 发布时间：2026-11-11T03:02:01.000Z

## 摘要

国家发展改革委表示，将紧扣“十五五”规划纲要，推动数字丝绸之路、创新丝绸之路、绿色丝绸之路和健康丝绸之路建设，深入实施共建“一带一路”科技创新行动计划，促进科技创新和产业创新深度融合。
