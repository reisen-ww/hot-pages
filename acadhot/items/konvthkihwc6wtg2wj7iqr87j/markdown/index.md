# Adelaide大学在 BMJ 发表综述：气候变化与栖息地破坏正推动蝙蝠致命疾病传播

## 摘要

Adelaide大学团队在 BMJ 发表综述，指出气候变化和栖息地破坏正推动蝙蝠向城市和农业区迁移，导致埃博拉、尼帕病毒等致命疾病传播风险上升。研究强调极端高温会加剧蝙蝠病毒释放量，并揭示农业扩张导致蝙蝠与牲畜接触增加的传播路径。保护蝙蝠栖息地被证实可降低人畜共患病爆发的可能性，例如Adelaide市通过树冠喷淋系统降温的实践案例。
