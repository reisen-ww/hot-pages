# MYCN扩增神经母细胞瘤中SGOC代谢通路调控嘌呤salvage依赖性的研究

> 原标题：Low serine-glycine-one-carbon pathway activity defines purine salvage dependence in neuroblastoma

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

某团队发现MYCN扩增神经母细胞瘤中低SGOC代谢活性导致嘌呤salvage依赖性增强。稳定同位素追踪显示非MYCN扩增细胞通过减少丝氨酸衍生甘氨酸和一碳单位对嘌呤从头合成的贡献，同时基础水平次黄嘌呤和腺嘌呤salvage活性升高。

## 推荐理由

研究揭示了低SGOC代谢活性的神经母细胞瘤对嘌呤salvage途径高度依赖，为靶向代谢的治疗策略提供了分子基础。
