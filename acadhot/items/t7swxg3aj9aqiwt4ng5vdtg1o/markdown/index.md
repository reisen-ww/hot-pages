# 分子科学研究所与东京大学科学和技术大学合作揭示碳中心金(I)簇的化学键演化规律

> 原标题：Unraveling bonding evolution in carbon-centered gold(I) clusters

- 来源：Phys.org
- 发布时间：2026-11-17T20:10:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/t7swxg3aj9aqiwt4ng5vdtg1o
- 原文：https://phys.org/news/2026-11-unraveling-bonding-evolution-carbon-centered.html

## 摘要

分子科学研究所、东京大学科学和技术大学及福建大学合作团队在JACS Au发表研究，系统比较了CAu4、CAu5、CAu6的化学键类型与电子共享机制。研究发现，随着金原子数从6减少到4，碳金键从3中心2电子离域键演变为2中心2电子常规键，CAu5表现为中间态；同时揭示了配体尺寸对手性核心结构稳定性的调控规律，并解析了碳原子2s/2p轨道对键型演化的电子贡献。
