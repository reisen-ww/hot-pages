# 某团队在bioRxiv发表动态蛋白调控的CDK响应型磷酸降解子标签

> 原标题：CDK phospho-degron tags for dynamic protein regulation

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/gysr1ucfdqal6d9agfe6685qd
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.13.766399v1?rss=1

## 摘要

某团队开发出模块化的CDK响应型磷酸降解子标签，可在酵母中实现动态蛋白稳定性调控。通过系统修饰CDK结合基序和Cks1激活位点，生成具有不同降解动力学和磷酸化阈值的变体，并整合磷酸化调控定位模块实现多层级蛋白调控。研究证实降解子性能受细胞密度和CDK活性显著影响，为合成生物学中的动态蛋白调控提供了标准化模块设计框架。

## 推荐理由

该研究提出模块化CDK响应型磷酸降解子标签，为动态蛋白调控提供了可扩展的合成生物学工具，适用于多细胞系统优化。
