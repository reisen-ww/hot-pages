# 氢气火焰为何会变色及影响因素

> 原标题：Why hydrogen flames can glow orange, then turn nearly invisible

## 摘要

研究发现氢气火焰的颜色变化主要由空气中的钠含量决定，钠含量高时火焰呈明显橙色，钠含量低时火焰几乎不可见。这影响了家用氢气灶具的安全性和可靠性。研究人员建议采用其他检测技术，如紫外线或红外线火焰检测器，以提高氢气设备的性能，使其在不同环境条件下都能可靠工作。
