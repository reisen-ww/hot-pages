# CXCR2 是必需的，调控出生后乳腺导管发育并塑造基质微环境

> 原标题：Cxcr2 is required for ductal outgrowth and shapes the stromal microenvironment in postnatal mammary gland development

## 摘要

该研究揭示CXCR2在出生后乳腺导管发育中起必需作用，并通过调控上皮-基质细胞协调间接影响乳腺发育。实验发现Cxcr2缺失小鼠出现乳腺导管发育延迟、上皮面积减少及基质重塑异常（脂肪细胞体积缩小、胶原沉积增加），伴随严重系统性免疫失调（粒细胞增多、适应性免疫细胞减少）。研究首次建立CXCR2调控乳腺发育与乳腺癌微环境的关联，为理解肿瘤微环境发育机制提供新框架。

## 推荐理由

该研究揭示了CXCR2通过上皮-基质细胞协调间接调控乳腺发育的机制，并首次将这一通路与乳腺癌微环境联系起来。
