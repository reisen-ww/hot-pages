# KIMS 研究团队开发快速均匀加热碳复合材料技术

> 原标题：Faster heating, stronger bonds for carbon composites

## 摘要

韩国材料科学研究院（KIMS）研究团队开发了一种利用纳米复合气凝胶（结合碳纳米管、磁性氧化铁和聚己内酯）的感应连接技术，实现了碳纤维增强热塑性复合材料（CFRTP）的快速均匀加热和粘接。
