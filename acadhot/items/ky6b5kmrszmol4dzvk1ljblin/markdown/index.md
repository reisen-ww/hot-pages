# 查尔斯达尔文大学追踪鲁姆丛林矿金属遗留对芬尼丝河食物链的影响

> 原标题：Study tracks Rum Jungle Mine's metal legacy through Finniss River food web

## 摘要

查尔斯达尔文大学首次系统追踪了鲁姆丛林铀矿关闭后对芬尼丝河食物链的金属遗留影响。研究发现藻类（Spirogyra）和碎屑（detritus）金属浓度最高，且存在从基础食物链向顶级捕食者（如巴拉曼迪鱼）的稀释效应。该成果为评估矿区生态修复效果提供了新监测指标，建议后续研究金属积累对生物健康的影响。
