# Furcellaria lumbricalis 红藻参考基因组的首次构建

> 原标题：A de novo reference genome of the red seaweed Furcellaria lumbricalis

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/qjucr8cywupmw1ouyoc9wk8ke

## 摘要

某团队基于PacBio HiFi和Oxford Nanopore长读测序技术，首次为红藻Furcellaria lumbricalis构建了包含149个contigs、总长918.2 Mb的参考基因组，其中重复序列占比达90.5%，N50值为15.5 Mb。

## 推荐理由

该研究首次为红藻Furcellaria lumbricalis构建了参考基因组，提供了详细的组装数据、基因注释及重复序列比例，为后续进化与生态学研究奠定基础。
