# Drosophila 纪律型差异的基因组学分析揭示了不同光敏性和睡眠基因的选择模式

> 原标题：Pooled sequencing reveals patterns of underlying genomic divergence in Drosophila chronotypes

- 发布时间：2026-11-16T00:00:00.000Z

## 摘要

通过长期进化实验演化出的 Drosophila 纪律型差异，研究团队进行了池化测序，发现早起型群体主要积累与光敏性、睡眠和生物钟基因的变异，而晚起型群体则主要积累与生物钟、mRNA 交替机制和蜕皮相关的变异。这些结果揭示了纪律型分化的进化机制。
