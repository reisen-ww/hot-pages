# 社会补偿改变个体损失对动物社会网络结构的影响

> 原标题：Social compensation changes predicted effects of individual loss in animal societies

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/db1dqpygqp0afkm6l8jvmkdwi
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.18.767549v1?rss=1

## 摘要

研究模拟了268个动物社会网络中个体损失和社会补偿对网络结构的影响，发现补偿行为改变了个体损失的结构性效应，但这些效应依赖于被移除的个体类型。补偿策略相似，但移除中心、边缘或随机个体产生的网络响应不同。研究结果表明，社会补偿可能在动物种群减少时重新组织社会网络结构，改善对社会结构变化的预测。
