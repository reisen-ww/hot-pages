# 某研究团队在 bioRxiv 发表 SARS-CoV-2 S 蛋白磷酸化位点 Y674F 突变体功能研究

> 原标题：A conserved tyrosine in the S1/S2 loop shapes SARS-CoV-2 spike processing and host protease usage.

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

某研究团队发现 SARS-CoV-2 磷酸化位点 Y674F 突变体显著降低病毒通过 TMPRSS2 进入宿主细胞的能力。通过质谱分析纯化病毒颗粒，构建 Y674F 突变株后，其在 Vero 细胞中复制与野生株相当，但在人类呼吸道细胞线中复制减弱。仓鼠感染实验显示突变株肺病毒载量降低，抗原染色减弱，证实 Y674 磷酸化对 S 蛋白加工和宿主蛋白酶功能的关键作用。

## 推荐理由

该研究提供了 SARS-CoV-2 磷酸化位点 Y674F 突变体对病毒进入机制的关键证据，为解析 S 蛋白功能提供了新方法
