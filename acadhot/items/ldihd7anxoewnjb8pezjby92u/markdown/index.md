# 某研究团队分析澳大利亚家庭脱离电网的动机与成本效益

> 原标题：Secondhand solar, tiny houses, no bills—we found how Australians are going off‑grid and if it's worth it

## 摘要

某研究团队通过访谈40户澳大利亚脱离电网家庭（主要分布在东南昆士兰），发现经济因素（55%）与环境意识（25%）是主要动机。常规房屋平均配置6.6kW太阳能+40kWh电池，小屋配置3.5kW太阳能+2×4kWh电池。
