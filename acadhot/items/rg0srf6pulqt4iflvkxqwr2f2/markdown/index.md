# 某研究团队基于博物馆标本发现新西兰鹪莺灭绝后新亚种

## 摘要

某研究团队通过分析博物馆保存的鹪莺标本，确认了其灭绝后（约20年）存在新亚种，该成果为生物多样性保护中的标本数字化保存提供了案例参考。
