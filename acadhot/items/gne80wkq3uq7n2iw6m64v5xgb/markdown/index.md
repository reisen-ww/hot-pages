# 全球野生动物受人为噪声影响研究：80%物种出现性状改变

> 原标题：噪声污染伤害全球野生动物

- 发布时间：2026-11-09T10:23:27.000Z

## 摘要

一项大规模分析揭示，人为噪声对全球野生动物的生理和行为产生广泛影响。研究涵盖陆地与水域共177个物种，结果显示80%的物种至少出现一种性状改变，包括基因表达、免疫功能、器官发育异常及行为模式（如鸟类鸣叫、鲸类觅食）改变。部分物种对噪声的响应存在相反效应（如亲代抚育行为）。Science 2026年11月发表相关论文（DOI: 10.1126/science.adu9593）

## 推荐理由

研究揭示了人为噪声对野生动物生理和行为的多维度影响，其中80%的物种至少出现一种性状改变，为生态保护提供了量化依据。
