# 共享电动滑板车使用者更常将事故归因于缺乏经验

> 原标题：Shared e-scooter users attribute near misses to inexperience: Longitudinal study

- 来源：Phys.org
- 发布时间：2026-11-12T13:00:02.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/eemgajd45lyagkb1awj7lltoj

## 摘要

一项由QUT道路安全研究人员领导的 longitudinal 研究发现，共享电动滑板车使用者更倾向于将接近事故归因于缺乏经验，而非私人电动滑板车使用者。研究跟踪了285名澳大利亚使用者一年，结果显示共享电动滑板车使用者认为缺乏经验的比例显著高于私人电动滑板车使用者（分别为2.3和1.3）。
