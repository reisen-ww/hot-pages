# 基因组聚类引擎生成首个公开单倍型块亚型数据集

## 摘要

某团队发布首个公开单倍型块基因组聚类数据集，包含2548名来自26个群体的样本（数据源自1000 Genomes Project），提供基因组哈希值和聚类结果，支持变体效应分析及基因型-表型关联研究。数据集已通过CC0协议开放，可在https://data.haploblocks.org和AWS开放数据注册库获取。
