# 研究调查司机愿意为“鲑鱼安全”轮胎支付多少溢价

> 原标题：Study investigates what drivers would pay for 'salmon-safe' tires

- 来源：Phys.org
- 发布时间：2026-11-10T14:40:12.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/gpggdhf726wzqp48saiv3jwya
- 原文：https://phys.org/news/2026-11-drivers-pay-salmon-safe.html

## 摘要

洛杉矶、俄勒冈和华盛顿州近700名受访者中，中位数显示司机愿意为“鲑鱼安全”轮胎支付10%的溢价，相当于每套四条轮胎多支付76美元。约25%的受访者表示愿意支付更高溢价，显示保护鲑鱼对部分消费者很重要。研究团队希望继续研究去除轮胎中化学物质的经济影响。
