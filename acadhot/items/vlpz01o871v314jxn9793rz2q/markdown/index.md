# 基西县电子社区健康报告系统持续支持效果评估

## 摘要

肯尼亚基西县电子社区健康系统（eCHIS）的持续支持显著提升用户满意度和系统一致性（343名用户调查+5站实地观察）。研究发现技术支持响应速度（每加快1级 odds比1.87）和系统稳定性（崩溃频率每降低1级满意度提升0.6倍）比单次培训（94.5%覆盖率但无统计学关联）更重要。
