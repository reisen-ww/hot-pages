# 美国失去麻疹消除状态：疫苗接种率下降引发专家担忧

> 原标题：Measles is back in the US: what worries scientists

- 来源：Nature

## 摘要

美国2026年麻疹病例达58,213例，较2025年同期增长3.6倍，PAHO宣布其失去消除状态。专家指出，未接种疫苗的成年人（占病例40%）和宗教团体（如安息日会）的疫苗接种率低是主因，可能导致孕妇感染、新生儿先天麻疹及后续腮腺炎等疫情扩散。

## 推荐理由

美国麻疹病例激增与疫苗接种率下降直接相关，专家指出未接种疫苗的成年人（占病例40%）和宗教团体（如安息日会）的疫苗接种率低是主因，可能导致孕妇感染、新生儿先天麻疹及后续腮腺炎等疫情扩散。
