# 玉米花粉中辅助B染色体对染色质可及性与基因表达的影响研究

> 原标题：Accessory B Chromosomes Alter Chromatin Accessibility and Gene Expression in Maize Pollen Nuclei

- 发布时间：2026-11-11T00:00:00.000Z

## 摘要

Urbis 等团队在玉米花粉中发现辅助B染色体显著改变染色质可及性与基因表达模式。研究使用流式细胞术分离花粉核（n=120），结合ATAC-seq和RNA-seq分析，发现B染色体不仅影响自身区域，还导致标准A染色体染色质可及性改变及基因表达差异（p<0.01）。论文完整呈现了染色质可及性热图与差异表达基因列表（DOI:10.64898/2026.11.09.765325v1）。

## 推荐理由

论文提供了B染色体对标准A染色体染色质可及性的定量数据，为植物自私遗传元件研究提供新视角。
