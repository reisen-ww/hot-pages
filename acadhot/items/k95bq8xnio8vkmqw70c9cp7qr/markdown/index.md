# 天文学家使用甚长基线阵列精确测量双矮星系统

## 摘要

天文学家利用美国国家科学基金会的甚长基线阵列（NSF VLBA）精确测量了双矮星系统 DG CVn 的轨道、质量和距离，发现两颗活跃的红矮星每隔 4.511 年绕彼此运行一次。这些观测结果提供了该类型双星系统中迄今为止最精确的动力学测量之一。
