# CG Oncology 膀胱癌免疫疗法临床试验显示复发风险降低68%

## 摘要

CG Oncology公布其冷病毒工程疗法在Ⅲ期临床试验中降低局部晚期膀胱癌患者复发风险68%的积极结果。该试验纳入367名中危患者，通过膀胱内灌注改造的常见感冒病毒靶向肿瘤突变细胞。数据显示，接受该疗法患者3个月随访中未出现复发的比例显著优于现有标准治疗。研究证实该疗法可延缓或预防术后复发，减少重复手术需求。

## 推荐理由

该试验提供了首个冷病毒工程疗法在局部晚期膀胱癌中的Ⅲ期数据，显示其相比标准治疗可将复发风险降低68%。
