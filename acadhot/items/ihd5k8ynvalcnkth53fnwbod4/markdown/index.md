# 南非大学团队提出基于肠道微生物数据的AI模型助力非洲畜牧业抗热

> 原标题：Local AI trained on gut microbe data could help African livestock withstand heat

- 来源：Phys.org
- 发布时间：2026-11-10T18:00:11.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ihd5k8ynvalcnkth53fnwbod4
- 原文：https://phys.org/news/2026-11-local-ai-gut-microbe-african.html

## 摘要

南非大学研究团队在《Agriculture》发表论文，提出通过训练AI模型分析本地牲畜肠道微生物代谢信号，指导农民调整放牧时间与饲料配比，从而提升非洲本土牛羊在高温干旱下的存活率与产奶量。研究强调需基于非洲本土养殖环境数据构建专用AI模型，并指出血液检测、粪便样本和直肠拭子是获取关键微生物代谢数据的技术手段。
