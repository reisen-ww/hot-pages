# 局部皮层动力学如何塑造脑区间交互

> 原标题：Waveform morphology links local circuit kinetics to cortical interactions

## 摘要

研究结合神经群体建模与人类及猕猴颅内记录，发现局部突触动力学通过波形形态影响脑区间交互。波形不对称性与局部时间不可逆性高度相关，而平均瞬时α频率与跨区交互更相关。这些发现揭示了波形形态携带局部神经动力学信息，为理解皮层交互提供机制框架。
