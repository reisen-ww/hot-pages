# 某团队在 bioRxiv 发表人类螺旋神经节三维细胞图谱构建的深度学习流程

> 原标题：A Complete Three-Dimensional Spiral Ganglion Neuron Map in a Human Adult using a Deep Learning Pipeline

## 摘要

某团队在 bioRxiv 发表人类螺旋神经节三维细胞图谱构建的深度学习流程，该流程通过UNet++模型实现97%的自动计数准确率，并首次完整可视化27,880个神经节细胞的三维分布及频率图谱，验证了每10个切片抽样即可保证98%的总计数准确率。

## 推荐理由

论文提出了一种基于深度学习的三维神经节细胞自动检测方法，可迁移至其他组织结构的数字化分析。
