# 卡尔斯鲁厄理工学院在《物理评论快报》发现量子比特能量可被缺陷回收

> 原标题：Hidden defects return a qubit's lost energy

- 发布时间：2026-11-16T14:20:08.000Z

## 摘要

卡尔斯鲁厄理工学院团队在《物理评论快报》发表研究，发现量子比特能量可通过材料缺陷回收。通过连续测量不同频率超导量子比特的量子跃迁行为，建立能量交换模型，并利用电场强度变化识别缺陷特征。该成果为量子计算机抗干扰设计提供了新思路，相关预印本arXiv:2603.11889，DOI:10.1103/j1r2-5ph7。
