# 新属Pelseria以植物学家命名

> 原标题：New daisy genus named after botanist

- 发布时间：2026-11-17T22:30:01.000Z

## 摘要

植物学家Pieter Pelser因其对植物进化研究的贡献，新建立的南美雏菊属Pelseria以他的名字命名。Pelser的研究发现，一种长期归类于Senecio属的植物实际上演化出了独立的路径。尽管Pelser从未亲眼见过Pelseria野生植物，这一荣誉仍是对他的研究工作的认可。
