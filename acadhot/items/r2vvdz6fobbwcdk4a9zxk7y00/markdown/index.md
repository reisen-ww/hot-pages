# 澳大利亚政府与多所大学联合研究揭示中年女性职场灵活性与经济安全需求

> 原标题：Study finds midlife women face unique need for workplace flexibility

- 来源：Phys.org
- 发布时间：2026-11-12T16:00:12.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/r2vvdz6fobbwcdk4a9zxk7y00
- 原文：https://phys.org/news/2026-11-midlife-women-unique-workplace-flexibility.html

## 摘要

研究显示，40-55岁女性因职业责任、家庭照料和健康问题（包括围绝经期和更年期）的叠加，对职场灵活性的需求与现有安排存在显著差距（最大差距达85.3%）。多数中年女性倾向完全远程工作（53.0%），但当前岗位薪资不足覆盖基本生活开支（研究样本中该比例最高），且晋升机会低于年轻同行（OR=0.62），加剧工作与家庭压力。
