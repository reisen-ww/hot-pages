# 微软称一个隐藏的 Windows Bug 触发了持续逾一天的宕机事故

- 来源：奇客 Solidot
- 发布时间：2026-11-16T15:00:34.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/o9jf6l0bjlobr3d3dtf89fphw
- 原文：https://www.solidot.org/story?sid=85903

## 摘要

微软公布了一个隐藏的 Windows Bug 导致 Microsoft 365 网络网关服务器宕机超过一天。该 Bug 在特定流量条件下耗尽处理器和内存资源，触发条件包括 Teams 流量迁移和部分服务器不可用。
