# Nature：Jinho Park 团队揭示 DNA 复制叉重启的分子机制

## 摘要

Jinho Park 等在 Nature 发表研究，阐明 PRIMPOL 蛋白通过识别 CDC45-MCM2-7-GINS 复合体，将引物转移至高保真聚合酶 ε 的分子机制，并指出该过程可减少突变性 DNA 合成。研究为理解复制叉崩溃修复机制提供了新视角。

## 推荐理由

论文揭示了 PRIMPOL 蛋白通过结合 CDC45-MCM2-7-GINS 复制叉复合物，将引物转移至高保真聚合酶 ε 的分子机制，为后续研究复制叉崩溃修复提供了关键理论依据。
