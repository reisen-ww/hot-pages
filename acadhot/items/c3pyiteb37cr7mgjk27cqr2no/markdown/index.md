# 美国司法部将主导审查DoorDash收购Instacart交易

- 发布时间：2026-11-17T00:33:13.000Z

- 原文：https://36kr.com/newsflashes/4073090930824323?f=rss

## 摘要

美国司法部将牵头审查DoorDash以170亿美元收购Instacart的交易，评估其是否存在反垄断问题。通常此类交易由联邦贸易委员会负责，但此次司法部接管审查。所有金额超过1.34亿美元的交易都必须接受联邦反垄断审查，并在交割前等待30天。
