# 某团队发表空间相关性函数方法揭示肝纤维化中分区丢失

> 原标题：A spatial correlation function approach reveals zonation loss in liver disease

- 发布时间：2026-11-17T00:00:00.000Z

## 摘要

某团队提出空间相关性函数方法，发现小鼠肝纤维化仅部分基因（如Cyp2c29、Pon1）空间相关性丢失，而人类肝纤维化几乎所有基因均丢失，揭示组织结构重组与表达水平变化不平行。该方法通过计算基因间表达相关性随距离衰减的参数（易感度、相关长度），可识别1266个未知分区的肝细胞基因。
