# 母体分离小鼠浦肯野细胞电路重塑及小脑突触可塑性受损研究

> 原标题：Maternal separation remodels Purkinje cell circuits and impairs cerebellar synaptic plasticity

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ym4twhu32mllz614zvdo7e9nq
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.08.765140v1?rss=1

## 摘要

某研究团队通过分离CD1小鼠（出生后第2-18天）的母体，发现其小脑Purkinje细胞树突分支和兴奋性输入发生重塑，导致长期突触可塑性受损及BDNF信号通路减弱。
