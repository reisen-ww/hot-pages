# 首个人工设计磷酸三酯酶ZAPP-1的晶体结构解析

> 原标题：Crystal structure of the first de novo designed phosphotriesterase ZAPP-1

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/xonrp4wgu96avow0f9vldn0qm

## 摘要

研究团队通过RFdiffusion3设计流程，首次解析了人工设计的磷酸三酯酶ZAPP-1的晶体结构（1.42Å和2.28Å分辨率）。结果显示三个独立晶体结构中C RMSD值均低于1.0Å，证明设计模型与实验结果高度吻合。

## 推荐理由

该研究验证了RFdiffusion3设计流程的高精度，但结构分析指出需优化活性位点预组织
