# 某研究团队在bioRxiv发表：靶向端粒完整性增强放疗敏感性，揭示胶质瘤DNA损伤响应适应性脆弱性

> 原标题：Targeting Telomere Integrity Enhances Radiosensitivity and Reveals Adaptive DNA Damage Response Vulnerabilities in Diffuse Midline Glioma

## 摘要

某研究团队在 patient-derived DIPG 模型中验证了 6-thio-dG（THIO）联合放疗可显著抑制肿瘤生长并延长生存期。机制研究表明 THIO 通过激活 ATM/ATR 信号通路引发端粒功能障碍，并抑制 E2F 基因表达。该联合疗法在三种不同 H3 突变亚型的胶质瘤模型中均有效，为端粒靶向治疗提供了可迁移的方法。
