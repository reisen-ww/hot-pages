# 某研究团队揭示精氨酸蛋白对DNA的核苷特异性识别机制

> 原标题：Nucleobase-Specific Recognition of DNA by Protamine

- 来源：bioRxiv
- 发布时间：2026-11-10T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/dpccb4dg8hxxkmwat9l7mrrlp

## 摘要

某研究团队通过分子动力学模拟和实验验证，发现精氨酸蛋白（protamine）对DNA的核苷特异性识别存在GC序列偏好性（GC:AT=2.6:1）。实验显示，8个鲑精氨酸蛋白快速包裹35bp DNA分子，在主要沟槽偏好GC序列（O6和N7作为氢键受体），在次要沟槽AT序列占比更高（2.1:1）。

## 推荐理由

论文提供了分子动力学模拟与实验验证相结合的方法，可迁移用于其他无序蛋白与DNA的相互作用研究
