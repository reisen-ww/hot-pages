# Cell 发表小鼠胚胎百万级细胞谱系追踪图谱

> 原标题：DNA 'flight recorder' traces embryonic development cell by cell

- 来源：Phys.org
- 发布时间：2026-10-13T21:00:06.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/wa26tcnv3mxg3svxzs2woc6hb
- 原文：https://phys.org/news/2026-10-dna-flight-embryonic-cell.html

## 摘要

Jonathan Weissman 团队在 Cell 发表研究，利用 PEtracer 追踪小鼠胚胎发育过程中超过 100 万个细胞的谱系历史，重建细胞分裂及其向不同组织和器官分化的过程。研究将细胞谱系与基因表达和细胞在胚胎中的位置结合，用于确定细胞何时走向特定命运，并为研究出生缺陷、癌症和干细胞分化提供图谱资源。DOI: 10.1016/j.cell.2026.09.050

## 推荐理由

研究将细胞谱系、基因表达与胚胎空间位置结合起来，为分析细胞命运分化及其与出生缺陷、癌症的联系提供了新的观察框架。
