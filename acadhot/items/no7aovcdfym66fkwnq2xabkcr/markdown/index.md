# 全球约25%爬行动物依赖岩石栖息地，为何保护仍显不足？

> 原标题：A quarter of the world's reptiles use rocky habitats. So why aren't we protecting them?

## 摘要

研究显示全球约25%的陆生爬行动物（包括蛇类、蜥蜴和蚯蚓蜥）完全依赖岩石栖息地生存，此类物种地理分布范围平均比非依赖岩石的物种小68%，且濒危风险高51%。论文提出通过农业用地恢复表面岩石（如澳大利亚牧场案例）可在一年内显著提升当地爬行动物多样性和种群数量，但全球岩石栖息地正面临采矿、城市化及机械粉碎等威胁，目前仅3%的岩石栖息地被纳入保护计划。
