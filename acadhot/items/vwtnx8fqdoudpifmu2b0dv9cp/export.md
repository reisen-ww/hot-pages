# 某研究团队在 bioRxiv 发表胆碱激酶A通过脂滴形成介导烷基化药物耐药机制的研究

> 原标题：Choline kinase A is required for alkylating agent resistance via lipid droplet formation

- 发布时间：2026-11-09T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/vwtnx8fqdoudpifmu2b0dv9cp

## 摘要

研究通过无偏见的基因筛选发现胆碱激酶A（CHKA）在T-ALL细胞中通过脂滴形成调控DNA修复因子RAD51的表达，从而介导烷基化药物耐药。实验表明即使CHKA失活，恢复脂滴形成或RAD51表达仍可维持耐药性。该成果首次阐明脂滴代谢与DNA损伤响应的转录调控关联，为靶向脂代谢的癌症治疗提供新思路。
