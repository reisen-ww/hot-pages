# 某国际团队在Advanced Materials发表晶界辅助氢传感器研究成果

> 原标题：Crystal boundaries help hydrogen sensors work in hot, humid air

- 发布时间：2026-11-10T16:40:16.000Z

## 摘要

某国际团队开发出可在22°C至80°C、湿度0%-90%环境下稳定工作的催化氢传感器，晶界促进钯纳米颗粒形成并降低水汽干扰。原型机检测误差小于5%，连续运行100次后性能稳定，满足ISO 26142标准。研究结合分子动力学模拟与实验验证，揭示晶界调控氢化物形成机制，为工业级氢能监测提供新思路。
