# 首尔国立大学团队开发五种金属复合氧化物乙醇传感器，响应率提升12.6倍

> 原标题：Combining five metals in one oxide improves ethanol gas sensing

- 发布时间：2026-11-13T18:40:07.000Z

## 摘要

首尔国立大学研究团队在Advanced Science发表成果，开发出基于五种金属复合氧化物的高性能乙醇气体传感器，其响应率达5135%，较传统低熵氧化物提升12.6倍。实验显示该传感器在300°C下对50ppm乙醇的检测极限为4.8ppb，且在六个月稳定性测试和90%湿度条件下仍保持性能。研究团队计划进一步探索多元素组合以开发多气体检测传感器。
