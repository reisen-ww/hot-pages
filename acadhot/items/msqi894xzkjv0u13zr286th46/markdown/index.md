# 为什么气候焦虑让部分青年采取行动而让另一部分陷入停滞

> 原标题：Why climate anxiety makes some youth take action, while others freeze

- 来源：Phys.org

## 摘要

研究发现，气候焦虑对美国青少年和年轻人的态度影响复杂。虽然一些人因焦虑而采取环保行动，但另一些人则因感到厌烦而陷入“生态停滞”状态，完全放弃行动。研究指出，当青少年同时感受到焦虑和厌烦时，他们更可能完全放弃参与气候行动。有效动员青少年需要调整沟通策略，避免引发厌烦情绪，而应引导他们将气候担忧转化为实际行动。
