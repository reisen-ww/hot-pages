# 海洋洋流模型预测沿海生物多样性的空间结构

> 原标题：Ocean current models predict spatial structure for coastal biodiversity

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/t96asbay6uuxs82fh7h1gkm5q
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.764070v1?rss=1

## 摘要

通过个体为基础的模型模拟海洋洋流携带的幼体，研究团队预测了被动扩散沿海物种的中性基因多样性模式，发现地理区域内具有相似祖先的区域与最近的“上游”种群相关，这种结构打破了隔离距离假设。模型预测与关键盐沼贻贝的基因组群体调查结果高度一致，验证了该模型的有效性。
