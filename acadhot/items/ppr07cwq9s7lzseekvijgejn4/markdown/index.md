# 某团队在bioRxiv发表AAV9载体修复LRPPRC基因的首次体内证据

> 原标题：LRPPRC gene replacement therapy preserves cardiac function and prevents premature death in a mouse model of mitochondrial disease

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ppr07cwq9s7lzseekvijgejn4
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.762002v1?rss=1

## 摘要

某团队通过AAV9载体在小鼠模型中成功修复LRPPRC基因，恢复氧化磷酸化（OXPHOS）功能并预防心肌病，样本量为5只 knockout小鼠。该疗法突破传统AAV载体容量限制，为线粒体疾病治疗提供新策略。

## 推荐理由

该研究首次在体内验证了AAV9载体修复LRPPRC基因可恢复氧化磷酸化功能并预防致命性心肌病，为线粒体疾病治疗提供了新方法学参考。
