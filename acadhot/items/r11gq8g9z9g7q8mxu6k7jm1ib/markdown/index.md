# Citrobacter rodentium 感染破坏结肠黏液屏障功能

> 原标题：Citrobacter rodentium infection disrupts colonic mucus barrier function via ablation of intercrypt goblet cells

## 摘要

研究发现，Citrobacter rodentium 感染早期破坏内层黏液层，增加黏液渗透性，并导致粪便黏液层厚度改变。缺失 Spdef 基因的小鼠表现出内层黏液层完整性受损和隐窝入侵增加，表明隐窝间杯状细胞对于维持内层黏液层的完整性和保护上皮细胞至关重要。
