# MolMap 解决小分子扰动下的功能染色质响应

> 原标题：MolMap resolves functional chromatin responses to small-molecule perturbation

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/em0cykzg4l8z4pbwqm6ojksob
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.16.766766v1?rss=1

## 摘要

某团队提出 MolMap 方法，通过分析未修饰化合物在原核核环境中的染色质响应，直接定位小分子扰动引发的即时功能染色质变化。该方法通过量化 Tn5 可及性及局部染色质组织，区分早期染色质反应与下游细胞适应。实验对比显示，MolMap 能捕获活细胞 ATAC-seq 无法检测的早期染色质响应，并在白血病模型中揭示耐药细胞与敏感细胞的染色质响应差异。

## 推荐理由

提出一种新型测序方法 MolMap，用于分析小分子化合物对染色质的即时响应，并与活细胞 ATAC-seq数据进行比较
