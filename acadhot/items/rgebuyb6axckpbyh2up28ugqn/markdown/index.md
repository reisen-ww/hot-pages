# 某团队提出分离质谱定量与鉴定的方法，显著提升蛋白质组覆盖率和定量精度

> 原标题：Decoupling Quantification and Identification for Label-Free Top-Down Proteomics Improves Proteome Coverage

## 摘要

某团队在生物样本库（bioRxiv）发表预印本，提出通过MS1仅定量后进行靶向MS2鉴定的分离流程，使可靠定量质谱峰数翻倍，蛋白质鉴定覆盖率提升50%。该方法已验证适用于不同色谱条件、质谱采集设置和样本制备策略，并在大肠杆菌葡萄糖/乙酸培养实验中揭示新生物学机制。
