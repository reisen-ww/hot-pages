# 某团队在bioRxiv发表基因尺度DNA与染色质原子分辨率模拟方法

> 原标题：Gene-scale DNA and chromatin ensembles with atomic resolution

- 来源：bioRxiv
- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/ah15oqlm3w4kdmmiy0w4mo8lq

## 摘要

某团队提出HCG-DNA方法，通过四核苷酸片段库组装实现百万碱基级DNA结构模拟，并整合染色质原子模型。该方法验证了DNA链弹性特性与 persistence length 关系，支持从原子到染色质再到染色体尺度的结构连续性研究，为分子模拟和AI训练提供可扩展的基准模型。

## 推荐理由

该论文提出了一种高效构建原子级DNA和染色质结构的方法，其可扩展的模型为分子动力学模拟和AI训练提供新工具
