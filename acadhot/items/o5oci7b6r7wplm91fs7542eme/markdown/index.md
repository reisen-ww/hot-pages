# 国际专家呼吁加强海洋监测以应对极端海洋热浪

> 原标题：Call to improve global ocean monitoring to prepare for marine heat waves

- 来源：Phys.org
- 发布时间：2026-11-19T12:00:15.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/o5oci7b6r7wplm91fs7542eme
- 原文：https://phys.org/news/2026-11-global-ocean-marine.html

## 摘要

国际专家在《自然》杂志上警告，太平洋温度上升并预测将出现极端厄尔尼诺气候事件，呼吁通过AI预测海洋热浪并加强全球海洋监测，以支持渔业和沿海社区的可持续发展。研究人员建议采取一系列行动方案，包括调整捕捞策略、暂时关闭渔业和改进水产养殖操作，并强调需要持续的资金支持和跨部门合作。
