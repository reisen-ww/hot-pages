# 德州农工大学AgriLife研究团队在 Nature Communications 发表线粒体蛋白质互作预测研究

> 原标题：AI points researchers toward new disease targets hidden in mitochondria

- 来源：Phys.org
- 发布时间：2026-11-06T19:20:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/iqt9hpneb7rbv1pgrlns5vxkq
- 原文：https://phys.org/news/2026-11-ai-disease-hidden-mitochondria.html

## 摘要

德州农工大学AgriLife研究团队利用AI工具AlphaFold-Multimer预测了线粒体内1,100种蛋白质的2,895种潜在互作关系。实验室验证了其中部分预测结果，并开放了在线数据库MitoMatch供全球研究者使用。
