# 用酿酒原理解决化学品生产难题

## 摘要

一项研究通过借鉴酿酒行业的微生物处理方法，解决了微生物在生产化学品过程中被毒害的问题。研究人员将生产过程分为两步：第一步，工程微生物利用可再生原料生产温和的中间体；第二步，工程酶将中间体转化为最终化学品。这一方法有望提高化学品产量，降低生产成本，推动生物基化学品的商业化。该项目由曼彻斯特大学和壳牌公司合作进行，旨在通过生物工程技术开发可持续的化学品生产路线。
