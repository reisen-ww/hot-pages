# ChromBPNet 预测揭示非编码变异在造血过程中的谱系结构效应

> 原标题：Chromatin accessibility predictions reveal lineage-structured effects of noncoding variants across hematopoiesis

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/pbm5pr9qa43sv0w2eqsrddwmq
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.12.766027v1?rss=1

## 摘要

研究者训练了针对 17 种造血细胞类型的 ChromBPNet 模型，分析了 302,830 个变异，发现 5.6% 的变异可改变染色质可及性。这些预测反映了造血谱系结构，且与基因组关联研究（GWAS）的精细映射结果互补。虽然 ChromBPNet 预测的可及性效应提供了变异作用的细胞类型信息，但对调控元件和基因调控关系的了解有限。所有预测结果可在指定网址获取。
