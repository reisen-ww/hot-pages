# 某团队在 bioRxiv 发表衰老视觉系统去分化的机制解释

> 原标题：A Mechanistic Account of Dedifferentiation in the Aging Visual System

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

某团队在 bioRxiv 发表论文，通过计算模型模拟神经退化，发现切断下顶叶皮质（IT）或上游连接、添加噪声均减少 IT 去分化，表明该过程无需局部起源；破坏外周 V1 的空间选择特异性 IT 神经元，可选择性降低空间分化，可能解释衰老中更强的空间去分化现象。

## 推荐理由

论文通过计算模型模拟神经退化，发现去分化可能不源于局部，为视觉系统衰老机制提供了新视角
