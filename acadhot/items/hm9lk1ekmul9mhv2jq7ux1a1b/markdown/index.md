# 南非国家健康部门发布2023年HIV治疗指南修订，分析3个月与6个月检测间隔的效果

## 摘要

南非国家健康部门2023年修订HIV治疗指南，将首次病毒载量检测时间从6个月缩短至3个月，并将随访间隔延长至6个月以上。基于18个基层医疗机构的16,338名患者数据（2022-2025），结果显示指南实施后3个月检测覆盖率快速提升至72-85%，但两组病毒抑制率无显著差异（72% vs 72%）。

## 推荐理由

指南修订后3个月病毒载量检测覆盖率显著提升（72-85%），但检测时间长短与病毒抑制率无统计学差异（72% vs 72%），为其他地区调整检测间隔提供参考依据。
