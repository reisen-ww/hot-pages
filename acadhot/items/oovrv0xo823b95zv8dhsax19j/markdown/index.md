# 集成健康诊所生活方式干预的现实世界效果：一项回顾性队列研究

## 摘要

一项回顾性单臂队列研究显示，印度ESIC医学院附属医院Faridabad的集成健康诊所通过生活方式干预（包括香料提取物、饮食和瑜伽）治疗1,737名患者，其中1,466名患者有效反馈显示，84.4%的患者报告了缓解，且随干预措施的增加缓解率上升。尽管没有对照组，但研究支持该干预措施的可行性，并建议进行前瞻性、对照研究。
