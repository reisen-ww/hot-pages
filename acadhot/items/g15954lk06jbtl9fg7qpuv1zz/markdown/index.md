# ReCaRL方法在不确定性鲁棒的胸部X光多标签分类中的应用

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

Jin 等在 medRxiv 发表 ReCaRL 方法用于胸部X光多标签分类，通过构建临床关联图实现可靠性加权更新。内部评估显示该方法 macro AUROC 0.821（基线 0.812），外部评估 AUROC 0.799，后处理校准使内部 Brier score 从 0.113 降至 0.102。
