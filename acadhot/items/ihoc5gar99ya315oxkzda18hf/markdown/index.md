# Spondias tuberosa 干旱适应型树种的染色体规模基因组揭示 Anacardiaceae 科保守架构

> 原标题：The chromosome-scale genome of the drought-adapted Caatinga tree Spondias tuberosa reveals a conserved, unduplicated architecture within Anacardiaceae

## 摘要

巴西 Caatinga 半干旱地区特有的乌木树（Spondias tuberosa）染色体规模参考基因组已生成，包含 24,232 个蛋白质编码基因，52.01% 重复 DNA 和 1.78 百万异质单核苷酸多态性（SNP）。

## 推荐理由

该研究提供了 Spondias tuberosa 的染色体规模参考基因组，并揭示了其在干旱适应中的基因组结构特征，为后续比较基因组研究提供了重要基础。
