# 无酒精和低酒精葡萄酒中缺失的香气成分被识别

> 原标题：White wine drinkers help pinpoint what's missing in no- and low-alcohol drinks

## 摘要

《澳大利亚昆士兰大学》研究人员通过化学分析和感官评估，发现无酒精和低酒精葡萄酒在去酒精化过程中失去了或改变了重要挥发性香气化合物。他们招募了经常饮用白葡萄酒的消费者，评估添加特定化合物是否能提高无酒精葡萄酒的酒香和整体接受度。研究团队还探索使用非酿酒酵母进行发酵，以自然增加香气化合物的生产，旨在改善无酒精葡萄酒的酒香。
