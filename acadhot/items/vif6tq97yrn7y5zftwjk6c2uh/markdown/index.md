# Farrell等团队在HCMV疫苗开发中揭示gB是抗体介导吞噬的关键靶点

> 原标题：HCMV glycoprotein B, but not the pentameric complex, is a key target of antibody-mediated phagocytosis

## 摘要

Farrell等团队发现HCMV的gB蛋白是抗体介导吞噬的关键靶点，而五聚体复合物PC不参与此过程。研究通过含/不含PC的gB亚单位疫苗兔模型实验，证实PC的添加未增强中性抗体活性或抑制病毒细胞结合。此外，阻断gB后会导致吞噬功能下降，支持gB作为疫苗抗原的潜力。研究为预防HCMV垂直传播提供新靶点证据。

## 推荐理由

论文通过兔模型实验验证了gB蛋白是抗体介导的病毒吞噬关键靶点，为HCMV疫苗设计提供了直接证据
