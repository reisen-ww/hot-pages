# Nature：核孔蛋白糖基化与进口蛋白液化的 FG 障碍在活细胞中的研究

## 摘要

某团队在 Nature 发表的论文揭示了核孔蛋白通过糖基化和进口蛋白液化 FG 障碍的分子机制，通过冷冻电镜技术解析了 FG 障碍的动态结构，并验证了进口蛋白在维持屏障通透性中的作用。
