# 某团队在bioRxiv发表AGPAT2代谢重编程介导PD1抑制剂相关心肌炎的机制研究

> 原标题：AGPAT2 Inflammatory Metabolic Reprogramming Mediates Immune Checkpoint Inhibitor-associated Myocarditis via LPAR5-pyroptosis Axis

- 来源：bioRxiv
- 发布时间：2026-11-14T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/uilumbfmanku0dbp1mbiso0oa

## 摘要

某团队在PD1诱导的小鼠心肌炎模型中发现，AGPAT2代谢重编程通过LPA和LPAR5-pyroptosis轴引发心肌损伤，并发现血清LPA水平升高与ICIAM风险相关。该研究为靶向LPAR5的治疗提供了依据。

## 推荐理由

该研究揭示了AGPAT2代谢重编程与ICIAM的关联，为开发靶向LPAR5的治疗方案提供了新思路。
