# 某研究团队在 Molecular Cell 发表：代谢物如何保护消耗它的酶

## 摘要

某研究团队在 Molecular Cell 发表论文，揭示代谢物色氨酸通过结合TDO2酶的第二个结合位点，稳定酶蛋白并调控其降解机制。研究使用CRISPRi筛选发现CK2激酶和CUL1–β-TrCP泛素连接酶的级联作用，结合冷冻电镜解析TDO2结构变化。
