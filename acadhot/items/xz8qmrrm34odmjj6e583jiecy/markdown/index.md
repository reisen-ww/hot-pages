# 阴道代谢物介导阴道微生物群与沙眼衣原体感染风险的关系

## 摘要

研究发现，阴道代谢物在沙眼衣原体（CT）感染风险中起中介作用。携带细菌性阴道病（BV）相关细菌和代谢物的女性更易感染CT。具体而言，Lactobacillus crispatus等乳杆菌和几种BV相关细菌的浓度和相对丰度与CT感染风险相关。阴道代谢物在微生物群与CT感染之间的关系中起显著中介作用。
