# 法国专家向总统提交报告：建议对生成式人工智能加强监管

- 发布时间：2026-11-11T05:55:32.000Z

## 摘要

法国一个专家委员会建议对生成式人工智能加强监管，通过限制奉承迎合机制、开展上市前跨学科风险评估等措施，防范其对个人认知能力、心理健康及社会运行带来的潜在危害。报告由法国人工智能与数字委员会组织编写，提出18项政策建议。
