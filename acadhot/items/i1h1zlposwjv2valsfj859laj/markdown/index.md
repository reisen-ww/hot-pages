# 热带土地利用强度增加重构生物多样性：Nature发表研究揭示单一作物种植园嵌套性变化

> 原标题：Tropical land-use intensification restructures biodiversity

- 来源：Nature
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/i1h1zlposwjv2valsfj859laj
- 原文：https://www.nature.com/articles/s41586-026-11298-6

## 摘要

Nature发表研究揭示热带土地利用强度增加导致生物多样性显著丧失和群落重组，首次量化比较显示单一作物种植园的嵌套性（nestedness）比森林群落高42.7%，该发现为整合农业与自然栖息地的多税种保护策略提供了依据。DOI:10.1038/s41586-026-11298-6
