# 南极冰冻区足迹或破坏稀有微生物生态系统研究

## 摘要

本研究发现73%的靴子携带上游微生物DNA，且清洁消毒无法完全阻断微生物传播，建议加强南极冰冻区生物安全措施。实验比较了当地土壤微生物与靴底、直升机滑板等装备表面微生物，揭示跨区域作业可能加速本地特有微生物扩散。
