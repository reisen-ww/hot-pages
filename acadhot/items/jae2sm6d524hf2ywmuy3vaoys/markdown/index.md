# 科廷大学研究团队发现1.15亿年前的恐龙化石中含完整血红素

> 原标题：Dinosaur blood—oldest discovery rewrites what fossils can reveal about the past

## 摘要

科廷大学联合巴西国家博物馆等机构在《PNAS》发表研究，首次在1.15亿年前的恐龙化石中检测到矿物化血红素和胶原蛋白氨基酸，挑战了生物分子在极长时间内无法保存的假设。研究揭示恐龙快速埋葬于低氧、微生物丰富的环境中，血红素通过矿物化（hausmannite）稳定结构。该成果为分子古生物学开辟新路径，可能影响外星生命探索。

## 推荐理由

该研究提供了首次化学证实化石中存在完整血红素的红细胞证据，为分子古生物学和天体生物学研究提供了新方法
