# 哺乳动物转录延伸中组蛋白‘搭便车’机制的研究

## 摘要

某团队通过单分子平台实时观察哺乳动物染色质转录延伸过程，发现延伸复合体（EC）在解离组蛋白后仍能携带其继续移动DNA，这一现象称为组蛋白‘搭便车’机制。研究进一步表明：延伸因子SPT6和IWS1通过不同机制促进该复合体形成，而组蛋白伴侣FACT和NAP1L1则推动从‘搭便车’到核小体重组装的过渡。

## 推荐理由

论文通过单分子技术揭示了染色质转录中组蛋白‘搭便车’机制，并解析了SPT6和IWS1的协同作用
