# NASA旅行者1号探测器首次抵达一个光日里程碑

> 原标题：Voyager 1 spacecraft reaches one light-day milestone

## 摘要

NASA旅行者1号探测器在周三首次抵达距离地球一个光日的里程碑，目前约26亿公里（16亿英里）远。该探测器自1977年发射以来已飞行近50年，持续探索星际空间。其携带的‘金唱片’向 extraterrestrials 传递人类信息，数据用于研究星际间物质。探测器部分设备已远程关闭以节省能源，仍持续观测磁场的等隐现象。
