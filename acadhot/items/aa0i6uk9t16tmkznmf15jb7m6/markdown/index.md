# 抗体完整轻链重塑淀粉样变可变域聚合动力学

## 摘要

Patel 等团队基于 AL 淀粉样变性患者来源的 LC（AL55）开展研究，发现完整轻链（FL）通过短暂与可变域（VL）相互作用，使 VL 聚合速度降低近四倍，并导向蛋白酶敏感、成核能力不足的原纤维聚集体，而非成熟淀粉样纤维。

## 推荐理由

该研究揭示了完整轻链与可变域在淀粉样变形成中的动态平衡机制，为靶向可变域的治疗策略提供了理论依据。
