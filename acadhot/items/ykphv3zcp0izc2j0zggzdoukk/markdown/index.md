# KMT2A-MENIN复合物被确认为SETBP1突变白血病的新型治疗靶点

> 原标题：The KMT2A-MENIN complex is a therapeutic vulnerability in SETBP1-mutant leukemia

- 发布时间：2026-11-19T00:00:00.000Z

## 摘要

研究团队发现KMT2A-MENIN复合物是SETBP1突变白血病的新型治疗靶点，并验证了相关抑制剂的临床潜力。实验表明CRISPR-Cas9干扰KMT2A或MEN1可抑制SETBP1驱动的增殖和白血病相关转录程序。

## 推荐理由

抑制剂在患者来源的SETBP1突变白血病细胞中显著抑制克隆生长，同时促进髓系分化，为临床转化提供了直接证据。
