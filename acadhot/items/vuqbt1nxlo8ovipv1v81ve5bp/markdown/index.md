# 设计扭曲钙钛矿中的位错驱动极化涡旋网络

> 原标题：Designing dislocation-driven polar vortex networks in twisted perovskites

- 来源：Nature
- 发布时间：2026-11-18T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/vuqbt1nxlo8ovipv1v81ve5bp

## 摘要

通过4DSTEM和DFT等分析方法研究自由支撑的SrTiO3层，发现扭曲钙钛矿中存在长程有序的螺旋位错图案及拓扑极化涡旋阵列。
