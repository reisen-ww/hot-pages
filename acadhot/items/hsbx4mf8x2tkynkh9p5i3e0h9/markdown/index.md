# 东京大学与欧洲同步辐射装置合作实现超短X射线脉冲聚焦的世界纪录

> 原标题：Scientists squeeze record-breaking X-ray power into an incredibly tiny spot

- 发布时间：2026-11-08T03:46:51.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/hsbx4mf8x2tkynkh9p5i3e0h9

## 摘要

东京大学与欧洲同步辐射装置合作，在Optica发表研究，首次实现波长为硬X射线的300飞秒超短脉冲聚焦至180×330纳米区域，强度达10²⁰瓦/平方厘米。铜原子实验证实脉冲强度超过10²⁰瓦/平方厘米，并观测到受激发射（ASE）现象。
