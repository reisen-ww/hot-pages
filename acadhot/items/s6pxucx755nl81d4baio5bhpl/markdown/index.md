# 日本东北大学与台北科技大学在《Inorganic Chemistry》发表水分子介导铜离子反铁磁配对的研究

> 原标题：Water molecules turn out to be secret messengers for magnetism

## 摘要

日本东北大学与台北科技大学在《Inorganic Chemistry》发表研究，发现水分子通过氢键在氟化配位铜化合物中诱导形成反铁磁对。研究团队通过单晶X射线衍射和核磁共振实验，证实低于260K时水分子有序排列导致氢键网络重构，进而形成反铁磁相互作用。该成果为设计新型磁性材料提供了无需强化学键直接耦合磁离子的新途径。

## 推荐理由

该研究为化学家设计磁性材料提供了新方法，通过氢键系统性地调整磁性材料行为。
