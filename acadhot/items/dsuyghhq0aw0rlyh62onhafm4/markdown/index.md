# LipidRT 在 bioRxiv 发表：基于保留时间一致性的脂质注释新方法

> 原标题：LipidRT: leveraging retention time coherence for robust lipid annotation in reversed-phase LC-MS-based lipidomics

- 来源：bioRxiv
- 发布时间：2026-11-18T00:00:00.000Z

## 摘要

某团队在 bioRxiv 预印本平台开发了 LipidRT 软件工具，通过保留时间一致性验证方法显著提升未靶向 reversed-phase LC-MS 脂质组学分析中脂质注释的准确性和覆盖范围，减少人工校验需求。该工具采用 R 语言 Shiny 应用框架，通过色谱保留时间相关性约束模型参数，排除时间不一致的注释结果，使分析流程自动化程度提高 40%，支持 300 种以上脂质分子注释。
