# 苹果为iPhone 20周年纪念机型开发两种设计方案

## 摘要

据爆料，苹果正在为iPhone 20周年开发四款机型，采用两种不同设计方案，包括平面玻璃盖板和四边曲面玻璃设计。曲面版本屏幕边框几乎不可见，呈现出近乎无边框的视觉效果，苹果已对此进行三年原型测试。
