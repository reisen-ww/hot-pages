# 澳大利亚央行行长Bullock称通胀风险仍然偏向上行

## 摘要

澳大利亚央行行长Michele Bullock表示，澳大利亚仍面临通胀上升的风险，暗示政策制定者将继续关注进一步收紧政策。她指出，油价高企、AI数据中心热潮及通胀预期内化是主要上行风险，但房地产市场放缓和整体不确定性可能抵消部分风险。
