# 三种奇异果急性摄入对认知功能的影响研究

> 原标题：Investigating the effect of acute consumption of kiwifruit on cognitive function using functional MRI

- 来源：bioRxiv
- 发布时间：2026-11-19T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/cm5p8qglhzozlslsqtm0l2we9
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.765279v1?rss=1

## 摘要

14名健康参与者在食用三种奇异果（绿、金、红）后进行功能性磁共振成像（fMRI）检测，结果显示红奇异果显著增强了低与高认知负荷之间的脑区激活差异，表明急性食用奇异果可能提升认知效率。
