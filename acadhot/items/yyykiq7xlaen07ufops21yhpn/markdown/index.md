# 阿胡斯大学研究团队发现欧洲古代森林并非密林主导

> 原标题：Scientists discover Europe's ancient forests were nothing like we imagined

## 摘要

由阿胡斯大学Szymon Czyzewski博士领衔的研究团队在《Biological Conservation》发表成果，通过整合化石花粉、木炭残留物、食草动物牙齿DNA等多维度证据，重建了欧洲从新生代（约2300万年前）至工业革命前（约1800年前）的植被景观。
