# 某研究团队发现iPSC衍生心肌细胞厚丝蛋白比例接近成人水平

> 原标题：Adult-like thick-filament protein stoichiometry in immature human iPSC-derived cardiomyocytes

- 来源：bioRxiv
- 发布时间：2026-11-11T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/a33mgcp8awtxnflzp9pantjqg
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.09.761920v1?rss=1

## 摘要

某研究团队通过整合两项独立定量蛋白组学数据，发现iPSC衍生心肌细胞（iPSC-CMs）的厚丝蛋白比例与成人心肌高度匹配。研究对比了iPSC-CMs与胎儿心肌的全球共享蛋白谱，并发现其肌动蛋白结合蛋白（myosin-binding protein）比例与成人心肌区域一致。

## 推荐理由

论文通过比较iPSC-CMs与胎儿及成人心肌的厚丝蛋白比例，证明干细胞心肌细胞可用于研究蛋白剂量异常相关的心脏疾病
