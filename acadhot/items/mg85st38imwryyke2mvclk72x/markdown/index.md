# DxToniaNet：用于儿童脑瘫下肢扭转严重程度评估的神经网络

## 摘要

研究开发并验证了DxToniaNet神经网络，用于通过2D临床视频记录评估儿童脑瘫下肢扭转的严重程度。该模型在测试数据中表现出较小的误差（MAE 1.71，RMSE 2.21），准确区分了GDRS评分大于4分差异的视频，支持临床护理和临床试验中下肢扭转标准化评估。
