# CD3+CD4-CD8-（双阴性）T细胞通过炎症重塑增强胶质母细胞瘤患者生存

## 摘要

双阴性T细胞（DNTs）通过直接抑制肿瘤和炎症重塑髓系细胞增强胶质母细胞瘤患者生存。单细胞转录组分析显示胶质瘤髓系细胞群显著重构，包括促炎信号通路富集和抑制标志物LAIR1表达降低。人类研究证实未修饰DNTs抑制胶质瘤干细胞活性、增强巨噬细胞吞噬功能，并在异种移植模型中使生存期延长。该发现为DNT细胞疗法开发提供新靶点。

## 推荐理由

该研究为DNT细胞治疗胶质母细胞瘤提供了机制证据，支持后续临床转化探索。
