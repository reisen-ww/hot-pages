# Debrah 等在 bioRxiv 发表噬菌体肽 gp28 通过内外膜靶向作用促进细菌细胞死亡的研究

> 原标题：Phage peptide promotes bacterial cell death via inner and outer membrane targets

## 摘要

Debrah 等在 bioRxiv 发表研究，揭示噬菌体编码的 gp28 肽通过不对称分布靶向革兰氏阴性菌内外膜，诱导膜通透性改变并抑制多种临床分离的 UPEC 和其他革兰氏阴性菌生长。实验证实该肽的活性受脂多糖和二价阳离子竞争抑制，并扩展至对部分革兰氏阳性菌的表面电荷依赖性作用。

## 推荐理由

论文揭示了 gp28 肽通过电荷相互作用破坏细菌膜的具体机制，为开发基于噬菌体肽的抗菌药物提供了新思路。
