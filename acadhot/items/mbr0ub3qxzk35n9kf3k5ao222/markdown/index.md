# Mindel 等在 bioRxiv 发布序列模型预测转录因子结合的预印本

> 原标题：Sequence-based models predict TF binding with negligible contributions from motif cooperativity

- 发布时间：2026-11-17T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/mbr0ub3qxzk35n9kf3k5ao222

## 摘要

Mindel 等在 bioRxiv 发布预印本，通过 BPNet 模型验证转录因子结合预测中邻近位点的协同作用贡献可忽略。研究基于 ~2000 ENCODE TF 结合数据训练模型，发现模型仍能捕捉不同转录因子间的结合偏好差异，但全基因组预测中协同作用的影响可忽略不计。
