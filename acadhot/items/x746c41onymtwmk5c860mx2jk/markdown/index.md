# 某团队提出基于本体（Ontology）的 SEA-CDM 整合方法用于疫苗临床试验分析

> 原标题：Ontology-Based SEA-CDM Integration for Vaccine Clinical Trials: Query, Similarity, and Design Recommendation

- 发布时间：2026-11-13T00:00:00.000Z

## 摘要

某团队基于本体（Ontology）和 SEA-CDM 模型，开发了疫苗临床试验的语义检索、不良反应（AE）排名和试验设计推荐系统。该系统整合了 9,147 条疫苗相关临床研究数据，通过疫苗本体（VO）和不良反应本体（OAE）实现语义关联。

## 推荐理由

论文提出了基于本体（Ontology）的 SEA-CDM 整合方法，通过对比 TransE 和 CompGCN 模型在疫苗临床试验中的检索效果，为后续研究提供可迁移的数据分析框架。
