# 某研究团队发现多巴胺神经元编码努力成本为负奖励值

> 原标题：Dopamine reward prediction error signal encodes effort cost as negative reward value

- 来源：bioRxiv
- 发布时间：2026-11-13T00:00:00.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/j1xqfd0p9ju533f45lnjcda1o
- 原文：https://www.biorxiv.org/content/10.64898/2026.11.11.765978v1?rss=1

## 摘要

某研究团队通过灵长类动物二元选择任务实验，发现多巴胺神经元在刺激呈现时通过抑制性信号编码努力成本为负奖励值，在真实努力发生后根据实际努力与预测的差异产生抑制或兴奋信号，该信号模式与时间差强化学习形式一致。
