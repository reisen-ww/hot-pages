# Rapidus 2纳米芯片量产计划因SRAM技术未突破受挫

## 摘要

日本政府支持的芯片初创公司Rapidus因未能在2026年夏季前完成静态随机存取存储器（SRAM）的稳定生产，导致2纳米芯片量产计划延迟。目前其工程师团队面临技术突破压力，但尚未实现关键SRAM单元的量产能力，可能影响日本半导体产业战略布局。
