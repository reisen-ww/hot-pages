# NIH 将最后一批政府拥有的实验黑猩猩移至保护区

## 摘要

美国国立卫生研究院（NIH）将在明年年初将位于德克萨斯州的近三十余只政府拥有的实验黑猩猩移至路易斯安那州的一个保护区，履行其在2015年宣布的将所有政府拥有的黑猩猩移至保护区的承诺。
