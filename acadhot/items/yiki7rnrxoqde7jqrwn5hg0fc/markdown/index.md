# 加州大学圣巴巴拉分校与苏黎世联邦理工学院合作开发AI增强仿生眼，临床试验显示精准度提升

> 原标题：AI-powered bionic eye breakthrough could help the blind see again

- 发布时间：2026-11-12T11:55:55.000Z

## 摘要

加州大学圣巴巴拉分校与苏黎世联邦理工学院等团队合作开发AI驱动的仿生眼技术，在西班牙完成的首个人体试验中，植入96电极的视觉皮层刺激装置通过AI优化实现更精准的视觉感知（如光点、形状），并发现脑活动比刺激参数更能预测感知。该研究由NIH资助，发表在Neuron 2026年11月号。
