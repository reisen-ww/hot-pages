# Science发表DNA Typewriter追踪小鼠胚胎细胞谱系历史的研究

> 原标题：'DNA Typewriter' records cells' history in developing mouse embryo

- 来源：Phys.org
- 发布时间：2026-10-11T22:20:01.000Z
- 学术热点：https://reisen-ww.github.io/hot-pages/acadhot/items/rdfiflqjv0kfa585kvd6mrufp
- 原文：https://phys.org/news/2026-10-dna-typewriter-cells-history-mouse.html

## 摘要

华盛顿大学和Dartmouth College等团队在Science发表研究，利用DNA Typewriter记录小鼠受精卵及胚胎细胞的分裂历史，并重建从合子到器官形成后期、历时13.5天的细胞谱系。

## 推荐理由

研究展示了如何用DNA Typewriter按时间顺序记录小鼠胚胎细胞分裂史，并据此追踪细胞谱系与命运分化时点。
