# 开发者可通过新版 AWS 体验访问 SageMaker Studio

> 原标题：Developers can now access SageMaker Studio through the new AWS experience

- 来源：AWS Machine Learning Blog
- 发布时间：2026-10-19T22:39:24.000Z

## 摘要

AWS 推出新版注册登录体验，新客户用 Google、GitHub、Apple、Amazon 账号或邮箱经 2–3 步即可进入已配置好的 Amazon SageMaker Studio，无需高级 AWS 账户流程、手机号验证或信用卡（大多数客户）。
