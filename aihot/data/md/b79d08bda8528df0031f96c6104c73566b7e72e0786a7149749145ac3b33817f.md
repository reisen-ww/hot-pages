# 研究发现更复杂的 coding agent harness 只增成本不提通过率

> 原标题：Fancy harnesses make coding agents more expensive but not better, study finds

- 来源：The Decoder
- 发布时间：2026-10-24T09:21:39.000Z
- MyHOT：https://reisen-ww.github.io/hot-pages/aihot/items/dkkmzvn6hxlhk4d0s2xm8a5hc
- 原文：https://the-decoder.com/fancy-harnesses-make-coding-agents-more-expensive-but-not-better-study-finds/

## 摘要

Liu 和 Han 的研究让 5 个模型在 Claude Code、OpenCode、mini-SWE-agent 三个 harness 上跑 SWE-bench Verified，发现换 harness 带来的结果变化与单纯重跑相当，而三个 harness 消耗的 token 是最简方案的 2 到 3 倍，通过率却仍在测量不确定性内。
