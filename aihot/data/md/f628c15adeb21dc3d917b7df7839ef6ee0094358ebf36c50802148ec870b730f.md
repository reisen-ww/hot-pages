# ChatGPT 新增锁定会话功能，可用 PIN 或 Face ID 保护隐私

## 摘要

OpenAI 宣布 ChatGPT 新增锁定会话功能，用户可用四位数 PIN 或 Face ID、Touch ID 保护对话隐私。锁定后的对话会移入单独的 Locked Chats 区域，拥有独立于常规 Memory 的记忆，重置 PIN 会永久删除所有受保护内容。
