# 如何在 VS Code 中继续 GitHub Copilot app 会话

## 摘要

在 VS Code 中选择 "Open in VS Code" 可直接打开 GitHub Copilot app 会话，任务、计划、对话、diff 与 worktree 全部保留，无需重建上下文。教程演示逐行审查 agent 改动、手动编辑、用集成终端跑 npm test / npm run lint 本地验证，并可继续向 Copilot 提问，最后提交推送到会话关联的 pull request。
