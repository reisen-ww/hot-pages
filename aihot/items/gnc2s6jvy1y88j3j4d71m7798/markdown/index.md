# OpenAI低调将数据中心更名为‘计算园区’

> 原标题：OpenAI is quietly renaming data centers ‘compute campuses’

- 发布时间：2026-11-03T15:00:44.000Z

## 摘要

OpenAI宣布将数据中心更名为‘计算园区’并启动Grid Protectors Program，承诺承担电力成本并改善社区关系。但批评者认为改名回避了环境负担和居民权益问题。Activist groups指出重命名未能解决数据中心对当地资源造成的压力，OpenAI未回应具体动机和未来计划。
