# Anthropic 研究员揭示模型训练效率加速提升

> 原标题：Anthropic can already retrain Mythos with "a fraction of the compute originally needed," says former researcher Coxon

- 发布时间：2026-11-14T11:21:41.000Z

## 摘要

Anthropic 前研究员 Jacob Coxon 表示，公司 IPO 路演中展示的图表显示模型训练所需计算资源正在以超指数方式减少。他指出，Anthropic 的 Mythos 模型训练已实现大幅提速，仅需少量初始计算资源即可重新训练，这表明算法效率正以惊人的速度提升。Coxon 建议暂停先进模型开发以助同行追赶。
