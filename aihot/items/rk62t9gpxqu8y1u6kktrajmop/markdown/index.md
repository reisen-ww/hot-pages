## 摘要

OpenAI 前成员 Andrej Karpathy 周末利用 Claude 模型构建视频平台，推荐效果优于 YouTube。43 万条 Hacker News 评论被提炼为 6,454 个视频，无需登录且本地存储。另衍生出 TristanTube，3 分钟内通过 Claude Code 从 YouTube 列表生成 47,000 个视频。
