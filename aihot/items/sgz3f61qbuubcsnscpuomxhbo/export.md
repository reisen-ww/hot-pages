# Claude Code 新规则限制游戏克隆，但AI游戏复制浪潮难阻

> 原标题：Claude’s new rules against game cloning won’t stop the AI copying boom

## 摘要

Claude Code 2.1.314版本（2026-10-30发布）新增'tengu_heron_brook'规则，明确禁止克隆具体游戏。XDA验证显示该规则已存在于Claude Opus 5.5系统提示包。作者认为此措施仅能缓解企业责任风险，无法阻止AI游戏复制的规模化发展。
