## 摘要

OpenFold3 是开源的生物分子结构预测模型，现已可在 Amazon SageMaker JumpStart 上部署。通过几行代码，用户可以轻松将 OpenFold3 部署到自己的 AWS 账户中，预测蛋白质、DNA、RNA、小分子配体及其复合体的 3D 结构。该模型支持多 GPU 实例并行运行，适合高通量筛选管道使用。
