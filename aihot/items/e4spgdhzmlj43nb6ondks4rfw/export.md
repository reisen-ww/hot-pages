## 摘要

AWS 提出一种基于事件驱动的架构，利用 AWS CloudTrail、Amazon EventBridge 和 AWS Lambda 自动同步 AWS Agent Registry。该架构支持单账户和跨账户环境，确保 MCP 服务器更新时，相关记录能及时同步，提高注册表的可靠性和准确性。
