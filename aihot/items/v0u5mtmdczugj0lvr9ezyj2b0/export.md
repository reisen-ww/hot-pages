# Discord 更新 Markdown 预览，.md 文件可正确渲染

> 原标题：Discord now formats Markdown previews right

- 发布时间：2026-10-22T18:58:19.000Z

## 摘要

Discord 今日更新上线正确的 Markdown 预览：上传 .md 文件后会直接渲染出表格和格式，而不是显示一堆符号。更新还新增侧边栏右键"Move to…"功能，用于整理服务器和频道；Discord Nitro 会员现在可上传最大 1GB 的文件。
