# Google Deepmind推出AlphaGenome 2单细胞基因组分析模型

## 摘要

Google Deepmind发布AlphaGenome 2单细胞基因组分析模型，在疾病基因和疫苗响应预测上精度提升30%，并支持AI药物研发。该模型基于1070万个体细胞数据训练，可预测DNA物理包装和甲基化标记，在TenK10K基准测试中识别出约30%的致病基因变体，优于前代模型16%的准确率。系统支持通过少量细胞数据推断新细胞状态，已在COVID-19疫苗研究中验证其区分激活T细胞的能力。

## 推荐理由

通过单细胞分析提升疾病基因和疫苗响应预测精度，并支持AI驱动的药物研发
