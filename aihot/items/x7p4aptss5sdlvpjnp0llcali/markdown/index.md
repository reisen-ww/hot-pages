# 高盛从交易员和银行家中撤回AI编码工具

> 原标题：Goldman Sachs pulls AI coding tools from traders and bankers

- 发布时间：2026-11-02T20:00:03.000Z

## 摘要

高盛从交易员和银行家中撤回AI编码工具，仅限工程师使用，原因包括生产力和风险管理。内部人士透露此举引发不满，此前高盛CIO曾公开称赞非技术人员使用AI快速原型开发。
