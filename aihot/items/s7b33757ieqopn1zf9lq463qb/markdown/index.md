## 摘要

OpenAI 和 Anthropic 分别宣布其 AI 模型在迁移 COBOL 代码方面取得进展，但专家指出实际应用仍需克服复杂性。OpenAI 的 GPT-6.1 Sol 和 Anthropic 的 Claude Code 均展示了在低推理努力下保持行为准确性的能力，但仍需解决系统拆分和测试等难题。
