# 通过 cross-Region inference 从加拿大访问 Amazon Bedrock 上的 OpenAI GPT 模型

## 摘要

Amazon Bedrock 通过 cross-Region inference（CRIS）让加拿大 Region 可调用 OpenAI GPT-5.6、GPT-6、GPT-6.1 三个模型族，推理在北美处理。
