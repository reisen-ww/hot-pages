## 摘要

Claude Code 团队将代码审查从 PR 提交后的终点关卡改为持续进行的过程，类似写作时的拼写检查。大多数变更在请人工审查前已由 Claude 至少审查和修复一次，以捕获常规错误，让团队精力集中于更高层次的问题。
