## 摘要

Dropbox以3.5亿美元收购Tigris Data，旨在通过其跨区域数据存储技术强化AI基础设施。DBX Agent Cloud将支持ChatGPT、Claude等模型，并计划2027年扩展至更多地区。收购标的曾为Uber开发存储系统，其技术可自动优化数据位置以降低访问延迟。Dropbox此前已收购Reclaim.ai、Promoted.ai等AI相关企业。

## 推荐理由

收购Tigris Data使Dropbox能优化跨区域数据存储，提升AI模型运行效率，并计划在2027年扩展服务范围。
