AWS 将其定义的八大负责任 AI 维度应用于 Amazon Aurora PostgreSQL，通过其内置的 Aurora Machine Learning 能力，简化了负责任 AI 的实施。本文详细探讨了可解释性维度，展示了如何使用 Retrieval Augmented Generation (RAG) 基础的客服聊天机器人实现透明、可解释的响应。
