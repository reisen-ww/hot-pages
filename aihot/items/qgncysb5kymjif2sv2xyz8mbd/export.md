# DeepSeek 开源推理框架 DeepInfer，支撑其最快最便宜的模型 V4.1-Flash

## 摘要

DeepSeek 以 Apache License 2.0 开源内部推理框架 DeepInfer，让 V4.1-Flash 模型能大规模快速生成回答。该框架基于 vLLM，通过优化计算内核、跨芯片分布式处理和更快的文本生成技术提升性能，同时发布的 deepseek-recipe 可复现官方 API 的 token 处理行为。
