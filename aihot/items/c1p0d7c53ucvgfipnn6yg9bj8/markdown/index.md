# Nvidia 开放 Nemotron 3.5 Transcribe 模型：整合转录、翻译与说话人识别

## 摘要

Nvidia 开放发布 Nemotron 3.5 Transcribe 模型，支持40种语言转录、31种翻译及13种说话人识别，在多语言ASR评测中排名前列。该模型通过合成数据训练，实测在印度医疗领域微调后错误率降至11.8%，性能优于开源医疗语音模型。Nvidia同时发布Granary v2多语言语音数据集（新增48种语言、约844,000小时录音），并提供训练工具链。
