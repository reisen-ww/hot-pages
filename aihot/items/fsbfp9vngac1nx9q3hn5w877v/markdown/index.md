## 摘要

Simon Willison 发布 Datasette Apps 0.3a0 版本，新增在 Datasette 内托管和编辑自定义 HTML 应用的功能。支持通过 # 标签自动补全应用列表，新增 app_add_stored_queries() 和 app_remove_stored_queries() 工具管理应用可调用的存储查询，用户需先审批写操作查询。
