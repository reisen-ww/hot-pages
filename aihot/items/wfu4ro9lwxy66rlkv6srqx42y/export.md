# Snapchat 发布 Easy Lens CLI 工具，支持与 Claude Code 等AI助手集成开发AR透镜

## 摘要

Snapchat 推出 Easy Lens CLI 工具，支持与 Claude Code 等AI编码助手集成开发AR透镜。开发者可通过自然语言描述需求，由AI助手完成从构建AR组件、生成资产到发布透镜的全流程，包括集成超过100种AR组件和50种AI资产生成器。
