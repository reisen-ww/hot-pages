## 摘要

NVIDIA NeMo Switchyard 是一个开源库，帮助 AI 代理选择合适的模型处理请求。通过 AWS Cloud Development Kit 部署 LiteLLM 和 Switchyard 插件，可以评估路由策略的成本效率。该示例使用 Amazon Bedrock 进行模型调用，通过实验性集成 LiteLLM 测量成本。
