## 摘要

OpenAI 宣布 ChatGPT 与 Work 平台功能合并，自 12 月起 Plus/Pro/Business 计划将共享 token 预算。具体机制包括：1) token 测算规则（复杂任务消耗更快）；2) 用户可通过 Settings 查看余额及重置时间；3) Instant 模型对话不占用预算但可能影响低价用户服务质量。此举或回应此前对 ChatGPT 功能复杂化引发的批评。
