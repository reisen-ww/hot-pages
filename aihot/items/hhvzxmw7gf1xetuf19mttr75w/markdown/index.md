# 美国联合航空禁止AI代理预订机票，称存在网络安全风险

## 摘要

美国联合航空宣布将限制AI代理访问其预订系统，以防范网络安全风险。该措施与多家银行近期警告形成呼应，银行指出客户若将账户密码共享给AI助手可能导致资金损失和账户变更。联合航空通过直接平台限制和间接渠道管控双重手段实施禁令，并更新了机票预订相关政策

## 推荐理由

航空公司与银行正加强安全措施，防止客户将账户密码共享给AI助手，相关风险包括数据泄露和违规操作
