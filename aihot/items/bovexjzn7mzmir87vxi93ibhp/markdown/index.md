## 摘要

企业 AI 的经济学正从 token 或 GPU-hour 成本转向每个有用业务成果的有效成本，利用率成为核心变量。文章对比自建、按需消费与集成私有 AI 平台三种模式，指出自有基础设施需配合调度、模型选择与 KV-cache 管理等运营纪律才能改善回报。HPE 委托的独立测试显示，HPE Private Cloud AI 在高利用率下每 token 有效成本低于反复租用同等容量。
