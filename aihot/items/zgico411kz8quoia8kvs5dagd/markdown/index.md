# 维基百科警告AI版权裁决或威胁开放网络

## 摘要

维基百科在AI版权诉讼中提出折中方案，主张未经许可训练模型需符合‘转化性使用’原则，并警告过度保护版权可能损害开放知识共享。该组织指出，若法院对合理使用原则过于宽泛，将威胁维基百科等开放知识平台；若过于严苛，则可能阻碍AI技术发展。维基百科建议，AI公司应尊重CC协议要求，并在生成内容时标注来源。
