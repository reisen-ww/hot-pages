# Hugging Face Hub 支持通过 Google Cloud 账户付费

## 摘要

Hugging Face Hub 支持通过 Google Cloud 账户统一付费，简化企业采购流程。管理员可在Google Cloud Marketplace订阅并关联组织，使用户消费计入现有Google Cloud账单，避免重复注册和支付问题。已订阅组织可通过Hugging Face设置页面查看Google Cloud账户的绑定状态。

## 推荐理由

通过Google Cloud账户统一支付Hugging Face服务费用，简化企业采购流程。
