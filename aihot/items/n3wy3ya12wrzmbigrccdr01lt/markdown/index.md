# Grok与OpenAI模型在中期选举中的政治倾向差异研究

> 原标题：Forced to pick, Grok’s AI model chooses Republicans. OpenAI’s picks Democrats.

- 发布时间：2026-10-24T15:00:00.000Z

## 摘要

研究显示Grok 4.7在92%的案例中选择共和党候选人，而OpenAI的GPT-6.1 Sol在97%的案例中支持民主党。差异源于模型训练数据、API调用参数及搜索模式，其中Grok的搜索结果更倾向保守媒体（如Turning Point Action、X），而GPT-6.1 Sol依赖主流新闻源（AP/Axios/Reddit）。

## 推荐理由

研究揭示了GPT-6.1 Sol与Grok在政治倾向上的显著差异，并探讨了其背后的训练数据、API调用参数和搜索模式差异
