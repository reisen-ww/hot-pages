# OpenAI宣布数据中台项目不再使用NDAs并与社区加强合作

> 原标题：OpenAI is stepping back from NDAs for data center projects

- 来源：The Verge · AI
- 发布时间：2026-11-06T00:37:56.000Z
- MyHOT：https://reisen-ww.github.io/hot-pages/aihot/items/t7jkps8q9ew4urouvzup9zoyr
- 原文：https://www.theverge.com/ai-artificial-intelligence/1028454/openai-data-center-nda

## 摘要

OpenAI宣布在数据中台项目中不再与公共官员签订保密协议（NDAs），并推出多项社区承诺：支付全额电费、公开招聘计划、未来所有计算园区均需遵守本地优先原则。此前亚马逊已宣布类似政策，显示行业正逐步减少对NDAs的依赖。

## 推荐理由

对比亚马逊等同行，OpenAI的NDAs政策调整反映了行业对透明度的重视，可作为评估企业社区责任的新参考。
