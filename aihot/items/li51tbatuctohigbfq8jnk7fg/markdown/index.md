# NVIDIA与半导体企业合作推动AI制造流程升级

> 原标题：AI Is Changing How Semiconductor Fabs Work — and Engineers Are Moving Faster Because of It

## 摘要

NVIDIA与Applied Materials、Siemens等企业合作，通过AI加速半导体制造中的物理模拟和数字孪生应用。案例包括：COMSOL利用cuDSS实现10倍加速、Applied Materials的Ginestra平台与cuDSS结合提升10倍、ACE+平台通过PhysicsNeMo加速35倍，以及Siemens集成cuLitho使光刻模拟加速17倍。
