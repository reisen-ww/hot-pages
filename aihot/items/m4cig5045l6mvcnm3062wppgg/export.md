## 摘要

ChatGPT 桌面应用现已在 AWS GovCloud (US) 上通过 Amazon Bedrock 提供 OpenAI 的前沿模型。配置 Codex 以通过 Amazon Bedrock Mantle 在 us-gov-west-1 地区路由模型请求，支持 AWS 身份和访问管理 (IAM) 以及现有 AWS GovCloud (US) 网络控制。
