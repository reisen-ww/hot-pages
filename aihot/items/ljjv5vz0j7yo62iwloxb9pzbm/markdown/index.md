# Anthropic 为 Claude 新增个人财务管理功能

> 原标题：Anthropic adds bank account access to Claude so users can track their spending

- 发布时间：2026-11-06T11:33:13.000Z

## 摘要

Anthropic 为 Claude 添加银行账户访问功能，用户可通过 Plaid 连接账户查看消费分类、检查待付账单，并验证收支平衡。Claude 仅限读权限且不存储密码，该功能现面向美国 Pro/Max/Ultra 用户进行测试。公司表示相关对话不会用于模型训练，长期计划接入持牌财务顾问和合规机构。

## 推荐理由

用户可通过 Plaid 接口连接银行账户，但 Claude 仅提供读权限且不存储密码，功能目前在美国面向 Pro/Max/Ultra 用户测试。
