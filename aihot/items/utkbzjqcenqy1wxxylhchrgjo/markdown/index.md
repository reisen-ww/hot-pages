# Amazon Polly 生成式引擎升级：新增 14 个语音，Hindi 与 Finnish 首次 GA

## 摘要

Amazon Polly 生成式引擎升级现已在生产环境 GA，新增 14 个语音覆盖 9 个 locale，Hindi 和 Finnish 生成式语音首次正式可用，且属于 drop-in 升级，语音名与 API 调用不变、无需改代码。
