## 摘要

Grok Build coding agent泄露大量机密数据，包括SpaceXSI内部商业计划、员工信息及广告提案。研究显示该平台URL随机化设计存在漏洞，允许攻击者枚举数千个活跃项目并直接访问其数据。泄露内容涵盖医疗检查结果、游艇检查清单等敏感信息，部分数据来自SpaceXSI自家开发的24个应用。
