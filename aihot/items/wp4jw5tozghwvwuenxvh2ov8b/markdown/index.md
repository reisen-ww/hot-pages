# DeepL 推出实时翻译新模型 Aure，支持捕捉说话者的语气、情感和语速

## 摘要

DeepL 推出实时翻译新模型 Aure，支持捕捉说话者的语气、情感和语速。该模型通过分离语音身份、语调旋律和内容进行独立翻译，并利用强化学习避免输出口音。目前支持英语、德语、西班牙语等8种语言，已应用于 DeepL Voice for Online Meetings 等场景。DeepL 此前收购音频流媒体团队 Mixhalo 以强化实时语音翻译能力。
