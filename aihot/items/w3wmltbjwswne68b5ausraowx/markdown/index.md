# 纽约时报起诉Brave浏览器非法抓取AI训练数据并绕过付费墙

> 原标题：The New York Times sues Brave web browser for AI scraping and bypassing paywalls

## 摘要

纽约时报起诉Brave浏览器未经授权抓取其内容用于AI训练，并利用浏览器功能绕过付费墙。诉讼指控Brave向Anthropic、Perplexity、Mistral等AI公司提供未经许可的版权内容，且未获得出版商同意。纽约时报强调AI开发需遵循伦理规范，Brave及涉事AI公司暂未回应置评请求。
