# Artex AI 挖客工具遭公开暴露

> 原标题：Hundreds of Artex AI hacking tools found publicly exposed to the web

- 来源：TechCrunch · AI
- 发布时间：2026-11-06T18:44:38.000Z

## 摘要

安全研究人员发现 Artex AI 挖客工具遭公开暴露，已导致韩国金融业及微软云客户等多起大规模网络攻击。该工具为开源自主渗透测试系统，微软指出其攻击链可从侦察到数据窃取全程自动化，暴露原因包括弱密码和未启用多因素认证。Censys数据显示超过800个未授权实例长期暴露，部分攻击涉及支付和游戏公司。Artex 已宣布转为闭源，但仍有代码片段在GitHub可下载。

## 推荐理由

原文揭示了 Artex 工具因配置不当被公开暴露的细节，包括其被用于韩国金融业攻击和微软云客户数据窃取案例，可作为评估开源AI工具安全风险的参考案例。
