# Google 推出 Agent Compute Engine，为每个 Gemini 智能体提供硬件隔离的 microVM

> 原标题：Google's Agent Compute Engine gives every Gemini agent its own hardware-isolated micro virtual machine

## 摘要

Google 宣布推出 Agent Compute Engine，让每个 AI 智能体独占一台由 Titanium 芯片保护的 microVM，该服务已支撑 Gemini 运行，并将在未来几个月开放预览。
