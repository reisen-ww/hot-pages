# Stripe 称 AI agent 购物交易量在增长，但拒绝披露具体数字

> 原标题：Stripe says AI agent purchases are adding up, but it won't share the numbers

## 摘要

Stripe 表示 AI agent 正通过其 Link 支付服务为用户购物，9 月交易笔数增长 38 倍、支付金额增长 20 倍，但未披露背后的绝对交易量和金额。使用 Link 的 agent 已从分析时的约 70 个增至约 200 个，包括 Meta 的 Muse 和 Grok Bot，单笔交易多在 $100 左右。零售占交易笔数 36%、金额 32%，旅行占金额 28%。
