# OpenAI 向北约及欧洲政府开放网络安全工具 Daybreak

## 摘要

OpenAI 向北约和多个欧洲政府提供了其网络安全工具 Daybreak。该工具利用 AI 模型帮助审计软件、发现漏洞并修补安全漏洞。欧盟网络安全机构 ENISA 已发现多处漏洞，而波兰 CERT Polska 则找到了 MikroTik 路由器中的六个被积极利用的漏洞。
