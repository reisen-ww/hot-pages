## 摘要

Meta Muse AI 新增 spaces 功能，允许用户通过描述创建定制化应用界面（如购物中心、学校仪表盘等），并与外部工具（如 Gmail、Google Calendar）实时同步数据。同时引入 Active Memory 和 Active Focus 能力，提升上下文理解与目标导向能力。该功能已面向所有 Muse 用户开放，未来计划支持空间共享与协作。
