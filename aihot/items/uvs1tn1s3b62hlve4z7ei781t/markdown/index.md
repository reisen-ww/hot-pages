## 摘要

OpenAI 推出 Images 2.6 模型，支持文本与照片生成动画GIF，并开放 Flare（高效）和 Sunburst（高质量）API 模型。用户通过 ChatGPT 和 API 每周生成图像量超40亿，较九月增长1亿。
