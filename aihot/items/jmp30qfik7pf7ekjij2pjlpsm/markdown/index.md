# Omen AI收购Aquatic Labs，整合实时水传感器技术

## 摘要

Omen AI以1600万美元现金加股票收购Aquatic Labs，双方技术互补：Omen的传感器检测水中元素，Aquatic Labs的传感器测试水碱性。整合后计划在2027年前推出覆盖1GW芯片的实时监测方案，降低数据中心因冷却液异常导致的停机损失（单次停机成本约5-7亿美元）。收购源于创始人Zach Laberge与Aquatic Labs CEO Allan Adams的投资者引荐。
