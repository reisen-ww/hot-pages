# Meta 首席基础设施负责人 Santosh Janardhan 即将离职

## 摘要

Meta 宣布其长期担任首席基础设施和工程联合负责人的 Santosh Janardhan 将离职，由前 Amazon 高管 Dave Brown 接替。Janardhan 原本于 2009 年加入 Meta，对公司的发展起到了重要作用。目前尚不清楚其离职的具体原因。
