# CSS Working Group 决议：按钮使用 pointer 光标

## 摘要

CSS 工作组在最近的会议上决定，按钮等交互元素应使用 pointer 光标，以指示可点击状态。这一决议总结了讨论中的意见，包括 text cursor 用于文本输入、grabbing hand 用于拖拽等。虽然默认浏览器样式可被用户自定义覆盖，但工作组认为这些元素应有明确的视觉反馈，以提升用户体验。
