## 摘要

Lucas Barrena 在 GitHub 公开该连接库仓库，支持浏览器、Node.js 和 React Native 的 P2P WebRTC 连接，内置信令服务器和节点发现功能。

## 推荐理由

该仓库提供了浏览器与 Node.js 间 P2P WebRTC 连接的完整解决方案，包含信令服务器、加密地址、自动 SDP/ICE 交换等核心功能
