## 摘要

某研究团队在 GitHub 开源轻量级自托管 LaTeX 编辑器 TexLite，支持集成 Codex、Claude Code 或 OpenCode 等代码代理。该工具已成功应用于完成 EMNLP、IEEE ICDE 等顶级会议论文的撰写，并支持实时协作、本地 Git 历史及 PDF 预览等功能。部署仅需 Node.js 环境，提供 Docker 镜像。
