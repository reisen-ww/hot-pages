# 有人使用 Tailscale 监控远程鱼缸或鸡舍吗？

## 摘要

作者为女友的鱼缸搭建了 Home Assistant 监控系统，使用 SMLIGHT SMHUB Nano 和 Tailscale 连接，通过 EHEIM aquaAlert+e 的 REST API 获取水温、导电性等数据。作者分享了基本的 Home Assistant 配置示例，并表示理解水处理建议仍有一定难度。
