# 哈佛大学研究人员发现AI编码工具使代码审查成为新瓶颈

> 原标题：Harvard researchers find AI coding agents shifted the bottleneck to code review

## 摘要

哈佛大学研究人员通过对比718家公司的代码提交与审查数据，发现AI编码工具使工程师代码量增加30%但未提升完成效率，瓶颈转移至代码审查阶段。研究特别指出法律AI工具如Harvey和Cooley的同类问题：虽然能加速初稿生成，但审查阶段耗时增加49%，且未公开审查效率的具体指标。

## 推荐理由

研究通过对比718家公司的代码提交与审查数据，揭示AI编码工具在提升代码量的同时未改善最终交付效率，瓶颈出现在代码审查环节，为法律AI采购提供评估指标参考
