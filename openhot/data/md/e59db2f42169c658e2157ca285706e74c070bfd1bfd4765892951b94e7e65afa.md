# Jiff 1.0发布：Rust生态自托管日期时间库正式上线

> 原标题：A datetime library for Rust

- 发布时间：2026-11-15T22:39:34.065Z

## 摘要

Jiff团队在GitHub发布Rust日期时间库1.0版本，支持自动处理夏令时和时区转换，已被uv、Cargo、Starship、fd、Nushell等主流项目采用。该库提供友好格式的持续时间输出、 RFC 2822/ISO 8601双解析、ICU4X多语言格式支持，并包含详细的API文档和示例代码。

## 推荐理由

Jiff 1.0版本提供了完整的日期时间处理API，包含友好格式的持续时间、ICU4X多语言支持、自动夏令时处理等特性，已被uv、Cargo、Starship等核心项目集成使用，是Rust生态中处理复杂时区场景的首选方案。
