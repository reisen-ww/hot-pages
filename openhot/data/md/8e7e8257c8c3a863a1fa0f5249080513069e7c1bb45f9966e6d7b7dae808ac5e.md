## 摘要

FareBot 是一个无需 API 密钥即可运行在 Docker 上的 Telegram 机器人，可自动追踪指定航班路线的价格并提醒价格下降。目前发现最低价格为 €17，比平时低 83%。由于 Google 航班页面无公开 API，机器人可能因页面变化而失效，需开发者定期维护。
