## 摘要

某团队在 GitHub 公开自托管 PHP 平台 Vale，支持 PHP 8.3+、MySQL/MariaDB/SQLite/PostgreSQL 数据库，内置内容编辑器、电商工具、分析系统，通过 AGPL-3.0 许可证授权。该平台强调零插件扩展，可按需启用/禁用功能模块，最小系统要求为 Raspberry Pi 级别硬件。
