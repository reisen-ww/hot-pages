## 摘要

Tokio-rs 发布 Rust 自托管全栈框架 Topcoat，支持异步组件与数据库直连。采用模块化设计，内置基于 Tailwind 的 UI 组件库，通过 # [component] 标记实现可编辑的 UI 组件。无需 WebAssembly 或客户端构建，通过 view! 宏直接编译生成 HTML，支持服务器端渲染与客户端实时交互。
