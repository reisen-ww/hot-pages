## 摘要

ChromeDevTools 发布 MCP 版本，支持 AI 编程助手自动化调试与性能分析。该工具通过 Chrome DevTools API 实现浏览器控制，包含性能分析、网络请求调试、截图等功能，支持 Node.js LTS 安装。
