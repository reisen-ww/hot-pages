# DeepSeek-AI 发布 DeepSeek-V4.1-Flash，多模态 MoE 模型将 KV Cache 压缩至每 token 890 bytes

## 摘要

DeepSeek-AI 发布 DeepSeek-V4.1-Flash，这是一款拥有 552B backbone parameters、支持最多 1M tokens 上下文的多模态 MoE 模型，每个 token 在预填充阶段激活 8B 参数、解码阶段激活 16B 参数。

## 推荐理由

报告集中展示了 KV Cache 压缩、长上下文和智能体基准结果，便于评估模型的推理成本与工程部署取舍。
