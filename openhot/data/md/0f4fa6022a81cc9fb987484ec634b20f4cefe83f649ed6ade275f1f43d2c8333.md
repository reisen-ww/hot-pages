## 摘要

开发者利用 Claude Code 构建了 Beep Locator，一个用于定位神秘蜂鸣声的软件系统。通过在房间内放置多台设备并使用三角定位法，最终在一堆未开封的盒子中找到了一个需要更换电池的古老一氧化碳探测器。系统通过 Python 服务器和 WebSocket 实现设备间的通信与协作，准确度可达约 40 厘米。
