## 摘要

Kornia 是 PyTorch 生态中首个提供可微几何变换、深度估计和鲁棒估计的参考实现，在 RTX 4090 上批量处理时，Gaussian blur 等操作比 OpenCV 快 70 倍，支持 CUDA 和 MPS 加速。安装需 pip install kornia，文档包含 1200+ operators 的性能对比。
