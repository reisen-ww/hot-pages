# 从 Redmi Note 7S 到无显示的 postmarketOS 服务器

> 原标题：My dead Redmi Note 7S to a headless postmarketOS server I SSH into from anywhere

## 摘要

作者将一台显示故障的 Redmi Note 7S 转变为 24/7 运行的无显示 postmarketOS 服务器，通过 USB 快速启动和 TWRP 系统恢复模式进行配置。该服务器使用 OpenSSH、NetworkManager 和 Tailscale，可从任何地方通过 SSH 连接。作者还解决了 MIUI 时代的 stock DTBO 分区问题，通过清零分区解决了启动失败的问题。
