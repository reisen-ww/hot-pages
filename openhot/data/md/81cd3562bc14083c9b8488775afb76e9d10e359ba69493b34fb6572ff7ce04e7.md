## 摘要

作者在 GitHub 开源自托管 AI 记忆系统 OpenYantra，支持通过 LibreOffice 打开存储的.ods 文件，并与 Obsidian 双向同步。系统采用 SQLite 和 Markdown 存储，集成 Claude Desktop 和 Cursor，并使用 SHA-256 审计日志确保数据可信
