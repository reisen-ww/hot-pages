## 摘要

社区团队在 GitHub 开源 PocketBase CE v0.0.1，通过核心扩展集成 multipage apps、PITR（Litestream）、MCP、Auto TLS 等功能，同时提供可选扩展支持容器化集群（hundreds of instances）和多租户管理。贡献者可通过讨论区 PR 提交修改建议。
