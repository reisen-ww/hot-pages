# uBlock Origin 过滤规则阻止 TechCrunch 自动播放视频

> 原标题：uBlock Origin filter to block autoplay videos in TechCrunch

## 摘要

uBlock Origin 过滤规则可阻止 TechCrunch 文章中的自动播放视频，通过在 Dashboard 中添加自定义规则并应用更改，可以隐藏视频播放器及其留下的空框。这些规则适用于 Firefox 的完整 MV2 版本。
