# GNU Emacs维护者回应LLM伦理争议：代码质量优先还是社会责任优先

## 摘要

GNU Emacs维护者因是否接受LLM生成贡献引发社区争议，核心分歧在于是否将伦理审查扩展至代码生产过程。作者指出自由软件运动需重新审视其伦理边界，建议项目公开制定贡献政策，避免因拒绝LLM贡献而默认支持现有权力结构。争议焦点涉及代码生产条件（如是否使用强迫劳动）、软件影响范围（如是否影响无计算机用户）及维护者决策标准（如是否仅关注代码质量）。
