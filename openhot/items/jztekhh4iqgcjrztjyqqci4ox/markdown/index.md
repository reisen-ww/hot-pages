## 摘要

闲鱼智能监控系统提供基于 Playwright 和 AI 的多任务实时监控，支持 Web 可视化管理、多账号并发、即时通知和定时调度等功能。系统通过 Docker 一键部署，并内置 Chromium，无需额外安装浏览器。
