# 美国30-33岁人群净资产中位数从2022年到2025年下降23%

## 摘要

美国30-33岁人群的净资产中位数从2022年到2025年下降了23%。中位净资产为6.8万美元，进入上四分位需23.5万美元，进入顶层10%则需44万美元，约为中位数的6.5倍。最低四分位的净资产仅为7100美元，最低10%的人群负债超过资产。
