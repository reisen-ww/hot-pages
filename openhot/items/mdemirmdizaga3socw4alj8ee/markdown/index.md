## 摘要

Google 发布了一个包含多种技能的仓库，支持 Google Cloud 产品和技术，如 Google Cloud 基础架构、AI/ML 和数据库管理。用户可以通过 `npx skills add google/skills` 安装特定技能，或使用 `npx skills update` 更新技能。仓库中提供了从认证到故障排除的全面解决方案。
