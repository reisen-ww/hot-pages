# Blaze 项目：Rust 项目的增量构建速度提升 92 倍

> 原标题：Incremental rust builds up to 92x faster than cargo/rustc

- 来源：Hacker News 热榜
- 发布时间：2026-10-27T03:09:07.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/n39vl9iq14sqsh1mtz58buik0
- 原文：https://github.com/indexable-inc/blaze

## 摘要

Blaze 项目在 GitHub 上开源，提供比 Cargo 快 9.1 到 24 倍的 Rust 项目增量构建工具。基准测试显示 Blaze 在 macOS arm64 平台上比 Cargo 快 24 倍，Linux aarch64 平台上快 11 倍。项目支持 macOS 和 Linux，Windows 平台则使用 Cargo。

## 推荐理由

项目提供了基准测试数据，显示 Blaze 在不同平台上的构建速度比 Cargo 快 9.1 到 24 倍，读者可以据此评估是否采用该工具。
