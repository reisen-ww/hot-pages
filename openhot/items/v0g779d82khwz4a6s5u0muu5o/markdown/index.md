## 摘要

阿里巴巴在GitHub开源AI代码审查工具Open Code Review，支持Git diff分析、LLM调用及全文件扫描，提供详细安装指南和基准测试数据。对比Claude Code，该工具在Precision和F1指标上表现更优，但Recall略低。文档包含快速上手、配置、集成指南及基准测试结果，基准基于50个开源仓库的200个PR和10种编程语言构建，经80+工程师验证。
