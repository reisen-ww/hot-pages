## 摘要

uv 工具链发布 0.13.7 版本，包含修复 Windows 系统句柄继承问题（#22977）、支持含本地标识的 CPython 构建运行（#23013）、修正数字开头的项目包命名冲突（#23022）等 12 项更新，提供 ARM64/PPC64LE/RISCV 等架构的预编译二进制文件。
