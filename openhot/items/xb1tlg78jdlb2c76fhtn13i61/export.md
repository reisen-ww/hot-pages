## 摘要

Deno 发布 v2.9.0，新增 `deno desktop`、`deno watch`、`deno list` 等子命令，并支持桌面应用输出 Linux `.deb`、`.rpm` 与 Windows `.msi` 安装包。该版本还扩展 Node.js 兼容能力、测试功能和依赖锁定文件迁移，改进 WebCrypto、Web Storage/KV、代码覆盖率与启动性能。

## 推荐理由

Deno 2.9.0同时扩展CLI、桌面应用、Node兼容与测试能力，适合从实际工作流变化中评估升级收益。
