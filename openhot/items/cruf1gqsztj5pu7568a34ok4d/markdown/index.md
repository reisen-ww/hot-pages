## 摘要

昨日，作者辞去了 Swift Android 工作组的职务，转而支持 Rust。尽管他高度评价 Swift 的性能和开发者友好性，但认为 Swift 在非 Apple 平台上将永远无法提供无缝体验。文章指出，随着软件开发转向由计算机自动生成代码，Rust 等“计算机语言”正逐渐成为主流，包括 PostgreSQL 和 TypeScript 在内的多个大型项目正从 Swift 转向 Rust。
