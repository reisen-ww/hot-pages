## 摘要

Dockmesh 是一个用于跨多主机管理 Docker Compose 堆栈的自托管 Web UI，支持 Git 部署、镜像更新、备份等功能，无需付费版本。最新版本为 0.5.1，可通过 `curl -fsSL | sudo bash` 安装。该项目已开源（AGPL-3.0），支持多语言界面。
