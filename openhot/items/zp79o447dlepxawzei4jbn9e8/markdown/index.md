## 摘要

开发者正在完善 mddog，这是一个终端工具，可让用户在终端中预览 Markdown 文件，效果如同在 GitHub 或 Obsidian 中查看。该工具利用 macOS 内置引擎将 Markdown 转换为实际格式，并以图像条的形式输出到终端。目前支持 headings 和图片渲染，用户反馈积极。
