## 摘要

NVIDIA 开源 Auto Ontology，提供企业级元数据层，支持自然语言转 SQL 查询及多数据库整合，部署支持 Kubernetes 和 Docker Compose。

## 推荐理由

该库通过整合企业多源数据，构建元数据层解决数据孤岛问题，支持自然语言转 SQL 查询及知识图谱构建，提升 AI 代理分析准确性
