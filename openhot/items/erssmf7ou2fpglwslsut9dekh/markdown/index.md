## 摘要

Mike Karliner 在 GitHub 开源 ThingStudio，支持 ESP32、RP2040 等微控制器，提供无需云服务的可视化编程环境。用户可通过安装编辑器、烧录 MicroPython 到硬件，快速实现 LED 点亮等基础功能。项目采用 Apache 2.0 许可证，目前处于 beta 测试阶段，招募硬件开发者参与优化。
