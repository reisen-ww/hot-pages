# Qwen 开源 Qwen3.8-2.4T-A95B 模型，支持 2.4T 总参数与 1,010,000 token 上下文

## 摘要

Qwen 在 Hugging Face 发布 Qwen3.8-2.4T-A95B，这是一个采用 Transformers 格式的文本模型，参数总量为 2.4T、激活参数为 95B，原生支持 262,144 tokens 并可扩展至 1,010,000 tokens。

## 推荐理由

仓库同时提供模型规模、上下文长度、推理框架兼容性和多项基准结果，便于评估其部署成本与长程 Agent 任务能力。
