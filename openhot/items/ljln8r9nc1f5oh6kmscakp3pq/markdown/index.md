## 摘要

某团队在 GitHub 上公开 agweb 项目，这是一个基于 WebKit 的 macOS 浏览器，专为编码代理设计。项目展示了 agweb 在资源占用和用户体验上的优势，包括无干扰、低内存占用和原生 macOS 事件支持。
