# AWS 发布 Lambda Web Functions，支持标准 HTTP 应用在多区域运行

- 发布时间：2026-10-13T10:07:03.000Z

## 摘要

AWS 发布 Lambda Web Functions，可直接运行 Express、Hono、Fastify、Next.js 等 Node.js 框架应用，无需改写为事件处理器或添加适配器。

## 推荐理由

AWS Lambda Web Functions 以标准 HTTP 服务器和单命令部署为入口，展示了多区域路由、流量分配与按 CPU 计费的完整使用路径。
