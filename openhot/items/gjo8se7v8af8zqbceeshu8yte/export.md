## 摘要

Onlook 开源设计师工具支持本地运行和多种导出格式（HTML/PNG/JPEG/PDF），与现有开发工具链兼容。项目基于 Electron 和 React 构建桌面端，允许通过 Claude Code 或 ChatGPT/Codex 集成自定义 AI 代理，导出内容包含 HTML/CSS、图像及 PDF 格式。
