## 摘要

作者于 2009 年创建 GitHub 账号，2023 年将 Inko 项目和个人项目迁回 GitHub，旨在增加项目可见度和贡献者数量。然而，由于 GitHub 上低质量的“贡献”增多，作者决定迁移至 Codeberg，因其对非自由软件的立场、反对 AI 和更符合自由软件精神的组织结构。迁移过程中，作者手动处理了 70 多个仓库，遇到 GitHub API 限流等问题，但最终顺利完成。
