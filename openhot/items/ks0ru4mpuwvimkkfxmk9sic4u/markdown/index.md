# 某DIY爱好者用WiFi通信解决高频启动等离子切割机与CNC控制器的连接问题

> 原标题：How to make a CNC plasma cutter with high-frequency start

## 摘要

某DIY爱好者通过WiFi通信和定制硬件（ESP32+74HCT245电平转换）解决了高频启动等离子切割机与CNC控制器的USB连接中断问题，并分享制作经验：使用12V Leadshine伺服电机替代官方推荐的18V版本，通过非接触式电磁屏蔽（铝箔包裹焊枪线）降低干扰，最终实现4mm钢板切割。材料包含电路设计、G代码发送器开发、机械结构搭建等关键步骤。
