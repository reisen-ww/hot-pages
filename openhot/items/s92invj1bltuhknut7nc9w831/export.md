## 摘要

开发者发布开源工具 viajante，无需账户或 API 密钥即可本地监控航班价格。通过 cron 或 systemd 定时任务运行，输出记录存储在 price-history.jsonl 文件中，支持 MIT 许可证和 GitHub 仓库。
