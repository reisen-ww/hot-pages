## 摘要

mr-andreas2 开源自托管图像存储方案 Replycant，支持 Git 多节点复制与端到端加密。项目包含 iOS 应用、Docker 服务器、Electron 桌面应用及 CLI 工具，性能测试在 Raspberry Pi 5 上表现优异，当前无 Android 版本但正在开发中，项目使用 AI 工具 cursor 实现但架构由作者设计，许可证为 GPL2。

## 推荐理由

对比 Immich 等现有方案，强调通过 Git + Git LFS 多节点复制和端到端加密实现数据持久性与隐私保护，并展示在 Raspberry Pi 5 上的性能表现。
