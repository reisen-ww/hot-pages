# 苹果 macOS 仍信任被 eMudhra 证书攻击的 git 工具

> 原标题：Apple's git still trusts the compromised eMudhra certificates

- 来源：Lobsters 热榜
- 发布时间：2026-10-28T11:03:56.591Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/vg4j326l1rd2ef4plflujxdnc
- 原文：https://emudhra.we-have-a-problem.com/apple.html

## 摘要

苹果 macOS 仍信任被 eMudhra 证书攻击的 git 工具，导致用户代码仓库可能被中间人篡改。开发者可通过手动移除证书根或运行检测命令避免风险。苹果已修复 Safari 等应用但未更新开发者工具，建议持续检查修复状态。

## 推荐理由

对比苹果与其他项目修复进度，揭示未修复漏洞导致用户代码仓库被中间人篡改的风险
