# LLVM LLDB项目首次支持Fortran调试

- 发布时间：2026-11-16T18:34:37.000Z

## 摘要

LLVM在LLDB中新增Fortran调试支持，通过RFC流程和合成子类实现动态数组解析，提供了完整的测试套件和运行时类型解析机制。

## 推荐理由

LLDB首次支持Fortran语言，通过RFC流程和合成子类实现动态数组调试，提供了完整的测试套件和运行时类型解析机制。
