# WD MyCloud支持即将取消

> 原标题：WD MyCloud support caught me off guard.

- 来源：Reddit r/selfhosted
- 发布时间：2026-11-06T21:07:07.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/bace5tve34sy6qkqptlcaqhxp
- 原文：https://www.reddit.com/r/selfhosted/comments/1xpo77q/wd_mycloud_support_caught_me_off_guard/

## 摘要

WD MyCloud PR2100将于今年12月停止远程访问支持，用户需选择升级Unraid系统、修复风扇或自建NAS以继续享受远程访问功能。
