## 摘要

Angular 是一个使用 TypeScript/JavaScript 构建移动和桌面 web 应用的平台，提供文档、快速入门、架构组件、表单 API 等功能。要开始贡献文档，可查看 angular.dev README。Angular 支持跨平台、速度快、可扩展，深受开发者喜爱。欲贡献代码或报告问题，请参阅贡献指南并选择帮助想要的问题。
