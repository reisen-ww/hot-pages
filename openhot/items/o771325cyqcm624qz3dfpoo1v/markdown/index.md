# 微软发布 .NET 11 运行时重大更新

> 原标题：What's new in the .NET 11 runtime

- 来源：Hacker News 热榜
- 发布时间：2026-11-10T12:20:07.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/o771325cyqcm624qz3dfpoo1v
- 原文：https://learn.microsoft.com/en-us/dotnet/core/whats-new/dotnet-11/runtime

## 摘要

微软发布 .NET 11 运行时，硬件要求从 x86-64-v1 升级至 x86-64-v3（新增 AVX、BMI 等指令集支持），并引入 Runtime Async V2（减少13帧到5帧的调试堆栈）。新增支持超过1024核处理器，优化了 WebAssembly 调试和 SIMD 控制能力。

## 推荐理由

硬件要求提升与运行时异步优化显著降低开发调试成本，同时支持超过1024核处理器，适用于高性能计算场景。
