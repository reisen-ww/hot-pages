## 摘要

作者正在重构家庭实验室并重新评估远程访问方式，考虑使用自托管的 Pangolin 或 Netbird。Pangolin 提供了集中的反向代理和对象基础权限，还新增了 VPN 功能；Netbird 则是 WireGuard 叠加网络，适合 P2P 连接，规则更简单。作者计划将 Authelia 用作身份验证服务，并希望简化母亲使用 Linux CLI 连接的体验。
