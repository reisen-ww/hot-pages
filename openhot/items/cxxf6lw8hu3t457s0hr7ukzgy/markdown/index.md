# 微软发布 .NET 11，包含C# 15、ASP.NET Core 3.2及AI工具集成

> 原标题：Announcing .NET 11

- 来源：Hacker News 热榜
- 发布时间：2026-11-10T16:01:27.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/cxxf6lw8hu3t457s0hr7ukzgy
- 原文：https://devblogs.microsoft.com/dotnet/announcing-dotnet-11/

## 摘要

微软在GitHub宣布.NET 11正式发布，包含C# 15的联合类型和封闭继承体系、ASP.NET Core 3.2的异步验证与OpenAPI 3.2支持、.NET MAUI默认使用CoreCLR运行时，以及集成MCP服务器模板和Microsoft Agent Framework的AI开发工具。

## 推荐理由

.NET 11引入C# 15的联合类型和封闭继承体系，优化了ASP.NET Core与Blazor的AI组件集成，同时提供更小的Linux/macOS安装包和实时热重载功能，开发者可对比现有版本进行性能测试
