# Kagi 推出无账户搜索功能，首 50 次免费且无需注册

> 原标题：Search for everyone

- 来源：Hacker News 热榜
- 发布时间：2026-11-05T20:03:34.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/kwv42whjm76sdngvpq8zkftgk
- 原文：https://kagi.com/changelog

## 摘要

Kagi 在 2026-11-05 发布无账户搜索功能，用户无需注册即可进行前 50 次搜索（注册后可获 100 次额外额度）。该功能通过社交媒体和社区运营维持，并同步开放了 Kagi 搜索 API 的预览接入。

## 推荐理由

无账户搜索功能允许用户直接访问 Kagi 搜索引擎，绕过注册流程，这对隐私保护和用户体验有直接影响。
