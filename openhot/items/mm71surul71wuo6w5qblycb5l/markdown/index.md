# GraphQL 基金会发布 HTTP 规范，解决互操作与可观测性难题

## 摘要

GraphQL 基金会发布 HTTP 规范，明确200 Not OK等状态码使用规则，新增GraphQL over HTTP媒体类型，解决代理缓存响应混淆问题。规范还规划了支持QUERY HTTP动词和持久化文档标准化，现有主流框架已适配新规。

## 推荐理由

规范明确了HTTP工具间的互操作标准，新增状态码和媒体类型提升可观测性，并规划了未来与QUERY HTTP动词的兼容支持
