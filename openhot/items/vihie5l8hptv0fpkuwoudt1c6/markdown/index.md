## 摘要

Qwen 在 Hugging Face 发布 Qwen3.8-27B-FP8，这是采用 block size 为 128 的 fine-grained FP8 量化模型，支持 Hugging Face Transformers、vLLM、SGLang 和 TokenSpeed。

## 推荐理由

仓库同时给出量化方式、推理框架、上下文长度和多项编码与视觉基准，便于评估 Qwen3.8-27B-FP8 的部署条件与适用场景。
