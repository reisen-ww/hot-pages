## 摘要

AWS Emulator 是一个本地运行的 AWS API 模拟器，无需 AWS 账户即可测试软件。它通过环境变量或嵌入模式与 AWS SDK 集成，支持 Linux、Windows 和 macOS。该项目无需额外服务费用，支持多核处理器，构建产物大小约为 100 GB。
