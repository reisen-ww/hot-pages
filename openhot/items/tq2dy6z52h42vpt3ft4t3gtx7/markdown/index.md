## 摘要

Hypha Technologies 在 GitHub 公开 Spindle 框架，支持 RFC 9112/9110/6455/7578/9651 等严格标准，内置 SQLite/PostgreSQL/WebSockets，类型安全贯穿 JSON 输入验证到前端界面。
