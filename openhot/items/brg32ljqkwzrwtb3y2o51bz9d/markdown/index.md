某团队在 crates.io 发布 Rust 实现的 Clojure 方言 alpha 版，支持编译与解释模式，适用于代理编程运行时。仓库提供在线测试（clj.rs/repl）与文档（docs.clj.rs），GitHub 仓库为 csm/clojurust
