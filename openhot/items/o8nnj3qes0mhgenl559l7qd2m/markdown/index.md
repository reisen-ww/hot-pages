## 摘要

mine 是一个跨平台的 Coalton 和 Common Lisp 集成开发环境，支持 Windows、macOS 和 Linux。它提供两种版本：mine-app 为全功能独立应用，mine-core 则需要自备终端。mine 集成了 REPL、调试器和类型提示等功能，支持结构化编辑，代码直接编译为原生代码以提高性能。
