## 摘要

disclaimrNG 是一个支持 Stalwart 的邮件签名服务器，通过 LDAP/Active Directory 获取用户数据并添加到每封邮件中。该项目已从 Python 2.7 和 Django 1.7 更新至 Python 3.12 和 Django 5，支持多租户和 Docker 部署。
