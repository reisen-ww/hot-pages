## 摘要

某团队在 GitHub 上公开 ADRs for AI 项目，提供模板、VS Code 扩展和 iOS 客户端，记录人类与 AI 合作过程。项目采用 Git 版本控制，详细记录每个问题及其决策过程，旨在使思考可追溯并复用。

## 推荐理由

项目提供了从零开始记录人类与 AI 合作过程的详细指南，读者可以借鉴其方法改进自己的项目管理。
