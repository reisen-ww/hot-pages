## 摘要

OpenAI 在 GitHub 发布 Codex-Security 工具包，支持通过 CLI 命令（需 Node.js 22.13.0+ 或 Python 3.10+）或 TypeScript SDK 自动化扫描代码库漏洞，可指定路径或提交差异范围扫描，生成 SARIF/JSON/CSV 报告。
