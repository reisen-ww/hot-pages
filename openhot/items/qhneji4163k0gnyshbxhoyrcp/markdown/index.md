## 摘要

biwak.info 是一个 Alpine 山屋和山峰地图，通过 slugify 方法将地名转换为 URL。为确保 URL 稳定，项目维护了一个 slug 注册表，记录每个 URL 对应的 OpenStreetMap ID 和名称，避免因数据更新导致链接失效。当前，42,866 个地点已分配了唯一 URL。
