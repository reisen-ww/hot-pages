## 摘要

Lexifina 在 GitHub 开源的 global-law 仓库中，使用 Lean 语言将美国税法逐条形式化验证，发现 138 处漏洞（含 67 处过时引用、24 处文本错误、13 处括号未闭合等），并测试发现 Tax-Calculator 等工具存在 14 处逻辑错误。
