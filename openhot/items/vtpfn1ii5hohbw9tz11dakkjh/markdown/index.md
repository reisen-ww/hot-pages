## 摘要

Jolt 是 Clojure 的自托管实现，支持原生 C 交互，编译为无需 JVM 的独立二进制文件。通过 Gambit 编译器将 Clojure 代码转换为 Scheme，可运行在 Chez 或 Gambit 编译的 JavaScript 后端，提供 persistent data structures、core.async 并发模型等完整 Clojure语义。
