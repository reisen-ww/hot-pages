# Immich默认每日全量文件校验引发资源消耗争议

> 原标题：PSA - Immich defaults to a full file checksum integrity check of all images every night

- 来源：Reddit r/selfhosted
- 发布时间：2026-11-07T18:37:37.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/pl269p8ghp89ts42dy1aso0wz

## 摘要

Reddit用户/u/james--arthur发现Immich默认每晚全量校验所有图片文件，导致不必要的处理器和IO资源消耗。该用户已通过GitHub讨论（https://github.com/immich-app/immich/discussions/29439）提出优化建议，并附上了v3版本相关说明。
