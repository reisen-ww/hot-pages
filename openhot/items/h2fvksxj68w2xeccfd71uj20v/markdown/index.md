# Blender 5.3正式发布：新增高斯溅射支持与性能优化

> 原标题：Blender 5.3 released with Gaussian Splat support

## 摘要

Blender 5.3发布，原生支持高斯溅射渲染技术，可导入PLY/SPZ/glTF文件并优化Geometry Nodes处理流程。新增DLSS 4.5降噪引擎，提升渲染效率；EEVEE支持全景相机渲染，Python API扩展开放。项目管理功能整合自定义变量、资产库共享及界面优化，提升协作效率。

## 推荐理由

新增原生支持高斯溅射（Gaussian Splat）渲染技术，优化EEVEE和Cycles渲染引擎性能，并引入项目管理功能及UI改进。
