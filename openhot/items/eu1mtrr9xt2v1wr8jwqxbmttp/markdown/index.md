## 摘要

Maak 项目团队在 GitHub 开源了一款支持 Lisp 语法定义命令和构建任务的命令运行器，正式发布 v1.0.0 版本。该工具提供详细的任务计划生成、依赖关系可视化解释和实时监控功能，支持包括 Rust、Python、Maven、Gradle 等在内的多种构建工具与容器系统。
