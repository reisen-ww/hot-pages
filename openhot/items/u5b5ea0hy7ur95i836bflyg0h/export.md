## 摘要

Uptime Kuma 是一个易用的自托管监控工具，最新版本支持多语言界面、20 秒间隔监控和 WebSocket 通知。它可以通过 Docker 或 Node.js 安装，支持 Debian、Ubuntu 等主流 Linux 发行版和 Windows 10。项目已获得 12.3k star，欢迎贡献与支持。
