# Mozilla Firefox 145版本发布：通过指纹识别研究显著提升用户隐私保护

> 原标题：Open research, stronger privacy: Making Firefox users harder to fingerprint

- 来源：Hacker News 热榜
- 发布时间：2026-11-11T12:44:06.000Z
- 开源热点：https://reisen-ww.github.io/hot-pages/openhot/items/valupcxo1s024tghy4cldjcst

## 摘要

Mozilla Firefox 145版本发布，通过指纹识别研究显著提升用户隐私保护。基于近2500万Firefox用户的数据分析，研究团队在CCS 2026国际安全会议发表论文，并开放测试网站和工具。

## 推荐理由

研究被顶级安全会议CCS 2026接受，并开放测试工具供公众验证指纹保护效果
