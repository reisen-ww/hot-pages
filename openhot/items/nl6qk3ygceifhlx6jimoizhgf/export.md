## 摘要

jQuery 4.1.0 和 3.8.0 已发布，后者包含过去几年累积的修复和改进。4.1.0 引入了新的 AJAX 运输完全回调 API，改进了选择器性能，并支持 XML 文档中的 CSS 方法。从 3.x 切换到 4.x 的用户可参考升级指南和 jQuery Migrate 插件。
