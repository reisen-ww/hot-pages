## 摘要

Airgorah 是一款用 Rust 编写的 WiFi 安全审计软件，支持捕获 WiFi 交通、发现连接客户端、执行去认证攻击等。该项目使用 MIT 许可证发布，支持 Linux 平台。用户可以通过 GitHub 获取安装和使用文档。
