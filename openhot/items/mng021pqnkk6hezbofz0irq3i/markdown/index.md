## 摘要

Devvm.dev 是一个开源项目，提供一个独立的虚拟机供每个项目使用，内置项目工具链并支持编码代理。该工具简化了开发环境的配置，确保代码和代理在隔离环境中运行，有效防止安全威胁。项目支持 macOS 和 Linux 平台，无需额外安装依赖即可快速启动。
