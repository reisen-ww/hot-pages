腾讯 Youtu Lab 发布 5B 多模态解析模型 Youtu-Parsing-Omni

tencent/Youtu-Parsing-Omni

AI 导读

腾讯 Youtu Lab 发布 Youtu-Parsing-Omni，这是一个 5B 多模态解析模型，可处理文档页、自然图像、图表、流程图、几何图、音频和视频，并以统一 JSON Schema 输出布局、文本、表格、公式、OCR、ASR、时间片段与描述等结果。

推荐理由

项目将图像、音频和视频解析统一到 5B 模型与单一 JSON Schema 中，并提供 vLLM 插件和评测结果，便于比较多模态解析方案的部署成本与覆盖范围。
