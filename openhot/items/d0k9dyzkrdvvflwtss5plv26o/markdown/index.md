## 摘要

Baochip-1x 是黄暴春（bunnie）的最新开源硬件项目，是一款基于 RISC-V 架构的 SoC，支持虚拟内存管理、TRNG、AES 加密等安全特性，并可通过红外摄像头进行结构验证。该项目使用 Rust 编写，旨在简化工具链，减少对脆弱 C 工具链的依赖。
