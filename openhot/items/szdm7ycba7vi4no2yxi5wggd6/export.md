## 摘要

Google Research 开源 PaperOrchestra 多智能体框架，实现从原始材料到 LaTeX 提交稿的自动化论文生成，支持文献整合、图表生成与自定义模板。项目依赖 Python 3.11 和 Conda 环境配置，需提供 API 关键字以调用模型服务。
