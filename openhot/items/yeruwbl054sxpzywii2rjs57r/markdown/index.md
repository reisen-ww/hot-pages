# 每个参赛作品必须开源且由参赛者投票决定获胜者

> 原标题：Running a hackathon where every entry has to be open source and the builders vote on winners. Looking for feedback before it starts.

## 摘要

一位组织者正在筹备一个为期一周的免费黑客马拉松，要求所有参赛作品必须是开源的，且基于付费产品的免费版本。参赛者提交后可投票选出获胜者，投票结果公开。奖金池由非营利组织管理，组织者本人不参与。该活动计划在100名参赛者加入后启动，目前正寻求开源项目贡献者的反馈。
