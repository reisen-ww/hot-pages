## 摘要

Disc Image Studio 是一款全能的光盘盘面可见图像生成与刻录工具，支持 Windows、Linux 和 macOS。用户可以导入图片并设计盘面，生成符合 CD、DVD 和单层 BD-R 光盘物理层约束的数据，刻录后光盘表面可见图案。该项目支持多语言界面，提供 GUI 和实验性 CLI 版本，适用于设计和刻录 CD、DVD 和蓝光光盘。
