## 摘要

Codemap 是一个 HTML 页面，可以映射 Go 模块中的每个包及其依赖关系，并支持在线查看和跳转。使用方法为在模块文件夹中运行 `go run github.com/peterretief/codemap@latest -o code-map.html`，然后在浏览器中打开生成的 code-map.html 文件。该工具适用于任何 Go 仓库，无需额外服务即可部署到任何网站。
