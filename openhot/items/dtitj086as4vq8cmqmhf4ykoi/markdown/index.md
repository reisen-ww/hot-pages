## 摘要

PaperPilot 是一个用 Rust 编写的 PDF 工具，支持本地运行和浏览器中的零安装工具。项目提供了 CLI、MCP 服务器、REST API 和桌面应用，并支持合并、压缩、OCR 等功能。性能基准和使用方法详见文档。
