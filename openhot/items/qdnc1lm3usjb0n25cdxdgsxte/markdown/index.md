## 摘要

ZigZag 是一个用 Rust 编写的视觉刺绣编辑器，支持 MCP 协议以便 AI 代理可以与用户一起创建和编辑设计。用户可以将 SVG 艺术作品转换为针迹，使用编辑器精细调整，然后导出兼容多种刺绣机的文件，或直接通过蓝牙发送到 Brother Skitch。该应用支持多种刺绣类型和编辑功能。
