# Ruby 发布修复正则表达式与字符串转换漏洞的多个安全更新

> 原标题：Multiple vulnerabilities in Regexp and String case conversion

- 来源：Hacker News 热榜
- 发布时间：2026-11-18T23:52:50.000Z

## 摘要

Ruby 官方发布安全更新，修复了正则表达式和字符串转换中的七个漏洞，部分漏洞可导致远程代码执行。修复版本为 Ruby 4.0.10、3.4.13 和 3.3.14，旧版本已不再维护。

## 推荐理由

Ruby 修复正则表达式与字符串转换漏洞，部分可触发远程代码执行，建议尽快升级至 4.0.10/3.4.13/3.3.14
